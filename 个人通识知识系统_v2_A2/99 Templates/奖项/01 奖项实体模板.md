# 奖项实体模板

> 模板文件自身不是奖项实体，避免被 `02 奖项实体库.base` 误收录。创建奖项实体时，复制下面的 frontmatter 与正文骨架到 `60 奖项/10 奖项实体/<奖项名>.md`。

## Frontmatter

```yaml
id: WL-AWARD-<ID>
type: award
name: <标准中文名>
name_original: ""
aliases: []
award_object: 作品
award_scope: ""
related_topics: []
award_map_status: 未建立
notes: ""
```
