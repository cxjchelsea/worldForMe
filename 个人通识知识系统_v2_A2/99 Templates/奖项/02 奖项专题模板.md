# 奖项专题模板

为一个奖建立完整专题时，复制下面的目录结构：

```text
50 奖项/20 奖项专题/<奖项名>/
├─ 00 <奖项名>.md
├─ 01 <奖项名>.canvas
├─ 02 <奖项名>作品.base
└─ 10 结构/
   ├─ 01 边界与颁奖对象.md
   ├─ 02 历史与制度演进.md
   ├─ 03 选评口味与偏见.md
   ├─ 04 与其他奖 / 专题对照.md
   └─ 05 阅读路线.md
```

## 00 奖项主页建议结构

```markdown
# <奖项名>

## 为什么值得沿这个奖阅读
## 颁奖边界
## 作品入口
## 五个结构入口
## 当前阅读进度
## 与六轴 / 文学专题的连接
```

## 02 奖项作品.base 规则

Base 只读取 `30 作品/`：

```yaml
filters:
  and:
    - type == "work"
    - awards.contains("WL-AWARD-<ID>")
```

建议至少提供：全部作品、已读、未读三个视图。

## Canvas 原则

Canvas 用来展示“边界 → 历史 → 口味 → 阅读路线”，不要复制六轴总地图，也不要手抄获奖名单。
