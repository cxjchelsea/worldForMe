# R轴专题模板：地域 / 文学传统

> 核心问题：**这个地区如何形成自己的文学传统；内部差异与跨国传播又怎样改变“谁能代表这个地区”？**

## 第一主维度

R轴专题的 `11` 应优先承载**区域文学自身的历史 / 传统入口**，而不是机械“一国一格”。

可以按实际情况使用：
- 历史阶段；
- 语言 / 子传统；
- 文学中心；
- 殖民 / 后殖民区域；
- 跨国文化带。

成熟旧专题的 `11 细分/` 如果已经承担稳定区域史，不为字面整齐强制重命名。

## 推荐 `10 结构`

```text
10 结构/
├─ 01 地域、语言与边界.md
├─ 02 区域文学史 / 传统总览.md
├─ 03 区域谱系与核心问题.md
├─ 04 内部多样性、传播与跨专题桥接.md
└─ 05 阅读路线.md
```

## 可选第二维 `12`

当区域内部已经形成稳定、跨国家 / 跨阶段使用的问题系统时，可建立：

```text
12 区域机制/
```

适合承载：
- 跨国问题横轴；
- 翻译 / 传播 / 迁徙；
- 殖民与后殖民关系；
- 谁代表该地区的去中心化问题。

`12` 不是第二套国别目录。

## 每个 `11` 节点重点回答

- 这一传统如何形成？
- 使用哪些语言 / 媒介？
- 与邻近传统的关系是什么？
- 哪些历史事件改变了文学结构？
- 它如何进入更大的区域与世界文学网络？

## 已验证样板：R6 拉丁美洲文学

已验证结构：

```text
11 细分/       = 九阶段区域文学史
12 区域机制/   = 十五条拉美问题横轴 + Boom去中心化
```

关键校正：

> **地域专题不能被一个最国际化的流派、国家或作家代表。**

拉美文学不等于魔幻现实主义，也不等于 Boom。

## 不要做成

- “一个国家一个书单”的旅游式目录。
- 把地域等同于单一民族 / 单一语言。
- 用 R 专题替代正式 M / G 分类。
- 忽略翻译、迁徙、殖民与跨国传播。
