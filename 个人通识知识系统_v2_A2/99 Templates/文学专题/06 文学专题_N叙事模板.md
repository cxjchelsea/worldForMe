# N轴专题模板：叙事技法 / 形式

> 核心问题：**这个叙事机制如何工作，它怎样改变读者获得信息、判断事实和理解故事的方式？**

## 第一主维度

N轴专题通常直接以**机制 / 体验变体**作为 `11` 第一维：

```text
11 技法变体/
```

或保留成熟专题已有的 `11 细分/`。

N轴不需要为了形式对称强行制造历史轴。

每个机制节点重点回答：
- 信息如何被组织？
- 谁知道什么？读者何时知道？
- 该机制制造什么阅读效果？
- 与相邻叙事技法如何区分？
- 哪些作品最适合案例精读？

## 推荐 `10 结构`

通常 3–5 个高层页即可，例如：

```text
10 结构/
├─ 01 技法定义与边界.md
├─ 02 机制 / 体验总图.md
├─ 03 更高层模型或阅读效果.md
├─ 04 阅读方法与跨专题桥接.md
└─ 05 阅读训练路线.md   # 按需
```

不要为了母模板凑页数。

## `12` 通常不是必需项

如果 `11` 已经完整承担机制层，就**不要再创建第二套 `12 机制/`**。

只有当出现一个真正正交、跨多个 `11` 机制复用的第二分析维度，而且需要独立知识页时，才创建 `12`。

例如可以考虑：
- 媒介 / 文本层面的另一套结构；
- 跨体裁的稳定效果模型；
- 需要独立解释的复杂比较框架。

但优先保持单维、精确、可训练。

## 已验证样板：N2 不可靠叙述

```text
11 细分/ = 十一种不可靠机制
12       = 不创建
```

高层另用“五层失真”解释这些机制发生在信息、认知、价值、多主体、文本哪一层，但**不再建立新的作品枚举**。

这验证了：

> **高层解释模型不等于必须新增第二数据库维度。**

## N轴规模原则

N专题不追求大书单。通常少量高质量案例比大量松散标签更有价值。

优先：
- 机制解释；
- 段落 / 章节级案例；
- 阅读辨识；
- 跨类型比较；
- 读后校准。

## M / N 边界

- M 解释美学范式 / 运动为何出现；
- N 解释具体形式机制如何工作。

例如：现代主义属于 M，意识流属于 N。

## 不要做成

- 把 N 专题硬改成文学史。
- 为同一机制再造一套平行 `12`。
- 把“常见于某类型”误写成“属于某类型”。
- 为了数量追求批量作品标签而牺牲机制解释。
