# 比较型 / umbrella 专题补充模板

适用于 Q15 这类“一个主锚点下包含多个文明传统、角色系统、历史派生传统或兄弟谱系”的专题。

沿用：

```yaml
topic_role: "umbrella"
```

不要为比较型专题另造第七条世界文学轴。umbrella 仍然只有一个 `primary_anchor`；具体子专题和作品的其他六轴关系留在各自层级。

## 与通用角色合同的关系

umbrella 仍遵守：
- `10` = 高层解释与比较导航；
- `11` = 第一主维度；
- `12` = 第二个成熟比较维度。

但在比较型专题中，这两个维度通常非常明确：

```text
11 系统/         = 比较谁
12 比较维度/     = 比较什么
```

因此 Q15 是“职责合同”的强样板，而不是要求所有专题复制它的目录。

## 推荐 `10 结构`

```text
10 结构/
├─ 01 比较范围与边界.md
├─ 02 总谱系与系统分类.md
├─ 03 核心比较维度.md
├─ 04 文明 / 传统之间的异同.md
├─ 05 演化、解构与现代重写.md
└─ 06 跨文明对读路线.md
```

`10` 只保留 umbrella 的高层比较逻辑，不承担某个子传统的完整历史或作品书单。

## `11 系统/`：第一主维度

如果 umbrella 已经拥有稳定子专题，推荐使用轻量注册页，而不是复制子专题内容：

```yaml
type: literature_topic_section
topic_id: WL-TOPIC-XXX
parent: WL-TOPIC-XXX-SYSTEMS
dimension: system
sequence: 1
system_name: 某系统
system_class: 某类别
```

注册页只负责：
- 一句话说明该系统在总谱系中的位置；
- 记录 `system_class` 等 umbrella 专用分类；
- 链接到子专题首页与子专题作品 Base。

子专题本身继续使用 `type: literature_topic_map`、自己的稳定 ID 和内部结构。

## `12 比较维度/`：第二分析维度

把真正需要跨系统反复比较的问题放在这里，例如：
- 合法性；
- 国家距离与空间结构；
- 伦理与共同体；
- 法律身份与国家授权；
- 技艺、身体与暴力形式；
- 英雄退场、神话化与解构。

推荐元数据：

```yaml
type: literature_topic_section
topic_id: WL-TOPIC-XXX
parent: WL-TOPIC-XXX-COMPARE
dimension: comparative_axis
sequence: 1
compare_cluster: 某比较维度
```

这里允许继续使用 `literature_topic_section`，因为这些节点是 umbrella 的注册 / 比较节点，不要求机械改成 direct topic 常用的 `literature_topic_mechanism`。

## 结构 Base 最低视图

至少区分：
1. 核心结构；
2. 子专题 / 系统注册；
3. 按 `system_class` 分组的系统；
4. 比较维度。

## 比较型专题原则

1. 比较的是问题与结构，不是武器、服饰或表面元素。
2. 不强迫所有子专题处于同一个分类层级。
3. 子专题保留自己的内部历史、结构页与作品字段。
4. umbrella 不重复维护作品实体，也不复制各子专题长书单。
5. 作品完整六轴坐标仍然只在 `40 作品/`。
6. Canvas 展示总谱系、系统类别与比较维度，不展开全部作品。

## 已验证样板：Q15 武人、英雄与秩序

```text
10 = umbrella 高层比较逻辑
11 = 八个系统注册 + system_class
12 = 六个跨系统比较维度
```

这个样板证明：

> **umbrella 可以比较性质并不完全相同的传统，只要比较问题稳定、系统性质被明确标注。**
