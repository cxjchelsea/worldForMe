# 比较型 / umbrella 专题补充模板

适用于 Q15 这类“一个主锚点下包含多个文明传统、角色系统或兄弟谱系”的专题。

沿用现有字段：

```yaml
topic_role: "umbrella"
```

不要为比较型专题另造第七条世界文学轴。

## 推荐 `10 结构`

```text
10 结构/
├─ 01 比较范围与边界.md
├─ 02 历史谱系.md
├─ 03 核心比较维度.md
├─ 04 文明 / 传统之间的异同.md
├─ 05 演化、解构与现代重写.md
└─ 06 跨文明对读路线.md
```

## `11` 的使用

如果 umbrella 已经拥有稳定子专题，可直接让 `11` 由子专题入口承担，而不必重复复制作品。

例如 Q15：
- 武侠
- 欧洲骑士
- 日本武士 / 剑豪
- 欧洲剑客
- Western
- Gaucho
- 侠盗
- 海盗

## `12 深入专题`

更适合放真正的比较问题，例如：
- 私人暴力合法性
- 国家距离
- 武人伦理
- 空间结构
- 技能系统
- 英雄的消失与解构

## 比较型专题原则

1. 比较的是问题与结构，不是武器或表面元素。
2. 子专题保留自己的内部历史与作品字段。
3. umbrella 不重复维护一套作品实体。
4. 作品的完整多轴坐标仍然只在 `30 作品/`。
