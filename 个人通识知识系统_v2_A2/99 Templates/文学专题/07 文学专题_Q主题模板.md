# Q轴专题模板：主题 / 母题 / 文学问题

> 核心问题：**文学如何在不同时代、体裁和文明中反复回答同一个人类问题？**

## 推荐 `10 结构`

```text
10 结构/
├─ 01 主题定义与边界.md
├─ 02 历史中的问题变化.md
├─ 03 核心母题与思想问题.md
├─ 04 跨体裁与跨文明比较.md
└─ 05 阅读路线.md
```

这里的关键不是文件名必须逐字一致，而是五个职责必须能回答：

1. 这个主题到底讨论什么、不讨论什么？
2. 同一个问题在历史中怎样改变？
3. 可以沿哪些核心问题 / 母题横向比较？
4. 不同体裁、地区、文明或叙述位置有什么不同？
5. 如何先建立骨架，再进行问题式阅读？

## 推荐 `11` 与 `12`

新建专题默认优先：

```text
11 核心问题/
```

但成熟 Q 专题如果已经形成稳定而有意义的纵轴，可以保留原有 `11`，再用 `12` 承担问题深化。例如战争文学：

```text
11 细分/          # 已稳定承担七个历史阶段
12 核心问题/      # 六个跨时代战争问题群
```

因此模板追求的是**职责统一，不是路径字面统一**。

### 核心问题页重点回答

- 这个问题在什么时代发生变化？
- 不同体裁如何表达它？
- 不同地区 / 文明给出什么不同答案？
- 哪些主体或叙述位置通常被忽略？
- 哪些作品适合跨时代、跨体裁比较？
- 与其他 Q 节点、G 类型、M 思潮怎样交叉？

## Q轴优先描述

- 人类问题
- 母题
- 经验类型
- 伦理冲突
- 主体位置
- 记忆与责任
- 跨体裁比较
- 跨文明比较

## Property → Note 升格规则

Q专题通常会有大量轻量横轴，不应为每个标签立刻创建 Markdown。

推荐顺序：

```text
作品 Property / Base 标签
↓
形成稳定的比较问题
↓
需要独立解释、比较或阅读路线
↓
升格为 11 / 12 核心问题 Note
```

例如战争文学保留20条 `war_axes`，但只把它们归并成6个真正需要独立解释的问题群。

## 作品 Base 建议

除 `全部 / 核心骨架 / 骨架未读 / 系统扩展 / 已读` 外，Q专题尤其适合增加：

- 按历史阶段；
- 核心问题群视图；
- 已标注主题关系；
- 必要时的“跨体裁”或“需复核”视图。

核心问题视图应直接复用作品已有 Property，不另造平行作品数据库。

## Canvas 建议

Q专题推荐至少分为四块：

```text
Q轴核心结构
历史纵轴
主题横轴 / 核心问题
数据与阅读入口
```

Canvas 展示结构关系，不铺全部作品节点。

## 不要做成

- 把主题专题误做成“某一种小说”的书单。
- 强迫所有作品属于同一 G 类型。
- 把历史纵轴和主题横轴混成一套分类。
- 为每个轻量标签都创建一张很薄的 Note。
- 忽略同一主题在诗歌、戏剧、小说、纪实中的真实性契约差异。

## 典型适用

- 爱情文学
- 战争文学
- 历史、记忆与时间
