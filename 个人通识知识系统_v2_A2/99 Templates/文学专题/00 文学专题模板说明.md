# 文学专题模板说明

## 1. 设计原则

文学专题采用“统一文件骨架 + 六轴知识变体”。

统一的是：
- `00` 专题首页
- `01` Canvas
- `02` 结构 Base
- `03` 作品 Base
- `10` 结构知识页
- `11` 主拆分维度
- `12` 深入专题（按需创建）
- `_source` 原始资料归档

变化的是专题内部的认识论结构：
- T：阶段 / 转折
- R：地域 / 语言 / 传统 / 传播
- M：形成背景 / 美学原则 / 运动谱系
- G：类型演化 / 亚类型 / 类型机制
- N：叙事机制 / 技法变体 / 阅读效果
- Q：主题演化 / 人类问题 / 跨体裁比较

## 2. 与世界文学六轴的关系

专题层只设置一个 `primary_anchor`。具体作品的其他 T / R / M / G / N / Q 坐标继续保存在 `30 作品/` 的唯一作品实体中。

不要为了让一个专题“分类完美”而新增重复专题或重复作品实体。

## 3. 专题角色

沿用现有字段：

- `topic_role: "direct"`：直接锚定一个六轴节点的专题。
- `topic_role: "umbrella"`：用于 Q15 这类总谱系 / 比较型专题。

不新增与 `primary_anchor`、`topic_role` 重复的字段。

## 4. 标准目录

```text
XX 专题名称/
├─ 00 专题名称.md
├─ 01 专题名称.canvas
├─ 02 专题名称结构.base
├─ 03 专题名称作品.base
├─ 10 结构/
│  ├─ 01 ...
│  ├─ 02 ...
│  ├─ 03 ...
│  ├─ 04 ...
│  └─ 05 阅读路线.md
├─ 11 [主拆分维度]/
├─ 12 深入专题/        # 可选；知识足够厚时再创建
└─ _source/
```

## 5. 各轴的 `11` 文件夹建议

| 轴 | 推荐名称 | 核心拆法 |
|---|---|---|
| T | `11 历史阶段` | 阶段 / 转折 |
| R | `11 地域传统` | 国家 / 语言 / 子传统 |
| M | `11 流派与表现` | 分支 / 地区表现 / 运动内部差异 |
| G | `11 类型分支` | 亚类型 / 类型谱系 |
| N | `11 技法变体` | 机制 / 变体 |
| Q | `11 核心问题` | 母题 / 人类问题 / 经验类型 |

已有专题中的 `11 细分` 不要求一次性重命名；新专题优先采用语义化名称，旧专题在后续专题重构时再迁移，避免无意义路径变更。

## 6. Markdown 与 Base 职责

- Markdown：保存定义、历史逻辑、比较、机制、阅读方法。
- Base：动态显示作品或结构节点。
- `30 作品/`：唯一作品实体。
- `_source/`：保存原始书单、旧稿、资料快照。

专题首页不写当前作品总数；数量只由 Base 动态计算。

## 7. 作品字段原则

全局字段优先复用：
- `id`
- `type`
- `author`
- `read_status`
- `topics`
- `axis_t` / `axis_r` / `axis_m` / `axis_g` / `axis_n` / `axis_q`

专题私有字段只在真正需要时增加，例如：
- `myth_priority`
- `myth_tradition_cluster`
- `myth_motifs`

不要给全部作品预创建所有专题字段。

## 8. 深入专题升格规则

先用作品 Property / Base 承载轻量分类。只有当某个分支已经需要独立解释、比较、阅读路线时，才升格为 `12 深入专题/*.md`。

原则：

> 标签 / Property 先于 Note；知识足够厚以后再升格为 Note。

## 9. 推荐验证顺序

1. 用 G 轴专题测试类型模板（优先：推理文学）。
2. 用 Q 轴专题测试主题模板（优先：战争文学）。
3. 用 Q15 测试 umbrella / 比较型模板。
4. 模板稳定后再批量规范现有专题。
