# M轴专题模板：思潮 / 运动 / 美学范式

> 核心问题：**为什么作家开始不满意旧的文学方式，并发展出新的美学方案；不同地区为什么会长出不同版本？**

## 第一主维度

M轴专题的 `11` 可承担：
- 内部分支；
- 运动 / 传统入口；
- 不同地区表现；
- 第一代 / 第二代 / 后继变体。

这些只是专题内部导航，不替代正式 R 轴。

## 推荐 `10 结构`

```text
10 结构/
├─ 01 定义、边界与争议.md
├─ 02 形成背景与历史 / 全球传统总览.md
├─ 03 现代经验 / 美学原则与形式机制.md
├─ 04 全球化、前驱反动与跨专题桥接.md
└─ 05 阅读路线.md
```

## 可选第二维 `12`

当专题已经形成跨地区 / 跨传统复用的形式—经验系统时，可建立：

```text
12 思潮机制/
```

适合承载：
- 形式与经验横轴；
- 非同步现代性；
- 殖民 / 翻译 / 媒介机制；
- 跨体裁的美学实现。

## M / N 边界

必须区分：

> **M = 美学范式 / 运动 / 历史性方案**
>
> **N = 具体叙事机制 / 形式技术**

例如：
- 现代主义属于 M；
- 意识流属于 N。

M专题可以解释“为什么一种技法成为重要美学资源”，但不要把 N 技法直接吞成 M 子类。

## 已验证样板：M3 现代主义文学

```text
11 细分/             = 十一个传统入口
12 现代主义机制/     = 形式与经验横轴 + Global Modernism / 殖民现代性
```

这验证了：

> **思潮专题应把形式读成对历史经验的回应，而不是孤立技巧清单。**

## 不要做成

- 只背流派名称和代表作。
- 把不同地区简单当成欧美模式的“地方版本”。
- 把具体技法与美学范式混成同一级分类。
- 为了目录对称制造没有第二分析维度的 `12`。
