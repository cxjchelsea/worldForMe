# 作者专题模板

为一个作者建立完整专题时，复制下面的目录结构：

```text
50 作者/20 作者专题/<作者名>/
├─ 00 <作者名>.md
├─ 01 <作者名>.canvas
├─ 02 <作者名>作品.base
└─ 10 结构/
   ├─ 01 创作阶段.md
   ├─ 02 作品谱系.md
   ├─ 03 核心主题与母题.md
   ├─ 04 风格与叙事机制.md
   └─ 05 阅读路线.md
```

## 00 作者主页 Frontmatter

```yaml
id: WL-AUTHOR-MAP-<ID>
type: author_map
author: <标准作者名>
author_id: WL-AUTHOR-<ID>
version: 1.0
status: draft
```

## 00 作者主页建议结构

```markdown
# <作者名>

## 为什么值得系统阅读
## 创作生涯总览
## 作品入口
## 五个结构入口
## 当前阅读进度
## 与五轴 / 文学专题的连接
```

## 10 结构页 Frontmatter

```yaml
type: author_map_structure
author: <标准作者名>
section: creative_stages
version: 1.0
```

`section` 取值：`creative_stages` / `work_lineage` / `themes` / `style_narrative` / `reading_route`。

## 02 作者作品.base 规则

Base 只读取 `40 作品/`：

```yaml
filters:
  and:
    - type == "work"
    - author == "<标准作者名>"
```

建议至少提供：全部作品、已读、未读、按出版年四个视图。

## Canvas 原则

Canvas 用来展示“创作阶段 → 作品谱系 → 主题 / 风格 → 阅读路线”，不要复制五轴总地图。
