# 作者模板说明

作者层有两种模板：

- [[01 作者实体模板]]：当你想持续追读某位作者时使用。
- [[02 作者专题模板]]：当你想系统研究 / 完整追读某位作者时使用。

原则：先有阅读兴趣，再建作者实体；先有系统阅读需求，再建作者专题。不要为作品库中的每个作者批量建页。

## 模板与实体的边界

`99 Templates/作者/` 下的三份模板文件自身只保留 `type` / `scope` / `version`，统一使用 `type: template_doc`，避免被作者实体 Base 当成真实作者。创建作者实体时，从 [[01 作者实体模板]] 复制其中的 `type: author` frontmatter 与正文骨架到 `50 作者/10 作者实体/`。
