## 当前定位

历史不再以“世界史 / 中国史 / 政治史 / 经济史”作为唯一学习树，而采用：

```text
兴趣提供入口
时间提供坐标
历史提供解释
```

### 1. 时间主轴

回答：**发生在什么时候？**

从史前与早期文明，到古代、 中古、近代早期、工业化、世界大战、冷战与全球化。

时间只负责定位，不要求按顺序读完。

### 2. 兴趣入口

回答：**我为什么会进入这段历史？**

两类入口：

```text
生活对象
├─ 饮食、饮品、服饰、审美
├─ 建筑与居住
├─ 名字、称谓、婚姻、节日、葬礼
├─ 语言、书籍、地图、颜色
├─ 桌游、体育、音乐、戏剧、小说、电影、电子游戏
└─ 货币、旅行

喜欢的作品
├─ 桌游
├─ 小说
├─ 电影
├─ 电子游戏
└─ 其他真正触发历史问题的作品
```

### 3. 历史解释层

回答：**为什么会变成这样？**

主要解释维度：

```text
政治与制度
经济与贸易
社会与阶层
宗教与思想
科学与技术
战争与国家竞争
环境与地理
人口与迁移
传播、媒介与消费
```

## 重点方法

历史路线优先采用：

```text
一个具体兴趣
→ 一个真实问题
→ 起源与时间线
→ 关键转折
→ 地区比较
→ 因果解释
→ 今天为什么是这样
→ 与其他入口连接
```

因此继续保留并重点使用：

- 社会史
- 微观史
- 日常生活史
- 城市史
- 思想文化史
- 全球史
- 物质文化史
- 消费史

政治史、战争史、经济史、科技史等不是被删除，而是从“主目录”转为解释历史现象时使用的重要视角。
