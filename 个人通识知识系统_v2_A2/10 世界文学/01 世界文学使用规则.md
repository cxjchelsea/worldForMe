# 世界文学使用规则

## 1. 六轴职责

### 四个主坐标
- T：时间 / 文学史阶段
- R：地区 / 文学传统
- M：思潮 / 运动 / 美学范式
- G：体裁 / 类型 / 叙事传统

### 两个辅助坐标
- N：叙事技法 / 形式
- Q：主题 / 母题 / 文学问题

六轴不是一棵总树，而是六套不同问题的坐标系统。一部作品可以同时拥有多个轴值，同一轴在允许多重归类时也可以是列表。

## 2. Taxonomy、Anchor 与 Topic Map 必须分离

固定区分：

```text
Taxonomy Node  = 六轴中的分类节点
Topic Anchor   = 某专题在六轴中的 canonical 挂载点
Topic Map      = 20 专题地图/ 下的知识地图
```

专题不要求统一出现在固定深度。判断标准不是“第几级”，而是：

> **专题必须挂到能够完整代表其范围的最具体 canonical node。**

专题 stable ID 与 taxonomy 地址解耦；专题迁移 anchor 时，不因此修改 `WL-TOPIC-*`。

## 3. G轴 v2：层级 + Facet

G1、G7 等上位文类采用普通 taxonomy group → leaf。

例如：

```text
G1 口述与民间文学
└─ G1.1 神话
   └─ 世界神话文学 Topic

G7 纪实文学
└─ G7.4 旅行文学 / Travel Writing
   └─ 旅行文学 Topic
```

G4 小说采用 **faceted taxonomy**：

```text
G4 小说
├─ G4.1 length_form
├─ G4.2 historical_form
├─ G4.3 social_character
├─ G4.4 historical_reality
├─ G4.5 genre_tradition
├─ G4.6 speculative_idea
└─ G4.7 audience_market
```

`G4.1–G4.7` 是 facet group，不是互斥的七类小说，也不是正式专题最终 anchor。

当前已实体化的专题 leaf 包括：

- G4.3.1 成长小说
- G4.3.4 家族小说
- G4.4.1 历史小说
- G4.5.1 推理 / 犯罪
- G4.5.2 科幻
- G4.5.3 奇幻
- G4.5.4 恐怖 / 怪奇
- G4.5.5 冒险
- G4.6.2 反乌托邦

完整 G v2 对照见 [[08 G轴Canonical Taxonomy]]。

## 4. 分级系统

### T / R / M / G：文学史重要度
- **S**：承重骨架
- **A**：重要支系
- **B**：扩展节点

### N / Q：阅读经验覆盖度
- **Core**：应有基础经验
- **Expand**：值得拓展
- **Interest**：兴趣扩展

分级只用于阅读导航，不是文学价值排名。

## 5. 作品如何进入系统

作品实体唯一位于 `30 作品/`。

已读或主动校准作品使用：

```text
axis_t
axis_r
axis_m
axis_g
axis_n
axis_q
axis_source: read_calibrated
```

### G轴新规则

`axis_g` 本来就是列表，因此 v2 不需要修改作品 schema。

- 新校准作品：优先写最具体 leaf。
- 一个作品可以跨多个 G facet，因此允许多个 G leaf。
- `G4.3 / G4.5 / G4.6` 等 facet group 不再作为新的最终校准值。
- 已有作品里的粗粒度 G4.x 值属于 **legacy facet values**，不批量重写；只在重读、主动校准或专题维护时渐进细化。

例如《1984》未来可以从：

```text
G4.5 现代类型文学
G4.6 思辨与思想类型
```

逐步细化为更具体的科幻／反乌托邦 leaf；不要求本轮批量迁移全部作品。

## 6. Topic 机器关系

`topics` 只保存稳定 Topic ID，例如：

```text
WL-TOPIC-G45-SF
WL-TOPIC-G46-DYSTOPIA
```

专题换 anchor 不修改这些 ID。专题 Base 继续使用 `topics.contains("...")` 精确匹配。

`primary_anchor` 表示 canonical taxonomy 挂载点；新增：

```yaml
anchor_mode: exact | leaf | umbrella
```

G 轴本轮重挂专题均使用 `anchor_mode: leaf`。

## 7. 阅读状态与数据职责

`read_status`：

```text
未读
在读
已读
重读
```

- Markdown：保存知识与规则。
- `.base`：动态展示作品和状态。
- `30 作品/`：唯一作品实体。
- `_source/`：原始资料与审计档案。
- 专题首页不维护动态作品数量。

## 8. Registry 过渡规则

六轴 taxonomy 正在按 [[07 六轴Taxonomy层级审计]] 分阶段修复。

在全部轴修复完成前：

- `id-registry-world-literature.json` = v2.3 基础 registry；
- `id-registry-world-literature-v2-g-overlay.json` = G 轴 v2 canonical overlay；
- 同 ID 以 overlay 为准，新 ID 由 overlay 扩展。

等 T/R/M/G/N/Q 全部迁移完成后，再 fold 为单一 v2 registry，删除 overlay。
