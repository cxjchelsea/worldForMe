# 世界文学使用规则

## 1. 六轴不是完全平级

### 四个主坐标
- T：时间 / 文学史阶段
- R：地区 / 文学传统
- M：思潮 / 运动 / 美学范式
- G：体裁 / 类型 / 叙事传统

### 两个辅助坐标
- N：叙事技法 / 形式
- Q：主题 / 母题 / 文学问题

## 2. 分级系统

### T / R / M / G：文学史重要度

- **S — 承重骨架**：缺失会明显破坏对世界文学历史演进、主要传统、核心美学范式或主要文类形成的理解。
- **A — 重要支系**：对较全面的文学史知识很重要，可在 S 级骨架形成后展开。
- **B — 扩展节点**：具有清晰文学史价值，更适合第二轮深化、专题研究或兴趣扩展。

S/A/B 是阅读导航优先级，不是文学价值、艺术质量或文明高低排名。

### N / Q：阅读经验覆盖度

- **Core — 应有基础经验**：最好实际读过能充分体现该技法或主题的代表性作品。
- **Expand — 值得拓展**：明显扩大形式感受、主题经验或理解范围。
- **Interest — 兴趣扩展**：更专门、更媒介化或更依赖个人兴趣。

## 3. 使用顺序

1. T / R / M / G：先补 S，再补 A，最后按兴趣进入 B。
2. N / Q：优先保证 Core 有真实作品经验，再用 Expand 扩大跨度。
3. 总地图的等级只服务于“世界文学第一轮骨架”；进入具体专题后，专题内部应重新计算核心程度。
4. 不为塞进某一本书而修改六轴底层结构。

## 4. 六轴关系示例

- 现代主义属于 **M 轴**；意识流属于 **N 轴**。两者高度相关，但不是同一层级。
- 魔幻现实主义属于 **M 轴**；奇幻属于 **G 轴**。
- 女性主义文学属于 **M 轴**；女性处境属于 **Q 轴**。
- 拉美文学属于 **R 轴**；拉美 Boom 属于 **M 轴**。
- 家族小说属于 **G 轴**；历史、记忆与时间属于 **Q 轴**。
- 武侠、西部属于 **Q15** 的专题入口；它们仍可在 **G4.5** 作为类型名出现，但不再于 G 轴另建专题。

## 5. 作品如何进入系统

一部作品可以同时映射到：

```text
T  时间
R  地域
M  思潮
G  类型
N  叙事
Q  主题
```

作品实体在 `30 作品/`。阅读状态写在各作品的 `read_status`，数量由作品库 Base 查看。

已读映射按实际阅读发生，不按专题完成度一次性铺开。六轴字段只在真正读过、或主动校准某本书时才填写。

已读作品用这组字段记录坐标。日常写成 **编号 + 中文**，与 `10 世界文学/03 节点/` 一致：

```text
axis_t   时间，如 T5 二战后多极文学
axis_r   地域，如 R2 东亚文学
axis_m   思潮，如 M5.4 魔幻现实主义；对不上思潮就留空
axis_g   类型，优先写到 G4.3 / G4.5 这一级
axis_n   叙事；只有讲法特别值得标时才写
axis_q   主题，通常 1—3 个
axis_source: read_calibrated
```

完整对照见 [[06 六轴代码对照]]。六轴显示用编号 + 中文；以后校验时核对前缀是否对得上中文名。G4.1–G4.7 属于 G4 小说，不是 G1 的下级。

`topics` 是专题书单的机器关系键，必须写纯稳定 ID，例如 `WL-TOPIC-G45-SF`。不要把中文名并进这个字段。专题 Base 用 `topics.contains("WL-TOPIC-G45-SF")` 做整项匹配，不是前缀匹配。中文展示看 `topic_links`、专题首页、专题 Base 和 [[06 六轴代码对照]]。未读书先不要批量填六轴。

专题作品库的「已读」视图会显示这六列。总作品库只留全部 / 未读 / 在读 / 已读 / 已读按时间 / 已读按地域 / 需复核；专题切片回各专题 `03 *作品.base`。

各专题作品库另有「骨架未读」：优先级 ★ 且未读。Q15 总库用总谱系核心且未读。下一步从这张表长出来，不另写静态本数。

六轴节点看 [[04 世界文学总地图]]；已建专题看 [[20 专题地图/02 专题入口]]。

专题首页不写当前作品数。Markdown 只保存知识；数量只由对应 `.base` 动态计算。

`read_status` 只回答「我读过没有」：

```text
未读
在读
已读
重读
```

书目能不能信，继续看 `verification_status` 等校验字段，不占用阅读状态。
