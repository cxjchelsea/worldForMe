# 世界文学使用规则

## 1. 五轴职责

### 四个主坐标
- T：时间 / 文学史阶段
- R：地区 / 文学传统
- M：思潮 / 运动 / 美学范式
- G：体裁 / 类型 / 叙事传统

### 一个辅助坐标
- Q：主题 / 母题 / 文学问题

N 轴（叙事技法 / 形式）已整轴撤销，不再作为坐标，也不再挂专题。作品上遗留的 `axis_n`、`WL-TOPIC-N2-UNRELIABLE` 视为 legacy，新校准不再写。

五轴不是一棵总树，而是五套回答不同问题的坐标系统。一部作品可以同时拥有多个轴值；同一轴在语义允许时也可以是列表。

## 2. Taxonomy、Anchor 与 Topic Map 必须分离

固定区分：

```text
Taxonomy Node  = 五轴中的分类节点
Topic Anchor   = 某专题在五轴中的 canonical 挂载点
Topic Map      = 20 专题地图/ 下的知识地图
```

专题不要求统一出现在固定深度。唯一标准是：

> **专题是无法再分的叶节点展开的知识地图。有正式子节点的父节点不挂专题。**

因此：

- T5 可以挂专题：T 轴只到一级，T5 本身就是叶节点。
- G4.5.2、M3.1 可以挂专题：它们已经是叶。
- M1、M2、M4、M5 可以挂整组专题：它们是叶。具体思潮（浪漫主义、魔幻现实主义等）在专题内部展开，不预建 `M1.1` / `M2.2`。
- M3 不挂专题：它拆成 M3.1 现代主义与 M3.2 先锋派两叶。
- R1–R9 可以挂专题：它们都是叶节点。国家／语言／内部传统只在专题里展开，不升格为全局 R 子坐标。
- R10 不挂整区专题：它下面只留 R10.2 非洲离散文学，避免与 R7 重复建坐标。
- Q1–Q15 都是问题群，本身不挂专题。专题从下一级叶子展开，例如 Q2.1 爱情、Q6.1 战争、Q15.1 武侠。

专题 stable ID 与 taxonomy 地址解耦。专题迁移 anchor 时，不修改 `WL-TOPIC-*`。

`primary_anchor` 表示 canonical taxonomy 挂载点，且必须是叶节点；`anchor_mode` 使用：

```yaml
anchor_mode: exact | leaf | group_index
```

- `exact`：专题范围基本等于该叶节点，例如 T5、R6。
- `leaf`：专题挂在父类下的具体叶节点，例如 G4.5.2 科幻、M3.1 现代主义、Q15.1 武侠。
- `group_index`：问题群上的比较入口，不是叶专题，例如 Q15 总览、Q10 现有通史。

## 3. T轴：只有真实时间范围才是时间坐标

当前全局 canonical 时间坐标为 T0–T6。

旧版 `T0.1 / T3.5 / T5.2 ...` 描述的是一个时期中的制度、文类、思潮或历史过程，不是更细时间区间，因此 v2 统一解释为 `historical_feature / stage_feature`，不再作为新的 `axis_t` 值。

真正需要细分时间时，必须显式定义时间范围。专题内部时间阶段不会自动升格为全局 T 节点。

## 4. R轴：区域树允许跨区域关系

R 轴全局坐标只到一级：R1–R10。国家、语言、内部区域和大多数离散类型在专题内部展开，不建成 `R4.2`、`R2.1` 这类全局子节点。

唯一例外：非洲离散文学的 canonical 坐标为 `R10.2`；R7 通过关系指向它，不再同时维护 `R7.7`。

若以后某个内部传统要独立成专题，再二选一：继续留在现有整区专题里，或新建叶节点并同步拆专题。不预建空的国家节点。

## 5. M / Q 的已修复坍缩节点

当前已冻结：

```text
M3 现代主义与先锋派
├─ M3.1 现代主义                 ← 现代主义文学
└─ M3.2 先锋派                   ← 专题待建

Q1–Q15 问题群
└─ Q*.* 叶节点                   ← 专题从叶子展开
   已有：Q2.1 爱情、Q6.1 战争、Q15.1–Q15.8
```

## 6. G轴 v2：层级 + Facet

G1、G7 等上位文类采用普通 taxonomy group → leaf：

```text
G1 口述与民间文学
└─ G1.1 神话                     ← 世界神话文学

G7 纪实文学
└─ G7.4 旅行文学 / Travel Writing ← 旅行文学
```

G4 小说采用 **faceted taxonomy**：

```text
G4 小说
├─ G4.1 length_form
├─ G4.2 historical_form
├─ G4.3 social_character
├─ G4.4 historical_reality
├─ G4.5 genre_tradition
├─ G4.6 speculative_idea
└─ G4.7 audience_market
```

`G4.1–G4.7` 是 facet group，不是互斥的七类小说，也不是正式专题最终 anchor。

当前已实体化的正式专题 leaf：

- G4.3.1 成长小说
- G4.3.4 家族小说
- G4.4.1 历史小说
- G4.5.1 推理 / 犯罪
- G4.5.2 科幻
- G4.5.3 奇幻
- G4.5.4 恐怖 / 怪奇
- G4.5.5 冒险
- G4.6.2 反乌托邦

## 7. 作品如何进入系统

作品实体唯一位于 `30 作品/`。

已读或主动校准作品使用：

```text
axis_t
axis_r
axis_m
axis_g
axis_q
axis_source: read_calibrated
```

### G轴规则

`axis_g` 是列表：

- 新校准作品优先写最具体 leaf。
- 一本作品可以跨多个 G facet，因此允许多个 G leaf。
- `G4.3 / G4.5 / G4.6` 等 facet group 不再作为新的最终校准值。
- 已有作品里的粗粒度 G4.x 值作为 legacy facet values 保留；只在重读、主动校准或专题维护时渐进细化。

### T / R / M legacy 规则

- 已有 `T*.x` 坐标不进行无差别批量改写，但新校准不再写这些 feature code。
- `R7.7` 视为 `R10.2` 的 deprecated duplicate alias；后续主动校准时迁移到 `R10.2`。
- 已有作品上的 `M2.1` / `M2.2` / `M5.4` 等细坐标保留为 legacy；新校准写 M1–M5，或在该思潮独立成专题后再写对应叶节点。M3.1 仍是现行坐标。
- `axis_n` 与 `WL-TOPIC-N2-UNRELIABLE` 随 N 轴撤销而停用，不批量改写旧页。

## 8. Topic 机器关系

`topics` 只保存稳定 Topic ID，例如：

```text
WL-TOPIC-G45-SF
WL-TOPIC-G46-DYSTOPIA
```

专题换 anchor 不修改这些 ID。专题 Base 继续使用 `topics.contains("...")` 精确匹配。

当前正式顶层 Topic 的 stable ID → canonical anchor 映射统一登记在 `id-registry-world-literature.json` 的 `topic_anchors` 中。`WL-TOPIC-N2-UNRELIABLE` 已随 N 轴撤销。

## 9. Registry：唯一机器真相

六轴修复已经完成首轮收束。从 v2.4 开始：

- `id-registry-world-literature.json` 是**唯一 canonical identity registry**；
- registry 只承担 stable ID、父子关系、节点语义、anchorability、Topic anchor 与 legacy alias；
- 阅读优先级、解释正文与导航链接以各 canonical node Markdown 为准，避免 registry 重复维护易过期展示信息；
- 原先 G / M-N-Q / T-R 三份 overlay 已完成 fold，不再参与运行时读取。

## 10. 分级系统

### T / R / M / G：文学史重要度
- **S**：承重骨架
- **A**：重要支系
- **B**：扩展节点

### Q：阅读经验覆盖度
- **Core**：应有基础经验
- **Expand**：值得拓展
- **Interest**：兴趣扩展

分级只用于阅读导航，不是文学价值排名。

## 11. 阅读状态与数据职责

`read_status`：未读 / 在读 / 已读 / 重读。

- Markdown：保存知识与规则。
- `.base`：动态展示作品和状态。
- `30 作品/`：唯一作品实体。
- `_source/`：原始资料与审计档案。
- 专题首页不维护动态作品数量。
- `40 作者/`、`50 奖项/`：实体访问层，不进入五轴，不占用 `WL-TOPIC-*`。
- `60 世界名著/`：正典地图，作品上用 `canon_level` 标注，实体仍在 `30 作品/`。
