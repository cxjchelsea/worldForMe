# R10 跨区域文学传统

> 路径：[[../../世界文学地图|世界文学]] → [[../../02 轴/R轴 世界文学传统|R轴]] → **R10 跨区域文学传统**

现代世界文学不能假设“一位作家 = 一个国家”。R10 用来承载跨国、离散、移民、流亡和跨语言网络。

```text
R10  [S]
├─ R10.1 犹太离散文学  [S]
├─ R10.2 非洲离散文学  [S]      ← canonical 已实体化
├─ R10.3 华裔 / 华人离散文学  [A]
├─ R10.4 南亚离散文学  [A]
├─ R10.5 阿拉伯离散文学  [A]
├─ R10.6 移民文学  [S]
├─ R10.7 难民 / 流亡文学  [A]
└─ R10.8 跨语言文学  [A]
```

非洲离散文学不再同时作为 `R7.7` 独立坐标；R7 通过关系链接到本节点。
