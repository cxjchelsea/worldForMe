# N2 聚焦与可靠性

> 路径：[[../../世界文学地图|世界文学]] → [[../../02 轴/N轴 叙事技法|N轴]] → **N2 聚焦与可靠性**

原 N2 把“谁能感知／知道什么”和“叙述是否可信”并排列成同一级条目，容易把两种不同问题混为一谈。v2 将它们拆成两个子系统：

```text
N2  [Core]
├─ N2.1 聚焦 / Focalization
│   ├─ 零聚焦
│   ├─ 内聚焦
│   ├─ 外聚焦
│   ├─ 固定聚焦
│   └─ 变换聚焦
│
└─ N2.2 叙述可靠性 / Narratorial Reliability
    ├─ N2.2.1 可靠叙述
    └─ N2.2.2 不可靠叙述  ← 已建专题
```

聚焦主要回答**信息通过谁的感知与认知受到限制**；可靠性主要回答**读者是否应当接受叙述者的报告、解释或价值判断**。二者可以组合，但不是同一维度。
