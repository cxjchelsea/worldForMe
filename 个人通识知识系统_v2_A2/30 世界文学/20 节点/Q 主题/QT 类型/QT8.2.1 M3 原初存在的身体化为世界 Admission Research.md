## 2. Proposed minimum definition

工作名：

```text
原初存在的身体化为世界
body-to-world / primordial-body cosmogony motif
```

正式候选 `required_invariants`：

```text
R1 primordial_embodied_source
存在一个在宇宙形成中具有构成性地位的具身原初存在。

R2 irreversible_bodily_transformation
该存在的身体发生死亡、被杀、牺牲、肢解或其他不可逆转化。

R3 anatomical_to_cosmic_mapping
身体整体或多个身体部位被转化／配置为天地、天体、地貌、水系、方向、自然材料或其他构成世界的结构。
```

最低准入：

```text
R1 + R2 + R3
```

R2 不要求某种固定机制；`death / killing / sacrifice / dismemberment / transformation` 都是实现方式。

R3 是最关键的边界条件：

> 不是“死后长出一朵花”就算，而是**身体材料直接参与构成世界／宇宙结构**。

# 4. Cross-tradition source pressure test

## 4.1 Tiamat / Enūma Eliš

**匹配：`FULL_MATCH / HIGH_CONFIDENCE`**

ORACC 对 Tiamat 的学术条目明确概述：Marduk 杀死 Tiamat 后将其劈成两半，以其身体制造 heaven and earth，并把眼睛、乳房等身体部位转化为底格里斯—幼发拉底河、山脉等地理结构。

结构：

```text
primordial embodied sea-deity
+
defeat / killing / splitting
+
body parts → heaven / earth / rivers / mountains
```

因此完整满足 R1–R3。

但该版本同时包含：

```text
cosmic combat
victory of new divine order
post-combat ordering
```

这些属于 Tiamat 变体的 optional slots，不应进入 M3 的最低定义。

来源证据：
- ORACC, Ancient Mesopotamian Gods and Goddesses, “Tiamat (goddess)”
- https://oracc.museum.upenn.edu/amgg/Listofdeities/Tiamat/index.html

source_status：`external_source_verified_text_only`

## 4.2 Ymir / Old Norse cosmogony

**匹配：`FULL_MATCH / HIGH_CONFIDENCE`**

《诗体埃达》Vafþrúðnismál 21 明确给出身体—宇宙映射：

```text
Ymir flesh → earth
bones → mountains
skull → sky
blood → sea / ocean
```

这是非常纯粹的 body-to-world 结构实例。

结构：

```text
primordial giant
+
killing / bodily disassembly
+
body parts → earth / mountains / sky / ocean
```

完整满足 R1–R3。

它证明 M3 不能被定义成：

```text
Tiamat-like dragon combat
```

因为即使存在杀戮，其角色关系、冲突逻辑和宇宙定序叙事与 Enūma Eliš 并不相同。

来源证据：
- Vafþrúðnismál 21, Poetic Edda
- https://www.sacred-texts.com/neu/poe/poe.pdf

source_status：`external_source_verified_text_only`

## 4.3 Puruṣa / Ṛgveda 10.90

**匹配：`FULL_MATCH / HIGH_CONFIDENCE`**

Ṛgveda 10.90 的 Puruṣa Sukta 以 sacrificial body 为宇宙与社会秩序来源。

关键映射包括：

```text
mind → moon
eye → sun
breath → wind
navel → firmament
head → heaven
feet → earth
ear → directions
```

此外，身体还被映射为社会阶序。

结构：

```text
cosmic embodied Puruṣa
+
sacrificial division / transformation
+
body parts → celestial / spatial / terrestrial order
```

完整满足 R1–R3。

Puruṣa 是本轮最重要的边界压力测试之一，因为它说明：

```text
body-to-world motif
≠ slain enemy motif
```

这里的核心机制是 sacrificial cosmology，而非击败敌对原初怪物。

来源证据：
- Ṛgveda 10.90 / Puruṣa Sukta
- Vedic Heritage Portal: https://vedicheritage.gov.in/hi/samhitas/rigveda/shakala-samhita/rigveda-shakala-samhita-mandal-10-sukta-090/
- Translation/exegesis: https://vedicheritage.gov.in/ebooks/Perception_of_the_Vedas.pdf

source_status：`external_source_verified_text_only`

## 4.4 Pangu / Chinese reception tradition

**匹配：`FULL_MATCH_AS_LATER_RECEPTION_WITNESS / SOURCE-LAYER_CAUTION`**

中国盘古材料必须拆分见证层。

### A. 《三五历纪》见证

《艺文类聚》所引徐整《三五历纪》保存的是：

```text
天地混沌如鸡子
→ 盘古生其中
→ 天地开辟
→ 阳清为天 / 阴浊为地
```

这一层非常适合 M2「天地分离」，但**本身不是完整的 body-to-world 证据**。

来源：
- https://ctext.org/text.pl?if=en&node=539866

### B. 后出／接受传统中的身体化生

后续汇编保存了明确的盘古身体—世界映射：

```text
breath → wind / clouds
voice → thunder
eyes → sun / moon
limbs → four extremes
blood / vessels → rivers
flesh → fields / soil
hair → stars / vegetation
bones / teeth → metal / stone
sweat → rain / dew
```

另有《述异记》传统保存头、腹、四肢成为五岳等映射。

这些材料满足 R1–R3，因此盘古可以作为 M3 的完整中国接受实例；但必须标注：

```text
Pangu sky-earth separation witness
≠ Pangu body-to-world witness
```

不能把后出的尸体化生细节反投射为《三五历纪》最早见证的原文内容。

来源证据：
- Chinese Text Project, Tianzhong Ji 卷十一所引相关材料：https://ctext.org/wiki.pl?chapter=750092&if=gb
- Chinese Text Project, Shuyi Ji 引文：https://ctext.org/wiki.pl?chapter=734248&if=en

# 6. Boundary review

## 6.1 M3 vs cosmic combat

```text
cosmic combat
≠ body-to-world motif
```

Tiamat 同时包含二者；Puruṣa 则证明没有敌对战斗也可完整满足 M3。

只有：

```text
combat
+
body becomes constitutive world structure
```

才可同时进入 M3。

---

## 6.2 M3 vs sacrifice

```text
sacrifice
≠ body-to-world motif
```

任何牺牲都不自动属于 M3。

Puruṣa 属于 M3 是因为牺牲之后存在明确的：

```text
body part → world / cosmos mapping
```

---

## 6.3 M3 vs M2 天地分离

M2 的最小逻辑是：

```text
primordial non-separation
→ separation
→ world-space result
```

M3 的最小逻辑是：

```text
primordial embodied source
→ irreversible bodily transformation
→ anatomical-to-cosmic mapping
```

二者可共现，但互不蕴含。

Tiamat 可同时形成天地并满足 M3；Puruṣa 的核心不是天地原先贴合后被分开；盘古的不同见证层甚至可分别支持 M2 与 M3。

因此：

```text
M2 ≠ M3
```

---

## 6.4 M3 vs P2 plot_pattern candidate

P2 候选：

```text
原初敌对体
→ 胜利者击败
→ 肢解／转化
→ 身体构成世界
→ 新秩序建立
```

P2 比 M3 更严格。

```text
P2 full match
→ likely carries M3

M3 instance
→ does not require P2
```

Puruṣa 是关键反例：完整 M3，但并不存在“原初敌对体→胜利者击败”的 sequence。

所以本轮不把 M3 扩张成 plot_pattern。

---

## 6.5 M3 vs archetype / symbol

“原初巨人”“被牺牲的宇宙人”若未来形成稳定文化角色功能，需独立 archetype admission。

“宇宙身体 / cosmic body”若脱离来源情节并形成跨文本时代媒介的稳定文化意义，也应独立 symbol admission。

本轮 M3 只回答：

> **世界由一个具身原初存在的身体材料构成这一基本叙事单元是否反复出现。**
