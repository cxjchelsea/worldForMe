# QT8 世界文化母题、原型与叙事传统

> 路径：Q轴 → QT 类型与叙事传统 → **QT8 世界文化母题、原型与叙事传统**

QT8 是文化叙事生成机制的 umbrella：从叙事来源、跨文明母题，到母题在具体历史社会中的文化化形态。

```text
QT8 世界文化母题、原型与叙事传统
├─ QT8.1 神话、传说与民间叙事
├─ QT8.2 世界文化母题与原型
└─ QT8.3 英雄、边疆与法外者文化传统
```

## 三层职责

- [[QT8.1 神话、传说与民间叙事]]：叙事资源层，回答“人类讲过哪些传统故事？”
- [[QT8.2 世界文化母题与原型]]：母题与谱系层，回答“这些故事反复出现什么结构，如何溯源、传播、定型与变形？”
- [[QT8.3 英雄、边疆与法外者文化传统]]：文化传统层，回答“某些母题如何进入具体社会并形成成熟文化传统？”

## 治理原则

1. QT8 上级节点负责导航，解释性叶节点负责专题研究。
2. QT8.1 纵向研究来源谱系；QT8.2 横向研究母题；二者在具体故事与文本处交叉。
3. QT8.2 使用多标签，不要求一个故事只归入一个母题。
4. 必须区分结构相似、历史传播、明确引用与直接改编。
5. QT8.3 不把文化传统简化为共同母题，而必须纳入社会制度、历史环境与伦理体系。
6. 本阶段只建立 taxonomy 骨架，不预建空专题地图包。
