# QT8 世界文化母题、原型与叙事传统

> 路径：Q轴 → QT 类型与叙事传统 → **QT8 世界文化母题、原型与叙事传统**

QT8 是文化叙事生成机制的 umbrella：从叙事来源，到跨文明反复出现的母题、文化原型、叙事结构与文化符号，再到这些叙事资源在具体历史社会中形成的成熟文化传统。

```text
QT8 世界文化母题、原型与叙事传统
├─ QT8.1 神话、传说与民间叙事
├─ QT8.2 世界文化母题、原型与叙事结构
└─ QT8.3 英雄、边疆与法外者文化传统
```

## 三层职责

- [[QT8.1 神话、传说与民间叙事]]：**来源谱系层**，回答“这个故事、人物、意象从哪套文化叙事传统中来？通过哪些文本和传播机制被保存、定型与重塑？”
- [[QT8.2 世界文化母题与原型|QT8.2 世界文化母题、原型与叙事结构]]：**横向抽象与文本谱系层**，回答“这些故事反复调用哪些母题、文化原型、叙事结构和文化符号？它们如何跨文本、跨文明传播、变形和被重新使用？”
- [[QT8.3 英雄、边疆与法外者文化传统]]：**历史化文化传统层**，回答“某些叙事原型与母题进入具体社会以后，如何在制度、历史环境和伦理体系中形成成熟文化传统与文学类型？”

## QT8.2 的四类核心对象

QT8.2 不把所有重复文化现象统称为“母题”，而正式区分：

1. **motif｜母题**：反复出现的基本叙事单元，例如兄弟相残、禁忌知识、王者归来。
2. **archetype｜文化原型**：可被反复调用的角色／人物模型，包括抽象角色原型与命名型文化原型。所罗门王、亚瑟王、梅林、孙悟空等可在满足“长期重写与高复用”条件时作为命名型文化原型研究。
3. **plot_pattern｜叙事结构**：故事反复采用的组织方式，例如离乡—试炼—归乡、预言—逃避—实现。
4. **symbol｜文化意象／符号**：形成稳定文化含义并被持续复用的物件或意象，例如圣杯、石中剑、禁果、金箍棒。

`theme`（主题）继续主要由 QH facet 承担，QT8.2 只建立关系，不重复建设主题 taxonomy。

## 跨层关系

QT8 的核心不是建立严格单继承树，而是让三个层次在具体对象处相互连接：

```text
QT8.1 来源传统
    ↓ 提供人物、故事、意象、文本
QT8.2 母题／原型／叙事结构／符号
    ↓ 在历史社会中被重组、制度化、文学化
QT8.3 成熟文化传统
```

例如：

```text
中国神话—传说—民间传统（QT8.1）
        ↓
孙悟空（命名型文化原型）
├─ 母题：反叛权威、封印与释放、修行与驯化
├─ 抽象原型：Trickster／反叛英雄／文化英雄
├─ 叙事结构：获得力量 → 反叛 → 镇压 → 释放 → 远行试炼
└─ 文化符号：金箍棒、金箍、五行山……
        ↓
后世小说、戏曲、影视、游戏中的持续重写
```

## 治理原则

1. QT8 上级节点负责导航；真正的重型专题研究下沉到解释性叶节点。
2. QT8.1 纵向研究来源谱系；QT8.2 横向研究叙事组件与文本谱系；二者在具体人物、故事、意象与文本处交叉。
3. QT8.2 使用多标签：一个故事、人物或作品可以同时承载多个母题、多个原型关系、多个叙事结构与文化符号。
4. 必须区分结构相似、历史传播、明确引用、人物／名称借用与直接改编；不得把相似自动解释为历史影响。
5. 命名型文化原型必须与其“来源人物／来源文本”区分。QT8.1 负责来源与传统内形成，QT8.2 负责原型化、跨文本比较和后世重写。
6. QT8.3 不把文化传统简化为共同母题，而必须纳入社会制度、历史环境、伦理体系、角色身份与文学史机制。
7. 当前阶段优先稳定 taxonomy 与对象模型，不为了完整而提前建立大量空专题包。
