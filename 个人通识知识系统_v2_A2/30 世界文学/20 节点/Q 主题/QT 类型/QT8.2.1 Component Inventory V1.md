## 1. 问题域边界

QT8.2.1 研究的是：

> **世界如何从“尚未成形／尚未分化”的状态进入具有天地、空间、秩序、方向和可居住结构的宇宙。**

重点不是所有“第一次发生的事情”，而是宇宙层级的：

```text
origin
→ differentiation
→ ordering
→ spatialization
→ habitable cosmos
```

因此需要主动分流：

```text
人类／生命被制造
→ 优先检查 QT8.2.4 造物、创造与失控

世界毁灭后重新开始
→ 优先检查 QT8.2.2 毁灭、灾变与世界重生

王权建立宇宙秩序
→ 可与 QT8.2.8 建 secondary cluster / relation

神战、屠龙、文明冲突本身
→ 优先检查 QT8.2.18；只有其直接承担宇宙生成时才保留在本域
```

## 2. 第一轮证据基础

比较神话研究常把 cosmogony 按若干反复出现的结构类型讨论，包括：

```text
creation from chaos / primordial undifferentiated state
cosmic egg
world parents
emergence
earth diver
creation by a creator / ordering act
```

同时，一个具体传统经常组合多个类型，而不是只属于其中一种。

本轮 inventory 还使用了以下跨传统压力点：

- 《Enuma Elish》：原初水体、神际冲突、Tiamat 身体构成天地、Marduk 定序宇宙；
- 《创世记》1：从未分化状态经分离、命名／言说与次序形成可居世界；
- 希腊 cosmogony：Chaos、Gaia / Uranus、代际分化与天地结构；
- 中国盘古传统：宇宙卵、阴阳／天地分离、身体化为世界；
- Mesoamerican / Maya 材料：世界中心、四方、世界树／axis mundi；
- North American earth-diver / emergence traditions：原初水域、取土、世界展开。

这些只是 inventory 级证据锚点；正式专题仍需逐条回指 QT8.1 或建立明确 `source_status`。

# 3. Motif candidates

## M1｜原初未分化 → 宇宙秩序形成

**建议状态：`PROMOTE_TO_TOPIC_BUILD_QUEUE / HIGH`**

工作名：

```text
从原初混沌／未分化状态到有序宇宙
```

最低候选 invariants：

```text
存在尚未稳定分化的原初状态
+
发生至少一次决定性的区分／定序行为
+
结果形成可辨识的宇宙结构
```

常见 optional slots：

```text
原初水域
黑暗
命名／言说
光暗分离
天地分离
方向与时间建立
神祇职能分配
```

边界：

```text
“混乱→秩序”作为抽象 theme
≠ motif

必须存在可叙述的宇宙生成／定序事件。
```

为什么优先：覆盖 Mesopotamian / Hebrew / Greek 等多个已可回指来源传统，且是本问题域最上位但仍可操作的叙事单元。

---

## M2｜天地分离

**建议状态：`PROMOTE_TO_TOPIC_BUILD_QUEUE / HIGH`**

工作名：

```text
天地由贴合／混合状态被分开
```

最低候选 invariants：

```text
天与地原本未分、贴合或处于共同体
+
某种行动／过程使二者分离
+
分离创造出生命／人类可存在的空间
```

可由：

- 神祇；
- 后代；
- 文化英雄；
- 自发宇宙过程；

完成。

该 motif 与“世界父母分离” plot pattern 有重叠，但不等同：motif 只要求天地分离这个基本叙事单元，不要求完整角色顺序。

---

## M3｜原初存在的身体化为世界

**建议状态：`PROMOTE_TO_TOPIC_BUILD_QUEUE / HIGH`**

工作名：

```text
宇宙由原初存在／巨人／怪物身体构成
```

最低候选 invariants：

```text
存在具有身体的原初存在
+
身体发生死亡／肢解／转化
+
身体部位转化为宇宙或自然结构
```

高价值来源候选：

```text
Tiamat
Pangu
Ymir（待 QT8.1.3 核证）
Purusha（待 QT8.1.6 核证）
Tlaltecuhtli 等（外部来源待 QT8.1 建档）
```

治理注意：

```text
body-to-world motif
≠ 必然存在 cosmic combat
```

战斗只是常见实现方式，不应写进 required invariant。

---

## M4｜言说／命名使世界获得秩序

**建议状态：`HOLD_FOR_CROSS_TRADITION_EVIDENCE / MEDIUM`**

候选最低结构：

```text
神圣／权威言语、命名或宣告
+
言语本身改变宇宙状态
+
产生存在、分类或秩序
```

当前《创世记》证据很强，但跨传统材料需要进一步收集后才能判断它是独立 motif，还是若干传统中的 creation mechanism。

不要因为“神说话了”就自动准入。

---

## M5｜从原初水域中取得土地／建立陆地（earth-diver）

**建议状态：`HOLD_FOR_SOURCE_BUILD / MEDIUM-HIGH`**

结构辨识度高：

```text
世界最初被水覆盖
→ 某存在潜入水中
→ 带回泥土／沙／实体物质
→ 陆地由此展开
```

这是比较神话中成熟的 cosmogonic motif 类型，但当前 worldForMe 的相关 QT8.1 美洲／北亚来源层尚不足，暂不直接开专题。

---

## M6｜从宇宙卵中创生

**建议状态：`DUAL_TYPE_CANDIDATE / HOLD`**

它既可以被描述成 motif：

```text
原初卵状容器
→ 孵化／破裂
→ 神祇／天地／宇宙生成
```

也可能更适合作为长期跨媒介的 `symbol: 宇宙卵`。

当前不同时建立 motif 与 symbol 两个重型专题。优先等待 symbol admission evidence，再决定：

```text
一个 symbol 专题
+ 其中记录“卵生宇宙” motif candidate
```

还是两个独立 component。

# 4. Archetype candidates

## A1｜宇宙定序者／造物者

**建议状态：`HOLD / NEEDS_FUNCTIONAL_BOUNDARY`**

候选 core functions：

```text
介入未定型宇宙
将混合状态区分为结构
建立空间／时间／自然职能秩序
使世界成为可居住环境
```

风险：过于宽泛，容易退化成“所有 creator gods”。

正式建立前必须证明：

```text
creator deity
≠ 任何参与创世的神
```

并至少跨两个来源实例核证稳定角色功能。

---

## A2｜天地分离者／开辟者

**建议状态：`HOLD / MEDIUM`**

可能形成 abstract archetype：

```text
处于被压缩／未分化宇宙中
→ 主动造成天地分离
→ 为后续生命／共同体创造空间
```

但当前它可能只是 M2「天地分离」中的 agent slot。必须证明“角色功能”本身跨故事稳定后才能升级为 archetype。

---

## A3｜盘古

**建议状态：`NAMED_ARCHETYPE_CANDIDATE / HOLD`**

盘古非常适合未来测试 named archetype，但不能仅因为“著名创世人物”就准入。

必须进一步验证：

```text
required_identity_anchors
+
stable role-function continuity
+
跨时代接受／重写
```

在 QT8.1.7 中国神话—传说—民间传统完成来源层建设前，不直接建立正式 named archetype。

---

# 5. Plot-pattern candidates

## P1｜世界父母结合 → 后代受限 → 父母分离 → 天地展开

**建议状态：`PROMOTE_TO_TOPIC_BUILD_QUEUE / HIGH`**

候选 core slots：

```text
S1 原初天地／世界父母处于紧密结合状态
→ S2 后代／生命被压迫或缺乏空间
→ S3 后代或分离者实施分开行动
→ S4 天地分离，世界空间展开
```

这是比 M2 更严格的结构对象：缺少“父母—后代—分离行动”的顺序时，仍可属于天地分离 motif，但不属于本 plot pattern。

跨传统候选包括 Greek world-parent pattern 与 Polynesian / Māori world-parent traditions；后者需未来建立可靠 QT8.1 source status。

---

## P2｜原初敌对体 → 胜利者肢解 → 身体造世界 → 定序

**建议状态：`HOLD / HIGH_POTENTIAL`**

候选 sequence：

```text
原初或早期宇宙存在发生冲突
→ 新秩序代表击败原初敌对体
→ 敌体被肢解／转化
→ 身体构成宇宙结构
→ 胜利者建立宇宙秩序
```

《Enuma Elish》高度匹配；部分其他传统只匹配 body-to-world 而不匹配战斗。

因此当前不能把 M3 自动升级成 P2。需要至少第二个高质量 full/strong variant 来源后再建。

---

## P3｜未分化 → 分离 → 分类／定序 → 可居世界

**建议状态：`HOLD / TOO_ABSTRACT_FOR_NOW`**

虽然大量创世故事似乎共享这个顺序，但目前它很容易变成“cosmogony 的一般定义”，而不是足够具体的 plot pattern。

除非能够明确：

```text
core slots
causal linkage
terminal condition
```

否则暂不建专题。

# 6. Symbol candidates

## S1｜宇宙卵

**建议状态：`PROMOTE_TO_SYMBOL_ADMISSION_RESEARCH / HIGH`**

潜在 stable meanings：

```text
未分化但充满生成潜能的整体
封闭宇宙的孕育状态
统一体分裂为多样世界
再生／诞生／完整性
```

来源分布候选包括印度、希腊／Orphic、中国盘古后世传统及其他地区。

但正式 symbol 准入仍需验证：

```text
source attestation
+
cross-text reuse
+
stable named / visual reference
+
后世跨媒介 continuity
```

所以它是“优先研究”，不是已正式 ACCEPTED symbol。

---

## S2｜原初海／原初水域

**建议状态：`HOLD / MEDIUM`**

它在多种 cosmogony 中反复出现，但需要区分：

```text
primordial water as setting / substance
≠ later cultural symbol
```

如果无法证明脱离创世情节后仍有稳定文化意义，则应只作为多个 motif 的 optional slot，而不是 symbol。

---

## S3｜世界树／宇宙树

**建议状态：`PROMOTE_TO_SYMBOL_ADMISSION_RESEARCH / HIGH`**

潜在意义族：

```text
axis mundi
天地／冥界垂直连接
宇宙中心
四方与中心的空间秩序
生命、生长与宇宙结构同构
```

世界树不是所有传统中的“创世对象”，但它非常适合本问题域，因为它经常把已经形成的宇宙**空间化与可视化**。

需要与：

```text
sacred tree
life tree
genealogical tree
```

严格区分。

---

## S4｜宇宙山／世界中心山

**建议状态：`HOLD_FOR_LATER / MEDIUM`**

可能承担：

```text
cosmic center
vertical connection
sacred geography
axis mundi
```

但它与 S3 的功能高度重叠，且大量材料更适合放入宗教空间／神圣中心问题域。暂不列为首批建设对象。

# 9. 建设顺序建议

不建议一次建立全部 Tier 1。

第一批应选择三个边界差异最大的对象：

```text
1. M2 天地分离
   → motif

2. P1 世界父母结合→后代受限→天地分离→空间展开
   → plot_pattern

3. S1 宇宙卵
   → symbol admission research
```

这一组可以直接验证冻结后的一个关键能力：

> **同一创世问题域中，相似材料如何被拆分为 motif / plot_pattern / symbol，而不发生类型坍缩。**

M1 与 M3 可作为第二批；S3 世界树需要更多跨传统 symbol reuse 证据后建立。
