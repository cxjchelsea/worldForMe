# QT 类型与叙事传统

> 路径：世界文学 → Q轴 → **QT 类型与叙事传统**

Q 的两个 facet 之一。类型与叙事传统与另一 facet 不是互斥分类树，一部作品可以同时有多个 QT 与多个 QH。

```text
QT  类型与叙事传统
├─ QT1 推理与犯罪叙事
├─ QT2 科幻
├─ QT3 奇幻
├─ QT4 恐怖与哥特
├─ QT5 冒险与探索叙事
├─ QT6 乌托邦、反乌托邦与社会想象
├─ QT7 历史叙事
├─ QT8 世界文化母题、原型与叙事传统
├─ QT10 惊悚与悬疑叙事
├─ QT11 爱情与浪漫叙事
├─ QT12 灾变、末世与后末日叙事
├─ QT13 讽刺叙事
└─ QT14 旅行与游记
```

原 QT8「英雄、边疆与法外者文化传统」下沉为 QT8.3；原 QT9「神话、传说与民间叙事」下沉为 QT8.1。QT9 不再作为一级 taxonomy 节点。
