# QC1.1 来源传统专题模板 V1

> 本模板由两个成熟样板共同验证：[[QC1.1.1 希伯来—圣经叙事传统]] 与 [[QC1.1.2 希腊—罗马神话传统]]。前者代表“经典—编纂—正典—文本传承型”来源传统，后者代表“神话—史诗—戏剧—文学重写型”来源传统。两者内部机制不同，但都能稳定落入同一产品骨架，因此本文件冻结 QC1.1 V1 的通用结构。

## 0. 模板原则

QC1.1 模板统一的是**认知接口与产品接口**，不是把不同文化传统压成同一种历史。

核心原则：

> **固定壳，固定四层，固定语义接口；二级内容、文本角色、特殊见证类型与作品池按传统本身变化。**

---

# 1. 固定产品壳

成熟 QC1.1 专题统一采用：

```text
QC1.1.x 某来源传统/
├─ 00 某来源传统.md
├─ 01 某来源传统.canvas
├─ 02 某来源传统结构.base
├─ 03 某来源传统作品.base
├─ 10 传统本体与形成结构/
├─ 11 文本见证与内部演变/
├─ 12 叙事组件与跨文化关系/
└─ 13 后世接受与阅读/
```

`00–03` 与 `10–13` 为 V1 稳定接口。后续专题不得为了形式整齐重新引入独立 `20 数据层`。

---

# 2. 固定四层认知链

## 10｜传统本体与形成结构

回答：**这个来源传统是什么，它在什么历史、社会、宗教、仪式、口传与书写环境中形成？**

应覆盖的解释问题包括：

- 定义、时间、地域、语言与边界；
- 历史文化环境；
- 世界观、宇宙秩序与角色系统；
- 核心叙事循环、人物群与故事群；
- 口传、仪式、表演、书写、编纂、经典化等形成机制；
- 传统层面的内部演变与关键转折。

`10/08` 一类“内部演变”讨论的是**传统整体的历史变化**，不与 11 的文本角色重组重复。

## 11｜文本见证与内部演变

回答：**我们通过哪些文本、版本、编纂、重写、抄本或译本看见这个传统？这些见证如何重组传统材料？**

允许包含：

- 文本谱系索引；
- 源文本与较早见证；
- 定型文本与核心经典；
- 谱系阅读入口；
- 抄本、译本、编纂本、版本群等该传统特有的文本史对象。

这里必须区分：

```text
传统 tradition
≠ 文本见证 witness
≠ 具体作品 work
```

并非所有 witness 都必须伪装成 `work`。例如抄本传统、古代译本或集合性见证可以留在解释层或数据实体层。

## 12｜叙事组件与跨文化关系

回答：**这套来源传统向 QC2 提供哪些可复用叙事组件，又与其他来源传统存在什么可证实关系？**

应覆盖：

- QC2 组件映射；
- motif / tale_type / character_type / named_archetype / plot_pattern / symbol；
- 传播、借用、翻译、接触、共同来源、独立平行与弱相似；
- 证据等级与不确定性。

禁止把结构相似自动写成历史传播。

## 13｜后世接受与阅读

回答：**这些叙事资源后来如何被文学与文化继续调用，我应该怎样进入这套传统？**

应覆盖：

- 后世文学与文化传播；
- 与 T / R / M / G / Q 及其他专题的桥接；
- 个人阅读路线；
- 支撑研究书目。

`11/谱系阅读入口` 与 `13/阅读路线` 必须区分：前者回答“哪些文本能看见传统谱系”，后者回答“我实际怎样读”。

---

# 3. 二级页面：允许变化

V1 **不规定每个专题必须拥有完全相同的二级文件名与数量**。

固定的是四个问题域，不固定的是具体拆分。例如：

- 希腊—罗马可以突出史诗、悲剧、神话汇编与罗马重写；
- 希伯来—圣经可以突出编纂、经典化、抄本见证与古代译本；
- 北欧传统未来可能突出诗体埃达、散文埃达、萨迦材料与基督教记录环境；
- 其他来源传统可按自身材料形态调整。

若某一维度没有可靠材料，可留空或暂不建页，不为了模板完整而制造内容。

---

# 4. Structure Base 固定接口

结构 Base 统一以语义字段组织，不依赖物理文件夹推断意义。

最低接口：

```text
structure_type_zh   所属模块
dimension           机器可读维度
dimension_zh        中文维度
sequence            顺序
history_position    节点作用
id                  编号
```

`structure_type_zh` 的稳定值为：

```text
传统本体与形成结构
文本见证与内部演变
叙事组件与跨文化关系
后世接受与阅读
```

物理目录负责存储；语义字段负责知识模型。移动文件不应改变节点的知识意义。

---

# 5. Works Base 固定接口

作品 Base 只投影中央 `40 作品` 中的作品实体，不在专题目录复制完整作品事实。

建议过滤：

```text
type == work
AND file.folder == 40 作品
AND topic_priority ∈ ★ / ◆ / △
```

每个 QC1.1 专题至少保留以下局部字段：

```text
qcxxx_priority
qcxxx_internal_tradition
qcxxx_tradition_stage
qcxxx_text_role
qcxxx_role
```

含义：

- `priority`：阅读与专题建设优先级；
- `internal_tradition`：该作品在本来源传统内部的位置；
- `tradition_stage`：传统历史生命中的阶段；
- `text_role`：作品在文本谱系中的主要功能；
- `role`：作品对该专题的认知作用。

同时保留通用跨轴接口：

```text
author
read_status
axis_t
axis_r
axis_m
axis_g
axis_q
id
verification_status
```

建议视图：全部、★、◆、△、未读、已读、按内部传统、按传统阶段、按文本谱系角色、按专题角色、按 T/R/M/G/Q、待传统归类、待校验。

---

# 6. `text_role` 规则

统一的是字段名和解释目的，**不是全 QC1.1 共用一套枚举**。

`text_role` 回答：

> **“这部作品／文本在本来源传统的文本谱系里主要起什么作用？”**

局部词表应在单个专题内部保持受控、可解释、尽量少而稳定。

已验证示例：

- QC1.1.1：核心叙事编纂、解释框架、循环叙事、王权叙事、历史神学重写、先知重写、智慧重写、礼仪记忆、启示重写、边界叙事；
- QC1.1.2：较早书面见证、整理文本、关键文学重写、神话汇编、罗马重写等。

不同传统不得为了“字段统一”硬套彼此的角色词。

---

# 7. 作品池规则

作品数量以**谱系覆盖与阅读用途**决定，不设硬性配额。

两个成熟样板目前均为 20 本：

```text
QC1.1.1 = 3 ★ + 12 ◆ + 5 △
QC1.1.2 = 5 ★ + 10 ◆ + 5 △
```

由此只能得到经验值：成熟来源传统专题常见约 **15–25 个作品锚点**，其中核心与重点应构成主体；不能推出“每个专题必须 20 本”。

选书优先判断：

1. 是否补足关键传统阶段；
2. 是否承担新的文本谱系功能；
3. 是否代表重要内部传统或故事群；
4. 是否帮助理解形成、转折、传播或接受；
5. 是否存在明显重复覆盖。

不按“每个文类几本”平均分配，也不为凑数增加弱相关作品。

---

# 8. Canvas 规则

Canvas 用来表达**认知路径**，不是无证据关系图。

推荐主链：

```text
主页
→ 专题定位
→ 传统本体／核心叙事群
→ 文本见证
→ QC2 与跨文化关系
→ 后世接受
→ 作品 Base
```

允许根据传统特点增加“抄本／译本”“编纂”“版本分支”等节点。

禁止：

- 因故事相似自动画传播边；
- 因时间先后自动画来源边；
- 为视觉完整制造不存在的因果链。

# 9. 固定项、可变项与禁止项

| 类型 | 内容 |
|---|---|
| 固定 | 00–03 产品壳、10–13 四层、Structure Base 语义接口、Works Base 五个专题字段、作品唯一事实源、证据纪律 |
| 可变 | 二级页面、内部传统、传统阶段词表、`text_role` 局部词表、特殊 witness 类型、作品数量与 ★/◆/△ 比例 |
| 禁止 | 独立 20 数据层、复制作品事实、强制 20 本、跨传统硬套同一 text_role、由相似性推断传播、为了模板完整填充无证据内容 |

---

# 10. V1 验收标准

一个 QC1.1 专题达到 V1 成熟状态，至少应满足：

- [ ] 来源传统边界清楚；
- [ ] 00 主页说明专题定位与四层路径；
- [ ] Canvas 可作为认知导航，且无推断边；
- [ ] 10–13 四层均已建立或明确标注合理空缺；
- [ ] Structure Base 使用统一语义接口；
- [ ] Works Base 只投影 `40 作品`；
- [ ] 核心作品具备 priority / internal_tradition / tradition_stage / text_role / role；
- [ ] 主要文本见证、关键转折与内部传统得到覆盖；
- [ ] QC1.2 与 QC2 的边界清楚；
- [ ] 传播关系遵守证据等级；
- [ ] 未知与争议被显式保留；
- [ ] 已足够服务个人阅读与跨轴检索。

达到以上状态即可 `stage_freeze`，不要求穷尽所有作品与研究。

# 11. 冻结样板

## QC1.1.1 希伯来—圣经叙事传统

状态：**QC1.1 V1 冻结参考样板**。

验证重点：经典编纂、正典化、抄本／译本见证、礼仪与解释传统可以被四层结构容纳，而无需把特殊文本史对象强制做成普通作品。

## QC1.1.2 希腊—罗马神话传统

状态：**QC1.1 V1 冻结参考样板**。

验证重点：口传、史诗、戏剧、神话汇编、希腊化与罗马重写可以被同一四层结构容纳，同时保持自身文本角色词表。

两者共同证明：

> **QC1.1 的通用性来自问题结构与接口，而不是来自材料内容同质化。**

---

# 12. 后续使用顺序

对 QC1.1.3–QC1.1.11：

```text
读取节点边界
→ 复制固定产品壳
→ 建立四层问题结构
→ 按本传统材料设计二级页面
→ 建立初始作品池
→ 标注五个 QC 专题字段
→ 补文本见证与 QC2 映射
→ coverage review
→ stage freeze
```

每完成 2–3 个结构差异较大的来源传统，可回看模板，但不得因局部特殊性频繁改动稳定四层。
