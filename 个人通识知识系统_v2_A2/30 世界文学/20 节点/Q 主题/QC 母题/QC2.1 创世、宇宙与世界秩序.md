只有出现明确新证据或真实学习缺口时，才重开 component expansion，例如：

- M4 获得至少两个独立传统的强完整来源；
- P2 获得第二个高质量 full-sequence witness；
- A1/A2 出现超出 creator / agent slot 的稳定跨故事 core functions；
- S2/S4 获得充分 symbol continuity 且证明有显著增量价值；
- 新研究推翻现有 required invariants / type boundaries；
- 实际使用中反复出现现有六个 component 无法解释的查询缺口。
