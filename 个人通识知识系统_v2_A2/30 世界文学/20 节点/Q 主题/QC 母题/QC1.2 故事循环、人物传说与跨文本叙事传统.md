# QC1.2 故事循环、人物传说与跨文本叙事传统

QC1.2 是 QC1 的**具体叙事传统层（cross-text narrative traditions）**。

它研究一个可识别的故事、人物或故事群如何穿过不同时代、语言、地域、作者、文类和媒介，形成具有自身历史生命的叙事传统。

它回答：

> **“这个故事／人物／故事循环是怎样形成、分叉、传播、被重新解释，并最终成为后世可以持续调用的叙事资源的？”**

QC1.2 的建立，是为了填补 [[QC1.1 神话、传说与民间叙事|QC1.1 来源传统]] 与 [[QC2 世界文化母题、原型与叙事结构|QC2 叙事组件]] 之间的尺度断层。

## 1. 典型对象

QC1.2 可以容纳四类主要对象：

| resource_type | 说明 | 例子仅作候选说明 |
|---|---|---|
| narrative_cycle | 围绕共同事件、人物群或世界形成的故事循环 | 特洛伊循环、底比斯循环 |
| figure_tradition | 围绕命名人物长期积累的叙事传统 | 亚瑟王、罗宾汉、亚历山大、浮士德、唐璜 |
| story_tradition | 一个具体故事在多个文本与文化中的历时生命 | 某一持续被改写的故事传统 |
| collection_tradition | 故事集、框架叙事或叙事集合的形成、编纂与传播传统 | 《一千零一夜》相关故事集合传统、《五卷书》传播传统 |

以上“例子”不等于已经准入正式 QC1.2 编号；正式专题必须经过准入判断。

## 2. QC1.2 与 QC1.1 的区别

### QC1.1 看来源环境

```text
希腊—罗马神话传统
凯尔特—不列颠传说传统
日耳曼—北欧神话传统
中国神话—传说—民间传统
……
```

问题是：**这个文化世界产生了什么叙事资源？**

### QC1.2 看一个资源自己的生命史

```text
早期材料
→ 最早文本见证
→ 关键定型
→ 分支与变体
→ 跨语言／地域传播
→ 重要重写
→ 现代再生产
```

问题是：**这个具体叙事传统怎样一路变化？**

一个 QC1.2 对象可以同时连接多个 QC1.1 来源传统；因此 QC1.2 不按文明硬分箱。

## 3. 与 QC2 的边界

QC1.2 仍然研究**有名称、有历史、有文本见证的具体叙事传统**。

QC2 研究从许多故事中抽象出的可复用组件。

例如：

```text
“亚瑟王传统” → QC1.2
“圣杯”作为长期文化符号 → QC2 symbol
“求索神圣目标” → QC2 motif / plot_pattern
“正统王权的证明与恢复” → QC2 相关组件
```

又如：

```text
“特洛伊故事循环” → QC1.2
“围城” → QC2
“复仇链” → QC2
“英雄荣誉冲突” → QC2
“归乡” → QC2
```

不得为了寻找共同母题而抹去具体文本谱系；也不得因为两个传统拥有相似组件，就推断二者存在历史传播。

## 4. QC1.2 专题最低解释结构

成熟专题建议使用以下结构。

### 10 定义与边界

- 传统名称及命名史
- 什么材料属于该传统
- 什么只是邻近材料
- 时间、语言与地域范围
- 研究中存在的边界争议

### 11 早期材料与最初见证

- 已知最早的口头背景（若可论证）
- 最早可核查文本或图像／记录见证
- “后世文本声称古老”与“可证实古老”的区别

### 12 核心叙事核

记录使该传统保持可识别性的核心人物、事件、关系和世界设定。

这里描述的是**该具体传统的叙事核**，而不是把它直接抽象成 QC2 motif。

### 13 文本谱系

```text
早期见证
→ 关键定型文本
→ 主要分支
→ 重要改写
→ 后世版本
```

对不能证明直接继承的文本，不强行画成单线谱系。

### 14 地域、语言与版本分支

- 地域版本
- 语言传统
- 宗教／政治环境中的再解释
- 角色和事件增删
- 相互竞争的版本

### 15 人物与叙事结构的历史变化

关注同一个人物／事件在不同时期如何被重新定义，例如：

- 身份变化
- 道德评价变化
- 关系结构变化
- 结局变化
- 新人物、新事件进入传统

### 16 文类与媒介迁移

追踪传统如何进入：

- 口头叙事
- 史诗／编年／宗教文本
- 骑士传奇／戏剧／诗歌
- 小说
- 儿童文学
- 戏剧、电影、漫画、游戏等现代媒介

只记录对传统形态有解释意义的媒介迁移，不做作品大全。

### 17 传播、借用与证据

对每一个“受到影响／传播至／来源于”的判断，记录：

- 关系类型
- 时间可行性
- 接触通道
- 文本或研究证据
- 证据等级
- 是否存在争议

结构相似本身不能证明传播。

### 18 QC2 组件地图

把该传统中稳定或重要的叙事组件映射至 QC2：

```text
motif
character_type
named_archetype
plot_pattern
symbol
tale_type（适用时）
```

该部分是索引与关系层，不复制 QC2 专题内容。

### 19 后世生命与现代再发明

研究：

- 经典化
- 民族化／宗教化／政治化
- 浪漫主义或现代主义重构
- 商业文化再生产
- 全球传播
- 当代反写、戏仿与颠覆

### 20 阅读路线与数据层

- 核心原始文本
- 可靠译本
- 关键研究著作
- chronology
- source references
- work references
- relation records

## 5. 正式专题准入门槛

一个对象升格为正式 QC1.2 专题，原则上至少满足以下条件中的四项：

1. **可识别性**：存在相对稳定的故事核、人物核或循环边界；
2. **历时性**：跨越多个时期，不能由单一作品完全解释；
3. **多文本性**：拥有多个重要文本见证、版本或重写；
4. **谱系价值**：其演变过程本身具有解释价值；
5. **跨语境生命**：发生重要的跨语言、地域、文类或媒介迁移；
6. **复用价值**：能显著帮助理解多部重要文学作品或多个 QC2 组件。

仅仅“故事很有名”不足以准入。

## 6. 不应升格为 QC1.2 的情况

- 只有单一作品承载、没有独立传统生命的故事；
- 单个 motif 或 symbol；
- 只有零散相似案例，没有可追踪谱系；
- 为了目录完整而人为制造的故事类别；
- 资料极少且无法建立基本时间线的对象。

这些对象可以继续存在于 QC1.1 数据层、QC2 component、40 作品或普通笔记中。

## 7. 首批候选池，而非预建目录

以下对象适合作为后续候选研究池，但**当前不自动创建正式节点**：

- 特洛伊故事循环
- 底比斯故事循环
- 亚瑟王传统
- 圣杯叙事传统
- 尼伯龙根／沃尔松叙事群
- 罗宾汉传统
- 亚历山大传奇传统
- 浮士德传统
- 唐璜传统
- 《一千零一夜》故事集合与传播传统
- 《五卷书》及其跨文化传播传统

建设时优先从真实阅读问题反向选择样板，而不是按此列表批量建包。

## 8. 建设状态原则

```text
candidate
→ source_ready
→ admitted
→ topic_build
→ coverage_review
→ stage_frozen
```

冻结后，只有出现新阅读需求、关键新材料、明显结构缺口或证据修正时才重开。
