> 本文件维护 QC1.2 的**规划长名单**，不是正式 taxonomy 编号表。

# 0. 使用规则

QC1.2 只收录具有自身历时文本生命的**具体故事、人物、故事群或集合传统**，不建设“世界故事大全”。

候选对象原则上至少应满足下列六项中的四项：

1. 有可识别的故事核、人物核或循环边界；
2. 跨越多个时期；
3. 有多个重要文本见证、版本或重写；
4. 有可研究的文本谱系、分叉或变体；
5. 有重要跨语言、地域、文类或媒介生命；
6. 对多部作品或多个 QC2 组件具有解释复用价值。

## 状态词

```text
FORMAL       已正式准入并获得 QC1.2.x 编号
NEXT         已决定作为下一正式专题建设
P1           高价值候选，原则上应进入长期 QC1.2
P2           中高价值候选，需结合阅读需求和 source readiness 决定
HOLD         有价值但粒度、边界或与上级专题重叠尚未解决
QC2_FIRST    更可能首先属于 QC2；只有形成可证文本谱系时才升格 QC1.2
WORK_FIRST   更适合先留在具体作品／作品接受层
```

## 资源类型

```text
narrative_cycle      围绕共同事件、人物群或世界形成的故事循环
story_tradition      某一具体故事跨文本、跨时期的历时生命
figure_tradition     围绕命名人物长期积累的叙事传统
collection_tradition 故事集合、框架叙事或编纂传统的形成与传播
```

> `provisional_resource_type` 是候选期工作标签，不代表最终冻结类型。

# 5. QC2_FIRST：不要因为“很有名”直接放入 QC1.2

以下对象首先更像**跨故事组件、角色类型、结构或 tale type**。只有能够证明存在一个可追踪的具体文本传统时，才应回升 QC1.2。

| 对象 | 优先去向 | 原因 |
|---|---|---|
| 世界洪水故事 | QC2 | 跨文化平行／传播问题复杂，不应预设一个统一文本谱系 |
| 创世故事 | QC2 / QC1.1 | 是大型 motif／cosmogony 类别，不是单一具体叙事传统 |
| 灰姑娘 | QC2 tale_type 优先 | 跨文化版本众多，若以后研究“欧洲文学灰姑娘谱系”再建 QC1.2 |

| 小红帽 | QC2 tale_type / WORK lineage | Perrault—Grimm 等可建小型谱系，但规模暂不足以优先升格 |
| 杰克与豆茎 | QC2 tale_type | 更像民间故事类型 |
| 变形人／狼人 | QC2 / QT | 属怪物、变形与类型文学资源，不是单一故事传统 |
| 吸血鬼 | QC2 / QT | 角色／类型传统过大，不能等同德古拉 |

# 6. WORK_FIRST：默认留在作品及接受史层

以下对象虽然拥有巨大影响，但当前首先由一部确定作品构成其身份。除非后续证明其已经形成具有独立谱系的传统，否则不急于建立 QC1.2。

- 《贝奥武甫》
- 《神曲》但丁地狱之旅
- 堂吉诃德
- 鲁滨孙／Robinson Crusoe（其后“鲁滨孙式小说”更可能进入 QT 类型史）
- 弗兰肯斯坦／怪物
- 德古拉（吸血鬼文学更偏 QT；“德古拉人物传统”可长期观察）
- 卡门
- 浮生式单一现代经典人物及其普通改编链

原则：**“改编很多”本身不足以升格；必须证明新文本之间形成了可解释、可复用的传统生命，而不只是某部作品的接受史。**

# 10. 维护原则

1. 候选池可以很大，正式 taxonomy 必须克制；
2. 不为了地域平均而制造专题；
3. 不把相似故事自动视为一个历史传统；
4. 不把单一作品的影响史自动升级为 QC1.2；
5. 父专题能够解释时，先不拆人物子专题；
6. 一个对象可以同时连接多个 QC1.1 来源传统；
7. 候选 ID 永久稳定，正式编号只在 admitted 后分配；
8. 新阅读反复遇到同一叙事资源时，提高其建设优先级；
9. 完成多个异质样板后再冻结 QC1.2 通用模板；
10. 本文件是规划层，不替代专题正文、证据笔记或中央作品事实。
