# QC3 文化模型专题模板 V1

> 本模板由两个差异明显的正式 Pilot 验证：欧洲骑士英雄模型、侠／江湖英雄模型。

## 1. QC3 正式模型定义

QC3 正式模型研究：

> **某个具体历史社会如何把角色、关系、伦理、秩序／空间、QC1 传统与 QC2 组件组织成稳定可复用的文化模型，并在后世持续被重写。**

不是人物百科、类型史、抽象主题或制度史。

## 2. 准入 Gate

每个候选至少检查：

```text
A1 可识别历史社会基底
A2 稳定角色／关系／伦理／空间结构
A3 跨时期叙事或媒介生命
A4 超出单一 QC2 component / 单一人物 / 单一 genre
A5 可连接 QC1 / QC2 / Work 中的多个证据入口
A6 能解释现实历史与文化神话之间的距离
```

建议：4/6 可研究，5/6 高优先级，6/6 强候选。

A5 不要求必须存在一个单一 QC1.2.x。第二 Pilot 已证明“多个来源环境 + 多个潜在具体传统 + 中央作品”也可以合法输入 QC3。

## 3. 标准专题结构


文件名可调整，但职责必须保留。

## 4. 人类可读主页必须回答

1. 一句话理解；
2. 为什么这是 QC3，而不是 QC1/QC2/QT/QH/历史；
3. 核心角色位置；
4. 核心关系结构；
5. 核心伦理排序；
6. 秩序与空间；
7. QC1 输入；
8. QC2 组件星座；
9. 必要历史条件；
10. 中央作品阅读锚点；
11. 后世重构；
12. 边界与证据纪律。

## 5. 输入关系不是强制线性

合法形式包括：

```text
QC1.1 → QC3
QC1.2 → QC3
QC1.1 + QC1.2 → QC3
QC2 → QC3
历史条件 → QC3
QT ↔ QC3（类型与文化模型双向接口）
Work → QC3
```

QC3 不要求所有输入都经过同一链条。

## 6. 作品层规则

中央 `40 作品` 始终是作品唯一事实源。

正式模型只给中央作品追加本模型字段并由 Works Base 投影，不在专题内复制完整作品实体。

作品数量不是模型完成度指标。只选能覆盖模型关键变化的锚点。

## 7. 历史边界

```text
制度怎样真实运行 → 历史领域
制度／社会条件怎样被文学转化为角色、关系与伦理期待 → QC3
```

文学中的宫廷、江湖、边疆、帮会、门派等不得直接等同于现实社会结构。

## 8. QC2 边界

```text
复仇、求索、法外正义、战士英雄等可复用组件 → QC2
这些组件在具体社会中如何组合成“骑士”“侠”等文化角色世界 → QC3
```

QC3 不复制 component 定义，只说明组合机制。

## 9. QT 边界

```text
骑士文学、武侠、Western 等类型形成与生产机制 → QT
骑士、侠、cowboy/outlaw 等文化角色—伦理—秩序模型 → QC3
```

类型与文化模型可以高重叠，但不是同一对象。

## 10. 两 Pilot 验证结论

### Pilot 1：欧洲骑士

强 QC1.2 上游；等级共同体、主君忠诚、宫廷与宗教伦理突出。

### Pilot 2：侠／江湖

无单一已冻结 QC1.2 上游；私人正义、义、师徒门派、江湖与国家法突出。

两者社会结构明显不同，但模板全部可用，因此：

```text
QC3_CULTURAL_MODEL_TEMPLATE = VALIDATED_V1
```

## 11. Reopen Gate

只有在新正式模型出现以下情况时重开模板：

- 无法用角色／关系／伦理／秩序结构表达；
- 无法处理 QC1/QC2/历史/QT 的输入边界；
- Works Base 机制无法承载作品映射；
- 新模型暴露稳定且高复用的新增必需维度。

否则后续只按模板填充，不继续反复改架构。
