# QC3 历史化文化叙事传统

QC3 研究叙事资源与叙事组件进入具体历史社会以后，如何与制度、阶层、伦理、政治合法性、空间经验和媒介传统结合，形成持续被调用、重写和再定义的文化角色、社会想象与叙事世界。

QC3 不等于“文化概论”，也不等于文学类型目录。它关注的是 **历史化组织机制**。

基本模型：

```text
QC1 来源叙事与历史材料
        +
QC2 motif / tale_type / character_type / named_archetype / plot_pattern / symbol
        +
制度 / 阶层 / 伦理 / 空间 / 政治 / 媒介
        ↓
历史化文化叙事传统
        ↓
QT 类型 / QH 主题 / R 区域文学 / T 时期 / 40 作品
```

准入原则：一个对象原则上需同时具备真实历史社会基底、稳定角色／伦理／空间结构、跨时期叙事生命，并且不能仅由单一母题或单一文学类型充分解释。

首个建议 Pilot 为“英雄、武人、边疆与法外者文化传统”，优先比较侠／江湖、欧洲骑士、日本武士／剑豪、美国西部／cowboy／outlaw；正式建节点前先按 [[QC 总体架构与建设规范 V2]] 完成范围与证据评估。
