# QC3 历史化文化叙事传统

> 路径：Q轴 → QC 母题与叙事组件 → **QC3 历史化文化叙事传统**

## 一句话理解

QC3 研究：**QC1 的叙事资源与 QC2 的可复用组件进入具体历史社会后，如何与制度、阶层、伦理、空间经验和媒介传统结合，形成稳定的文化角色世界、社会想象与后世可持续重写的文化模型。**

最简记忆：

```text
QC1 = 传统从哪里来
QC2 = 由哪些组件构成
QC3 = 这些组件在具体社会中被组织成什么文化模型
```

QC3 的核心不是“某国文化概论”，而是 **历史化组织机制**。

## QC3 不是什么

```text
QC3 ≠ 某国文化百科
QC3 ≠ 单一 motif
QC3 ≠ 单一人物传说
QC3 ≠ 文学类型目录
QC3 ≠ 真实制度史本身
QC3 ≠ 抽象主题讨论
```

真实制度本身进入历史领域；文学类型进入 QT；抽象主题进入 QH。QC3 只研究这些现实条件如何被叙事化、理想化、冲突化和持续重构。

## 当前试运行分析维度

一个成熟 QC3 文化模型至少从五个维度观察：

1. **角色模型**：一个文化期待某类人应当怎样行动；
2. **社会关系模型**：角色之间的义务、忠诚、冲突与依附如何被组织；
3. **价值／伦理模型**：什么被认为高贵、可耻、正当、值得牺牲；
4. **文化秩序模型**：这些角色与伦理依托什么制度、阶层、空间和共同体成立；
5. **后世续写与应用**：该模型如何被浪漫化、民族化、商业化、全球化或反转。

这五项当前作为**分析维度**，不急于分别建设成平行 taxonomy。

## QC3 准入 Gate

一个对象原则上至少满足以下 4/6：

1. 有可识别的真实历史、社会或制度基底；
2. 已形成相对稳定的角色、伦理、关系或空间结构；
3. 存在跨时期持续的叙事、文本或媒介生命；
4. 不能仅由单一 QC2 component、单一人物或单一 QT genre 充分解释；
5. 能连接多个 QC1 / QC2 / Work 对象并形成高复用解释价值；
6. 能讨论“历史现实”与“文化神话／后世重构”之间的距离。

建议：`PASS >= 4/6` 才进入正式 Topic Build。

## 标准解释链

```text
QC1.1 来源环境 / QC1.2 具体叙事传统
              +
QC2 motif / archetype / plot_pattern / symbol
              +
历史制度 / 阶层 / 伦理 / 空间 / 媒介
              ↓
QC3 历史化文化模型
              ↓
40 作品 / QT / QH / R / T / 后世应用
```

这不是强制线性链；允许 QC1.1、QC1.2、QC2、Work 分别直接为 QC3 提供证据。
