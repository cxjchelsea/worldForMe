# QC2 世界文化母题、原型与叙事结构

> 路径：Q轴 → QT8 世界文化母题、原型与叙事传统 → **QC2 世界文化母题、原型与叙事结构**

QC2 是横向抽象与文本谱系层：比较不同来源谱系中反复出现的叙事组件，并追踪它们的源文本、定型、传播、变体与后世使用。

它不再把所有重复文化现象统称为“母题”，而正式区分四类对象：**母题（motif）／文化原型（archetype）／叙事结构（plot pattern）／文化意象与符号（symbol）**。这些对象可以交叉、多标签共存，但不得互相替代。

## 一、对象模型

| 对象类型 | 核心问题 | 典型例子 |
|---|---|---|
| motif｜母题 | 故事反复在讲什么基本叙事单元？ | 兄弟相残、禁忌知识、王者归来、冥界之旅 |
| archetype｜文化原型 | 哪类角色、人物模型或高度定型的文化人物被反复调用？ | 圣王、Trickster、导师；亚瑟王、孙悟空、所罗门王 |
| plot_pattern｜叙事结构 | 故事通常以什么关系和顺序展开？ | 离乡—试炼—归乡；预言—逃避—实现 |
| symbol｜文化意象／符号 | 哪些物件、形象或意象形成稳定、可复用的文化含义？ | 圣杯、石中剑、禁果、金箍棒 |

> `theme`（主题）不作为 QC2 的核心对象类型。主题回答“作品在讨论什么抽象问题”，仍主要由 QH 主题 facet 承担；QC2 可以建立关系，但不重复建设主题 taxonomy。

## 二、文化原型的两级区分

文化原型必须进一步区分：

### A. 抽象角色原型

跨越具体作品与人物的角色模型，例如：

- 圣王／天选之王
- Trickster／诡计者
- 智者导师／魔法导师
- 文化英雄
- 法外英雄
- 牺牲者／替罪者
- 诱惑者
- 怪物／边界存在

### B. 命名型文化原型

由具体传统人物或文学人物长期重写后形成的高复用文化原型，例如：

- 所罗门王
- 亚瑟王
- 梅林
- 浮士德
- 唐璜
- 孙悟空
- 哪吒
- 罗宾汉

命名型文化原型不是“一个母题”。它通常同时承载多个母题、多个抽象角色原型、若干文化符号以及一组典型叙事结构。

例如：

```text
孙悟空（命名型文化原型）
├─ 抽象原型：Trickster／反叛英雄／文化英雄
├─ 母题：反叛权威、异类英雄、封印与释放、修行与驯化、自由与秩序
├─ 叙事结构：获得力量 → 反叛 → 被镇压 → 被释放 → 远行试炼 → 新秩序
└─ 符号：金箍棒、金箍、七十二变、筋斗云、五行山
```

因此，一个具体人物是否应进入“文化原型”层，不看它是否著名，而看它是否已经超出单一文本人物身份，成为可被后世持续调用、重写和重新赋义的文化模型。

## 四、QC1.1 → QC2 的映射规则

QC1.1 保存来源传统与具体故事材料；QC2 负责抽象与比较。二者在具体人物、故事和文本处交叉。

一个来源对象进入 QC2 时，应至少回答：

```text
它属于哪一种对象类型？
├─ motif
├─ archetype
├─ plot_pattern
└─ symbol

它来自哪些 QC1.1 来源谱系？
最早／较早可见于哪些文本？
在哪些文本中获得关键定型？
与哪些其他对象构成稳定关系？
后世有哪些明确引用、改写或结构性继承？
```

## 五、文本谱系与影响关系

文本关系至少区分：

- 源文本／早期见证
- 定型文本／核心经典
- 推荐阅读文本

后世关系至少区分：

- direct_adaptation｜直接改编
- explicit_reference｜明确引用
- structural_inheritance｜结构继承
- character_or_name_borrowing｜人物／名称借用
- motif_inversion｜母题反转／重写
- weak_similarity｜弱相似，仅记录比较，不主张历史影响

不得把“结构相似”自动解释为“存在传播或直接影响”。

## 六、治理规则

1. 一级母题簇保持相对稳定；具体 motif / archetype / plot_pattern / symbol 作为专题内部词表与实体持续扩展。
2. 一个故事、人物或作品可以映射多个母题簇，也可以同时关联多种对象类型。
3. 命名型文化原型必须与其来源人物／文本区分：来源属于 QC1.1 的叙事谱系，原型化与后世重写属于 QC2 的比较层。
4. `theme` 仍由 QH 主题 facet 主要承担，QC2 只建立关系，不重复分类。
5. 每个 QC2 专题统一记录：对象定义、来源谱系、文本谱系、内部结构、跨文化比较、后世变体与关系置信度。
6. 对亚瑟王、孙悟空、所罗门王等命名型文化原型，不以“角色百科”方式处理，而研究其如何从具体人物／故事演化为可重复调用的文化模型。
7. QC2 的目标不是穷尽所有文化符号，而是建立足以解释经典文学、神话及现代再创作的高复用叙事组件网络。
