# QC2 世界文化母题、原型与叙事结构

> 路径：作品知识网络 → QC 母题与叙事组件 → **QC2 世界文化母题、原型与叙事结构**

QC2 是横向抽象层：从不同来源传统、具体叙事传统与作品中识别可重复调用的叙事组件，并比较它们的来源、结构、变体与后世使用。

它不把所有重复文化现象统称为“母题”，而正式区分四类对象：**母题（motif）／文化原型（archetype）／叙事结构（plot pattern）／文化意象与符号（symbol）**。这些对象可以交叉、多标签共存，但不得互相替代。

一级簇的呈现与建设统一遵循：[[QC2 一级簇呈现与建设规范 V1]]。

## 一、对象模型

| 对象类型 | 核心问题 | 典型例子 |
|---|---|---|
| motif｜母题 | 故事反复在讲什么基本叙事单元？ | 兄弟相残、禁忌知识、王者归来、冥界之旅 |
| archetype｜文化原型 | 哪类角色、人物模型或高度定型的文化人物被反复调用？ | 圣王、Trickster、导师；亚瑟王、孙悟空、所罗门王 |
| plot_pattern｜叙事结构 | 故事通常以什么关系和顺序展开？ | 离乡—试炼—归乡；预言—逃避—实现 |
| symbol｜文化意象／符号 | 哪些物件、形象或意象形成稳定、可复用的文化含义？ | 圣杯、石中剑、禁果、金箍棒 |

> `theme`（主题）不作为 QC2 的核心对象类型。主题回答“作品在讨论什么抽象问题”，仍主要由 QH 主题 facet 承担；QC2 可以建立关系，但不重复建设主题 taxonomy。

## 二、文化原型的两级区分

### A. 抽象角色原型

跨越具体作品与人物的角色模型，例如：

- 圣王／天选之王
- Trickster／诡计者
- 智者导师／魔法导师
- 文化英雄
- 法外英雄
- 牺牲者／替罪者
- 诱惑者
- 怪物／边界存在

### B. 命名型文化原型

由具体传统人物或文学人物长期重写后形成的高复用文化原型，例如：

- 所罗门王
- 亚瑟王
- 梅林
- 浮士德
- 唐璜
- 孙悟空
- 哪吒
- 罗宾汉

命名型文化原型不是“一个母题”。它通常同时承载多个母题、多个抽象角色原型、若干文化符号以及一组典型叙事结构。

例如：

```text
孙悟空（命名型文化原型）
├─ 抽象原型：Trickster／反叛英雄／文化英雄
├─ 母题：反叛权威、异类英雄、封印与释放、修行与驯化
├─ 叙事结构：获得力量 → 反叛 → 被镇压 → 被释放 → 远行试炼 → 新秩序
└─ 符号：金箍棒、金箍、七十二变、筋斗云、五行山
```

一个具体人物是否进入“文化原型”层，不看它是否著名，而看它是否已经超出单一文本人物身份，成为可被后世持续调用、重写和重新赋义的文化模型。

## 四、QC1 → QC2 双输入规则

QC2 同时接收 QC1.1 与 QC1.2 的输入，二者职责不同。

### QC1.1 → QC2：来源环境

QC1.1 保存文化／宗教／区域来源传统及早期叙事材料，回答：

> 这个 component 出现在哪些来源环境和较早见证中？

QC1.1 可以直接向 QC2 提供 component 候选，不要求先经过 QC1.2。

### QC1.2 → QC2：具体传统生命史

QC1.2 保存有名称、有文本生命的具体故事、人物、循环与集合传统，回答：

> 这个 component 在哪些具体叙事传统中被组织、定型、强化、变体化或持续调用？

### 理想连接

```text
QC1.1 来源传统
      ↓
QC1.2 具体叙事传统（若存在）
      ↓
QC2 component
      ↓
40 作品 / work reference
```

但该链不是强制线性。以下都合法：

```text
QC1.1 → QC2
QC1.2 → QC2
QC1.1 + QC1.2 → QC2
```

## 五、文本谱系与影响关系

文本关系至少区分：

- 源文本／早期见证
- 定型文本／核心经典
- 推荐阅读文本

后世关系至少区分：

- direct_adaptation｜直接改编
- explicit_reference｜明确引用
- structural_inheritance｜结构继承
- character_or_name_borrowing｜人物／名称借用
- motif_inversion｜母题反转／重写
- weak_similarity｜弱相似，仅记录比较，不主张历史影响

不得把“结构相似”自动解释为“存在传播或直接影响”。

## 七、治理规则

1. 一级问题域保持相对稳定；具体 motif / archetype / plot_pattern / symbol 作为正式 component 持续扩展。
2. 一个故事、人物、传统或作品可以映射多个 QC2.x；一个 component 有一个 primary cluster，可有多个 secondary clusters。
3. 命名型文化原型必须与其来源人物／文本／QC1.2 传统区分。
4. `theme` 仍由 QH 主题 facet 主要承担；QC2 不把“时间、爱情、记忆、自由”等抽象主题直接当 component。
5. 每个正式 component 至少维护：定义与边界、来源证据、结构／意义、跨传统比较、后世变体、作品入口和关系置信度。
6. 不为了四类数量均衡而强建 component。
7. 不按 QC2.1 → QC2.20 机械填满；优先由已有 QC1.1、QC1.2 与真实阅读材料反向生成候选。
8. QC2 的目标不是穷尽所有文化符号，而是建立足以解释经典文学、神话和现代再创作的高复用叙事组件网络。
