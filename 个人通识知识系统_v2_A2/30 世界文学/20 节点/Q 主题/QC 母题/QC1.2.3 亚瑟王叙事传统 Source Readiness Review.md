# QC1.2.3 亚瑟王叙事传统 Source Readiness Review

## 结论

`BOUNDARY_CHECK = PASS`  
`SOURCE_READINESS = PASS`  
`ADMISSION = PASS`

建议正式类型：`figure_tradition`。

亚瑟王传统不是一个固定故事循环，而是围绕“亚瑟”这一命名中心人物不断吸附、重组和分化的跨文本叙事网络。它特别适合作为 QC1.2 第一个 `figure_tradition` 样板。

---

# 1. 为什么不是 narrative_cycle

亚瑟王材料当然存在可排列的生平区段：出生／加冕、建国、圆桌、战争、骑士冒险、圣杯探索、兰斯洛特—桂妮维亚危机、莫德雷德叛乱、卡姆兰与死亡。

但如果只按 chronology 组织，会遮蔽真正的文学史结构：

```text
亚瑟这一中心人物
      ↓
共同王廷／世界框架
      ↓
梅林、兰斯洛特、高文、珀西瓦尔／加拉哈德、特里斯坦、莫德雷德等人物或子传统
      ↓
编年史、诗体 romance、法语散文循环、英语集成文本、现代重写
```

很多关键作品并不把亚瑟作为行动主角，却依赖“亚瑟王廷”提供叙事世界。因此本专题的核心对象应是 `figure_tradition`，而不是再次套用 `narrative_cycle`。

---

# 2. 边界

## 纳入

- 亚瑟作为命名人物及其王权／王廷框架的历时变化；
- 早期威尔士／不列颠材料与拉丁编年史中的亚瑟；
- 蒙茅斯的杰弗里《不列颠诸王史》形成的连贯亚瑟传记；
- Wace、Chrétien de Troyes 等对圆桌、骑士冒险与宫廷 romance 的扩展；
- 兰斯洛特—圣杯／Vulgate Cycle 等法语散文循环；
- Post-Vulgate、Prose Tristan 等重组；
- 马洛礼《亚瑟王之死》的晚期集成；
- 重要近现代重写。

## 不自动纳入

- 所有“中世纪骑士文学”；
- 只具有圣杯、魔法剑、圆桌、骑士等抽象组件的作品；
- 与亚瑟王廷无实质文本关系的“类亚瑟”作品；
- 每一个圆桌骑士都立即拆成独立 QC1.2 节点。

# 4. 最低文本锚点

第一轮至少需要覆盖以下角色，而不是追求作品数量：

1. **早期／编年史定型**：蒙茅斯的杰弗里《不列颠诸王史》；
2. **法语宫廷 romance 扩张**：Chrétien de Troyes 代表作品；
3. **散文循环化**：Lancelot-Grail / Vulgate Cycle；
4. **圣杯／梅林／兰斯洛特等子传统重组**：Vulgate / Post-Vulgate 相关文本；
5. **英语晚期集成**：马洛礼《亚瑟王之死》；
6. **近现代再发明**：后续按实际阅读加入一个结构性重写锚点。

中央 `40 作品` 已确认至少存在《不列颠诸王史》与《亚瑟王之死》，可直接复用，不重复创建。

---

# 5. figure_tradition 要验证的新能力

QC1.2.3 不主要验证“故事分支”，而验证：

```text
central_figure
→ court/world framework
→ figure_network
→ subtraditions
→ textualization / compilation / rewriting
```

特别需要回答：

1. 中心人物是否必须是每部作品的主角？——不必须；
2. 子人物何时只是人物网络节点，何时升格独立 QC1.2？
3. 圣杯这类对象如何同时连接 story_tradition 与 QC2 symbol/motif？
4. 如何记录一个传统被“世界化”：从亚瑟个人传记扩展为圆桌骑士共享宇宙；
5. 如何避免把所有相关人物强制合并进一个无限膨胀专题。

---

# 6. source readiness

当前已具备：

- 稳定边界；
- 可建立最低 chronology；
- 多个关键文本阶段；
- 清晰的法语散文循环与马洛礼集成阶段；
- 足够材料区分人物中心、人物网络与子传统；
- 足够证据支持“法语散文循环不是单一作者一次写成的统一作品，而是逐步形成与重组”的复杂文本史。

因此无需等待 QC1.1.4 凯尔特—不列颠传说传统先完成专题化。QC1.1.4 仍作为来源环境 hub；QC1.2.3 可独立建立具体人物传统谱系。
