# QC 世界叙事资源、母题谱系与文化传统

QC 研究故事从何而来，叙事组件如何在不同文本与文化中反复出现、传播和变形，以及这些资源与组件如何进入具体历史社会，形成稳定的文化角色、叙事世界与文学传统。

- [[QC1 世界文化叙事传统|QC1 世界叙事资源与来源传统]]：**叙事资源与来源传统层**——人类讲过什么故事，它们从哪里来、如何形成、保存、定型与传播。
  - [[QC1.1 神话、传说与民间叙事|QC1.1 神话、宗教与民间叙事来源传统]]：文化／宗教／区域性的来源传统 hubs，回答“这个文化世界提供了什么叙事资源？”
  - [[QC1.2 故事循环、人物传说与跨文本叙事传统]]：具体故事、人物与故事循环的跨文本生命史，回答“这个叙事传统如何形成、分叉、传播和重写？”
- [[QC2 世界文化母题、原型与叙事结构]]：**母题与叙事组件层**——哪些 motif / tale type / character type / named archetype / plot pattern / symbol 被反复调用，它们如何组合、迁移与变形。
- [[QC3 历史化文化叙事传统]]：**历史化文化传统层**——叙事资源与组件如何与制度、伦理、阶层、空间和社会经验结合，形成侠、骑士、武士、西部等持续被重写的文化叙事传统。

三层分别回答 **来源、组件、历史化组织** 三个问题；它们通过具体故事、人物、文本、作品与证据关系连接，而不是互相复制内容。

QC1 内部再区分两种尺度：

```text
QC1.1 来源传统 hub
文化／宗教／区域叙事资源库
        ↓ contains / supplies
QC1.2 具体叙事传统
故事／人物／循环的文本生命史
        ↓ attests / realizes
QC2 可复用叙事组件
```

这条链路用于消除过去“从整个文明传统直接跳到抽象母题”的尺度断层；实际知识网络允许跨层和多源连接，并不强制所有对象经过同一路径。
