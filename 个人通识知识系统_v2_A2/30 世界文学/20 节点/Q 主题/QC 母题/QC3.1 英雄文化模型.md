# QC3.1 英雄文化模型

> QC3 首个 Pilot 问题域：研究不同历史社会如何把“有能力、承担风险、获得荣誉或代表共同体的人”塑造成具有稳定角色、关系、伦理、空间与后世生命的文化模型。

## 一句话理解

QC2 可以告诉我们“战士英雄、求索、牺牲、复仇、荣誉”这些组件是什么；QC3.1 进一步追问：**为什么某个社会会把这些组件组织成‘骑士’、‘侠客’、‘武士’、‘cowboy/outlaw’等不同的英雄世界。**

## 当前分析维度

每个英雄文化模型至少回答：

1. **角色**：谁有资格成为英雄？
2. **关系**：英雄忠于谁、保护谁、反抗谁？
3. **伦理**：荣誉、忠诚、勇武、牺牲、正义如何排序？
4. **秩序与空间**：宫廷、江湖、边疆、战场、共同体怎样塑造英雄？
5. **后世续写**：这一模型后来怎样被浪漫化、民族化、商业化或反转？

+

```

### P2 古希腊英雄模型｜READY_FOR_ADMISSION

重点测试：荣誉、命运、战功、家族与共同体如何共同塑造英雄；并检验 QC3 是否能与 QC2.6 / QC2.11 / QC2.18 清楚分工。

### P3 侠／江湖英雄模型｜READY_FOR_ADMISSION

重点测试：侠客角色、义、私人正义、师徒/门派/江湖关系、国家法与江湖秩序之间如何形成独立文化模型，并与 QT 武侠类型保持区分。

### P4 日本武士／剑豪英雄模型｜NEEDS_EVIDENCE

重点测试：历史武士阶层、后世武士道建构与文学/影视中的武士形象如何区分。

### P5 美国西部 cowboy / outlaw 模型｜NEEDS_EVIDENCE

重点测试：边疆空间、个人主义、暴力合法性、法与法外者、文明/荒野边界如何共同形成英雄模型。

### P6 Robin Hood / social bandit 模型｜NEEDS_EVIDENCE

重点测试：命名人物传统与更广泛“社会匪徒/法外英雄”模型之间的关系边界。

→ QC3.1
```
