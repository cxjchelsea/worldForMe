# QC3.1 英雄文化模型

> 研究不同历史社会如何把可复用叙事组件与真实社会条件组织成稳定的英雄角色、关系、伦理、空间和后世文化模型。

## 已验证的两个正式模型

1. [[../../../30 专题/QC3.1 英雄文化模型/10 正式模型/欧洲骑士英雄模型/00 欧洲骑士英雄模型|欧洲骑士英雄模型]]｜ACCEPTED｜Pilot 1
2. [[../../../30 专题/QC3.1 英雄文化模型/10 正式模型/侠与江湖英雄模型/00 侠与江湖英雄模型|侠／江湖英雄模型]]｜ACCEPTED｜Pilot 2

两者社会结构差异明显：

```text
欧洲骑士
→ 主君 / 等级共同体 / 荣誉 / 宫廷与宗教秩序

侠／江湖
→ 义 / 私人正义 / 师徒门派 / 江湖 / 国家法张力
```

但都可以稳定使用：

```text
角色
关系
伦理
秩序／空间
QC1 输入
QC2 输入
历史条件
QT 接口（如有）
40 作品
后世重构
证据边界
```

因此：

```text
QC3.1_STATUS = PILOT_VALIDATED
```

## 固定分工

```text
来源、人物与具体叙事传统的文本生命史 → QC1
可复用叙事组件 → QC2

文学类型与文类机制 → QT
抽象主题 → QH
真实制度运行 → 历史领域
```
