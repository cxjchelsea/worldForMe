# QX 文学意象与场景

> 核心问题：**作品中哪些可感知的意象、物象、空间与场景真正承担了文学功能？同一对象在不同作品中又如何改变其作用与意义？**

QX 是 Q 轴中的“文学意象与场景” facet。它与 QT、QH、QC 并列，但回答的问题不同：

- **QT**：作品采用什么类型／叙事传统；
- **QH**：作品讨论什么人类问题；
- **QC**：作品复用了什么跨文化母题、原型与叙事组件；
- **QX**：作品调用了哪些具体可感知对象，以及这些对象如何在文本中工作。

## 1｜唯一事实源

所有针对**单部作品**的正式 QX 事实只维护在：

```text
40 作品/<作品>.md
```

作品页中的 `qx:` YAML 是唯一事实源。其他 QX 文档只做结构说明、索引与跨作品比较，不重复维护另一套作品级事实。

正式关系的核心字段：

```text
object
salience
function
evidence
```

可选增强字段：

```text
manifestation
meaning
perceptual_channel
mode
phase
scope
```

## 2｜QX 收什么

QX 收录可以在文本中相对明确定位、具有感知性、并且值得跨作品比较的元素，例如：雨、月亮、河流、森林、镜子、门、窗、火车、废墟、病床、宴席、黑夜。

QX 不直接收录：

- 抽象主题，如“孤独”“自由”“死亡焦虑”——归 QH；
- 完整叙事母题，如“禁忌被打破”“英雄下潜”“弑父”——归 QC；
- 类型标签，如“哥特”“旅行文学”“灾变文学”——归 QT；
- 单一作品中偶然出现、没有独立文学作用的普通名词。

## 4｜正式准入规则

QX 不做“出现即标注”。普通对象原则上至少满足以下四项中的两项：

1. **复现性**：在作品中有有意义的重复；
2. **结构性**：参与开篇、结尾、转折、世界状态变化等关键位置；
3. **绑定性**：与人物、关系、家族、空间、身份或历史阶段形成稳定绑定；
4. **辨识度**：移除后会明显削弱作品、人物或场景的识别度。

例外：只出现一次但决定性极强的对象，可按 `singular_pivotal` 准入。

以下理由单独都不足以入库：

```text
出现过
出现很多次
可以象征某物
营造了气氛
属于传统象征词典
我个人很喜欢
为了让每部作品都有QX
```

## 5｜对象与作品内形态

```text
object = 跨作品比较的对象
manifestation = 它在本作品中具体怎样出现
```

例如：

```text
object: 雨
manifestation: 持续数年的连绵长雨
```

默认不把春雨、秋雨、暴雨、细雨等都预先拆成独立节点；先作为 manifestation 保留，只有形成稳定跨作品传统后才考虑继续分化。

## 6｜显著性与功能

正式关系的 `salience` 只使用：

```text
significant
core
dominant
```

低于 significant 的对象不进入正式 QX。

`function` 记录“对象在作品中做了什么”，优先从受控功能表中选择，例如：

```text
氛围塑造、空间塑造、世界状态、时间标记、场景转换
情绪外化、人物塑造、身份标识、关系映射、权力标识
人物行动条件、情节推动、情节转折、伏笔 / 预示、结构标记
前后回声、记忆触发、隔离、连接、遮蔽、暴露、阻碍、边界 / 阈限
主题承载、象征强化、对照 / 反讽、仪式化
```

`meaning` 不是固定象征词典，只在作品内部证据足够时填写。

## 7｜具体专题如何激活

候选词不等于专题。一个具体 QX x.x 专题原则上满足：

1. 至少 **3 部正式作品**出现同一归一化对象；
2. 至少有 **两种有意义的功能、使用方式或语义变体**；
3. 对象不只是背景陈设；
4. 值得长期跨作品积累。

达到门槛后，专题正文建立在：

```text
30 专题/QX 文学意象与场景/10 已激活专题/
```

## 8｜短篇与合集

短篇不再作为强制 QX 单元。只有存在高辨识、结构性强、具有跨作品比较价值的核心物象，或该短篇本身是重要独立阅读对象时，才优先单篇进入 QX。

```text
SHORT_STORY ≠ MANDATORY_QX_UNIT
EDITORIAL_COLLECTION ≠ MANDATORY_STORY_MAP
ZERO_QX ≠ COVERAGE_GAP
```
