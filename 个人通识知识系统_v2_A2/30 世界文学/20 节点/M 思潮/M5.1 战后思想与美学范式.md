# M5.1 战后思想与美学范式

> 路径：[[../../00 世界文学使用规则|世界文学]] → [[../../10 轴/M轴 文学思潮与美学范式|M轴]] → [[M5 战后与当代美学范式|M5 战后与当代范式]] → **M5.1 战后思想与美学范式**

M5.1 是叶节点。

> 核心问题：**二战以后，当主体、意义、现实与语言的稳定性受到怀疑时，文学如何重新组织现实、经验与叙事？**

## 内部范围

- 存在主义
- 荒诞
- 法国新小说
- 魔幻现实主义
- 后现代主义

这些对象并非同一历史运动，但都主要回答文学内部的思想与美学重组：主体是否稳定、世界是否有意义、现实是否可透明再现、叙事是否仍能保持连续、文本是否还能声称单一真理。

## 认知主线

二战 / 大屠杀 / 冷战与现代性危机  
→ 意义与主体危机  
→ 存在主义 / 荒诞  
→ 再现与叙事危机  
→ 法国新小说  
→ 现实层级与文本权威进一步不稳定  
→ 魔幻现实主义 / 后现代主义等不同回应。

## 边界

- M5.1 不是“所有战后文学”。作品必须对理解上述思想或美学转型具有结构意义。
- 魔幻现实主义按美学/叙事模式处理，不等同于拉丁美洲 Boom；Boom 作为作家网络和文学史现象归 M4。
- 后殖民、女性主义、酷儿、去殖民等主要作为权力与知识框架时，归 [[M5.2 权力、身份与世界批评|M5.2]]。
- 与 M3.1 的区别：M3.1 主要研究现代经验如何迫使文学改变形式；M5.1 更进一步追问主体、意义、现实与文本权威本身是否仍然稳定。
