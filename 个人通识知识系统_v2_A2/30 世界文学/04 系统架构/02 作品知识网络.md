# 作品知识网络

> 回答：作品内部“有什么”，以及作品“通向哪些长期文化结构”。

作品知识网络由两个稀疏层组成：

| 代码 | 网络 | 核心问题 | 作品事实源 |
|---|---|---|---|
| IM | 意象网络 | 哪些具体可感知对象在作品中具有高显著度，并值得跨作品比较？ | `imagery:` |
| CN | 文化叙事网络 | 作品与哪些来源传统、叙事组件、文化模型发生有证据的关系？ | `cultural_narrative_relations:` |

它们不追求覆盖率，也不是作品必须填写的坐标。

## IM 意象网络

入口：[[../20 作品知识网络/IM 意象/IM 文学意象与场景|IM 文学意象与场景]]

工作流：

```text
作品内抽取
→ salience / function / evidence
→ 归一化对象
→ 跨作品聚类
→ 达到门槛后激活 IM 专题
```

作品页使用 `imagery:`；内部对象 ID / 组号使用 `im_id`、`IM1`、`IM16` 等新命名。旧 `qx` / `IM*` 只作为历史迁移来源理解，不再写入新内容。

## CN 文化叙事网络

入口：[[../20 作品知识网络/CN 文化叙事/CN 母题与叙事组件|CN 文化叙事网络]]

```text
CN1 纵向谱系
├─ CN1.1 来源环境 / 文化土壤
└─ CN1.2 具体叙事传统的历史生命

CN2 横向结构
└─ 跨传统可复用叙事组件

CN3 横向结构
└─ 历史化文化模型
```

- CN1：追踪故事从哪里来、怎样形成和演变；
- CN2：抽取可以脱离具体传统复用的结构零件；
- CN3：研究这些资源进入历史社会后形成的角色、关系、伦理、秩序与空间模型。

旧 CN1 / CN2 / CN3 已机械映射为 CN1 / CN2 / CN3；旧编号保存在节点 `legacy_code` / `legacy_codes`。

## 稀疏映射原则

读完作品只在有价值时询问：

1. 是否明确重写某个具体传统？→ CN1.2
2. 是否有特别重要的可复用叙事组件？→ CN2
3. 是否明显继承、强化、批判或反转某种文化模型？→ CN3
4. 来源环境是否明确且具有解释价值？→ CN1.1

没有就留空。

## CN 关系边

优先使用有类型关系：

`retells`、`adapts`、`continues`、`reframes`、`structural_similarity`、`uses`、`foregrounds`、`transforms`、`critiques`、`subverts`、`reorders`。

## 证据纪律

- text date ≠ origin
- precedence ≠ direct source
- plot similarity ≠ transmission
- later coherent narrative ≠ early original
- modern reconstruction ≠ extant original

## 节点产品职责

正式 CN 节点不是分类说明，而是微型专题课程 / 学习路径。至少逐步提供：定义、边界、关键子问题、相关节点、核心作品、扩展作品、对照作品、阅读路线与证据纪律。

中央 `40 作品` 始终是作品唯一事实源。专题只投影作品，不复制作品实体。
