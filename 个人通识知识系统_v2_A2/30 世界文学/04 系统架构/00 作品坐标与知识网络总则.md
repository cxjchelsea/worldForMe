# 作品坐标与知识网络总则

> 本文件自 2026-09-07 起作为世界文学顶层信息架构的权威说明。旧“ 五轴 + Q 内部 facet ”模型进入兼容期，不再作为新建设的概念模型。

## 1. 顶层架构

世界文学现在由两套机制组成：

```text
A 作品坐标系统
├─ T  时间 / 文学史阶段
├─ R  地域 / 文学传统
├─ M  思潮 / 运动 / 美学范式
├─ G  体裁 / 文本形式
├─ QH 主题 / 人类问题
└─ QT 类型 / 叙事机制

B 作品知识网络
├─ QX 意象网络
└─ QC 文化叙事网络
```

这不是“八轴”。六个坐标回答作品“在哪里”；QX / QC 通过稀疏关系回答作品“有什么”与“通向哪里”。

## 2. 两种数据机制

### A. 坐标型

T / R / M / G / QH / QT 是作品定位字段，具有较高覆盖率，可双向浏览：

```text
作品 → 坐标
坐标 → 作品集合
```

QH 回答“作品在思考什么问题”；QT 回答“作品采用什么类型或叙事机制”。它们保留多值能力，但不再隶属于一个必须统一存储的 `Q` 轴。

### B. 稀疏抽取 / 关系型

QX / QC 不追求 coverage。

- QX：只抽取作品内部高显著度、可比较的具象对象；事实源为作品页 `qx:` 结构化对象。
- QC：只记录作品与长期文化叙事结构之间有解释价值且有证据的关系；事实源逐步使用作品页 `qc_relations:` 关系对象。

没有可靠关系时留空，不为了字段完整而补标。

## 3. 稳定代码与路径兼容

QH / QT / QX / QC 四组代码全部保留，作为稳定的知识标识符；不重新编号。

当前物理路径也暂时保留：

```text
10 轴/
20 节点/Q 主题/
```

它们是历史兼容地址，不再代表新的概念层级。这样可保持既有 WikiLink、Base、Canvas、专题引用和外部链接继续工作。

旧 `Q轴 文学主题与人类问题.md` 改为兼容入口，只负责解释旧模型并转向新系统。

## 4. 作品唯一事实源

作品实体仍然且只位于：

```text
40 作品/<作品>.md
```

专题、节点、Base、Canvas 只做导航、投影、聚合与解释，不复制作品实体。

## 5. 新作品字段模型

新写入的 canonical 字段：

```yaml
axis_t: []
axis_r: []
axis_m: []
axis_g: []
axis_qh: []
axis_qt: []
axis_source: read_calibrated | inferred

qx: []
qc_relations: []
```

其中：

- `axis_*` 为定位字段；
- `qx` 为作品内意象抽取；
- `qc_relations` 为作品与 QC 节点的有类型关系；
- `topics` / `topic_links` 仍服务专题投影，不替代坐标或知识关系。

### legacy `axis_q`

已有作品大量使用：

```yaml
axis_q:
  - QT...
  - QH...
```

该字段暂不批量删除。迁移期规则：

1. 读：Base / 脚本允许把 `axis_q` 视为 legacy fallback；
2. 写：新校准优先写 `axis_qh` 与 `axis_qt`；
3. 改：当作品被主动重读或校准时，再把对应 QH / QT 值迁入新字段；
4. 删：只有仓库完成覆盖率检查后，才讨论移除 `axis_q`。

不得把 QX 或 QC 塞进 `axis_q`、`axis_qh` 或 `axis_qt`。

## 6. QC 关系模型

`qc_relations` 不是普通标签列表。推荐结构：

```yaml
qc_relations:
  - target: "QC1.2.3 亚瑟王叙事传统"
    relation: retells
    evidence: "..."
  - target: "QC2.17 求索、宝物与神圣目标"
    relation: uses
    evidence: "..."
```

允许的关系词优先从以下集合选择：

```text
retells
adapts
continues
reframes
structural_similarity
uses
foregrounds
transforms
critiques
subverts
reorders
```

关系可以为空；证据不足时不得把 `structural_similarity` 升格为直接来源关系。

## 7. QC 证据纪律

永久遵守：

```text
text date ≠ origin
precedence ≠ direct source
plot similarity ≠ transmission
later coherent narrative ≠ early original
modern reconstruction ≠ extant original
```

QC1 追踪来源与历史生命；QC2 抽取可复用组件；QC3 研究组件进入具体历史社会后形成的角色、关系、伦理、秩序与空间模型。

## 8. QT 与 QC 的边界

QT 今后只承担“类型 / 叙事机制”坐标。

仓库现存 QT8 及其部分子树包含旧模型遗留的文化传统对象，与 QC3 已发生职责重叠。迁移期处理原则：

- 不删除、不改号、不粗暴移动，保障旧专题与 WikiLink；
- 冻结其作为新 taxonomy 的扩展；
- 新的文化角色世界、社会规则与历史化模型进入 QC3；
- 现有作品若仍使用 QT8.*，按主动校准逐步判断：真正属于类型机制的保留 QT；文化模型关系迁移到 QC3；
- 不因为结构相似自动创建 QC 直接来源边。

## 9. QX 与 QC 的边界

- QX = 文本内部“有什么”：雨、海、门、镜子、房间、火车等可感知对象如何工作。
- QC = 文本背后“调用了什么”：叙事传统、组件、文化模型如何被继承、改写、批判或重组。

同一对象可以在两个系统中产生不同层级的事实，但不得用一个字段代替另一个。

## 10. 节点与专题职责

### 坐标节点

T / R / M / G / QH / QT 节点负责：定义边界、提供稳定坐标、投影作品、连接专题。

### 网络节点

QX / QC 节点负责：跨作品聚类、关系解释、证据组织与阅读路径，不要求每部作品都有映射。

正式 QC 节点应逐步具有：定义、边界、关键子问题、与其他节点关系、核心作品、扩展作品、对照作品、阅读路线与证据纪律。

作品角色可使用：★ 核心锚点、◆ 结构性扩展、△ 对照作品、○ 关联实例。

## 11. 迁移策略

本轮采用兼容迁移，不做大规模路径搬迁：

```text
旧物理路径保留
        ↓
新治理模型接管语义
        ↓
Base / Canvas 按坐标与网络分层展示
        ↓
作品字段渐进拆分 axis_q → axis_qh + axis_qt
        ↓
QC 逐步关系化，QX 保持结构化抽取
```

只有当旧路径引用量、作品字段覆盖率和专题依赖都完成检查后，才考虑第二阶段物理目录迁移。
