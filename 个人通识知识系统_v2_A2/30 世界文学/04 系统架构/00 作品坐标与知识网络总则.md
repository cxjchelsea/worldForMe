# 作品坐标与知识网络总则

> 本文件是世界文学顶层信息架构的权威说明。2026-09-08 起，旧 QH / QT / QX / QC 与 `10 轴/`、`20 节点/` 只保留在迁移 provenance 中，不再作为 canonical 命名或物理结构。

## 1. 顶层架构

```text
A 作品坐标系统
├─ T   时间 / 文学史阶段
├─ R   地域 / 文学传统
├─ M   思潮 / 运动 / 美学范式
├─ G   体裁 / 文本形式
├─ TH  主题 / 人类问题
└─ TY  类型 / 叙事机制

B 作品知识网络
├─ IM  意象网络
└─ CN  文化叙事网络
```

这不是“八轴”。六个坐标回答作品“在哪里”；IM / CN 通过稀疏关系回答作品“有什么”与“通向哪里”。

## 2. canonical 物理目录

```text
30 世界文学/
├─ 10 作品坐标系统/
│  ├─ T 时间/
│  ├─ R 地域/
│  ├─ M 思潮与美学/
│  ├─ G 体裁/
│  ├─ TH 主题/
│  └─ TY 类型与叙事机制/
├─ 20 作品知识网络/
│  ├─ IM 意象/
│  └─ CN 文化叙事/
├─ 30 专题/
└─ 40 作品/
```

旧 `10 轴/` 与 `20 节点/` 不再保留为第二套主目录。历史编号通过节点 `legacy_code` / `legacy_codes`、`legacy_id` 和作品 `legacy_axis_q` 保存。

## 3. 两种数据机制

### A. 坐标型

T / R / M / G / TH / TY 是高覆盖作品定位字段，可双向浏览：

```text
作品 → 坐标
坐标 → 作品集合
```

TH 回答“作品在思考什么问题”；TY 回答“作品采用什么类型或叙事机制”。

### B. 稀疏抽取 / 关系型

IM / CN 不追求 coverage。

- IM：只抽取作品内部高显著度、可比较的具象对象；事实源为作品页 `imagery:`。
- CN：只记录作品与长期文化叙事结构之间有解释价值且有证据的关系；事实源为 `cultural_narrative_relations:`。

没有可靠关系时留空，不为了字段完整而补标。

## 4. 作品唯一事实源

作品实体始终且只位于：

```text
40 作品/<作品>.md
```

专题、坐标节点、知识网络节点、Base、Canvas 只做导航、投影、聚合与解释，不复制作品实体。

## 5. canonical 作品字段

```yaml
axis_t: []
axis_r: []
axis_m: []
axis_g: []
axis_th: []
axis_ty: []
axis_source: read_calibrated | inferred

imagery: []
cultural_narrative_relations: []
```

- `axis_*` 为作品定位；
- `imagery` 为 IM 作品内意象抽取；
- `cultural_narrative_relations` 为作品与 CN 节点的有类型关系；
- `topics` / `topic_links` 服务专题投影，不替代坐标或知识关系。

## 6. legacy 规则

第二阶段迁移映射：

```text
QH -> TH
QT -> TY
QX -> IM
QC -> CN
```

作品旧合并 Q 字段只以 `legacy_axis_q` 保留原始 QH / QT 值用于审计，不参与 canonical 检索。新内容不得创建 `axis_q`、`axis_qh`、`axis_qt`、`qx` 或 `qc_relations`。

节点旧编号通过：

```yaml
legacy_code: QH...
legacy_id: WL-QH...
```

若节点此前已有更早迁移来源，则使用 `legacy_codes` 同时保存多代 provenance。

## 7. CN 关系模型与证据纪律

`cultural_narrative_relations` 使用有类型关系：

`retells`、`adapts`、`continues`、`reframes`、`structural_similarity`、`uses`、`foregrounds`、`transforms`、`critiques`、`subverts`、`reorders`。

永久遵守：

```text
text date ≠ origin
precedence ≠ direct source
plot similarity ≠ transmission
later coherent narrative ≠ early original
modern reconstruction ≠ extant original
```

CN1 追踪来源与叙事传统的历史生命；CN2 抽取跨传统可复用组件；CN3 研究历史化文化模型。

## 8. TY 与 CN 的边界

TY 只承担“类型 / 叙事机制”坐标。旧 TY8 中由原 QT8 继承的文化传统对象继续作为冻结兼容内容存在，但新的文化角色世界、社会规则与历史化模型进入 CN3，不再扩建混合 taxonomy。

## 9. 治理原则

1. 不新增没有阅读或证据支撑的坐标 / 网络关系；
2. 不为了覆盖率强制填写 IM / CN；
3. 不重新建立旧 QH / QT / QX / QC canonical 命名；
4. 不恢复旧 `10 轴/`、`20 节点/` 物理目录；
5. 所有结构调整必须通过 Base / Canvas / WikiLink / 作品字段长期校验。
