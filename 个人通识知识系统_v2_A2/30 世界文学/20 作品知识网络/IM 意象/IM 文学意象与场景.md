# IM 文学意象与场景

> 新路径：世界文学 → 作品知识网络 → **IM 意象网络**。核心问题：**作品中哪些可感知的意象、物象、空间与场景真正承担了文学功能？同一对象在不同作品中又如何改变其作用与意义？**

IM 不再被定义为 Q 轴 facet，而是作品知识网络中的稀疏抽取层。它只抽取作品内部具有高显著度、可比较价值的具象对象；有则标，无则不标。

- **TH**：作品在思考什么主题 / 问题，是作品坐标；
- **TY**：作品采用什么类型 / 叙事机制，是作品坐标；
- **IM**：作品内部有什么高显著意象，是稀疏作品内抽取；
- **CN**：作品与哪些长期文化叙事结构发生关系，是稀疏文化关系网络。

真正的 IM 整合发生在意象类别与专题层，而不是在单作品页面中复制跨作品结论。

## 1｜唯一事实源

所有针对**单部作品**的正式 IM 事实只维护在：

```text
40 作品/<作品>.md
```

作品页中的 `imagery:` YAML 是唯一事实源。其他 IM 文档只做结构说明、索引与跨作品比较，不重复维护另一套作品级事实。

正式关系的核心字段：

```text
object
salience
function
evidence
```

可选增强字段：

```text
manifestation
meaning
perceptual_channel
mode
phase
scope
```

## 2｜IM 收什么

IM 收录可以在文本中相对明确定位、具有感知性、并且值得跨作品比较的元素，例如：雨、月亮、河流、森林、镜子、门、窗、火车、废墟、病床、宴席、黑夜。

IM 不直接收录：

- 抽象主题，如“孤独”“自由”“死亡焦虑”——归 TH；
- 完整叙事母题，如“禁忌被打破”“英雄下潜”“弑父”——归 CN；
- 类型标签，如“哥特”“旅行文学”“灾变文学”——归 TY；
- 单一作品中偶然出现、没有独立文学作用的普通名词。

## 4｜正式准入规则

IM 不做“出现即标注”。普通对象原则上至少满足以下四项中的两项：

1. **复现性**：在作品中有有意义的重复；
2. **结构性**：参与开篇、结尾、转折、世界状态变化等关键位置；
3. **绑定性**：与人物、关系、家族、空间、身份或历史阶段形成稳定绑定；
4. **辨识度**：移除后会明显削弱作品、人物或场景的识别度。

例外：只出现一次但决定性极强的对象，可按 `singular_pivotal` 准入。

以下理由单独都不足以入库：

```text
出现过
出现很多次
可以象征某物
营造了气氛
属于传统象征词典
我个人很喜欢
为了让每部作品都有IM
```

## 5｜对象与作品内形态

```text
object = 跨作品比较的对象
manifestation = 它在本作品中具体怎样出现
```

例如：

```text
object: 雨
manifestation: 持续数年的连绵长雨
```

默认不把春雨、秋雨、暴雨、细雨等都预先拆成独立节点；先作为 manifestation 保留，只有形成稳定跨作品传统后才考虑继续分化。

`object` 只写一个可比较的名字，不要写成 `雨 / 雷雨`、`书信 / 明信片`。斜线后的作品内形态放入 `manifestation`。

已激活专题的正式关系必须使用该专题的标准对象名：

```text
IM1.1 → 雨
IM3.1 → 海
IM16.1 → 书信
```

作品专名、独特器物或尚未归一的复名可以暂时保留原文；不要为了迁就 Obsidian 属性面板把 `qx` 改成字符串列表。

## 6｜显著性与功能

正式关系的 `salience` 只使用：

```text
significant
core
dominant
```

低于 significant 的对象不进入正式 IM。

`function` 记录“对象在作品中做了什么”，优先从受控功能表中选择，例如：

```text
氛围塑造、空间塑造、世界状态、时间标记、场景转换
情绪外化、人物塑造、身份标识、关系映射、权力标识
人物行动条件、情节推动、情节转折、伏笔 / 预示、结构标记
前后回声、记忆触发、隔离、连接、遮蔽、暴露、阻碍、边界 / 阈限
主题承载、象征强化、对照 / 反讽、仪式化
```

`meaning` 不是固定象征词典，只在作品内部证据足够时填写。

## 7｜具体专题如何激活

候选词不等于专题。一个具体 IM x.x 专题原则上满足：

1. 至少 **3 部正式作品**出现同一归一化对象；
2. 至少有 **两种有意义的功能、使用方式或语义变体**；
3. 对象不只是背景陈设；
4. 值得长期跨作品积累。

达到门槛后，专题正文建立在：

```text
30 专题/IM 文学意象与场景/10 已激活专题/
```

## 8｜短篇与合集

短篇不再作为强制 IM 单元。只有存在高辨识、结构性强、具有跨作品比较价值的核心物象，或该短篇本身是重要独立阅读对象时，才优先单篇进入 IM。

```text
SHORT_STORY ≠ MANDATORY_IM_UNIT
EDITORIAL_COLLECTION ≠ MANDATORY_STORY_MAP
ZERO_IM ≠ COVERAGE_GAP
```

## 9｜如何维护

- 作品级事实只改 `40 作品/<作品>.md` 源码中的 `imagery:` YAML，不要改生成区，也不要在 Obsidian 属性面板里编辑橙色的 `qx` JSON。
- 属性面板无法展开对象列表；那里的问号和整段 JSON 是显示限制，不是数据损坏。
- 跨作品解释只写在已激活专题；04、作品页「文学意象」区和 `imagery_count` 等派生字段由脚本生成。`05` 是读取这些派生字段的 Base，不要手改。

## 10｜如何使用 IM

- 想看一部作品有哪些意象 → 进入 `40 作品/<作品>.md` 或 [[../../30 专题/IM 文学意象与场景/05 作品意象一览|作品意象一览]]；
- 想看一个意象出现在哪些作品 → [[../../30 专题/IM 文学意象与场景/04 意象关系索引|意象关系索引]]；
- 想研究同一意象在不同作品中如何工作 → 进入已激活专题；
- 想浏览整个 IM → [[../../30 专题/IM 文学意象与场景/00 文学意象与场景|IM 专题阅读入口]]。
