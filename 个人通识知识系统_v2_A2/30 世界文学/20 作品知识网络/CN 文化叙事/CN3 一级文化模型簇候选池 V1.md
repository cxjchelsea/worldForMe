# CN3 一级文化模型簇候选池 V1

> 本池用于决定“哪些问题域值得成为 CN3.x 一级簇”。它管理的是 **cluster candidate**，不是具体文化模型。具体模型仍由 [[CN3 候选文化模型池 V1]] 与各簇内部候选池管理。

## 1. 为什么现在才建一级簇候选池

CN3 已完成两个差异明显的正式模型验证：

- 欧洲骑士英雄模型；
- 侠／江湖英雄模型。

两个样板证明：`角色 + 关系 + 伦理 + 秩序/空间 + 后世重构` 更适合作为每个文化模型内部的固定分析维度，而不是五个平行一级 taxonomy。

因此 CN3 一级簇应回答：

> **一个社会反复把哪一类角色、关系和秩序组织成可持续重写的文化模型世界？**

## 2. 一级簇准入 Gate

每个一级簇候选检查 7 项：

```text
B1 下面至少能容纳多个彼此可区分的具体文化模型
B2 在多个文化/时期中都有稳定可比较的问题域
B3 不能被单一 CN2 component、TH theme、TY genre 或历史专题替代
B4 可以复用 CN3 Cultural Model Template V1
B5 现有 CN1 / CN2 / Work 中已有足够材料可作为初始输入
B6 对实际阅读具有高复用解释价值
B7 边界足够清楚，不会天然成为“什么都能放”的杂物箱
```

建议状态：

```text
ACCEPTED_CLUSTER
READY_FOR_ADMISSION
NEEDS_BOUNDARY
NEEDS_EVIDENCE
DEFERRED
REJECTED
```

## 4. 为什么没有单列“价值伦理”“共同体”“后世应用”

它们当前作为横向分析维度，而不是一级簇：

```text
荣誉 / 忠诚 / 孝 / 贞洁 / 自由 / 正义
→ 在具体文化模型中分析其排序与作用
→ 不单独升为 CN3 一级簇
```

```text
共同体 / 宫廷 / 江湖 / 门派 / 城市 / 边疆
→ 作为秩序与空间维度
→ 只有未来出现无法由角色模型承载的稳定独立对象时才考虑升格
```

```text
后世应用 / 浪漫化 / 民族化 / 商业化 / 全球化
→ 每个正式 CN3 模型都必须处理的生命史维度
→ 不单列 CN3.x
```

## 5. 与其他 Q 轴层的边界

```text
CN2：可复用组件
CN3：具体社会组织出来的文化模型
TH：作品讨论的抽象问题
TY：文学类型及其生产机制
历史：真实制度、阶层和社会运行
```

例如：

```text
“父子冲突” → CN2
“孝是否正当” → TH
“中国父子/孝子文化模型” → CN3
“宗法制度怎样运行” → 历史
```


这里的优先级只表示**下一次需要验证时的顺序**，不要求批量建设。
