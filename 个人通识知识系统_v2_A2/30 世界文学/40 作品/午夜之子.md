# 午夜之子

## TH1.2 位置

- 角色：比较
- 自由维度：自由是否可能；受限处境中的能动性与反抗
- 边界：国家历史与记忆归 TH7/TY7；个人在历史牵引中还能否行动归 TH1.2。

## TH1.1 位置

- 角色：比较
- 主体性维度：自我如何形成；记忆、身体与人格连续性；角色、面具与他者目光
- 比较功能：检验个人自我、家族叙事与国家历史是否可以被清楚拆开。

## TH3.4 位置

- 角色：骨架
- 核心问题：P1 / P3 / P4 / P5 / P6
- 边界：国家历史如何被记住归 TH7；这些历史如何制造“印度是谁、谁属于印度”的民族文化共同体归 TH3.4。

## TH3.5 位置

- 角色：骨架
- 核心问题：P1 / P2 / P3 / P6
- 边界：民族共同体如何被叙述归 TH3.4；分治、边界变化和政治历史如何迫使人物实际迁移归 TH3.5。

## TH7 位置

- 角色：骨架
- 核心问题：P1 / P2 / P3 / P5 / P6
- 边界：国家共同体身份归 TH3.4；历史题材与叙事机制归 TY7；私人/家族/国家过去怎样被记忆和重写归 TH7。
