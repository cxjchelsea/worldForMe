# 作品字段规范

> `40 作品/` 是世界文学作品实体的唯一事实源。本规范只定义作品页如何存储坐标与知识网络关系，不创建第二套作品数据库。

## 1. canonical 字段

```yaml
id: WL-WORK-...
type: work
read_status: 未读 | 在读 | 已读 | 重读

axis_t: []
axis_r: []
axis_m: []
axis_g: []
axis_qh: []
axis_qt: []
axis_source: read_calibrated | inferred

topics: []
topic_links: []

qx: []
qc_relations: []
```

## 2. 坐标字段

`axis_t`、`axis_r`、`axis_m`、`axis_g`、`axis_qh`、`axis_qt` 都是作品定位字段。

- QH = 作品在思考什么问题；
- QT = 作品采用什么类型契约 / 叙事机制；
- 一部作品允许多个 QH / QT；
- 没有依据时留空；
- `axis_source` 仍记录坐标来源。

### legacy `axis_q`

现有大量作品仍把 QH / QT 混存在 `axis_q`。迁移期允许保留，但它只作为兼容字段：

```yaml
axis_q:
  - QT2 科幻
  - QH5 权力、制度与秩序
```

新写入不得继续以 `axis_q` 作为唯一字段。作品被主动校准时，应拆为：

```yaml
axis_qt:
  - QT2 科幻
axis_qh:
  - QH5 权力、制度与秩序
```

在仓库完成覆盖率核验前，不要求批量删除旧 `axis_q`。

## 3. QX：结构化意象抽取

QX 继续使用现行 `qx:` 结构，不降级为标签列表：

```yaml
qx:
  - qx_id: null
    object: 雨
    primary_group: QX1
    salience: core
    function: [氛围塑造, 结构标记]
    evidence:
      - "文本证据说明"
```

只有满足 QX 准入规则的高显著度对象才写入。没有就不写。

## 4. QC：有类型文化叙事关系

推荐结构：

```yaml
qc_relations:
  - target: "QC1.2.3 亚瑟王叙事传统"
    relation: retells
    evidence:
      - "可核查证据"
  - target: "QC2.17 求索、宝物与神圣目标"
    relation: uses
    evidence:
      - "作品结构证据"
```

### canonical relation

```text
retells
adapts
continues
reframes
structural_similarity
uses
foregrounds
transforms
critiques
subverts
reorders
```

必要时可以增加 `source_reference`、`confidence`、`note`，但不能用 `direct_source` 类断言替代证据。

## 5. `topics` 与网络关系不是一回事

- `topics`：机器稳定专题 ID，用于 Base 投影；
- `topic_links`：Obsidian 专题导航；
- `axis_*`：作品定位；
- `qx` / `qc_relations`：作品知识关系。

四类职责不可混用。

## 6. 迁移顺序

```text
新作品 / 新校准：直接写新字段
已有作品：旧字段可读
主动重读 / 校准：axis_q → axis_qh + axis_qt
QX：保持原结构
QC：有证据时才补 qc_relations
最终：覆盖率检查后再决定是否删除 axis_q
```

不得为了完成迁移而给所有作品强制生成 QX / QC。

## 7. 正文展示

作品正文建议把旧“ 五轴坐标 ”标题逐步改为“作品坐标”，并显示 T / R / M / G / QH / QT；QX 与 QC 分别作为“意象关系”和“文化叙事关系”展示，而不是继续合并成 Q 内容。
