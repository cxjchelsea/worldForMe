# 作品字段规范

> `40 作品/` 是世界文学作品实体的唯一事实源。本规范只定义作品页如何存储坐标与知识网络关系，不创建第二套作品数据库。

## 1. canonical 字段

```yaml
id: WL-WORK-...
type: work
read_status: 未读 | 在读 | 已读 | 重读

axis_t: []
axis_r: []
axis_m: []
axis_g: []
axis_th: []
axis_ty: []
axis_source: read_calibrated | inferred

topics: []
topic_links: []

imagery: []
cultural_narrative_relations: []
```

六个作品坐标是 `T / R / M / G / TH / TY`；两个稀疏知识网络是 `IM / CN`。

## 2. 坐标字段

`axis_t`、`axis_r`、`axis_m`、`axis_g`、`axis_th`、`axis_ty` 都是作品定位字段。

- TH = 作品在思考什么问题；
- TY = 作品采用什么类型契约 / 叙事机制；
- 一部作品允许多个 TH / TY；
- 没有依据时留空；
- `axis_source` 仍记录坐标来源。

### legacy `legacy_axis_q`

第二阶段迁移后，旧 Q 合并字段只以 `legacy_axis_q` 保留，供迁移 provenance 与历史审计使用：

```yaml
legacy_axis_q:
  - QT2 科幻
  - QH5 权力、制度与秩序
```

这里故意保留旧 QH/QT 值，表示“迁移前原始数据”，不参与 canonical 坐标检索。

新写入不得再创建 `axis_q`、`axis_qh` 或 `axis_qt`。

## 3. IM：结构化意象抽取

IM 使用 canonical `imagery:` 结构，不降级为标签列表：

```yaml
imagery:
  - im_id: null
    object: 雨
    primary_group: IM1
    salience: core
    function: [氛围塑造, 结构标记]
    evidence:
      - "文本证据说明"
```

只有满足 IM 准入规则的高显著度对象才写入。没有就不写。

历史字段 `qx` 与 `qx_count` 已退出 canonical；计数如需展示应由 `imagery` 派生，而不是维护第二事实源。

## 4. CN：有类型文化叙事关系

推荐结构：

```yaml
cultural_narrative_relations:
  - target: "CN1.2.3 亚瑟王叙事传统"
    relation: retells
    evidence:
      - "可核查证据"
  - target: "CN2.17 求索、宝物与神圣目标"
    relation: uses
    evidence:
      - "作品结构证据"
```

### canonical relation

```text
retells
adapts
continues
reframes
structural_similarity
uses
foregrounds
transforms
critiques
subverts
reorders
```

必要时可以增加 `source_reference`、`confidence`、`note`，但不能用 `direct_source` 类断言替代证据。

历史字段 `qc_relations` 已退出 canonical。

## 5. `topics` 与网络关系不是一回事

- `topics`：机器稳定专题 ID，用于 Base 投影；
- `topic_links`：Obsidian 专题导航；
- `axis_*`：作品定位；
- `imagery` / `cultural_narrative_relations`：作品知识关系。

四类职责不可混用。

## 6. 命名空间

```text
A. 作品坐标系统
T   时间
R   地域
M   思潮 / 美学
G   体裁
TH  主题
TY  类型 / 叙事机制

B. 作品知识网络
IM  意象
CN  文化叙事
```

旧映射仅用于历史理解：

```text
QH -> TH
QT -> TY
QX -> IM
QC -> CN
```

新内容不得继续建立 QH / QT / QX / QC canonical code。

## 7. 迁移与兼容原则

- `legacy_axis_q` 只保留迁移前原始 Q 值；
- 节点通过 `legacy_code` / `legacy_codes`、`legacy_id` 保留旧编号 provenance；
- 不保留旧 `10 轴/`、`20 节点/` 物理目录作为第二套主结构；
- 不为了迁移强制生成 IM / CN；
- 不新增或合并任何 taxonomy 概念。

## 8. 正文展示

作品正文使用“作品坐标”显示 T / R / M / G / TH / TY；IM 与 CN 分别作为“意象关系”和“文化叙事关系”展示，不再合并成 Q 内容。
