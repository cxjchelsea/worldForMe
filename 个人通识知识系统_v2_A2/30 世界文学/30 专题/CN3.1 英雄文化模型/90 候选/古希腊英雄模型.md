# 古希腊英雄模型｜READY_FOR_ADMISSION

## 候选定位

研究古希腊叙事如何围绕战功、荣誉、命运、家族、神人关系和共同体评价组织英雄身份，并追踪这一模型在后世古典接受中的持续重写。

## Admission Gate

```text
A1 历史社会基底 = PASS
A2 稳定角色/关系/伦理/空间 = PASS
A3 跨时期叙事生命 = PASS
A4 超出单一 component / genre = PASS
A5 CN1/CN2/Work 可连接 = PASS
A6 现实 vs 文化神话可比较 = PASS
```

## 重点边界

- 不把“英雄旅程”当作古希腊英雄模型本身；
- 不把荷马英雄伦理直接等同于整个古希腊社会真实伦理；
- CN1 负责特洛伊等具体传统的文本生命史；CN2 负责荣誉、命运、复仇、归乡等组件；CN3 研究这些内容如何共同构成英雄文化模型。
