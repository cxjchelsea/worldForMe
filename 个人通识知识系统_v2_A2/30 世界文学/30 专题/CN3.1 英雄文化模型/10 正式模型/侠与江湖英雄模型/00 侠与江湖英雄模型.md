# 侠／江湖英雄模型

> **一句话理解：**“侠”不是简单的会武功者，“江湖”也不是普通地点。这个模型研究中国叙事如何把个人能力、义、承诺、报恩复仇、师徒门派、私人正义、国家法与法外空间组织成一种长期可重写的英雄文化世界。

## 1. 为什么这是 CN3，而不只是“武侠”类型

```text
武侠小说怎样形成、有哪些类型机制
→ TY

“侠”怎样成为一种稳定的角色期待，
“义”怎样约束行动，
“江湖”怎样形成与国家法并置的关系空间，
后世为什么不断重新发明这种角色与秩序
→ CN3
```

因此：

```text
侠／江湖英雄模型
≠ 武侠小说史
≠ 历史上的游侠阶层史
≠ 所有使用武功的角色
≠ 抽象的“正义”主题
```

## 2. 角色模型

核心角色并不是单一“侠客”，而是一组相互定义的角色位置：

- **侠客／游侠**：以个人能力承担超出日常秩序的行动责任；
- **师父／门派前辈**：传递技艺、规范与身份；
- **同道／结义者**：通过承诺、恩义或共同风险形成关系；
- **官府／国家权力代表**：合法暴力与正式秩序的来源；
- **豪强／恶霸／权力滥用者**：使“私人介入”获得叙事正当性的常见压力来源；
- **法外共同体成员**：当正式秩序失效或冲突时形成替代关系网络。

CN3 关心的不是这些人物是否历史上普遍存在，而是文学如何反复让这些角色位置彼此定义。

## 3. 关系模型

### 3.1 义与承诺

“义”不是单一抽象价值，而是在关系中起作用：

```text
受恩 → 必须报恩
结义 → 形成超越普通交往的义务
承诺 → 即使代价升高也不能轻易撤回
受辱／受害 → 可能形成复仇或主持公道的责任
```

### 3.2 师徒与门派

师承既传递能力，也传递身份与伦理。门派则把私人关系扩大为半制度化共同体：

```text
技艺
+
谱系
+
纪律
+
声望
+
内部权力
```

因此“江湖”不是无组织的自由世界。

### 3.3 侠与国家法

这是该模型最重要的张力之一：

```text
正式法律不足／被权力扭曲
        ↓
私人正义介入
        ↓
侠获得道德正当性
        ↓
但私人暴力本身又挑战国家合法秩序
```

不同作品会给出不同解决方式：吸纳、招安、合作、退出、对抗或彻底保持距离。

## 4. 伦理模型

当前最稳定的伦理轴不是“武功高低”，而是：

| 伦理轴 | 核心问题 |
|---|---|
| 义 | 对谁负有不能轻易撤销的责任？ |
| 信／诺 | 承诺是否高于个人利益？ |
| 报恩 | 接受恩惠是否形成长期义务？ |
| 复仇 | 私人报复什么时候被叙事视为正当？ |
| 公道 | 当正式法不能实现正义时谁可以行动？ |
| 家国 | 私人江湖义务何时需要让位于更大共同体？ |
| 自由 | 退出权力与组织是否可能？ |

这些不是 CN3 自己发明的抽象 theme；CN3 研究的是它们如何在“侠／江湖”模型中被具体排序。

## 5. 江湖：关系空间而不是地理空间

“江湖”在不同文本中的表现并不完全相同，但其高复用功能通常包括：

- 正式官僚秩序之外的人际网络；
- 门派、师徒、结义、仇怨与声名传播的关系空间；
- 允许人物跨地域流动和重新获得身份的行动空间；
- 与“庙堂／朝廷／官府”形成可对照但并非绝对隔绝的秩序层。

所以 CN3 不把江湖理解为固定地图，而是：

> **一种由关系、声望、能力与非正式规范维持的叙事社会空间。**

### 历史条件

只调用必要解释条件：

- 国家法与基层治理的历史差异；
- 士、民、武人及地方社会关系；
- 交通、商业、城市与跨地域流动；
- 说唱、章回、报刊连载等传播条件；
- 近现代民族国家与大众传媒环境。

真实制度史仍由历史领域维护。

## 7. 五个作品锚点怎样观察模型变化

| 作品 | CN3 观察重点 | 优先级 |
|---|---|---|
| 《史记》 | 早期游侠／侠义角色观念与国家秩序张力 | ◆ |
| 《水浒传》 | 法外共同体、义、官府冲突与招安 | ★ |
| 《三侠五义》 | 侠义角色如何与司法／国家秩序重新结合 | ★ |
| 《射雕英雄传》 | 现代武侠中的师承、江湖、侠义与家国重组 | ★ |
| 《笑傲江湖》 | 门派权力、组织纪律、自由与江湖秩序的反思 | ★ |

这些作品不是“侠文学完整书目”，而是当前最能覆盖文化模型关键变化的阅读锚点。

## 8. 一个非常重要的变化：法外并不等于反国家

侠／江湖模型内部存在多种路线：

```text
私人正义 → 与官府对立
私人正义 → 被国家吸纳
侠义能力 → 协助正式秩序
江湖身份 → 承担家国责任
个人自由 → 拒绝国家和门派双重权力
```

因此不能把“侠”简单定义成反体制人物。

## 9. 与欧洲骑士模型的对照

| 维度 | 欧洲骑士 | 侠／江湖 |
|---|---|---|
| 主要正当性来源 | 主君、荣誉、宫廷／宗教秩序 | 义、承诺、公道、个人判断 |
| 组织位置 | 较强地嵌入等级共同体 | 可嵌入门派，也可保持游离 |
| 典型空间 | 宫廷、战场、道路、圣地 | 江湖、门派、旅途、城镇、法外据点 |
| 与国家关系 | 常处于统治秩序内部 | 合作、吸纳、冲突、退出皆可 |
| 核心风险 | 忠诚冲突、荣誉失败、共同体崩解 | 私人正义失控、恩仇循环、组织权力化 |

这说明 CN3 模板并不依赖“封建欧洲”结构，也能解释不同社会条件下的英雄文化模型。

## 10. 后世重构

当前只冻结重构机制，不做作品百科：

```text
史传中的侠／游侠形象
→ 通俗叙事与绿林／侠义传统
→ 近现代武侠类型成熟
→ 金庸等综合重构
→ 电影、电视剧、漫画、游戏中的江湖模型
```

这里表示文化模型的再组织路径，不声称所有阶段存在单线直接文本传承。
