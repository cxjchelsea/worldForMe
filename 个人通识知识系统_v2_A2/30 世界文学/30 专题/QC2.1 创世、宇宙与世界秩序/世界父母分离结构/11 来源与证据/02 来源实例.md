# 02 来源实例

本页只记录来源实例如何匹配 P1 的四个 core slots；跨传统匹配不自动证明传播。

## Māori｜Rangi / Papa

建议匹配：`FULL_MATCH`

```text
S1 Rangi 与 Papa 紧密结合
→ S2 子代处于黑暗、拥挤或受压状态
→ S3 子代讨论并实施分离父母
→ S4 天地拉开，光与世界空间出现
```

`source_status: external_source_verified_text_only`

## 埃及｜Nut / Geb / Shu

建议匹配：`FULL_OR_NEAR_FULL_MATCH`

```text
S1 Nut 与 Geb 处于紧密天地结合
→ S2 世界空间尚未展开／后代神系处于受限宇宙状态
→ S3 Shu 将 Nut 抬起、使天地分离
→ S4 天空与大地分置，宇宙空间稳定
```

`source_status: external_source_verified_text_only`

治理注意：不同埃及文本、图像与后世概述对“offspring constrained”的叙述强度并不完全一致，因此正式记录中不把所有版本都强写成同一细节。

## 希腊｜Gaia / Ouranos / Kronos

建议匹配：`STRONG_VARIANT`

```text
S1 Gaia / Ouranos 形成紧密天地—父母结构
→ S2 Ouranos 压制／隐藏后代
→ S3 Gaia 谋划，Kronos 实施断裂行动
→ S4 父辈天空权力结构被不可逆打断，天地关系重组
```

`source_status: reference_topic`

希腊实例的 S4 不应机械写成与 Māori 完全相同的“物理空间被拉开”；它更接近天地父母关系与代际宇宙秩序的断裂重组，因此作为 strong variant 更稳妥。

## 跨传统结论

```text
Māori = full match
Egyptian = full / near-full match
Greek = strong variant
```

这足以支持 P1 作为独立 plot_pattern，而不是某一个传统的故事摘要。
