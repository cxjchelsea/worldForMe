# 01 定义、边界与结构准入

## 最小定义

“世界父母分离结构”不是“天地分离”的同义词，而是一条带有角色关系、顺序和因果压力的 plot pattern：

```text
世界父母紧密结合
→ 后代／生命处于受限空间
→ 后代或分离者实施分离
→ 天地展开并形成世界空间
```

## Core slots

```text
S1 world_parents_joined
S2 offspring_constrained
S3 separation_action
S4 cosmic_space_opened
```

只有四个槽位都存在，或 S2/S4 以功能等价形式明确出现时，才进入 full / strong match。

## 与 motif 的边界

```text
天地分离 motif
= 未分／贴合 → 分离 → 世界空间形成

世界父母分离 plot_pattern
= 父母身份 + 后代受限 + 分离行动 + 空间展开的顺序结构
```

因此：

```text
P1 full match → usually carries M2
M2 instance ↛ necessarily P1
```

盘古式天地开辟可属于 M2，但若缺少 world parents / offspring constraint，则不属于 P1。

## 与 archetype / theme 的边界

- “天地分离者”若只是 S3 的 agent slot，不自动形成 archetype；
- “代际冲突”“从压抑到自由”“秩序建立”属于主题或解释层，不是 plot pattern 本身；
- “父杀／子反抗”不是 required slot。
