# 08 后世变形与反结构

P1 的后世变形可以沿“删减／替换 core slot”理解，而不是把任何家庭冲突都视作本结构重写。

## 常见变形方向

```text
删除 S2 offspring_constrained
→ 只保留 world parents + separation

弱化 S1 world-parent identity
→ 天／地从亲属角色退化为抽象宇宙域

改变 S3 separation_action
→ 暴力断裂 / 支撑抬升 / 自发分离 / 仪式化分离

改变 S4 terminal state
→ 永久分离 / 被中介支撑 / 进入新的代际宇宙秩序
```

## 反结构候选

```text
separated cosmic parents → reunion / collapse
```

只有作品真正以 P1 顺序为参照并发生结构性倒置时，才考虑 `plot_pattern_inversion`；普通“天地重新合并”不自动构成反结构关系。
