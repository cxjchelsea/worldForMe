## 1. 研究问题

本轮不是判断“多个创世故事里有没有蛋”，而是判断：

> **“宇宙卵”是否已经超出单一情节中的容器／比喻功能，在跨文本、跨传统、跨时代与跨媒介接受中形成稳定、可识别的文化意义族，从而满足 QC2 V1 的 symbol 准入。**

冻结边界：

```text
source object / image
≠ source-story function
≠ later cultural symbol
```

## 2. Source-object 层

### 2.1 Orphic / Greek

Orphic cosmogony 中，world egg 不是普通道具：Phanes 从 cosmic egg 中诞生；后出的材料继续把 egg 与宇宙整体、天地分化、生命生成联系起来。

本层可支持：

```text
primordial container
cosmic generation
undifferentiated totality
birth of life / order
```

来源状态：

```text
QC1.1.2 Greek–Roman reference topic exists
但 Orphic material 仍需单独 source-story/text indexing
→ reference_topic_source_story_pending_index
```

### 2.2 Hindu / Brahmāṇḍa tradition

Vedic / Upanishadic 后续宇宙论把 cosmic egg / brahmāṇḍa 发展为可持续的宇宙模型：卵裂为天地，并在后续 Hindu cosmology 中继续被展开。

这不是一次性故事细节，而是长时段文本传统中的稳定宇宙表征。

来源状态：

```text
QC1.1.6 India reference topic exists
具体文本尚需回填
→ reference_topic_source_story_pending_index
```

### 2.3 Chinese Pangu material

徐整《三五历纪》经《艺文类聚》保存：

```text
天地混沌如鸡子
→ 盘古生其中
→ 天地开辟
```

但治理上必须降级处理：

```text
“如鸡子”
= strong supporting analogy / cosmogonic image
≠ 当前即可证明存在一套独立成熟的 Chinese cosmic-egg symbol tradition
```

因此中国材料支持“卵形未分化宇宙”这个意义族的跨传统可识别性，但不单独承担 symbol 准入。

来源状态：

```text
external_source_verified_text_only
```

## 3. Later symbol / reception 层

关键问题是：宇宙卵是否脱离原始创世情节后仍被以稳定语义调用。

现代艺术材料给出正面证据。

André Masson 的一组作品直接以 `The Cosmic Egg` 为核心，并以 egg 表达：

```text
germination
gestating energy
imminent metamorphosis
nature as generative totality
```

这与古代来源中的“未分化整体 / 生成容器 / 宇宙孕育”并非同一情节，却保持了明显可识别的意义连续。

因此：

```text
literal creation story continuity
= NOT_REQUIRED

semantic family continuity
= SUPPORTED
```

---

## 4. Stable meanings

当前可准入的 stable meaning family：

```text
SM1 primordial_totality
= 尚未分化、但包含未来世界可能性的整体

SM2 generative_potential
= 生命、秩序、形态尚未展开但正在孕育的潜能

SM3 gestation_and_birth_of_cosmos
= 宇宙／生命从封闭孕育状态中诞生

SM4 unity_to_differentiation
= 一个统一整体裂变／展开为多样的天地、生命或结构
```

不是所有实例都必须同时拥有四项。

---

## 5. Meaning shifts

当前可辨识的主要漂移：

```text
ancient cosmogony
→ literal / mythic container of cosmos or primordial being

philosophical-cosmological abstraction
→ universe-as-enclosed-totality / brahmāṇḍa

modern art
→ germination / creative energy / embryonic transformation / metamorphosis
```

因此：

```text
meaning_shift
≠ symbol continuity broken
```

相反，现代语义仍围绕“封闭整体中的生成潜能”这一中心族展开。
