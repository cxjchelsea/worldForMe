>
> Purpose: 在 M5 Earth-diver 补齐唯一 targeted component gap 后，判断该问题域是否可阶段性冻结内容扩张。
>
> Freeze ≠ 永久关闭研究；Freeze = 不再因“还有候选”而机械新增重型 component。

## 2. Core Problem Coverage

QC2.1 的问题域是：世界如何从尚未成形／尚未分化的状态进入具有天地、空间、材料、方向与可居住结构的宇宙。

六个 active components 已分别覆盖：

```text
天地分离
→ world-space via separation

世界父母分离结构
→ ordered parent-offspring separation sequence

宇宙卵
→ primordial totality / generative enclosure / differentiation symbol

身体化为世界
→ cosmic material via bodily transformation

世界树／宇宙树
→ cosmic-axis / multi-realm spatial organization

Earth-diver
→ land material via underwater retrieval and expansion / formation
```

因此当前不是同义专题堆叠，而是具有独立解释价值的机制／结构／符号组合。

```text
QC2.1_CORE_PROBLEM_COVERAGE = SUFFICIENT
```

## 6. Reading Coverage vs Component Coverage

Stage Freeze 不意味着阅读路线只读六个 component 的 source texts。

必须继续保留：

```text
component coverage
≠ reading coverage
```

尤其：

- Hebrew Genesis 1 的言说／命名与定序；
- primordial waters；
- creator / orderer figures；
- cosmic mountain；
- cosmic-combat variants；

都可作为比较阅读进入问题域，而无需为每一项创建独立重型 component。

## 9. Reopen Triggers

Stage Freeze 后，仅在以下情况之一成立时重开 QC2.1 component expansion：

1. 出现一种无法由现有六个 component 或阅读层解释的高价值创世机制；
2. M4 获得至少两个独立传统的强完整来源，证明其为稳定 motif 而非单一神学机制；
3. P2 获得第二个高质量 full-sequence witness，形成独立 plot-pattern 查询价值；
4. A1/A2 出现稳定跨故事 core functions，超出 creator / agent slot；
5. S2/S4 获得充分跨时代／跨媒介 symbol continuity，并证明对现有 S1/S3 有显著增量价值；
6. 新研究证据推翻现有 component 类型边界或 required invariants；
7. 学习实践证明现有地图存在明确、重复出现的查询缺口。

“不够多”“四种类型没有齐全”“某个候选很著名”都不是 reopen trigger。
