# QC2.1｜S3 世界树／宇宙树｜Symbol Admission Research

> 状态：`PASS / PROMOTE_TO_TOPIC_BUILD_QUEUE`
>
> 基线：`QC2_SYMBOL_TEMPLATE_V1_FROZEN`
>
> 目标：判断“世界树／宇宙树”是否已经超出普通 sacred tree / tree of life / genealogical tree，形成可独立建设的 `symbol` component。

---

## 1. Candidate

工作名：

```text
世界树／宇宙树
World Tree / Cosmic Tree
```

候选对象不是“神圣的树”这一宽泛宗教意象，而是：

> **以树形对象承担宇宙空间组织功能：连接上下宇宙域、标定世界中心、贯穿或支撑多层世界，并在后世仍以可识别的 cosmic/world-tree 身份被复用。**

因此候选判断重点不是：

```text
树是否神圣
树是否象征生命
树是否出现在创世故事
```

而是：

```text
树是否成为宇宙结构本身的可识别符号化模型
```

---

## 2. Symbol Admission Gate

按照 Symbol Template V1，需要证明：

```text
source object / image
≠ source-story function
≠ later cultural symbol
```

S3 准入需要同时满足：

1. 超出单一情节中的植物／神树功能；
2. 在多个传统中稳定承担宇宙空间组织功能；
3. 至少形成可识别的稳定意义族；
4. 存在跨时代／跨媒介明确复用，而不只是现代比较神话学标签；
5. sacred tree / tree of life / genealogical tree 边界可操作。

---

## 3. 强来源一｜Maya World Tree

Smithsonian National Museum of the American Indian 的 Maya 资料明确将：

```text
World Tree / Tree of Life
→ axis mundi
→ connection between Earth and sky
```

并进一步说明 ceiba 在 Maya 传统中连接：

```text
Underworld
terrestrial realm
skies
```

这提供了 S3 最核心的垂直宇宙连接证据。

Met Museum 的 Maya 文物说明进一步显示：

```text
四棵树 → 世界四角
第五棵树 → 世界中心
world tree → axis mundi
roots → Underworld
branches → heavens
```

也就是说，Maya world tree 不只是“神圣植物”，而直接参与：

```text
cosmic_center
+
vertical_cosmic_connection
+
ordered_world_space
```

因此：

`MAYA_WORLD_TREE = STRONG_SOURCE_INSTANCE`

---

## 4. 强来源二｜Norse Yggdrasil

Old Norse 来源传统中的 Yggdrasil 是另一种高匹配 world-tree 实例。

Eddic / Snorri tradition 中：

```text
Yggdrasil = immense ash / world tree
roots extend toward different cosmic regions
branches / roots organize relationships between realms
gods assemble in relation to the tree
```

现代资料常把“九世界全部像地图一样挂在树上”画得过度具体，因此本研究不把现代九界图直接反投射为中世纪来源内容。

可稳定使用的历史功能是：

```text
cosmic connectivity
multi-realm linkage
cosmic centrality / world structure
continuity under cosmic stress
```

而不是把“Tree of Life”当作 Old Norse 原名或唯一含义。

因此：

`YGGDRASIL = STRONG_SOURCE_INSTANCE`

治理：

```text
Yggdrasil
≠ generic Tree of Life
≠ modern nine-world infographic
```

---

## 5. 第三压力点｜Sentani Cosmic Tree

Met Museum 的 Lake Sentani house post 说明指出：

- Sentani 传统中的 inverted tree 可能指向宗教中的 cosmic tree；
- 该 cosmic tree 被描述为从 heavens 向 earth 生长。

这一来源的重要性不在于证明与 Maya / Norse 之间有传播链，而在于显示：

```text
树形 cosmic connector
```

可以在彼此无须预设直接关系的传统中承担类似宇宙连接功能。

因此：

`SENTANI_COSMIC_TREE = SUPPORTING_CROSS_TRADITION_INSTANCE`

默认关系：

`independent_or_unknown`

而不是 `historical_transmission`。

---

## 6. 后世明确复用｜Anselm Kiefer, Yggdrasil

Met Museum 收藏的 Anselm Kiefer《Yggdrasil》（约 1980）提供了非常重要的后世 explicit reuse 证据。

Met 的作品说明直接将作品标题与 Old Norse Edda 中的 Yggdrasil 对接，并指出 Kiefer：

- 将自己呈现为这棵树；
- 加入与 Yggdrasil 相关的动物；
- 将该对象继续用于 transformation / growth / decay / human evolution 等主题。

因此这里不是：

```text
一棵现代作品中的普通树
```

而是：

```text
named Yggdrasil
+
explicit source reference
+
modern visual reuse
+
semantic extension
```

可作为 S3 的跨时代／跨媒介 admission evidence。

关系候选：

```text
relation_type: symbol_reuse
or explicit_reference

evidence_level: documented
```

正式 topic build 时再决定 work record 的原子 relation type。

## 7. Stable Meanings

跨来源比较后，可以稳定压缩为三个核心意义族。

### SM1｜vertical_cosmic_connection

树的根、干、枝将不同垂直宇宙域连接起来：

```text
underworld / below
↕
earth / human realm
↕
heaven / upper realm
```

这是最稳定的 world-tree 判断条件。

### SM2｜cosmic_center_or_axis

树不只是连接两个地点，而承担：

```text
world center
axis mundi
cosmic pillar / orientation point
```

Maya 材料对这一点尤其强。

### SM3｜ordered_multi_realm_world

树形结构使多个宇宙层级／区域形成可理解、可定位、可联系的整体。

即：

```text
tree form
→ spatial relation between cosmic domains
```

而不仅是树本身“有生命”。

---

## 8. Later / Variable Meanings

以下意义在部分传统或后世接受中很重要，但暂不提升为所有 world-tree 实例必须共享的 stable meaning：

```text
life_and_regeneration
fate_and_cosmic_maintenance
knowledge_and_sacrifice
royal_legitimacy
resurrection
interdependence
vulnerability_and_decay
```

例如：

- Yggdrasil 与命运、Odin、宇宙受损相关；
- Maya world tree 可与王权、死后上升、中心政治秩序结合；
- Kiefer 将 Yggdrasil 推向 transformation / growth / decay。

这些应进入：

```text
later_meanings
contested_meanings
meaning_shifts
```

而不是全部塞进 `stable_meanings`。

---

## 9. Critical Boundary｜world tree ≠ sacred tree

### A. Sacred tree

一棵树可以因为神祇居住、祖先纪念、祭祀、禁忌或地方传统而神圣。

但如果没有明确宇宙空间组织功能：

`NOT_SUFFICIENT_FOR_S3`

### B. Tree of Life

“生命树”可能主要表达：

```text
生命
繁衍
长生
复活
丰饶
```

这些意义可以与 world tree 重叠，但不是同一概念。

因此：

```text
world tree
may overlap Tree of Life
but world tree ≠ Tree of Life by default
```

### C. Genealogical tree

族谱树／family tree 用树形表达血缘分支，不承担宇宙空间轴功能。

`EXCLUDE`

### D. Ordinary giant tree

巨大、古老或贯穿画面的树，不自动成为 cosmic tree。

必须有独立证据支持：

```text
cosmic_center
vertical_realm_connection
cosmic_spatial_order
```


也不是 archetype：
