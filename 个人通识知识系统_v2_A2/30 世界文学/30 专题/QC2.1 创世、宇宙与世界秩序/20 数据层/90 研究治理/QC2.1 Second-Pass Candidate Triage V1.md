## 2. 第一优先：M3｜原初存在的身体化为世界

**结论：`NEXT_ADMISSION_RESEARCH_TARGET / VERY_HIGH`**

工作定义：

```text
存在具有身体的原初存在
+
该存在死亡／被杀／被肢解／发生不可逆身体转化
+
身体部位成为天地、地貌、水系、天体或其他宇宙结构
```

### 证据成熟度

强来源候选：

```text
Tiamat / Enuma Elish
Ymir / Norse cosmogony
Purusha / Rigveda 10.90
Pangu / Chinese reception tradition
```

其中 Tiamat 与 Ymir 都明确呈现“身体部位 → 世界材料”的映射；它们还证明：

```text
body-to-world motif
≠ cosmic combat
```

因为 Tiamat 版本以战斗和尸体创世实现，而 Ymir 版本虽有杀戮，却拥有不同角色结构与宇宙组织方式。

### 增量价值

M3 能补充当前体系尚未覆盖的一种创世机制：

```text
M2 天地分离
→ 空间通过“分开”产生

M3 身体化为世界
→ 空间／自然结构通过“身体材料转化”产生
```

它也能为未来 P2「原初敌对体→击败→肢解→身体造世界→定序」提供 motif 端点，但不会提前创建 relation。

### 风险控制

不得把：

```text
任何死亡神祇
任何牺牲
任何尸体变自然物
```

自动纳入。必须满足“身体转化直接承担世界／宇宙结构生成”。

## 3. 第二优先：S3｜世界树／宇宙树

**结论：`SYMBOL_ADMISSION_RESEARCH_QUEUE / HIGH`**

候选稳定意义：

```text
axis_mundi
vertical_cosmic_connection
cosmic_center
ordered_world_space
life_and_cosmos_homology
```

Maya 材料已经显示世界树可承担：

```text
四方 + 中心
天空与大地分离
world center / axis mundi
```

这说明它不是单纯 sacred tree。

但正式准入前必须区分：

```text
world tree / cosmic tree
≠ sacred tree
≠ tree of life
≠ genealogical tree
```

并需要至少一条跨时代或跨媒介 symbol reuse 链，不能只凭多个文明都出现“树”。

## 4. 第三优先：M6｜从宇宙卵中创生

**结论：`DEFER / VALID_MOTIF_CANDIDATE`**

S1「宇宙卵」正式建成后，M6 的边界已经更清楚：

```text
S1 symbol
= 卵持续意味着什么

M6 motif
= 原初卵 → 破裂／孵化 → 神祇／天地／宇宙生成
```

M6 仍然是有效 motif candidate，但当前增量价值低于 M3：大量核心来源材料已在 S1 中被记录，若立即另建，容易造成来源与阅读层重复。

准入研究应等：

- S1 运行一段时间后确认确有独立叙事查询需求；或
- 出现足够多“不以宇宙卵稳定符号义为重点、但共享卵生宇宙事件”的来源实例。

因此：

`VALID_BUT_NOT_NEXT_BUILD`。

## 5. M1｜原初未分化 → 宇宙秩序形成

**结论：`DEMOTE_FROM_COMPONENT_BUILD / UMBRELLA_NAVIGATION_CONCEPT`**

第一轮曾标为 HIGH，但第二轮结合已建 components 后，发现它与 QC2.1 问题域本身高度同构：

```text
未分化
→ 分化／定序
→ 可辨识宇宙
```

几乎就是“创世、宇宙与世界秩序”的导航定义。

风险：

```text
problem-domain container
≈ M1 component
```

会导致容器与 component 重复。

因此暂不建重型专题。M1 作为：

```text
umbrella navigation concept
comparative cosmogony frame
```

保留在问题域主页与阅读路线中即可。

只有未来能提出比问题域更窄、可独立核验的 invariants，才重新开启 admission research。

## 6. A1｜宇宙定序者／造物者

**结论：`HOLD / TOO_BROAD_AS_ARCHETYPE`**

当前定义仍容易退化成：

```text

```

这不是稳定 archetype。

需要先证明一种更具体的跨故事角色功能，例如：

```text

而是为已存在的混沌世界划分空间、时间、职能和边界
```

并证明该功能在多个角色中稳定重复。

在此之前不建。
