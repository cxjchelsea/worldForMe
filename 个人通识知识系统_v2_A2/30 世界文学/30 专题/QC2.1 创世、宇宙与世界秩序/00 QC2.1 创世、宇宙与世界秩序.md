# QC2.1 创世、宇宙与世界秩序

> **一句话理解：**不同文化如何解释“一个还没有稳定结构的世界，怎样变成我们能够辨认的天地、陆地、宇宙层级与世界秩序”。

这里不是把所有“创世神话”堆在一起，而是把其中能够跨传统重复辨认、并且具有独立解释价值的**叙事组件**拆出来比较。

---

# 1. 这个问题域关心什么？

QC2.1 主要关心四类问题：

1. **世界怎样被分开？**——例如天地从未分状态变成上下空间；
2. **世界由什么生成？**——例如原初存在的身体转化为山川、天体与世界结构；
3. **陆地怎样出现？**——例如从原初水域下潜取土并形成大地；
4. **人怎样想象宇宙的整体结构？**——例如宇宙卵、世界树这样的文化符号。

因此：

```text
QC2.1
≠ “创世”这个抽象主题
≠ 世界各地创世神话百科
≠ 所有宇宙意象的收集箱
```

它只保留当前真正具有高复用解释价值的 component。

---

# 2. 当前核心组件

## 母题 Motif

### [[天地分离/00 天地分离|天地分离]]

世界最初处于天地／上下宇宙域未充分分离的状态，经过明确分化之后，才出现可辨认的世界空间。

**你可以用它理解：**为什么许多创世故事首先不是“创造东西”，而是“把原本混在一起的世界分开”。

### [[原初存在的身体化为世界/00 原初存在的身体化为世界|原初存在的身体化为世界]]

一个具有身体的原初存在，经死亡、牺牲、杀戮、肢解或其他不可逆转化，其身体成为天地、山川、天体、水系或其他世界结构。

**你可以用它比较：**Tiamat、Ymir、Puruṣa、盘古后世尸体化生叙事之间哪些相似，哪些并不意味着直接传播。

### [[Earth-diver 潜水取土创世/00 Earth-diver 潜水取土创世|Earth-diver / 潜水取土创世]]

在尚无稳定陆地的水世界中，行动者潜入水下取得泥土／沙土等材料，这些材料直接成为或扩展为陆地。

**核心不是“有水”或“有动物”，而是“潜水取土 → 陆地形成”的因果机制。**

---

## 叙事结构 Plot Pattern

### [[世界父母分离结构/00 世界父母分离结构|世界父母分离结构]]

```text
世界父母紧密结合
→ 后代／生命受到压迫或限制
→ 发生分离行动
→ 天地空间展开
```

它比“天地分离”更严格，因为这里不仅要发生分离，还要求一套稳定的角色关系与事件顺序。

当前已经建立正式关系：

```text
世界父母分离结构
→ carries_motif
→ 天地分离
```

---

## 意象／符号 Symbol

### [[宇宙卵/00 宇宙卵|宇宙卵]]

“卵”从创世叙事中的具体原初容器，发展为表达：

- 未分化整体；
- 生成潜能；
- 宇宙孕育；
- 从“一”向“多”分化；

的稳定文化符号。

### [[世界树宇宙树/00 世界树宇宙树|世界树／宇宙树]]

树不只是“生命”的象征，而是在一部分传统中承担：

- 连接不同宇宙层级；
- 标定世界中心；
- 组织多层世界；

的宇宙空间功能。

---

## 文化原型 Archetype

**当前没有必须独立建立的 archetype。**

“造物者”“开辟者”“天地分离者”等角色目前更适合作为具体 motif / plot pattern 中的行动者槽位，而不是为了四类齐全强行升格成独立原型。

# 3. 六个组件之间是什么关系？

可以先用下面这张认知图理解：

```text
                创世、宇宙与世界秩序
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
   世界被分开         世界由材料生成       世界如何被想象
       │                 │                 │
   天地分离        身体化为世界        宇宙卵
       │                 │             世界树
世界父母分离结构     潜水取土创世
```

注意：它们不是六种“完整创世神话类型”，而是六个可以在不同传统中独立出现、组合或变体化的 component。

当前只有一条达到正式关系门槛的跨类型关系：

```text
世界父母分离结构
→ carries_motif
→ 天地分离
```

其余对象即使可以共现，也不为了网络看起来更密而强行连线。

# 5. 具体叙事传统：QC1.2 在这里做什么？

QC1.2 负责回答：

> **某个 component 是否在一个有名称、有文本生命的具体故事／人物／循环／集合传统中被稳定组织、定型或持续改写？**

QC2.1 当前六个 component 主要由跨文化创世来源材料直接支撑，**目前没有必须依赖现有 QC1.2.1–QC1.2.4 才能成立的正式映射。**

这是合法状态，不需要为了“让 QC1.2 也出现”而强建连接。

未来如果例如某个具体 narrative tradition 长期稳定承载“世界树”“身体造世界”或某种创世结构，再建立：

```text
QC1.2 narrative tradition
→ carries / transforms / stabilizes
→ QC2 component
```

因此 QC2 的输入允许：

```text
QC1.1 → QC2
QC1.2 → QC2
QC1.1 + QC1.2 → QC2
```

而不是强制 `QC1.1 → QC1.2 → QC2`。

# 6. 典型来源材料与阅读入口

如果只是想理解 QC2.1，不需要把所有来源全文读完。可以围绕六个 component 选择代表性材料：

- **世界树**：Yggdrasil、Maya world tree 等。
