# 6. Reopen Gate

只有以下情况重开重型 component expansion：

1. 真实阅读中反复出现现有六个 component 无法解释的问题；
2. 新候选获得跨传统强证据，并具有明显独立解释价值；
3. 新研究推翻现有 required invariants / type boundaries；
4. QC1.1 / QC1.2 回填后暴露稳定但目前缺失的 component 类型；
5. 第二个同类问题域压力测试证明现有 cluster/component 模型不足。

不因“候选还很多”自动 reopen。
