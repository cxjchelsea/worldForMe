# 05 文本、视觉与媒介证据

## Maya

证据类型：`textual + visual/material`

重点不是单纯出现树，而是树与 underworld / terrestrial realm / sky、四方与中心的宇宙组织关系。

## Norse / Yggdrasil

证据类型：`textual`

Yggdrasil 在北欧宇宙论中承担世界层级连接与结构组织。现代图示可以帮助理解，但不得反向替代中古文本证据。

## Sentani

证据类型：`material + ethnographic description`

cosmic tree 作为 house-post imagery 的宇宙连接意义，为跨文化压力测试提供独立支持。

## Anselm Kiefer

证据类型：`visual + explicit named reference`

作品 *Yggdrasil* 保留明确命名连续性，并将宇宙树转用于现代艺术的历史、身份、成长、衰败与转化语境。

## 证据治理

```text
textual evidence ≠ visual evidence
visual resemblance ≠ iconographic inheritance
named reference > unsupported visual analogy
```

V1 不创建 `iconographic_inheritance` relation；若未来出现完整 documented visual chain，再进入 amendment review。
