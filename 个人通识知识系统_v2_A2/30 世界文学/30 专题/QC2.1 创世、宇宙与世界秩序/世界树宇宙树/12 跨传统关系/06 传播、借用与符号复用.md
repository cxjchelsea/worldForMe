# 06 传播、借用与符号复用

必须区分：

```text
explicit_reference
symbol_reuse
historical_transmission
structural_similarity
independent_or_unknown
```

## 当前判断

- Maya / Norse / Sentani 之间：只证明独立或关系未知的结构相似，不创建 historical_transmission。
- Kiefer → Yggdrasil：明确命名引用与文化再使用，可作为 `symbol_reuse`。

## 禁止推断

```text
多个文明都有 cosmic tree
→ 单一起源
```

不成立。

```text
视觉上都像一棵大树
→ iconographic inheritance
```

也不成立。

## 关系原子性

每条正式数据记录只表达一个 relation_type 和一个 evidence_level；跨文化比较说明不能替代传播证据。
