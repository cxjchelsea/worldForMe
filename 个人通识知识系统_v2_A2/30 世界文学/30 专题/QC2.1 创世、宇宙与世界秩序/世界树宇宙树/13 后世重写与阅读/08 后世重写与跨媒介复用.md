# 08 后世重写与跨媒介复用

后世 world-tree reuse 需要至少保留以下之一：

```text
cosmic axis identity
vertical realm connection
world-center function
explicit Yggdrasil / world-tree naming
```

## 代表性现代复用

### Anselm Kiefer｜Yggdrasil

明确调用北欧 Yggdrasil 名称与文化对象，但语境从中古宇宙论转向现代艺术中的：

- 历史与身份；
- 生长与衰败；
- 转化；
- 记忆与时间。

因此属于：

```text
symbol_reuse
+
semantic_shift
```

而不是 direct adaptation。

## 不自动收录的情况

- 普通奇幻作品出现一棵巨大树；
- “生命树”仅表示治愈／生命值；
- 家族树、技能树、科技树；
- 视觉上像 Yggdrasil 但没有来源或宇宙轴证据。

## 后续研究方向

可继续寻找：

- 文学中明确命名的 Yggdrasil/world-tree reuse；
- 游戏中真正承担多世界连接机制的世界树；
- 建筑、公共艺术中的 axis-mundi tree reinterpretation。

进入数据层前均需单独核证。
