# 10 阅读与研究

## 来源路线

1. Maya world tree / ceiba：先理解四方、中心、上下界与 axis mundi。
2. Norse Yggdrasil：比较多层宇宙连接与世界结构组织。
3. Sentani cosmic tree：作为独立跨文化压力点，避免把 world-tree 误判成单一文化传播链。

## 符号研究路线

重点比较：

```text
world tree
vs sacred tree
vs Tree of Life
vs cosmic mountain / axis mundi
```

## 后世复用路线

从 Anselm Kiefer 的 *Yggdrasil* 观察：

```text
cosmological structure
→ historical / personal identity
→ growth, decay, transformation
```

## 研究问题

- 世界树何时只是神圣植物，何时真正承担宇宙轴功能？
- “生命树”与“世界树”在不同传统中如何重叠、又如何分开？
- 图像上的树形相似何时可以升级为 iconographic inheritance？
- 现代文学、影视与游戏中的 world tree 有多少属于明确 symbol reuse，而非独立的 fantasy giant-tree trope？

## 治理提醒

```text
cross-tradition similarity ≠ historical transmission
visual similarity ≠ iconographic inheritance
large sacred tree ≠ world tree automatically
```
