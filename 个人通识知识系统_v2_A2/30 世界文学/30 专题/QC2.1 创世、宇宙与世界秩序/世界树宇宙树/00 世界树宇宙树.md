# 世界树／宇宙树｜symbol

> **定位：**研究树形对象如何超出普通神圣植物或生命象征，成为连接宇宙层级、标定世界中心并组织多层宇宙空间的文化符号。

## 为什么是 symbol

```text
tree image
→ cosmological spatial function
→ repeated naming / reception
→ stable meaning family
→ later explicit reuse
→ semantic drift without loss of recognizability
```

## 稳定意义

```text
vertical_cosmic_connection
= 连接下界、人间、天界或其他垂直宇宙域

cosmic_center_or_axis
= 世界中心、宇宙轴、axis mundi

ordered_multi_realm_world
= 以树形关系组织多个世界层级或宇宙区域
```

## 边界

```text
world tree / cosmic tree
≠ sacred tree
≠ Tree of Life by default
≠ genealogical tree
≠ ordinary giant tree
```

如果树只表示生命、繁衍、丰饶、长生或家族谱系，而没有宇宙连接、中心或空间组织功能，不自动进入本 symbol network。

## 当前来源

- Maya world tree / ceiba：强来源，连接 underworld / terrestrial realm / sky，并承担中心轴功能；
- Norse Yggdrasil：强来源，多层世界连接与宇宙结构组织；
- Sentani cosmic tree：独立 supporting source，显示 cosmic-tree 语义并不限于单一文化圈；
- Anselm Kiefer, *Yggdrasil*：后世明确命名复用，进入现代艺术的成长、衰败、转化语境。
