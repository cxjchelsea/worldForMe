# 02 来源谱系

本专题按具体 tradition witness 与比较研究两层组织。

## A. Haudenosaunee / Iroquois

Library of Congress 保存的 Iroquois creation 展示材料提供完整 Earth-diver 结构：下层世界只有水与水生动物；Sky Woman 降落后，动物从水底取得 earth，泥土置于 Great Turtle 上并形成大地。

```text
source role: core source instance
source_status: external_source_verified_text_only
match: R1 + R2 + R3 + R4
```

这里上层 Sky World 已存在，不影响“待形成下界尚无稳定陆地”的 R1。

## B. Slavic / Eastern European

Andreas Johns 对 Slavic creation narratives 的研究记录了一组 Earth-diver 传统：primeval ocean 中，devil、bird 或其他行动者下潜取得 earth，并使其参与陆地／世界形成。

```text
source role: independent comparative tradition witness
source_status: external_source_verified_text_only
match: R1 + R2 + R3 + R4
```

它与 Haudenosaunee 的角色配置明显不同，因此可用于压力测试最低不变量，而不是证明传播。

## C. Comparative motif literature

Stith Thompson 的 *Motif-Index of Folk-Literature* 将 `A812 Earth Diver` 独立编目；现代世界神话概论也把 Earth-diver 作为 creation-myth type 讨论。

比较研究的职责是：

```text
证明 motif family 的学术先例与分布
```

而不是：

```text
替代具体传统的 source record
```

## 当前来源策略

本轮只建立两条正式 `qc2_source_reference`。北美 post-flood retelling、Siberian 分布综述等保持研究证据，不为了数量提升成 defining source。
