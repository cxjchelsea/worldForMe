# 01 定义、边界与准入

## 定义

Earth-diver 不是“水世界”主题，而是一个可重复识别的造陆机制。

### Required invariants

```text
R1 pre_land_water_dominant_world
R2 underwater_descent_for_earth_material
R3 retrieved_earth_material
R4 retrieved_material_causes_land_formation
```

R4 是关键边界：如果取回之物没有直接参与陆地形成，则不属于本 motif。

## Optional slots

```text
animal_diver
multiple_failed_dives
small_or_unlikely_successful_diver
turtle_or_other_support_platform
creator_uses_retrieved_material
material_self_expands
sky_world_above
cooperative_creation
sacrifice_or_death_of_diver
post_flood_setting
```

这些槽位高度可变，不能反过来定义母题。

## 不要求

```text
muskrat success
specific animal species
turtle support
creator deity
ex nihilo creation
single successful dive
post-flood setting
```

## 域边界

### QC2.1 主域

```text
before stable land exists
→ dive
→ retrieve earth
→ first stable land forms
```

### QC2.2 次级变体

```text
old world destroyed / flooded
→ dive
→ retrieve earth
→ land is recreated
```

后者可作为结构变体研究，但不能用来抬高 QC2.1 核心来源数量。

## 类型边界

```text
motif invariants
≠ ordered plot slots
≠ sacred-water theme
≠ animal-helper archetype
```

若未来出现稳定的“多次失败→微小动物成功→牺牲→泥土扩展”等固定顺序，应另做 plot_pattern admission，而不是扩张本 motif。
