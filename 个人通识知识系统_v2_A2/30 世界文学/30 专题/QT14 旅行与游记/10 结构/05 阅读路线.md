# 阅读路线

第一轮不要追求“去过多少地方”，而要完成七次观看方式变化：

1. 朝圣；
2. 中世纪跨文明旅行；
3. 早期现代海洋遭遇；
4. Grand Tour与启蒙；
5. 19世纪科学 / 帝国；
6. 20世纪文学旅行与叙述权危机；
7. 后殖民 / Diaspora / 当代混合旅行。

再任选一条横轴深挖，例如：

> Travel Gaze / Women Travellers / Scientific Travel / Walking / Return

实际作品请查看 [[../03 旅行作品.base|旅行作品数据库]]。

《剑桥旅行写作史》是研究参考书，不作为旅行文学 Work 混入中央作品库。
