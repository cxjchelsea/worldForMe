# QC3.1 英雄文化模型

> **一句话理解：**不同社会并不是用同一种方式理解“英雄”。英雄可以是追求个人荣誉的战士、效忠主君的骑士、行侠仗义的侠客、维护或挑战边疆秩序的法外者。QC3.1 研究的就是这些不同英雄世界是怎样被历史社会组织出来的。

---

# 1. 这个问题域关心什么？

不是问“文学里有哪些英雄”，而是问：

```text
谁有资格成为英雄？
英雄忠于谁？
英雄为什么可以使用暴力？
什么行为构成荣誉？
英雄和法律、国家、家庭、共同体是什么关系？
英雄必须付出什么代价？
这个模型后来为什么还能持续被重写？
```

因此：

```text
QC3.1
≠ 英雄人物百科
≠ QC2 英雄 archetype 汇总
≠ 战争文学书单
≠ 真实军事/制度史
```

---

# 2. 一个英雄文化模型由什么组成？

## 角色

谁是英雄，谁是英雄的对手、主君、同伴、被保护者、裁判者？

## 关系

英雄和主君、家族、同伴、国家、法律、神圣秩序之间有什么义务？

## 伦理

荣誉、忠诚、勇武、正义、牺牲、自由、复仇等价值如何排序？

## 秩序与空间

英雄存在于什么世界：宫廷、战场、江湖、边疆、城市、荒野还是法外空间？

## 后世续写

后世如何重新发明这种英雄：浪漫化、民族化、商业化、类型化、反英雄化或全球化？

# 3. 与 QC1 / QC2 的关系

```text
QC1
→ 告诉我们具体故事、人物、传统从哪里来、如何演化

QC2
→ 把故事拆成可复用组件：英雄类型、求索、牺牲、荣誉、复仇、圣杯等

QC3.1
→ 解释某个历史社会如何把这些组件组织成一套“英雄应该怎样活”的文化模型
```

例如：

```text
QC1.2.3 亚瑟王叙事传统
        +
QC2 战士 / 求索 / 王权合法性 / 圣杯 / 荣誉 / 禁忌爱情
        +
中世纪宫廷、封臣关系、宗教伦理与阶层环境
        ↓
欧洲骑士英雄模型
```

这里的“中世纪制度”不是 QC3 自己写制度史，而是作为解释骑士文化模型成立的历史条件。

# 5. 为什么不把“英雄”本身当 QC2 archetype 就结束？

因为：

```text
“战士英雄”
→ 可以是 QC2 的角色原型

“欧洲骑士英雄模型”
→ 战士角色
 + 主君—骑士关系
 + 宫廷空间
 + 荣誉与忠诚伦理
 + 宗教秩序
 + 后世骑士想象
→ QC3
```

QC3 的增量价值就在这个“组合后的文化世界”。
