# 欧洲骑士英雄模型｜PILOT

## 候选定位

研究中世纪欧洲及其后世接受中，骑士如何被塑造成一种同时受主君关系、宫廷规范、宗教伦理、荣誉与勇武约束的英雄文化模型。

## 为什么值得做

- 有明确历史社会基底，但文学中的“理想骑士”不能直接等同于真实骑士阶层；
- 可连接现有 [[QC1.2.3 亚瑟王叙事传统]]；
- 可连接多个 QC2 问题域：王权合法性、战士与荣誉、求索、禁忌爱情、共同体、神圣目标等；
- 中世纪 → 浪漫主义 → 现代奇幻 / 游戏等后世生命清楚，适合测试 reception/application 维度。

## Admission Gate

```text
A1 历史社会基底 = PASS
A2 稳定角色/关系/伦理/空间 = PASS
A3 跨时期叙事生命 = PASS
A4 超出单一 component / genre = PASS
A5 QC1/QC2/Work 可连接 = PASS
A6 现实 vs 文化神话可比较 = PASS
```

`6/6 → PILOT`

## 首轮拟研究结构

```text
角色：骑士 / 主君 / 同侪 / 贵妇 / 宗教权威 / 敌手
关系：忠诚、服从、竞争、保护、宫廷爱情
伦理：荣誉、勇武、忠诚、克制、信仰
秩序：宫廷、封臣关系、骑士阶层、宗教秩序
空间：宫廷、战场、道路、荒野、圣地
后世：浪漫化中世纪 → 奇幻骑士 → 游戏职业化
```
