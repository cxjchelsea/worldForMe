# 跨区域比较

T6 的比较重点不是寻找一个统一的“全球文学风格”，而是比较不同地区如何面对同一组全球条件。

| 比较问题 | 可观察差异 |
|---|---|
| 全球化 | 全球市场机会、文化同质化压力、地方语言坚持 |
| 迁徙与离散 | 移民、难民、侨民、跨国家庭、返乡 |
| 后殖民遗产 | 语言、教育、边界、国家暴力、文化代表权 |
| 记忆与历史 | Holocaust、独裁、殖民、战争、文革、Partition、奴隶制等不同记忆政治 |
| 身份政治 | 种族、性别、阶级、酷儿、原住民、宗教身份 |
| 类型融合 | 文学小说与科幻、奇幻、犯罪、恐怖、历史叙事的交叉 |
| 全球流通 | 英语直写、翻译进入、奖项驱动、跨国出版 |

## 比较原则

结构相似不等于历史同一。迁徙、创伤、身份或全球资本可以成为跨区域比较轴，但不能抹平具体政治与语言条件。
