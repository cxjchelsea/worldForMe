# TH1.4 死亡｜A级内容压力测试

## 1. 测试目标

本轮不重新设计坐标树，而是验证：

1. 七个核心问题是否足以覆盖死亡作为文学人类问题的主要结构；
2. P3“临终”、P6“选择死亡”、P7“死后持续”是否仍有独立解释力；
3. 是否出现必须新增第八问题或拆出 `TH1.4.x` 的证据；
4. TH1.4 是否能与 TH1.2 / TH1.3 / TH1.5 / TH6 / TH7 / TH8 稳定分工；
5. “死亡事件很多”是否会导致主题无限扩张。

## 2. 统一强判据

作品进入 TH1.4 核心，至少应持续追问下列一项：

- 死亡怎样从抽象知识变成“我的现实”；
- 临终如何改变身体、时间与生活排序；
- 人具体恐惧、拒绝、接受或选择死亡的什么；
- 他人的死亡作为不可逆事件怎样重组活者；
- 死亡之后究竟什么终结、什么继续。

如果作品只回答“谁死了 / 为什么被杀 / 死亡造成什么剧情后果”，不足以强命中。

## 4. 七问题复核

### P1 人如何意识到自己终将死亡
跨史诗、现代小说、灾难叙事稳定成立。

### P2 人为什么恐惧死亡
可与 P4 区分：P2 问恐惧对象，P4 问面对不可避免终结时的姿态。

### P3 临终如何改变生命经验
获得疾病、弥留、死刑、灾难逼近等多种支撑。其核心不是病种，而是**未来时间被压缩以后，生活如何重新排序**。

### P4 人能否接受并面对自己的死亡
与 P2 不重复；接受、拒绝、平静、抵抗均可形成不同文学答案。

### P5 他人的死亡如何改变活着的人
稳定，但只处理死亡的不可逆性怎样重组活者；若中心是连接断裂则转 TH1.3，若中心是记忆传递则转 TH7。

### P6 人是否能够选择自己的死亡
与 TH1.2 可稳定分工：TH1.2 分析选择空间与责任，TH1.4 分析死亡成为行动终点本身的意义。

### P7 死亡之后什么仍然持续
稳定。其核心不是列举来世、幽灵、记忆等类型，而是比较：**作品认为死亡终结了什么，又拒绝让什么终结。**

## 5. 防扩张规则验证

### 规则1：死亡很多 ≠ 死亡主题
《麦克白》《夜》通过。

### 规则2：哀伤 / 丧亲 ≠ 自动 TH1.4
只有作品持续处理死亡的不可逆性如何重组活者时才进入；若核心只是连接失效则优先 TH1.3。

### 规则3：鬼魂 / 来世 ≠ 自动 TH1.4
鬼魂可能只是叙事装置；完整灵魂、审判、轮回、救赎体系优先 TH8。

### 规则4：晚年 / 疾病 ≠ 自动 TH1.4
若作品不把身体变化转化为有限性、临终与死亡意识问题，则不强命中。

### 规则5：暴力死亡 ≠ 自动 TH1.4
谁制造死亡、怎样实施伤害、创伤如何持续 → TH6；死亡本身怎样成为有限性问题 → TH1.4。

## 6. 域外边界复核

```text
谁选择、还有什么选择、责任怎样分配
→ TH1.2

死亡后连接为什么断裂
→ TH1.3

死亡使人生是否有意义成为问题
→ TH1.5

死亡怎样被暴力制造
→ TH6

死者怎样被记忆、纪念、传递
→ TH7

死亡之后的灵魂、审判、轮回、救赎体系
→ TH8

死亡作为终结本身意味着什么
→ TH1.4
```

多标签允许，但每个标签必须解释不同机制。

## 7. 结构结论

```text
TH1.4_A_LEVEL_CONTENT_TEST = PASS

七个核心问题 = 稳定
第八问题 = 不需要
P3 临终 = 通过扩展样本复核
P6 与 TH1.2 = 边界稳定
P7 与 TH7 / TH8 = 边界稳定
跨时间 / 跨传统 / 跨形式 = 通过
TH1.4.x = 不需要
```

因此 TH1.4 可正式视为 **A 级成熟主题知识地图**。
