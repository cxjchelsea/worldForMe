# 阅读路线

T1 的目标不是平均阅读所有地区，而是建立“多中心文学网络如何保存、翻译、改写和传播文本”的结构理解。

## A｜骨架路线：约 15 个文本 / 文本群

优先覆盖不同文学网络与传播机制：

1. [[../../../40 作品/神曲|《神曲》]]：拉丁基督教传统与意大利俗语文学。
2. [[../../../40 作品/贝奥武夫|《贝奥武夫》]]：英雄叙事、口传与书写。
3. [[../../../40 作品/罗兰之歌|《罗兰之歌》]]：英雄歌与宗教—政治共同体。
4. [[../../../40 作品/坎特伯雷故事集|《坎特伯雷故事集》]]：英语俗语叙事与城市/朝圣框架。
5. [[../../../40 作品/卡里来和笛木乃|《卡里来和笛木乃》]]：印度—波斯—阿拉伯故事传统中的翻译与改写。
6. [[../../../40 作品/伊本·白图泰游记|《伊本·白图泰游记》]]：阿拉伯旅行文学、跨区域见闻与口述经验的书面化。
7. [[../../../40 作品/列王纪|《列王纪》]]：波斯语史诗、宫廷文学与文化记忆。
8. [[../../../40 作品/玛斯纳维|《玛斯纳维》]]：波斯苏菲诗歌、宗教经验与教学性文学。
9. [[../../../40 作品/库萨里|《库萨里》]]：犹太—阿拉伯语际文化、哲理对话与跨语言思想传播。
10. [[../../../40 作品/狄吉尼斯·阿克里塔斯|《狄吉尼斯·阿克里塔斯》]]：拜占庭英雄叙事与口传—文本化。
11. [[../../../40 作品/牧童歌|《牧童歌》]]：南亚梵语抒情、宗教情感与表演性。
12. [[../../../40 作品/太平广记|《太平广记》]]：汉文故事传统的编纂保存与宋代书籍文化。
13. [[../../../40 作品/源氏物语|《源氏物语》]]：和文宫廷文学。
14. [[../../../40 作品/三国遗事|《三国遗事》]]：朝鲜半岛佛教、神话与历史记忆的编纂保存。
15. [[../../../40 作品/松迪亚塔史诗|《松迪亚塔史诗》]]：西非口传与后世文本化。

> 骨架路线不要求全部完整通读。大型故事集、史诗和诗选可采用“代表章节 + 背景说明”。这里的十五项是十五个结构位置，不是十五本必须读完的 KPI。

## B｜理解路线：约 25—35 个文本 / 文本群

骨架完成后，再补同一网络内部的不同文本功能。推荐优先加入以下十个左右的扩展位置：

### 拉丁基督教与欧洲俗语

- [[../../../40 作品/尼伯龙根之歌|《尼伯龙根之歌》]]：另一条英雄歌传统。
- [[../../../40 作品/特里斯坦与伊瑟|《特里斯坦与伊瑟》]]：骑士罗曼司与宫廷爱情。

### 阿拉伯语—伊斯兰

- [[../../../40 作品/一千零一夜|《一千零一夜》]]：故事层累、编纂与跨期传播。
- [[../../../40 作品/卡里来和笛木乃|《卡里来和笛木乃》]]与《伊本·白图泰游记》一起构成“翻译故事 + 旅行见闻”的对照；后续若继续扩展，优先补诗歌或历史文本，不必继续增加故事集。

### 波斯语

- [[../../../40 作品/鲁拜集|《鲁拜集》]]：与《列王纪》《玛斯纳维》组成“史诗—抒情—神秘主义”三角。

### 希伯来语 / 犹太跨地域传统

- [[../../../40 作品/库萨里|《库萨里》]]已经解决核心锚点问题。若继续深化，可再补希伯来诗歌或旅行文本，但不再视为 T1 收束前的硬缺口。

### 南亚多语言传统

- [[../../../40 作品/牧童歌|《牧童歌》]]已提供梵语宗教抒情入口。后续优先补地方语言 devotional 传统或跨语言史诗改写；这属于深化，不再是当前收束阻塞项。

### 汉文文学世界

- [[../../../40 作品/李白诗选|李白诗选]]、[[../../../40 作品/杜甫诗选|杜甫诗选]]：唐诗、教育与经典化。
- [[../../../40 作品/太平广记|《太平广记》]]：编纂、异闻与故事保存。
- [[../../../40 作品/新编五代史平话|《新编五代史平话》]]：说话、历史叙事、俗语书面化与宋代印刷文化。

这四个位置已经把汉文网络从“只有唐诗”扩展成“诗歌 + 编纂 + 俗语叙事 + 印刷文化”。

### 日本与朝鲜文学网络

- [[../../../40 作品/平家物语|《平家物语》]]：讲唱、军记与文本化。
- [[../../../40 作品/枕草子|《枕草子》]]：宫廷散文、女性书写与审美。
- [[../../../40 作品/三国遗事|《三国遗事》]]：朝鲜半岛的佛教、神话、历史记忆与汉文编纂。

### 跨区域与扩展网络

- [[../../../40 作品/马可·波罗游记|《马可·波罗游记》]]：与《伊本·白图泰游记》形成不同旅行网络的比较。
- [[../../../40 作品/松迪亚塔史诗|《松迪亚塔史诗》]]：保留西非口传—文本化的世界文学参照。

## C｜机制路线

如果更关心“文本怎样在中古世界活下去”，可按五条机制横向阅读：

1. [[../12 传播与制度机制/01 保存与再经典化|保存与再经典化]]：`《太平广记》 / 《三国遗事》 / 古典与宗教文本`；
2. [[../12 传播与制度机制/02 翻译与改写|翻译与改写]]：`《卡里来和笛木乃》 / 《库萨里》`；
3. [[../12 传播与制度机制/03 手稿、书写与区域性印刷|手稿、书写与区域性印刷]]：`《太平广记》 / 《新编五代史平话》`；
4. [[../12 传播与制度机制/04 教育、宫廷与宗教机构|教育、宫廷与宗教机构]]：`《列王纪》 / 《源氏物语》 / 《玛斯纳维》`；
5. [[../12 传播与制度机制/05 口传、讲唱与表演|口传、讲唱与表演]]：`《贝奥武夫》 / 《狄吉尼斯·阿克里塔斯》 / 《平家物语》 / 《松迪亚塔史诗》`。

## D｜当前完整度判断

T1 现在已经覆盖：

- 拉丁基督教与欧洲俗语文学；
- 拜占庭/希腊语；
- 阿拉伯语—伊斯兰；
- 波斯语；
- 希伯来/犹太跨地域；
- 南亚；
- 汉文；
- 日本与朝鲜；
- 以及西非和跨区域旅行两个比较性扩展入口。

并且已经包含英雄歌、骑士罗曼司、故事集、旅行、史诗、抒情诗、神秘主义诗、哲理对话、宫廷文学、编纂、军记、俗语历史叙事与口传史诗等不同文本功能。

因此当前判断调整为：

- **地图结构：完整，可收束。**
- **骨架阅读：完整，可收束。**
- **理解阅读：达到个人系统阅读所需的可用完整度，可收束。**
- 后续新增作品只应由实际阅读产生的问题驱动，不再以“补齐中古全球文学百科”为目标。

## 阅读记录建议

每部 T1 作品至少记录五件事：

1. 所属语言/宗教/文学网络；
2. 保存与复制机构；
3. 主要传播媒介；
4. 翻译、注释或改写关系；
5. 它在后世成为经典或传播节点的原因。
