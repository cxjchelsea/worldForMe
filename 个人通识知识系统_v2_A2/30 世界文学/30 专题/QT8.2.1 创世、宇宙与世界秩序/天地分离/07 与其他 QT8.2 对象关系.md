# 07｜与其他 QT8.2 对象关系

本页只记录当前已正式准入对象与仍在候选阶段的自然关系；不为网络密度强制造边。

## 与 P1「世界父母分离结构」

P1 已正式准入，且已建立：

```text
世界父母分离结构 / plot_pattern
→ carries_motif / strongly_supported
→ 天地分离 / motif
```

该正式 relation 存储在 P1 的数据层。

这不意味着：

```text
P1 = M2
M2 必须由 P1 组织
```

M2 仍然只要求天地从未充分分离状态进入分离后的世界空间，不要求世界父母、受限后代或固定顺序。

## 与 S1「宇宙卵」

S1 已正式准入为 `symbol / ACTIVE_V1_COMPONENT`。

盘古等个别材料可同时出现“宇宙卵 + 天地分离”，但这种共现不是 M2 或 S1 的跨传统定义条件，因此当前不创建正式 `associated_with_symbol` 或其他关系。

## 与 M3「原初存在的身体化为世界」

M3 已正式准入为 `motif / ACTIVE_V1_COMPONENT`。

```text
M2 = 空间通过分离形成
M3 = 世界材料通过身体转化形成
```

二者可以在 Tiamat、Pangu 等材料中共现，但目前没有必要建立普遍 `co_occurs_with_motif` 边。

## 当前治理结果

```text
P1 → carries_motif → M2 = ACTIVE_RELATION
M2 local relation record count = 0
S1 relation to M2 = NOT_CREATED
M3 relation to M2 = NOT_CREATED
```

保持 meaningful target gate 与 relation atomicity。
