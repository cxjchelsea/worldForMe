# 天地分离｜motif

> **定位：**研究“天与地／上下宇宙域从未充分分离状态，经明确分化而形成可辨识世界空间”的跨传统叙事单元。

## 最低准入条件

```text
R1 primordial_non_separation
+
R2 cosmological_separation
+
R3 world_space_result
```

这一定义不要求世界父母、后代、特定创世神、暴力行动或光明出现；这些只属于常见变体。

## 边界

```text
天地分离 motif
≠ “混沌→秩序”抽象 theme
≠ 世界父母分离 plot pattern
≠ 任何单纯出现天空和大地的创世故事
```

世界父母结合→后代受限→分离行动→天地展开，是更严格的 `plot_pattern` candidate；它通常包含本 motif，但本 motif 不要求完整角色—顺序结构。
