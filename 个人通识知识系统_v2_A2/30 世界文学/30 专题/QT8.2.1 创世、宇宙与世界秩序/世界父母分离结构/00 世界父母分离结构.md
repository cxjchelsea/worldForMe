# 世界父母分离结构｜plot_pattern

> **定位：**研究“世界父母／天地父母紧密结合 → 后代或生命受限 → 分离行动 → 天地空间展开”的稳定叙事顺序。

## 核心序列

```text
S1 world_parents_joined
→ S2 offspring_constrained
→ S3 separation_action
→ S4 cosmic_space_opened
```

这个结构比 [[../天地分离/00 天地分离|天地分离]] motif 更严格：P1 通常包含“天地分离”，但单纯出现天地由未分状态被分开，并不足以构成本 plot pattern。

## 当前来源压力测试

- Māori Rangi / Papa：完整匹配四个 core slots；
- 埃及 Nut / Geb / Shu：完整或近完整匹配；
- 希腊 Gaia / Ouranos / Kronos：strong variant，后代受压与分离行动明确，但宇宙空间展开的表达方式与 Māori / Egyptian 传统不同。

## 正式跨类型关系

```text
世界父母分离结构
→ carries_motif
→ 天地分离
```

该关系已在 P1 与 M2 均完成 component acceptance 后按 V1 vocabulary 正式落库，是 QT8.2 V1 Freeze 后第一条真实 `qt82_component_relation`。
