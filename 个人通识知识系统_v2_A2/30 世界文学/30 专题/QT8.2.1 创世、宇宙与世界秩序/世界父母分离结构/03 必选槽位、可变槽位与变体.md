# 03 必选槽位、可变槽位与变体

## Core slots

```text
S1 world_parents_joined
S2 offspring_constrained
S3 separation_action
S4 cosmic_space_opened
```

## Optional slots

```text
darkness_before_separation
parental_resistance
violent_or_bodily_separation
light_emerges_after_separation
intermediary_supports_sky
succession_conflict
```

这些槽位可以高频出现，但不能写进 P1 的最低定义。

## Repeatable slots

当前：`NONE_REQUIRED`。

后代多次尝试分离、多人轮流行动等可以作为具体实例变体，但当前没有必要冻结成 repeatable slot。

## Terminal variants

```text
T1 parents_remain_permanently_separated
T2 separation_stabilized_by_intermediary
T3 separation_becomes_cosmic_or_dynastic_reordering
```

## Causal variants

```text
C1 offspring_need_space_causes_separation
C2 succession_conflict_causes_separation
C3 cosmic_ordering_agent_causes_separation
```

## 治理

```text
causal_variants ≠ core_slots
optional violence ≠ required sequence
world-parent identity ≠ generic creator pair
```

不同传统可以共享 core sequence，但通过不同 causal variant 实现。
