# 05 文本证据与关键定型

## 证据层级

```text
early_instance
→ defining_instance
→ canonical_reworking
→ later_structural_inheritance / structural_similarity
```

本专题当前不宣称某一文本“发明”世界父母分离结构。

## 当前关键证据入口

### Māori

Rangi / Papa 传统为完整结构实例，尤其适合验证：

```text
world_parents_joined
→ offspring_constrained
→ separation_action
→ cosmic_space_opened
```

### 埃及

Nut / Geb / Shu 的文本与图像传统为重要跨媒介证据。Shu 抬起天空、分离天地，使其成为 S3/S4 的强证据入口。

### 希腊

Hesiod《神谱》的 Gaia / Ouranos / Kronos 叙事为 strong variant，支持世界父母、后代压制和代际断裂，但不应把所有后世“天地分离”解释反投射为 Hesiod 文本的唯一原始意义。

## 治理

```text
文本年代
≠ 结构起源年代

后世解释
≠ 原始文本唯一意义

跨传统高匹配
≠ 传播事实
```
