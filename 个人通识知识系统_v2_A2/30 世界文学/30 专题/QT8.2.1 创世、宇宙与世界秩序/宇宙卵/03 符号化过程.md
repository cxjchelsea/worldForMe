# 03 符号化过程

本专题把“宇宙卵”从来源物象到文化 symbol 的形成过程拆成：

```text
原初卵形／封闭整体
→ 与宇宙生成绑定
→ 重复文本与宇宙论接受
→ “整体 + 潜能 + 孕育”意义稳定
→ 脱离单一创世情节仍可识别
→ 现代视觉艺术与思想语境继续复用
```

## 关键治理

```text
symbol continuity
≠ literal narrative continuity
≠ single transmission chain
```

多个传统独立使用 egg-cosmos imagery，不自动证明共同历史传播。

## 识别连续性的核心

即使后世作品不再讲述完整创世故事，只要仍明确调用“Cosmic Egg / world egg”并持续激活以下意义族，就可以视为 symbol reuse 候选：

- 封闭但充满潜能的整体；
- 孕育中的宇宙／生命；
- 从统一体向多样世界的展开；
- 创造、萌发、变形的临界状态。
