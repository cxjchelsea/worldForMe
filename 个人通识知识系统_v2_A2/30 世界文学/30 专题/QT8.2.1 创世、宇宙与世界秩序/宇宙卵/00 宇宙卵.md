# 宇宙卵｜symbol

> **定位：**研究“卵”如何从创世叙事中的原初容器／物象，发展为表达未分化整体、生成潜能、宇宙孕育与由一到多的文化符号。

## 为什么是 symbol

```text
source egg image
→ repeated cosmogonic use
→ stable meaning family
→ later named / visual reuse
→ semantic drift without loss of recognizability
```

它不是因为“很多故事里有蛋”而准入；准入依赖跨传统创世材料与后世明确的 Cosmic Egg 复用共同支持。

## 稳定意义

```text
primordial_totality
= 未分化但包含未来世界可能性的整体

generative_potential
= 尚未展开的生命、形式与秩序潜能

gestation_and_birth_of_cosmos
= 宇宙作为被孕育并出生的整体

unity_to_differentiation
= 单一封闭整体裂变／展开为多样世界
```

## 边界

```text
宇宙卵 symbol
≠ “从宇宙卵中创生” motif candidate
≠ 任何普通蛋形物象
≠ 盘古文本中“如鸡子”比喻的自动符号化
```
