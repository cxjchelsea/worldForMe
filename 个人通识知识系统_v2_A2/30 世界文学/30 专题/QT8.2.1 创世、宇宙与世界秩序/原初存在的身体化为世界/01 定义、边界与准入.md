# 01 定义、边界与准入

## 定义

本 motif 的最低辨识条件是：

```text
R1 primordial_embodied_source
存在一个具有构成性地位的具身原初存在

R2 irreversible_bodily_transformation
该存在身体发生死亡、被杀、牺牲、肢解或其他不可逆转化

R3 anatomical_to_cosmic_mapping
身体整体或多个部位成为天地、天体、地貌、水系或其他世界结构
```

三项缺一不可。

## 不属于本 motif 的情况

```text
普通人物死后化花／化鸟／化星
→ 若没有承担世界结构生成，不纳入

单纯巨人被杀
→ 没有 body→cosmos mapping，不纳入

仅出现献祭
→ 没有身体构成世界，不纳入

仅天地分离
→ 属于 M2 或其他对象，不自动纳入
```

## required invariants 与 optional slots

required invariants：

- primordial_embodied_source
- irreversible_bodily_transformation
- anatomical_to_cosmic_mapping

optional slots：

- cosmic_combat
- sacrificial_ritual
- dismemberment
- postmortem_transformation
- body_part_to_landscape_mapping
- body_part_to_celestial_mapping

## 与 plot pattern 的边界

若某些来源进一步稳定形成：

```text
原初敌对体
→ 战斗／击败
→ 肢解
→ 身体造世界
→ 新宇宙秩序建立
```

则应作为 P2 plot_pattern candidate 独立研究，不能把这些顺序槽位写进 M3 required invariants。
