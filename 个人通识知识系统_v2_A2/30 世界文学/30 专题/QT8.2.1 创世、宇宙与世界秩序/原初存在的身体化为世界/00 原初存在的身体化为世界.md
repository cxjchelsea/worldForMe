# 原初存在的身体化为世界｜motif

> **定位：**研究“一个具有身体的原初存在，经死亡、牺牲、杀戮、肢解或其他不可逆身体转化，其身体整体或部位成为天地、天体、地貌、水系或其他世界结构”的跨传统创世母题。

## 最低准入条件

```text
R1 primordial_embodied_source
+
R2 irreversible_bodily_transformation
+
R3 anatomical_to_cosmic_mapping
```

真正决定边界的是 R3：身体必须直接承担世界／宇宙结构生成，而不是普通的“死后化物”。

## 边界

```text
body-to-world motif
≠ cosmic combat
≠ sacrifice
≠ slain giant theme
≠ 天地分离 motif
≠ 原初敌对体→击败→肢解→身体造世界→定序 plot_pattern candidate
```

战斗、牺牲、肢解都只是常见实现方式，不属于 required invariants。

## 当前来源

- Tiamat / Enuma Elish：高匹配，战斗—尸体创世型；
- Ymir / Norse cosmogony：高匹配，巨人身体映射世界结构；
- Puruṣa / Rigveda 10.90：高匹配，牺牲—宇宙身体型；
- Pangu / Chinese reception tradition：高匹配，但必须区分早期“天地开辟”见证与后出“尸体化生万物”见证。
