# 03 内部结构与核心变体

## Required invariants

```text
R1 primordial_embodied_source
R2 irreversible_bodily_transformation
R3 anatomical_to_cosmic_mapping
```

## Optional slots

```text
cosmic_combat
sacrificial_ritual
dismemberment
postmortem_transformation
body_part_to_landscape_mapping
body_part_to_celestial_mapping
body_part_to_hydrological_mapping
body_part_to_directional_or_social_order
```

## 四类主要变体

### A. 战斗—尸体创世型

代表：Tiamat。

```text
敌对／宇宙冲突
→ 原初存在被杀
→ 尸体被分割
→ 身体成为天地与自然结构
```

战斗是 causal variant，不进入 required invariants。

### B. 巨人身体映射型

代表：Ymir。

重点不是“敌对神祇”身份，而是身体各部位与世界材料的系统映射。

### C. 祭祀—宇宙身体型

代表：Puruṣa。

```text
具身宇宙存在
→ 祭祀／分解
→ 身体部位转化为宇宙与社会秩序
```

它证明：牺牲机制可以实现 M3，而无需 cosmic combat。

### D. 死后化生型

代表：盘古后出接受传统。

```text
创世者完成开辟
→ 死亡
→ 身体与生命迹象化生自然／宇宙结构
```

这一变体常与 M2「天地分离」组合出现，但二者是独立 motif。

## 可变角色

原初存在可以是：

- primordial monster / adversary
- primordial giant
- cosmic person
- creator / culture hero

角色身份不是 motif 本体。

## 可变因果

```text
被击败
被牺牲
被杀
自然死亡
自我分解／宇宙化
```

只要 R2 与 R3 满足，因果机制可以不同。
