# 05 文本证据与定型

## Tiamat

《Enuma Elish》是当前 defining text 级来源。重点证据不是“神战”本身，而是 Tiamat 身体被分割并直接构成天地与自然结构。

```text
tradition_role: defining_text
```

## Ymir

《诗体埃达》与《散文埃达》保存北欧宇宙论中 Ymir 身体—世界映射，是 defining / canonical witness。

```text
flesh → earth
blood → sea
bones → mountains
skull → sky
```

## Puruṣa

《Rigveda》10.90 是 early / defining witness，显示祭祀宇宙人身体与天体、空间、方向及社会秩序的映射。

重要边界：

```text
sacrificial cosmology
≠ proof that sacrifice is required for M3
```

## Pangu

必须分开至少两个见证层：

```text
A. 早期开辟见证
天地混沌如鸡子 → 盘古生其中 → 天地开辟

B. 后出尸体化生见证
盘古死后身体／气／声／眼／四肢／血脉等化为宇宙与自然结构
```

只有 B 直接作为 M3 defining reworking / reception witness。

## 时间治理

不得把：

```text
后世成熟叙述
→ 反投射为最早文本唯一或完整形态
```

专题内必须持续区分故事传统、现存文本见证、后世编纂与接受层。
