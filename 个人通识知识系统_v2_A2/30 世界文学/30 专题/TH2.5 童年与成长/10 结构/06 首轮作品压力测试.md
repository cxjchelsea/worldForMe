# 首轮作品压力测试

本轮不是验证“哪些作品属于 Bildungsroman”，而是检验七个问题能否解释不同传统中的童年、成长、失败成长与反成长经验。

## V1 语料：15 部

|---|---|---|
| 《大卫·科波菲尔》 | P1 / P2 / P3 / P4 / P6 / P7 | 童年、教育、工作、城市与成人责任构成经典成长长弧。 |
| 《简·爱》 | P1 / P2 / P3 / P4 / P5 / P6 / P7 | 童年压迫、教育、职业、爱情与独立交叉，校准成长与主体性/爱情边界。 |
| 《远大前程》 | P1 / P2 / P3 / P4 / P6 / P7 | 阶级欲望、城市经验、羞耻与幻灭检验“社会上升是否等于成长”。 |
| 《小妇人》 | P1 / P2 / P3 / P4 / P5 / P6 / P7 | 家庭教育、姐妹关系、职业愿望、性别角色与失去共同参与成长。 |

## 七问题判断

- **P1 与 TH2.4 可区分**：TH2.4 研究亲子关系本身；P1 研究童年条件怎样形成后续发展起点。
- **P2 / P4 不合并**：教育训练是制度化学习；离家、城市、职业是进入更大社会世界的经验扩张。
- **P3 不并入爱情专题**：只有“关系如何改变发展轨迹”进入 P3，关系本身仍归 TH2.1/TH2.2。
- **P5 保留**：女性、Queer 与青春期叙事显示身体/性别经验会独立改变成长路径；但制度本身仍归 TH3。
- **P6 与 TH6 可区分**：这里处理失去/创伤的成长后果，不处理暴力或创伤本身。
- **P7 保留**：从《大卫·科波菲尔》的成人整合到《麦田里的守望者》《人间失格》的拒绝/失败，存在稳定的比较问题。
- 首轮未发现必须新增第八问题。

## 第二维判断

旧“九个历史区块”“成长机制横轴”“Bildungsroman / YA / Anti-Bildungsroman”等分别属于历史、机制与类型，不是同一逻辑层，因此不建立稳定第二维。
