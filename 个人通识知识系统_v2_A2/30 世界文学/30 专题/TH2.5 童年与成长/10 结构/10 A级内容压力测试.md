# A级内容压力测试

## 1. 测试目的

本轮不再验证“成长小说”类型边界，而验证 TH2.5 是否已经具备 A 级主题解释力：

- 七问题是否仍然稳定；
- 是否存在统一成长机制；
- 能否容纳非线性、失败和反成长；
- 是否会吞并 TH2.4、TH1.1、TH3、TH4、TH5、TH6；
- 是否需要第八问、第二内部维度或 `TH2.5.x`。

A级判据：作品必须能回答“**人物在哪些经验之后已经不能再以原来的方式判断、行动或生活，以及这种变化形成了什么新的能力/位置，或者为什么没有形成**”。

## 3. 七问题稳定性复核

### P1 童年经验
保留。童年提供发展起点，但不是所有童年描写都命中；必须看到它持续影响后续判断、关系或行动。

### P2 教育、训练与规训
保留。教育与 P4 社会经验不同：前者是制度化塑造，后者是进入陌生社会世界后的经验扩张。

### P3 同伴、友谊与亲密关系
保留。关系本身归 TH2.1/TH2.2；只有关系如何改变发展轨迹才进入 P3。

### P4 离家、城市、职业与社会经验
保留。离家不是自动成长；关键是新环境是否迫使人物获得新的行动能力、知识或责任。

### P5 身体、性别与欲望经验
保留。TH3 解释规范和社会赋义；P5 只解释这些经验怎样改变成长路线。

### P6 失去、失败与创伤
保留，但必须坚持：

```text
受苦 ≠ 成长
```

创伤可以加速承担责任，也可以造成发展停滞、重复与破坏。

### P7 成熟、融入或拒绝成人世界
保留，是整域终点判断，但不是强制结局。它负责比较整合、妥协、拒绝、停滞和失败。

## 4. 高风险误判

### 误判一：年龄增长 = 成长
FALSE。时间经过只是必要背景之一，不是发展证据。

### 误判二：受苦 = 成长
FALSE。苦难必须通过认识、能力、判断或行动变化才能进入成长机制；也可能直接造成中断。

### 误判三：离家 / 上学 / 工作 = 成长
FALSE。只有这些经验改变了人物的发展结构才成立。

### 误判四：人物最后想通了 = 成长
FALSE。一次顿悟不足以自动构成长弧；需要它重组后续行动或位置。

### 误判五：社会适应 = 成熟
FALSE。某些作品把“融入”写成妥协、异化或屈服，拒绝同样可能构成发展结果。

### 误判六：青少年主角 = TH2.5
FALSE。年龄与主角身份不能替代发展机制证据。

## 5. 域间边界复核

```text

```

```text

→ TH1.1

→ TH2.5
```

```text
性别 / 性规范怎样规定人？
→ TH3

这些规定怎样改写人物的成长机会和发展轨迹？
→ TH2.5
```

```text
阶级 / 劳动结构怎样运行？
→ TH4

进入工作、城市或阶级世界怎样改变人物？
→ TH2.5
```

```text
学校 / 国家怎样规训？
→ TH5

人物在规训中获得、抵抗或失去什么发展能力？
→ TH2.5
```

```text
暴力和创伤怎样发生、持续？
→ TH6

它们怎样加速、中断或扭曲成长？
→ TH2.5
```

## 6. 是否需要第八问题

本轮候选：

- “责任承担” → 已由 P4/P7 并可与 TH1.2 联动；
- “职业形成” → P4；
- “道德成长” → P2/P3/P6/P7 的具体结果，不宜独立；
- “性觉醒” → P5；
- “社会化” → P2/P4；
- “自我发现” → 若核心是主体认同，归 TH1.1。

没有出现跨作品、跨传统且无法被七问题解释的稳定第八类。

```text
EIGHTH_PROBLEM_REQUIRED = FALSE
```

## 7. 是否需要第二内部维度或 TH2.5.x

Bildungsroman / YA / Anti-Bildungsroman 属于类型；家庭/学校/城市/爱情/创伤属于形成机制；童年/青春/成年属于人生阶段；女性/Queer/殖民成长属于社会位置与传统。它们不是同一逻辑层，不能组成第二棵稳定分类树。

```text
SECOND_DIMENSION = NOT_REQUIRED
TH2.5.x = NOT_REQUIRED
LEGACY_HISTORY_AND_TYPE_LAYERS = COMPARISON_ONLY
```
