# 加朗、迪亚布与集合边界重写

## 1. 翻译不是透明搬运

在 `collection_tradition` 中，翻译可能同时承担：

- 语言转换；
- 选材；
- 顺序调整；
- 文体改写；
- 来源整合；
- 集合成员扩充。

因此 `translation_layer` 不能只记录 target_language，还应记录它对集合边界做了什么。

## 2. 加朗层为何是结构性转折

加朗法译一方面依赖阿拉伯语手稿，另一方面在后续卷册中又吸收新的故事来源。由此产生的欧洲《一千零一夜》并不是某一阿拉伯手稿的机械镜像，而成为一个具有自身巨大传播生命的翻译—编辑层。

建议模型：

```yaml
resource_type: translation_witness
source_witnesses: []
source_layers: []
target_language:
selection_mode:
editorial_recomposition:
added_members: []
removed_members: []
```

## 3. 迪亚布层的意义

迪亚布相关材料说明：一个故事可以通过口述／记录／译者采集等来源方式进入新的集合形态。

因此新增：

```text
source_mode
```

至少允许：

```text
manuscript_attestation
oral_source
written_source
translator_source_layer
print_editorial_layer
unknown
```

## 4. 不把全球知名度反推为早期核心性

《阿拉丁》《阿里巴巴》等后来极具代表性的故事可以是《一千零一夜》全球接受史中的核心成员，同时并不意味着它们属于现存最早阿拉伯语手稿的核心成员。

这两种判断必须同时成立，而不是互相排斥。

## 5. 翻译层的研究问题

未来每个重要译本优先回答：

- 底本是什么；
- 是否直接从阿拉伯语翻译；
- 是否经由另一种欧洲语言转译；
- 收录范围如何；
- 是否新增、删减、改写；
- 这一版本是否反过来影响后续“标准目录”的想象。
