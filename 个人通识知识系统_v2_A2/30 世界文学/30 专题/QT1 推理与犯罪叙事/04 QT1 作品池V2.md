# QT1 推理与犯罪叙事：作品池 V2

> 本页是 QT1 的**正式选书注册表**。作品实体仍只存在于 `40 作品/`；本页不复制作品元数据，只决定哪些作品进入 QT1 V2 的 Core / Expand，以及为什么进入。

## 1. V2 与旧 B 级书单的关系

旧 `[[_source/推理书单_原始版]]` 保留为候选档案与审计来源，不再等同于正式作品池。

旧版约 180–220 个节点的主要问题不是“书太多”，而是：

1. `★` 同时承担文学史重要、技法重要和实际阅读推荐，核心层过度膨胀；
2. 同一作者常因多个技法被重复提高优先级；
3. 英美、日本、北欧、中文密度较高，但“全球犯罪文学”仍存在明显地域空白；
4. 大众高流通作品、近二十年的当代代表与文学史正典没有被作为不同维度管理。

V2 因此采用两层池：

- **Core**：42 个不可替代或高度代表的阅读节点，用于建立完整骨架；
- **Expand**：约 60–80 个系统扩展节点，用于补作者、机制、地域与当代生态；
- 旧长书单其余作品进入 **Archive / Deep-dive Candidate**，不删除。

`mystery_layer` 与 Core / Expand 正交：

- `文学史骨架`
- `类型重要`
- `大众入口`
- `当代代表`

一部作品可以同时属于多个 layer。

# 4. 暂不并入正式池的边界作品

以下传统与 QT1 高度邻接，但默认不因“含调查/犯罪”自动进入正式 Core：

- 间谍小说：`三十九级台阶`、`柏林谍影`、`锅匠，裁缝，士兵，间谍` 等；
- Caper / 盗窃小说；
- 纯 Thriller / Suspense；
- 只把犯罪作为背景、但主要阅读契约并非调查/解释/犯罪结构的文学小说。

这些作品可通过 QT10 惊悚与悬疑、QT5 冒险与探索、其他主题或交叉专题进入，不需要强行塞进 QT1。

# 7. 维护规则

1. `40 作品/` 是唯一作品实体库；本页只维护作品池资格。
2. Core 原则上保持约 40–50 个节点；新增 Core 应说明“替代不了哪一个现有节点”。
3. Expand 原则上保持约 60–80 个节点；新增作品优先解决真实谱系/地域缺口，而非同作者继续堆量。
4. 作者深挖、全集式阅读不进入公共 Core / Expand，进入个人深挖层。
5. 大众入口不是“低级”，文学史骨架也不是“必须先读”；两者是不同价值维度。
6. 旧 `_source` 永久保留，不作为当前动态数量来源。
7. 若同一作品在其他专题出现，只追加专题关系，不创建重复 work entity。
