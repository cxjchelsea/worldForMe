# 类型谱系与核心机制

QT1 到此为止，不再向全局 Q 轴继续拆 `QT1.1 / QT1.2 ...`。本页下面出现的“本格、密室、Hard-boiled、Noir、Police Procedural”等全部属于**推理与犯罪叙事专题内部的分析坐标**。

专题内部至少要同时保留三套互相正交的坐标：

```text
A. 谜题 / 信息结构
“作者怎样制造、隐藏和释放信息？”

B. 犯罪叙事模式
“整部作品要求读者主要追踪什么？”

C. 调查主体 / 制度位置
“谁有资格调查、用什么制度和知识调查？”
```

如果只做一棵“流派树”，就会把密室、叙诡、暴风雪山庄这样的机制，和 Hard-boiled、Noir、Police Procedural 这样的整体叙事模式混在同一层。

## A. 谜题与信息结构

→ [[../12 类型机制/01 谜题与结构技法|谜题与结构技法]]

可使用的专题内部标签包括：

- 密室 / 不可能犯罪；
- Closed Circle / 封闭嫌疑人系统；
- 不在场证明；
- 时间 / 空间诡计；
- 身份与认知错位；
- 倒叙推理 / Howcatchem；
- 多重解答；
- 叙述性诡计；
- 日常之谜；
- 特殊设定推理；
- Meta Mystery / 类型自反。

这些不是互斥分类。同一本作品可以同时调用多个机制；部分机制本身具有剧透风险，因此作品页不要求全部公开标注。

## B. 犯罪叙事模式

→ [[../12 类型机制/02 犯罪小说模式|犯罪小说模式]]

最基础的三个问题仍然有用：

```text
Whodunit → 谁做的？
Howdunit → 怎么做到的？
Whydunit → 为什么发生？
```

但真正的专题谱系还包括：

- Classical / Golden Age Mystery；
- Hard-boiled；
- Noir / Neo-Noir；
- Police Procedural；
- Legal Crime / Courtroom Mystery；
- Forensic Crime；
- Social Crime；
- Psychological Crime；
- Domestic Crime / Domestic Noir；
- Cozy Mystery；
- Historical Mystery；
- Caper / Heist 边界叙事；
- Criminal-centred Crime Fiction；
- Meta / Experimental Mystery。

其中 Suspense / Thriller 与 QT10 邻接；Espionage 与 QT5、QT10 等可能交叉。是否进入 QT1，不看营销标签，而看犯罪、调查、证据和解释是否仍是主要叙事发动机。

## C. 调查主体与制度位置

同样的案件，因为“谁在调查”会形成不同的知识结构：

- 业余侦探 / Gentleman Detective；
- 私人侦探；
- 警察 / 调查团队；
- 律师 / 法庭参与者；
- 法医 / 科学专家；
- 记者；
- 历史调查者 / 档案研究者；
- 受害者、家属或普通人；
- 犯罪者本人。

这个维度特别适合观察推理文学怎样从“天才个人恢复秩序”扩展到现代制度、专业知识和不可靠主体。

## D. 历史与地域是另外两层坐标

类型机制不会脱离文学史和文学传统独立发展。

- 英国黄金时代强化公平游戏与封闭谜题；
- 美国 Hard-boiled / Noir 重写城市、暴力与秩序；
- 法国及欧洲大陆不断发展心理、警察、社会与反侦探传统；
- 日本形成本格—社会派—新本格及特殊设定等独特谱系；
- Nordic Crime 将犯罪与福利社会、制度裂缝结合；
- 中文及其他全球文学传统继续重组这些语法。

## 作品层怎样表达

- `mystery_history_cluster`：较粗历史位置；
- `mystery_history` / `mystery_history_detail`：更细历史信息；
- `mystery_technique`：明确可标注的谜题 / 信息结构；
- `mystery_mode`：明确可标注的犯罪叙事模式；
- `mystery_priority`：作品在 QT1 中的结构价值；
- `mystery_layer`：文学史骨架 / 类型重要 / 大众入口 / 当代代表，可多值；
- `read_status`：个人阅读状态。

这些字段彼此独立。专题内部标签服务于阅读和比较，不为了建立一棵漂亮分类树而强制每部作品唯一归类。
