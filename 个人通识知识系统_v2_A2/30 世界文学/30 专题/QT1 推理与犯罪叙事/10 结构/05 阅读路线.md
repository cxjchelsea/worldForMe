# 阅读路线

推理专题不适合把作品库从头到尾依次打卡。作品库的意义，是让你随时从不同结构进入，而不是制造新的“完成焦虑”。

## 第一轮：★ 核心骨架

目标：建立类型史的主干。

读完这一层后，应该能够解释：

```text
推理为什么诞生
→ 为什么形成黄金时代
→ Hard-boiled / Noir 为什么反抗古典谜题
→ 社会派为什么改变“推理在问什么”
→ 日本新本格为什么重新拾起谜题
→ 当代为什么重新走向融合
```

实际书目统一查看 [[../03 推理作品.base|推理作品数据库]] → **核心骨架 ★**。

## 第二轮：◆ 系统扩展

目标不是“多读”，而是把第一轮只看见名字的分支真正点亮：

- 重要作者的第二入口；
- 警察程序、法庭、法医、心理犯罪等制度型分支；
- 日本本格内部的细分；
- 北欧、欧洲大陆、中文推理；
- 关键边界类型。

查看 **系统扩展 ◆** 视图即可，不在本页复制名单。

## 第三轮：○ 个人深挖

当你已经知道自己偏爱什么以后，再按作者、技法、地域或模式扩展。

这一层不追求公共图谱的完整度，而进入：

> **“我为什么喜欢这一支？”**

○ 候选随阅读增加，数量看 Base，不在本页写死。

## 三种进入方式

- 想补文学史：从 [[02 历史演进]] → `11 历史细分` 进入。
- 想研究谜题或类型结构：从 [[03 类型谱系与核心机制]] → `12 类型机制` 进入。
- 想直接选下一本：从 [[../03 推理作品.base|推理作品数据库]] → **骨架未读** 进入。

## 阅读状态与优先级是两回事

- `mystery_priority`：这本书在推理专题中的结构价值。
- `read_status`：你个人是否已经读过。

以后已读映射只修改 `read_status`，不会改变作品在推理史中的位置。

## 维护规则

以后想把某本作品从 ◆ 提升为 ★，**只改作品 Markdown 的 `mystery_priority`**。Base 会自动更新；不要在本页手动维护作品名单。
