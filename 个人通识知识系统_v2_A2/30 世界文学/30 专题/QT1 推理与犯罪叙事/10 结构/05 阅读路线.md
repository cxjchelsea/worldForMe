# 阅读路线

推理与犯罪叙事专题不适合把作品库从头到尾依次打卡。作品库的意义，是允许你从**文学史、类型机制、现实阅读入口或个人兴趣**进入，而不是制造新的“完成焦虑”。

## 先区分三种字段

### 1. `mystery_priority`：专题结构价值

- `★` 核心骨架：理解 QT1 的第一轮主干。
- `◆` 系统扩展：补足关键分支、地域、作者和机制。
- `○` 深挖候选：形成兴趣以后再继续进入。

它回答的是：

> **如果我要理解推理与犯罪叙事，这本书有多重要？**

### 2. `mystery_layer`：为什么值得进入实际阅读视野

允许多值：

- `文学史骨架`
- `类型重要`
- `大众入口`
- `当代代表`

它回答的是：

> **这本书以什么理由值得被看见？**

一部作品可以同时属于多个阅读层。例如《东方快车谋杀案》既可能是文学史/类型史的重要作品，也可能是大众入口。

### 3. `read_status`：个人状态

只记录你是否已经阅读，不改变作品在类型史中的位置。

因此：

```text
专题重要性 ≠ 大众流行度 ≠ 当代性 ≠ 个人阅读状态
```

这四种东西不能再压进同一个优先级字段。

## 路线 A：第一次建立推理文学骨架

从 [[../03 推理作品.base|推理作品数据库]] → **核心骨架 ★** 进入。

目标不是读得多，而是读完后能够解释：

```text
犯罪故事怎样变成现代侦探小说
→ 为什么出现黄金时代与公平游戏
→ Hard-boiled / Noir 为什么把犯罪带回城市与社会现实
→ Police Procedural / 法庭 / 法医怎样让调查制度化
→ 社会派与心理犯罪为什么改变“推理在问什么”
→ 日本本格—社会派—新本格怎样形成自己的谱系
→ 当代犯罪文学为什么重新走向全球化与跨类型融合
```

## 路线 B：我想读“真正重要的类型作品”

查看 **类型重要** 视图。

这一层不要求作品必须是世界文学正典，而关注它是否：

- 推动某个推理/犯罪分支形成；
- 是重要机制的典型代表；
- 在类型读者共同体中长期具有影响；
- 为后来的作者提供了可识别的范式。

这能避免只按传统文学史筛书，把大量真正重要的类型作品排除在外。

## 路线 C：我现在只想找一本好进入的书

查看 **大众入口** 视图。

这里允许长期畅销、广泛改编、中文市场高可见度、跨圈传播度高的作品进入。它们不因为“流行”而自动升为 ★，也不因为“不够学院化”而被排除。

大众入口的职责是：

> **让我真的愿意从地图走进阅读。**

## 路线 D：我想知道今天的推理文学已经发展到哪里

查看 **当代代表** 视图。

重点补足：

- 当代犯罪小说的跨类型化；
- 女性、族裔、阶级与边缘经验进入犯罪叙事；
- Domestic Crime / Psychological Crime 等新重心；
- 全球犯罪文学，而不是只停在英美和日本；
- 新的制度、科技、城市与社会问题如何改变犯罪叙事。

“当代代表”不等于“当年畅销榜”。它要求作品对理解当代类型生态有持续价值。

## 路线 E：按兴趣深挖

当你已经知道自己偏爱什么以后，再从 Base 的技法、模式、历史位置和地域字段进入，例如：

```text
密室 / 不可能犯罪
Hard-boiled / Noir
社会犯罪
心理犯罪
Police Procedural
历史推理
日本新本格
北欧犯罪文学
中文推理
……
```

这些都是**专题内部路径**，不需要升格成 QT1.1、QT1.2 等全局 taxonomy 节点。

## 三种知识入口

- 想补文学史：[[02 历史演进]] → `11 历史细分`。
- 想研究谜题或犯罪结构：[[03 类型谱系与核心机制]] → `12 类型机制`。
- 想直接选下一本：[[../03 推理作品.base|推理作品数据库]] → `大众入口`、`核心骨架 ★`、`当代代表` 等视图。

## 维护规则

以后调整作品时分别修改对应字段：

- 改专题结构地位 → `mystery_priority`
- 改进入阅读视野的理由 → `mystery_layer`
- 改个人阅读状态 → `read_status`
- 改历史、技法、模式 → 对应 `mystery_*` 专题字段

不要在本页手工维护作品名单；名单始终由 `40 作品/` 唯一作品实体与 [[../03 推理作品.base|推理作品数据库]] 动态生成。
