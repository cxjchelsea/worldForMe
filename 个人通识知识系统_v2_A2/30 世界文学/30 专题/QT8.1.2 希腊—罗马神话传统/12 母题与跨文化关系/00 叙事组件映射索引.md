# QT8.2 叙事组件映射索引

本页是 QT8.1.2 → QT8.2 的接口总览。它不再把所有重复文化现象统称为“母题”，而统一按照 QT8.2 的四类对象模型记录：

- `motif`｜母题：反复出现的基本叙事单元
- `archetype`｜文化原型：抽象角色模型或命名型文化原型
- `plot_pattern`｜叙事结构：反复出现的关系与事件组织模式
- `symbol`｜文化意象／符号：具有稳定叙事功能或后世高复用性的物件、空间与形象

> QT8.1.2 只提供来源传统中的实例与文本证据；跨文明抽象、比较和后世原型化判断由 QT8.2 承担。

## 2. archetype｜文化原型候选

### 2.1 抽象角色原型

| 抽象原型 | 来源人物／角色候选 | 备注 |
|---|---|---|
| 文化英雄 | 普罗米修斯 | 重点观察“向人类带来能力／文明资源”这一功能 |
| Trickster／诡计者 | 赫尔墨斯、奥德修斯（条件） | 必须区分神性诡计者与智谋型英雄 |
| 悲剧英雄 | 俄狄浦斯、阿伽门农、俄瑞斯忒斯等 | 是后世批评框架还是跨文本稳定角色模型，需 QT8.2 继续界定 |
| 智者／预言者 | 忒瑞西阿斯、卡珊德拉等 | 可进一步拆“可靠预言者／无人相信的预言者” |
| 天选／合法统治者 | Zeus、埃涅阿斯等不同层级对象 | 不直接合并，需要区分神权与政治祖先叙事 |
| 反叛者／越界者 | 普罗米修斯 | 与文化英雄可重叠 |
| 怪物／边界存在 | 美杜莎、牛头怪、斯芬克斯等 | 可能更适合作为角色类群而非单一 archetype |
| 归乡英雄 | 奥德修斯 | 与 plot pattern 高度关联，需防止把结构误当角色原型 |

### 2.2 命名型文化原型候选

以下人物暂只标记为 `named_archetype_candidate`，不在 QT8.1.2 内直接判定通过：

- 普罗米修斯
- 奥德修斯／尤利西斯
- 俄狄浦斯
- 纳耳喀索斯
- 美狄亚
- 俄耳甫斯
- 赫拉克勒斯／赫丘利
- 埃涅阿斯
- 皮格马利翁

命名型文化原型的最低判定门槛：

```text
来源人物／故事明确
        ↓
后世长期重写
        ↓
跨文本／跨媒介重复调用
        ↓
名字本身或人物模型能够脱离原情节继续产生文化意义
```

例如“俄狄浦斯”是否进入命名型文化原型，不因为其著名，而取决于后世是否持续把“Oedipus”作为一种可重复调用的人物／解释模型。

## 3. plot_pattern｜叙事结构候选

| 结构 | 典型来源 | 说明 |
|---|---|---|
| 原初混沌 → 世代冲突 → 新秩序建立 | 《神谱》神代叙事 | 可与创世／王权两个母题簇相连 |
| 预言 → 逃避 → 预言实现 | 俄狄浦斯循环 | 典型宿命结构 |
| 离乡 → 漂泊／试炼 → 身份隐藏 → 归乡 → 秩序恢复 | 《奥德赛》 | 归乡结构不等于全部“英雄旅程” |
| 任务／资格 → 出发 → 怪物与异域 → 神助／同伴 → 返回／失败 | 英雄远征群 | 赫拉克勒斯、伊阿宋、珀尔修斯等可提供不同版本 |
| 越界／冒犯 → 暴露 → 惩罚／变形 | 多组神话 | 与禁忌、神人边界相关 |
| 上一代罪责 → 下一代承担 → 复仇 → 再复仇 → 制度性终止／新秩序 | 阿特柔斯家族／《俄瑞斯忒亚》 | 从血亲复仇向公共裁判转换是重要变体 |
| 失去爱人／任务 → 下降冥界 → 获得条件／知识 → 返回成功或失败 | 俄耳甫斯、埃涅阿斯等 | 同属下降结构但功能不同 |
| 欲望／追逐 → 拒绝／暴力 → 变形 → 新自然／象征身份 | 奥维德式多组故事 | 与 symbol 的生成关系尤其强 |
| 祖先流亡／使命 → 漂泊 → 战争／结盟 → 建城合法化 | 埃涅阿斯传统 | 罗马政治祖先叙事的重要结构 |

## 4. symbol｜文化意象／符号候选

| 符号／意象 | 来源语境 | 潜在功能 |
|---|---|---|
| 火 | 普罗米修斯 | 技术、文明、知识、神人边界 |
| 迷宫 | 忒修斯／牛头怪 | 空间迷失、秘密、封闭秩序、怪物中心 |
| 线团 | 阿里阿德涅 | 导引、逃离迷宫、知识性路径 |
| 金苹果 | 帕里斯裁判等 | 欲望、竞争、冲突触发物 |
| 船／归航 | 阿尔戈号、《奥德赛》 | 远征、漂泊、归乡、共同体 |
| 金羊毛 | 阿尔戈英雄 | 神圣目标／资格／远征 |
| 弓 | 奥德修斯等 | 身份确认、英雄资格 |
| 桂树／花／星辰等变形后自然形态 | 多组变形故事 | 记忆固定化、身份转化、永恒化 |
| 冥界之门／河流 | 多种下降叙事 | 生死边界、不可逆性、知识获取 |

符号是否成为 QT8.2 的 canonical symbol，应看它是否在来源传统中具有稳定叙事功能，并在后世被持续调用；单次出现的道具不自动升级为“文化符号”。

## 6. 映射治理

每一条正式映射至少记录：

```text
source_object
source_story_group
source_text_or_witness
component_type
canonical_component
relation_type
confidence
notes
```

其中：

- `source_object` 属于 QT8.1.2 的来源材料；
- `canonical_component` 属于 QT8.2；
- 一个来源对象可以映射多个组件；
- 一个 QT8.2 组件也必须允许来自多个 QT8.1 来源传统；
- 不因为结构相似就自动建立传播关系。
