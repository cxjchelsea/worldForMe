# 核心叙事循环与故事群

这是 Pilot 的主干页之一。第一版先建立故事群，不追求穷尽单篇故事。

## A｜宇宙与神代循环

原初状态 → 神族世代更替 → 新秩序建立 → 对秩序的挑战与维护。

## B｜普罗米修斯与人神边界故事群

文化馈赠／火 → 欺骗或越界 → 神圣秩序回应 → 惩罚及其文化解释。

## C｜英雄远征与怪物故事群

英雄获得身份或任务 → 离开共同体 → 怪物／异域试炼 → 神助／同伴 → 返回、失败或死亡。

## D｜特洛伊战争循环

前因与誓约 → 集结与远征 → 围城／英雄冲突 → 城破 → 幸存者、复仇与归乡分支。

## E｜归乡与漂泊循环

战争／离乡 → 长期漂泊 → 身份隐藏或试炼 → 重返家园 → 重新确认秩序。

## F｜亲族诅咒与悲剧家族循环

上一代过错／诅咒 → 预言或禁忌 → 亲族内部冲突 → 犯罪／复仇 → 下一代继续承担后果。

## G｜冥界下降与生死边界

失去／任务 → 进入死者空间 → 获得信息、尝试带回亡者或完成试炼 → 返回或失败。

## H｜变形叙事群

欲望／冒犯／逃避／奖惩 → 身体或存在形态改变 → 新身份／自然形态成为故事结局与记忆载体。

## 下一步

每个故事群继续补：主要人物、主要版本、较早见证文本、定型文本、四类 QT8.2 组件以及后世重写。
