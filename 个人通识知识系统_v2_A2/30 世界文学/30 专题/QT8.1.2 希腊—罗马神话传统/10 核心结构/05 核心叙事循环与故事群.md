# 核心叙事循环与故事群

## 核心原则

> 本页不按“人物百科”组织，而识别在希腊—罗马传统中具有强连接力、反复被文本重写的故事群。

一个故事群可以跨越多个作者、时代和文本版本。它不是“唯一正确版本”，而是一组围绕共同人物、事件链和叙事问题不断重组的传统材料。

每个故事群统一观察：

```text
核心结构
主要人物
主要版本差异
较早文本见证
关键定型文本
QT8.2 叙事组件
罗马阶段变化
后世重写潜力
```

## A｜宇宙生成与神代更替

### 核心结构

```text
原初存在
→ 神族生成
→ Uranus 一代秩序
→ Cronus 夺权
→ Zeus 一代反抗 Titans
→ 奥林匹斯新秩序建立
→ 权能／荣誉重新分配
```

### 关键意义

这是“宇宙从哪里来”的故事，也是“谁有资格统治”的故事。

核心问题包括：

- 父辈为什么反复害怕下一代？
- 新秩序通过什么获得合法性？
- 暴力夺权如何转化为稳定秩序？

### 文本入口

- 赫西俄德《神谱》是最关键的早期系统化见证之一。

### QT8.2 接口

- motif：创世、父子冲突、王权更替
- archetype：神王／旧王
- plot_pattern：预言威胁→压制后代→后代反抗→新秩序
- symbol：镰刀、雷霆等候选

## B｜普罗米修斯与人神边界

### 核心结构

```text
神与人之间的分配／差异
→ 欺骗、盗火或文化馈赠
→ 人类获得关键能力
→ Zeus 回应
→ Prometheus 与人类承担代价
```

### 核心问题

- 文明能力从哪里来？
- 技术／火／知识为何同时意味着进步与代价？
- 神圣秩序允许人拥有多少力量？

### 版本治理

Prometheus 不是一个固定故事。《神谱》《工作与时日》以及悲剧传统对他的功能和价值强调并不完全相同。

### QT8.2 接口

- motif：禁忌越界、知识／技术、惩罚
- archetype：文化英雄候选、反叛者候选
- plot_pattern：馈赠／盗取→越界→惩罚
- symbol：火

---

## C｜英雄远征、任务与怪物

这是一个大故事群，不等于所有英雄都有相同“英雄旅程”。

### 主要分支

- Heracles 的劳作／任务传统
- Perseus 与 Medusa
- Theseus 与 Minotaur
- Jason 与 Argonauts / Golden Fleece

### 共同结构

```text
身份／任务成立
→ 离开常规共同体
→ 进入边界／异域
→ 获取工具、同伴或神助
→ 面对怪物／禁令／试炼
→ 取得目标
→ 返回、建立秩序或产生新冲突
```

### 核心问题

“英雄”往往通过跨越文明边界而被确认，但怪物与异域也因此成为“谁定义正常世界”的镜子。

### QT8.2 接口

- motif：试炼、怪物对抗、神器、求索
- archetype：英雄、导师／神助者、怪物／边界存在
- plot_pattern：任务→远行→试炼→获得→返回
- symbol：金羊毛、迷宫等候选

## D｜特洛伊战争大循环

特洛伊战争不是只有《伊利亚特》。它是覆盖战争前因、战争本身、城破和战后命运的大型传统网络。

### 可拆为四段

```text
战争前因
→ 集结与远征
→ 围城与英雄冲突
→ 城破、返乡与幸存者谱系
```

### 核心人物群

Achilles、Agamemnon、Menelaus、Helen、Paris、Hector、Odysseus、Ajax，以及特洛伊与希腊双方大量英雄。

### 重要治理点

《伊利亚特》只聚焦战争末期的一小段冲突，不应被误写成“完整特洛伊战争故事”。大量前因和后续来自其他史诗传统、抒情诗、悲剧和后期神话整理。

### QT8.2 接口

- motif：战争、荣誉、复仇、牺牲、城破
- archetype：战士英雄、悲剧英雄候选
- plot_pattern：共同体战争→内部冲突→死亡／荣耀→秩序瓦解
- symbol：Achilles 的武具、木马等需按具体文本区分

## E｜归乡、漂泊与身份恢复

以 Odysseus 传统最具代表性，但“nostos／归乡”本身是特洛伊战争之后的重要故事群。

### 核心结构

```text
战争结束
→ 返乡受阻
→ 海上／异域漂泊
→ 怪物、诱惑、神意和身份试炼
→ 隐藏／恢复身份
→ 回到家园
→ 重新建立家庭与政治秩序
```

### 核心问题

归乡不是单纯“回家”，而是：

> 一个长期离开共同体的人，如何证明自己仍然拥有原来的身份和位置？

### QT8.2 接口

- motif：流浪、归乡、身份确认、诱惑
- archetype：漂泊英雄、Trickster／智谋者关系
- plot_pattern：离乡→试炼→隐匿身份→认出→秩序恢复
- symbol：海洋、弓、婚床等候选

---

## F｜亲族诅咒、复仇与悲剧家族

这是古典戏剧最重要的故事资源之一。

### 主要家族群

- Thebes / Oedipus 家族
- House of Atreus / Agamemnon—Orestes 家族

### 共同结构

```text
上一代罪／暴力／诅咒
→ 下一代继承问题
→ 预言、婚姻或权力冲突
→ 弑亲／复仇
→ 新一轮罪责
→ 神圣／法律／城邦秩序尝试终止循环
```

### 特别重要的转折

Aeschylus《Oresteia》把私人血亲复仇链与 Athena／Areopagus 审判联系起来，使故事不仅讨论“谁该复仇”，还讨论：

> 暴力循环是否能够被公共法律秩序重新处理？

### QT8.2 接口

- motif：弑亲、家族诅咒、血债复仇、禁忌亲属关系
- archetype：复仇者、被诅咒王族、预言者
- plot_pattern：旧罪→继承→复仇→再犯罪→秩序调停
- symbol：污染／血等须谨慎文本化

## G｜冥界下降与生死边界

### 主要分支

- Odysseus 获取亡者知识
- Heracles 完成任务
- Orpheus 试图带回 Eurydice
- 其他后期和罗马重写中的冥界之旅

### 核心结构

```text
失去／任务／求知
→ 获得进入边界的方式
→ 进入亡者空间
→ 接触亡者／守门者／规则
→ 得到知识或尝试带回对象
→ 返回成功、局部成功或失败
```

### 核心问题

- 死亡是否可以逆转？
- 活人为什么有资格进入亡者世界？
- 冥界之旅带回的究竟是人、知识还是身份改变？

### QT8.2 接口

- motif：冥界之旅、亡者归来、失去与追回
- archetype：下降者／引路者／冥界守护者
- plot_pattern：下降→禁令／试炼→返回或失败
- symbol：门、河流、渡者等需按具体文本记录

## H｜变形、欲望与身份转换

变形并非奥维德才出现，但《Metamorphoses》把大量希腊—罗马材料重新组织成以 transformation 为强连接机制的拉丁文学巨构。

### 常见触发

```text
欲望
冒犯
逃避追逐
神罚
神助
哀悼
身份隐藏
```

### 结果功能

变形可以：

- 终止追逐；
- 永久标记惩罚；
- 把人物转化为自然物／动物／星体；
- 保存记忆；
- 重新定义“人”的边界。

### QT8.2 接口

- motif：变形、惩罚、欲望、逃避
- archetype：变形者、追逐者、受罚者
- plot_pattern：冲突／欲望→变形→新秩序固定
- symbol：树、花、动物、星座等具体形式

## I｜罗马祖先、建城与帝国命运

这是必须保留的罗马本土／罗马化叙事维度，否则“希腊—罗马”会退化成“希腊神话 + 罗马名字”。

### 核心材料方向

- Aeneas 与特洛伊幸存者谱系
- Romulus / Remus 建城传统
- 神意、祖先与罗马政治共同体的关系

### 核心结构

```text
旧世界毁灭／离散
→ 幸存者迁徙
→ 获得神意／目的地
→ 战争与结盟
→ 新共同体建立
→ 后世王权／帝国获得祖先谱系
```

### QT8.2 接口

- motif：亡国、流亡、建国、天命／合法性
- archetype：祖先英雄、建城者
- plot_pattern：毁灭→迁徙→试炼→定居→建国
- symbol：城墙、祖先谱系等后续核验

# 故事群之间的关系

这些故事群不是九个互不相干的盒子。例如：

```text
特洛伊战争
├─ → Odysseus 归乡
├─ → Agamemnon 回归 → Atreus 家族复仇
└─ → Aeneas 离散 → 罗马祖先／建国叙事
```

又如：

```text
神代秩序
→ 人神边界
→ 英雄获得神性血统／神助
→ 英雄进入边界空间
→ 怪物、冥界、归乡等叙事展开
```

因此，Canvas 应优先表现这些“故事群之间的生成关系”，而不是画一个人物关系大全。

# 后续治理

下一轮内容建设时，每个故事群至少补齐：

1. 较早可见文本；
2. 关键定型文本；
3. 主要版本差异；
4. 罗马重写节点；
5. QT8.2 四类组件；
6. relation confidence。
