# 历史与谱系演进

```text
氏族 / 王朝 / 史诗谱系
→ 现实主义家庭实验室
→ Buddenbrooks / Forsytes：现代Family Saga成熟
→ 现代主义：家谱开始破裂
→ 中国、东亚、中东：现代化进入父权家庭
→ 拉美：Family Saga × Nation
→ 奴隶制 / 殖民：家谱本身被历史切断
→ Diaspora / 当代：从保存谱系到审问谱系
```

现代家族文学越来越关心的，不再是“家如何延续”，而是**这个家为什么被叙述成现在这个样子**。
