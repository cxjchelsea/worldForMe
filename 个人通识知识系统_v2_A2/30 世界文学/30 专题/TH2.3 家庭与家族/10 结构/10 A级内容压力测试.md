# A级内容压力测试

## 1. 测试目的

本轮不是重新证明“家庭文学很多”，而是检验 TH2.3 在升级到 A 级以后是否满足：

1. 七个核心问题继续稳定；
2. 统一机制能跨时间、跨传统解释作品；
3. TH2.2 / TH2.4 边界足够清楚；
4. TH4 / TH6 / TH7 / TH3.5 等外部主题不会被家庭主题吞并；
5. 不需要新增第八问或 TH2.3.x。

## 2. 强判据

作品只有在以下机制不可替代时才强命中 TH2.3：

```text
家庭成员资格
→ 资源 / 地位 / 家名分配
→ 角色、义务与权威
→ 个体人生路径
→ 跨成员 / 跨代传递
→ 外部冲击
→ 家族维系、断裂或重组
```

负向规则：

```text
有家庭成员 ≠ TH2.3
有亲子冲突 ≠ TH2.3
有夫妻冲突 ≠ TH2.3
跨多代叙事 ≠ TH2.3
人物来自名门 / 大家族 ≠ TH2.3
战争拆散某一家人 ≠ 自动 TH2.3
```

## 4. 七问题复核

### P1 谁被视为家人

继续独立成立。血缘、婚姻、收养、私生、失散、chosen family 等都能制造成员资格问题。

结论：

```text
P1 = STABLE
BLOOD_RELATION = NOT_SUFFICIENT
LEGAL_RELATION = NOT_NECESSARY
```

### P2 资源、财产与继承

《红楼梦》《布登勃洛克一家》《喧哗与骚动》《傲慢与偏见》证明资源沿亲属网络传递是稳定机制。

但必须维持：

```text
财富 / 阶级本身 → TH4
财富沿亲属规则传递 → TH2.3
```

结论：P2 稳定。

### P3 角色、义务与权威

《家》《金锁记》《到灯塔去》《变形记》显示，家庭会把“你是谁的谁”转化为具体义务与权威。

与 TH2.4 的边界：
- 家庭系统怎样规定父亲/母亲/长子/照料者角色 → P3；
- 某对父母子女怎样相爱、控制、冲突 → TH2.4。

结论：P3 稳定。

### P4 家庭怎样塑造人生选择

继续保留，但严格限界：只有家庭位置、家名、继承、照料义务等作为结构条件时成立。

```text
我是谁 → TH1.1
家庭位置使我能/不能做什么 → TH2.3 P4
```

结论：P4 稳定。

### P5 秘密、记忆与创伤传递

《百年孤独》《喧哗与骚动》《宠儿》《金锁记》提供稳定证据。

边界：
- 记忆如何进入公共历史 → TH7；
- 家庭作为沉默、转述、重复和传递装置 → TH2.3。

结论：P5 稳定。

### P6 外部历史冲击

《宠儿》《家》《愤怒的葡萄》《同名人》证明 P6 具有跨传统解释力。

但 P6 不是“作品发生了战争/迁徙”。必须出现家庭网络真实变化：成员失散、居住变化、照料重排、谱系断裂、跨地家庭形成等。

结论：P6 稳定。

### P7 维系、断裂与重新组成

从《红楼梦》的衰败、《宠儿》的重组、《变形记》的成员排除，到移民家庭的跨地维系，均显示 P7 不等于伴侣关系是否继续。

```text
一对伴侣继续 / 分手 → TH2.2
一个家庭网络继续 / 解体 / 重组 → TH2.3
```

结论：P7 稳定。

## 5. TH2 内部边界复核

### TH2.2 ↔ TH2.3

```text
两个人怎样共同生活、信任、修复、退出？
→ TH2.2

婚姻 / 伴侣关系怎样改变亲属网络、继承、家名和成员资格？
→ TH2.3
```

《米德尔马契》《金锁记》《安娜·卡列尼娜》验证两者可以共存但职责不同。

结论：PASS。

### TH2.3 ↔ TH2.4

```text
家庭系统规定了什么角色和义务？
→ TH2.3

具体父母—子女如何爱、养育、控制、依赖、冲突和分离？
→ TH2.4
```

《金锁记》《宠儿》《到灯塔去》验证边界可操作。

结论：PASS。

## 6. 高风险误判复核

### “多代小说 = 家族主题”

FALSE。跨代只是形式条件；必须分析家族系统如何传递和变化。

### “家里发生冲突 = 家庭主题”

FALSE。冲突可能真正属于爱情、亲子、性别、阶级或暴力。

### “战争/迁徙拆散家庭 = 自动 TH2.3”

FALSE。只有作品继续分析家庭网络怎样被重排、维系或重组时才成立。

### “血缘 = 家庭”

FALSE。TH2.3 同时处理被血缘家庭排除者与非血缘家庭的形成。

## 7. 是否需要第八问题

候选项测试：

- 照料：可以落入 P3，并在维系层进入 P7；
- 家名/名誉：可由 P3/P4/P5 解释；
- 祖宅/地方：资源层进入 P2，家园感另归 TH3.6；
- chosen family：P1 + P7 足够；
- 跨地家庭：P6 + P7 足够；
- 家庭暴力：家庭权力可进入 P3，具体暴力伤害进入 TH6。

未发现需要独立第八问的结构证据。

## 8. 是否需要 TH2.3.x

七问题已经组成可独立承载完整知识体系的叶节点内部结构。继续拆“继承家庭、创伤家庭、移民家庭、chosen family”等会把机制/历史条件误升格为坐标。

结论：

```text
TH2.3_A_LEVEL_CONTENT_TEST = PASS
SEVEN_PROBLEMS = STABLE
EIGHTH_PROBLEM = NOT_REQUIRED
CORE_FAMILY_SYSTEM_MECHANISM = STABLE
CROSS_TRADITION = PASS
TH2_SIBLING_BOUNDARIES = PASS
DOMAIN_BOUNDARIES = PASS
SECOND_DIMENSION = NOT_REQUIRED
TH2.3.x = NOT_REQUIRED
CONTENT_LEVEL = A
```
