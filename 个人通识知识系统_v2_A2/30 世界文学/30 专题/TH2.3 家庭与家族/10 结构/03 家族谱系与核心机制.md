# 家族谱系与核心机制

本页回答的不是“作品写了哪些家庭成员”，而是：**家庭为什么能够作为一个跨成员、跨时间持续运行的社会关系系统，以及这种系统如何塑造成员、传递资源与记忆，并在断裂后重新组成。**

机制是专题内部解释工具，不升格为新的 TH2.3.x。

## 1. 统一机制

```text
成员资格与亲属命名
→ 决定谁被算作“自己人”
→ 资源、姓名、地位、居所与继承权被分配
→ 角色、义务与权威形成稳定期待
→ 个体选择被家族位置约束或支持
→ 规则、秘密、记忆与创伤跨成员 / 跨代传递
→ 婚配、死亡、迁徙、战争、社会变迁打断既有结构
→ 家族通过继承、照料、排除、收养、重组或重新叙述自己来回应
→ 新结构再次定义成员资格、资源和义务
```

因此家庭系统不是一张静态家谱，而是一个循环：

> **谁属于我们 → 谁得到什么 → 谁应当做什么 → 这些安排怎样被传下去 → 外部变化如何打断它 → 家庭怎样重新定义自己。**

## 2. 成员资格：血缘只是其中一种规则

家庭首先要解决“谁属于我们”。成员资格可能来自：

- 血缘与出生；
- 婚姻与姻亲；
- 收养、继亲、寄养；
- 家名、宗族、户籍或法律承认；
- 长期照料与共同生活；
- 自愿结成的 chosen family；
- 共同经历创伤、迁徙或流亡后形成的替代亲属关系。

需要区分：

```text
有血缘
≠ 自动被承认为家人

没有血缘
≠ 不能形成家庭
```

文学经常通过私生子、养子、继亲、弃儿、失散亲属、混合家庭和 chosen family 暴露成员资格并非自然事实，而是被承认、命名和实践出来的关系。

## 3. 资源与继承：家庭怎样把过去送进未来

P2 不只是“谁分到遗产”。家族资源包括：

- 土地、房屋、祖宅；
- 现金、产业、债务；
- 姓名、头衔、声望；
- 教育机会、职业入口与社会关系；
- 照料资源；
- 甚至被迫继承的义务与风险。

继承的核心机制是：

```text
上一代积累 / 失去资源
→ 经由亲属规则分配
→ 下一代获得不同起点
→ 家族差异继续被复制或打断
```

所以 TH2.3 与 TH4 的区别是：TH4 研究阶级、财富和劳动结构；TH2.3 只在资源**沿亲属网络被保存、转移、集中、剥夺或再分配**时介入。

## 4. 角色、义务与权威：家庭怎样组织“应该”

家庭成员一旦被承认，就通常获得角色期待：

- 长子 / 幼子；
- 父亲 / 母亲；
- 媳妇 / 女婿；
- 继承人；
- 照料者；
- 经济供养者；
- 维持家名者；
- “懂事的孩子”或“承担责任的人”。

这些角色把亲属关系转化为规范：

```text
你是谁的谁
→ 你应该做什么
→ 你可以要求什么
→ 谁有权决定你的选择
```

P3 与 TH2.4 的区别在于：P3 研究**家庭系统里的角色分配**；TH2.4 研究具体父母—子女之间怎样爱、控制、照料、冲突和分离。

## 5. 家庭位置如何塑造成员人生

P4 不是泛泛的“家庭影响性格”，而是家庭结构怎样改变真实选择空间。例如：

```text
继承人身份
→ 职业与婚配义务

家族债务
→ 个体承担经济责任

家名 / 名誉
→ 某些行为变得不可接受

照料角色
→ 迁徙、职业和亲密关系选择受限
```

如果问题最终转为“我如何理解自己是谁”，进入 TH1.1；如果核心仍是“家庭位置如何组织我的人生路径”，则留在 TH2.3。

## 6. 传递机制：家庭为什么可以跨代持续

家族传递的不只有遗产，还包括：

- 公开家史；
- 被隐藏的秘密；
- 对某个成员的禁忌；
- 创伤与恐惧；
- 重复的角色分配；
- 对婚姻、性别、职业、阶级的期待；
- 名字、仪式与纪念实践。

可形成：

```text
上一代经历
→ 被讲述 / 隐瞒 / 误述
→ 下一代在不完整信息中行动
→ 重复、反抗或重新解释旧模式
```

这里与 TH7 的分工是：TH7 研究记忆如何进入历史时间；TH2.3 研究**家庭作为记忆传递装置**。

## 7. 外部冲击：历史怎样进入家族内部

战争、革命、奴隶制、殖民、迁徙、城市化、法律改革、经济危机等不会因为发生在家族作品里就自动成为 TH2.3。

只有当它们造成：

```text
成员失散
谱系断裂
家庭规模改变
居住结构改变
照料责任重排
继承规则失效
跨国家庭形成
新的成员被纳入 / 排除
```

才进入 P6。

## 8. 维系、断裂与重组

P7 的关键不是“这个家最后还在不在”，而是家族如何回应变化。

常见机制包括：

- 通过婚配和继承维系旧结构；
- 通过牺牲个体维持家族整体；
- 分家、断绝关系或流亡；
- 收养、继亲和再婚形成新结构；
- 失散成员重新连接；
- chosen family 替代断裂血缘；
- 重新讲述家史，为新家庭赋予连续性。

因此：

> **家庭重组不等于恢复原样。**

很多作品真正展示的是：旧家庭已经无法恢复，只能建立一种不同的关系网络。

## 9. 八组稳定张力

```text
血缘         ↔ 承认
个体利益     ↔ 家族义务
平等成员     ↔ 等级角色
共同资源     ↔ 私人所有
继承         ↔ 自主选择
公开家史     ↔ 家族秘密
连续谱系     ↔ 断裂家谱
维系旧家族   ↔ 重新组成家庭
```

这些张力是跨传统比较工具，不是第二层 taxonomy。
