# 家庭与家族

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH2 亲密关系、家庭与成长 → **TH2.3 家庭与家族**

## 1. 专题定位

本专题研究的不是泛泛的“亲情”，也不等于 Family Saga 类型史。它研究的是：**家庭或家族作为一个跨成员、跨时间的关系系统，如何界定谁属于“我们”，如何保存与分配资源，如何组织角色、义务与权威，如何把家名、秘密、记忆与创伤传递下去，又如何在婚配、死亡、迁徙、战争和社会变迁中维系、断裂或重新组成。**

最小纳入测试：

> 如果拿掉“这个家庭/家族作为一个持续系统如何组织成员、资源、义务与传递”，作品的主要冲突或意义结构是否会发生根本变化？若不会，一般不作为 TH2.3 核心。

因此：

```text
有家人出现
≠ TH2.3

有亲子冲突
≠ TH2.3

有夫妻关系
≠ TH2.3

跨了好几代
≠ TH2.3
```

真正进入 TH2.3 的，是**家庭网络本身成为因果结构**。

## 3. A级统一机制

家庭/家族可以理解为一套持续运行的关系系统：

```text
成员资格与亲属命名
→ 形成“谁属于这个家庭”
→ 资源、财产、姓名与位置在成员之间分配
→ 角色、义务与权威被制度化 / 日常化
→ 家庭位置进入个体人生选择
→ 秘密、记忆、创伤与规则跨成员 / 跨代传递
→ 外部历史冲击打断或重排既有网络
→ 家族通过继承、照料、婚配、迁移、收养、排除或重新结盟维系 / 解体 / 重组
↺
新的家庭结构重新定义成员资格、资源和义务
```

可压缩为：

> **成员资格 → 资源与位置 → 角色与义务 → 人生约束 → 跨代传递 → 外部冲击 → 维系/断裂/重组。**

## 4. 八组稳定张力

- 血缘 ↔ 承认
- 个体利益 ↔ 家族义务
- 平等成员 ↔ 等级角色
- 共同资源 ↔ 私人所有
- 继承 ↔ 自主选择
- 公开叙事 ↔ 家族秘密
- 连续谱系 ↔ 断裂家谱
- 维系旧家族 ↔ 重新组成家庭

其中最重要的校准是：

> **血缘不自动制造家庭成员资格，非血缘也不自动排除家庭。**

收养、继亲、姻亲、寄养、chosen family、断裂后重新组成的关系，都可以成为 TH2.3 的核心材料，只要作品真正分析“谁被承认为家人，以及这种承认带来什么资源、义务和位置”。

## 5. 与 TH2.2 / TH2.4 的最小分工

```text
两个人怎样把持续亲密关系经营下去？
→ TH2.2

一个家庭 / 家族网络怎样组织成员、资源、角色与传递？
→ TH2.3

父母—子女 / 祖辈—后代之间具体怎样爱、管教、依赖、冲突与分离？
→ TH2.4
```

同一作品可以多标，但必须分别提出独立问题。

例如《红楼梦》：
- 贾府内部的家产、婚配、等级、成员资格与衰败 → TH2.3；
- 某一对父母—子女之间的具体权威和情感关系 → TH2.4；
- 具体伴侣如何维持长期关系 → 只有当作品确实分析关系运行时才进入 TH2.2。

## 6. 与其他专题的边界

- **TH2.1 爱情与欲望**：具体他者如何成为爱欲对象 → TH2.1；婚配如何改变家族联盟、继承和成员资格 → TH2.3。
- **TH1.1 自我认同与主体性**：中心是“我是谁” → TH1.1；中心是“家名、家庭位置和家族义务如何限定我” → TH2.3。
- **TH3.1 性别与身体**：性别制度本身 → TH3.1；它进入家庭内部成为角色、继承或权威分配规则 → TH2.3。
- **TH4 社会、阶级与劳动**：阶级与财富结构本身 → TH4；资源如何沿亲属网络被继承、集中或剥夺 → TH2.3。
- **TH5 权力、制度与秩序**：国家、法律、制度本身 → TH5；法律怎样重新定义家庭成员资格、继承或婚配位置时可兼标 TH2.3。
- **TH6 战争、暴力与创伤**：伤害本身 → TH6；伤害怎样打断谱系、拆散家庭或在家族内部继续传递 → TH2.3。
- **TH7 历史、记忆与时间**：记忆如何保存、竞争、遗忘 → TH7；家庭作为保存、压抑、转述或沉默记忆的传递系统 → TH2.3。
- **TH3.5 迁徙与流亡**：位移如何改变生活结构 → TH3.5；迁徙如何把家庭变成跨地网络、重分照料和成员角色 → TH2.3。
