# 所罗门王｜named archetype Reference Topic

> **定位：**研究希伯来—圣经来源人物所罗门如何在保持命名与王族身份连续的同时，经由智慧、审判、知识、神圣王权、圣殿、超自然权能等特征的选择、放大、删减与新增，形成跨犹太、基督教、伊斯兰与秘传传统持续可识别的命名型文化原型。

## 1. named archetype 与 source figure 的分层

```text
QC1.1 source figure Solomon
→ 来源文本中的具体王者

QC2 named archetype Solomon
→ 在长期接受史中持续被识别为“所罗门／Sulayman”，
  但角色功能和故事系统不断被重写的文化人物模型
```

“著名”本身不构成准入；本专题关心的是身份连续性、稳定功能与可变接受特征如何共同维持 named archetype。

## 2. Accepted model

```text
required_identity_anchors
→ 保证“还是这个命名人物”

supporting_identity_anchors
→ 高稳定辨识特征，但不是纯身份同一性的最低条件

core_functions
→ 跨主要接受传统持续成立的角色功能

variable_features
→ 可被放大、删除、新增或重组的接受史特征
```

当前：

```text
required_identity_anchors
- Solomon / Sulayman 命名身份
- 大卫王族／以色列王身份连续

supporting_identity_anchors
- 智慧声望

core_functions
- 智慧王与裁判者
- 受神授权的王权
- 卓越／隐藏知识权威
```

“圣殿建造者／中心化者”已从 core 降为 variable feature：它在《列王纪》来源层极其重要，但不能作为所有后世 Solomon / Sulayman 重写都必须保留的角色功能。

## 3. 原型化链

```text
《列王纪》中的所罗门
→ 智慧／审判／圣殿／财富／王权张力
→ 智慧与作者权威的放大
→ 晚期古代超自然智慧／驱魔扩展
→ 《所罗门遗训》等 figure rewriting
→ Quranic Sulayman：先知王与神授权超自然统治
→ Solomonic magic：所罗门之名成为秘传知识权威
→ named archetype
```

这条链不要求各阶段具有同一神学或同一叙事序列；连续性由身份锚点与若干核心功能共同维持。

## 4. 关系词汇

Pilot B.1 已正式验证：

```text
figure_rewriting
```

用于：

> 同一可识别命名人物被继续使用，但其角色功能、故事环境或身份结构被系统性重写。

它区别于单纯 `character_or_name_borrowing`，也不要求像 `direct_adaptation` 那样改编某一整套来源故事。
