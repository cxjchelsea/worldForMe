# 来源人物与来源谱系

## 1. QC1.1.1 来源层

当前主要回指：

```text
QC1.1.1 希伯来—圣经叙事传统
→ 王权建立：扫罗—大卫—所罗门
→ 所罗门
```

来源人物功能包括：

- 智慧王；
- 圣殿建造者；
- 富强与国际声望的王；
- 王权集中与扩张的承担者；
- 后续王国分裂伏笔的一部分。

这说明来源层本身带有双重性：智慧／繁荣与王权负担／危机并存。

## 2. 主要来源文本

### 《列王纪》

核心入口：所罗门继承、求智慧、判断、圣殿建造、财富与国际声望，以及王权后期的张力。

QC1.1.1 已将《列王纪》标为 `historical_theological_reworking`；QC2 不在此重建整部文本史。

### 《历代志》

后续可用于比较所罗门形象的再组织方式；当前 Pass A 只标记为 `source_layer_parallel_reworking_candidate`，不在没有专题核证前扩大断言。

## 3. 原型化所需的后续层

```text
来源层

```

## 4. 来源治理

后世层不能倒灌进来源层。

```text
《列王纪》中的智慧王
≠ 已经完整具备中世纪 grimoire 中的魔法王形象
```

同样：

```text
《古兰经》中的 Sulayman
= Islamic reception / reconfiguration
≠ Hebrew Bible source layer 的另一抄本
```
