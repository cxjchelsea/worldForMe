# 阅读与研究

## 1. 最小阅读路线

```text
《列王纪》中的所罗门
→ 所罗门智慧传统／伪托作者权威
→ Josephus《犹太古史》8.42–49
→ 《所罗门遗训》
→ 《古兰经》中的 Sulayman
→ Solomonic magic / Key of Solomon 传统
```

阅读时持续追问：

- `required_identity_anchors` 是否仍存在？
- 智慧声望是身份支撑还是角色功能？
- 哪些来源特征被保留？
- 哪些来源特征虽然重要，却没有跨接受史稳定保留？
- 哪些新特征第一次进入并继续被复制？
- 人物是故事角色，还是已经成为知识／权威标签？
- 当前关系应是 `character_or_name_borrowing`、`figure_rewriting` 还是 `direct_adaptation`？

## 2. Pass B 的三个决定性答案

### 2.1 identity anchor 模型：保留并细分

Pass B 支持 named archetype 使用：

```text
required_identity_anchors
+
supporting_identity_anchors
```

当前所罗门：

```text
required
- Solomon / Sulayman 命名连续
- 大卫王族／以色列王身份连续

supporting
- 智慧声望
```

“智慧”非常稳定，但它不是纯粹身份同一性：匿名智慧王也可以具有同样功能。

### 2.2 builder_and_centralizer：从 core 降级

来源层中的圣殿建造与中心化极重要，但无法作为各主要接受层都必须保持的 named-archetype function。

因此：

```text
builder_and_centralizer
→ temple_builder_and_centralizer
→ variable_feature
```

新的 core functions：

```text
wise_king_and_judge
divinely_authorized_kingship
extraordinary_knowledge_authority
```

### 2.3 figure_rewriting：正式进入 Shared Data Layer

Pass B 支持：

```text
character_or_name_borrowing
< figure_rewriting
< direct_adaptation
```

这里的 `<` 表示关系表达强度／系统性逐步增强，不表示价值高低或证据高低。

`figure_rewriting` 专门表达：同一人物身份继续可识别，但角色功能和故事结构发生系统重组。

## 4. Pilot B.1 模板反馈

### KEEP

- `abstract_archetype / named_archetype` 区分；
- source figure 与 archetype 分层；
- `core_functions / variable_features`；
- `source_status`；
- relation record 原子性。

### ADD

named archetype 稳定字段：

```yaml
required_identity_anchors: []
supporting_identity_anchors: []
```

Shared Data Layer relation：

```text
figure_rewriting
```

### REVISE

named archetype 的 `core_functions` 不得直接复制来源人物最重要的所有特征；必须通过跨接受史压力测试。

### REMOVE / DEMOTE

```text

```

从 core 降为 `temple_builder_and_centralizer / variable_feature`。
