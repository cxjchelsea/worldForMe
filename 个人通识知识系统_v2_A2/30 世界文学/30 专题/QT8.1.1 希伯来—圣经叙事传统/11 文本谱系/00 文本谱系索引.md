# 文本谱系索引

QT8.1.1 的文本层不等于“圣经书卷目录”。本页解释不同文本／文本群在叙事传统中的角色。

## 首批角色

| 文本／文本群 | 当前角色 | Pilot 用途 |
|---|---|---|
| 《创世记》 | core_narrative_compilation | 创世、人类早期、洪水、祖先故事群 |
| 《出埃及记》 | core_narrative_compilation | 压迫、出走、摩西、盟约与共同体形成 |
| 《申命记》及申命传统 | interpretive_framework | 盟约、律法、历史解释框架 |
| 《撒母耳记》 | royal_narrative | 扫罗、大卫、王权建立与合法性 |
| 《列王纪》 | historical_theological_reworking | 王国、圣殿、国家失败与流亡解释 |
| 先知书文本群 | prophetic_reworking | 危机批判、审判、流亡与复归希望 |
| 《约伯记》 | wisdom_reworking | 受苦义人、正义与认识限度 |
