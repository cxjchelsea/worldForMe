# 推荐阅读入口

Pilot 阶段先定义“怎么进入文本”，不急于固定某一现代译本。目标不是从《创世记》一路机械读到最后一卷，而是按叙事机制进入。

## 1. 路线 A｜起源、祖先与人类边界

```text
《创世记》1–11
→ 亚伯拉罕故事
→ 雅各故事
→ 约瑟故事
```

重点观察：

- 创造与秩序
- 禁忌越界
- 兄弟冲突
- 洪水与灾后重建
- 离乡、应许、延迟与家族延续
- 家族冲突如何进入共同体起源叙事

## 2. 路线 B｜出埃及、盟约与共同体形成

```text
《出埃及记》叙事主干
→ 西奈／盟约核心段
→ 《申命记》选读
```

重点不是完整阅读全部律法细节，而是理解：

```text
压迫
→ 召唤
→ 解放
→ 穿越
→ 旷野
→ 盟约／律法
→ 共同体身份
```

## 3. 路线 C｜士师、王权与国家危机

```text
《士师记》选读
→ 《撒母耳记》主要叙事
→ 《列王纪》选读
```

建议重点追踪：

- 士师循环为什么不断重复；
- 为什么共同体要求王；
- 扫罗为何失败；
- 大卫为何同时成为理想王者来源与复杂问题人物；
- 所罗门、圣殿与王国合法性如何关联；
- 王国灭亡如何被重新解释。

## 4. 路线 D｜先知、流亡与复归

不建议一开始通读全部先知书，可先选一组具有代表性的危机文本，再回到具体经卷。

阅读问题应是：

- 先知怎样批判王权、社会不义和共同体秩序？
- 国家灾难怎样被解释？
- 审判之后为什么仍然保留复归和更新想象？
- 同一“希望”在不同先知文本中是否相同？

## 5. 路线 E｜智慧与受苦

```text
《箴言》选读
→ 《约伯记》
→ 《传道书》选读
```

这样可以先看到较稳定的智慧—报偿逻辑，再观察《约伯记》和《传道书》如何制造张力。

## 6. 路线 F｜诗篇、哀歌与共同体情感

选读：

- 王权／锡安诗篇
- 个人哀歌
- 共同体哀歌
- 感恩／赞美诗
- 《哀歌》部分章节

这条路线帮助理解：希伯来—圣经传统不只有“故事”，还通过可重复朗诵的情感与礼仪脚本保存共同体经验。

## 7. 最低成本主线

若只想建立通识骨架，可按：

```text
《创世记》1–11 + 祖先故事选读
→ 《出埃及记》核心叙事
→ 《申命记》选读
→ 《撒母耳记》主要叙事
→ 《列王纪》选读
→ 一组先知文本
→ 《约伯记》
```

对应知识链：

```text
世界与人类边界
→ 祖先与应许
→ 解放与盟约
→ 王权与国家
→ 灾难与流亡
→ 先知解释与复归希望
→ 正义与受苦问题
```

## 8. 文本史支线

在具备基本叙事骨架后，再进入：

```text
死海古卷
七十士译本
马所拉文本传统
现代校勘本
```

这条支线不是为了“多读几个圣经版本”，而是为了理解：

> 我们今天手里的圣经文本本身也有历史。

## 9. 暂不固定现代译本

选择译本时后续至少考虑：

- 是从希伯来语／亚兰语原文还是其他语言转译；
- 是否适合文学阅读；
- 是否提供必要注释；
- 是否说明重要文本异文；
- 是否明确其使用的文本底本。

现代研究、工具书与具体译本评估统一进入 `13.04 支撑研究书目`，避免与原典阅读路径混在一起。
