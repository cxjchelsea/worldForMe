# QT8.1.1｜希伯来—圣经叙事传统

> **定位：**研究古代以色列／犹大及后续犹太传统中，创世、祖先、出埃及、盟约、王权、流亡与复归等叙事如何形成、被书写与编纂，并经希伯来圣经／塔纳赫及其后续接受进入更广泛的犹太、基督教与伊斯兰文化网络。

## 1. 边界原则

本专题不是“圣经宗教百科”，也不把后世犹太、基督教、伊斯兰全部叙事混成一体。核心来源层以希伯来圣经／塔纳赫及与其形成相关的古代以色列—犹大叙事传统为中心；后续宗教传统的扩展与再解释作为接受史出口处理。

→ [[10 核心结构/01 定义、范围与边界]]

## 2. 核心结构速览

- 创世、伊甸与人类早期
- 洪水与灾变后秩序
- 巴别塔、语言分散与文明边界
- 族长／祖先叙事
- 出埃及、旷野与盟约
- 征服／定居与士师
- 王国、圣殿与王权
- 先知批判、流亡与复归
- 智慧、受苦与正义问题
- 弱者逆转、外来者与共同体身份边界

→ [[10 核心结构/05 核心叙事循环与故事群]]

## 4. 与 QT8.2 的接口

当前已完成第一轮跨主要故事群的四类对象映射，不再只是预留入口：

- `motif`：创世、禁忌越界、洪水、兄弟冲突、应许、牺牲试炼、解放、盟约、王权合法性、流亡与复归、义人受苦等
- `archetype`：祖先、先知、立法者／解放者、智慧王、受苦义人、被放逐者、地方拯救者等候选
- `plot_pattern`：秩序建立→越界→逐出；召唤→离乡→试炼→应许延续；压迫→召唤→出走→旷野→立约；失序→警告→灾难→流亡→复归等
- `symbol`：伊甸园、方舟、巴别塔、旷野、约柜、圣殿等候选，必须通过 symbol 准入规则，普通情节对象不自动进入符号层

摩西、约伯、该隐、所罗门、大卫等目前仍以命名型文化原型候选治理；是否正式进入 QT8.2，需要继续追踪跨文本、跨时代、跨媒介的稳定复用证据。

→ [[12 母题与跨文化关系/00 叙事组件映射索引]]

## 5. 跨文化关系治理

本专题特别区分两种方向：

```text
古代近东 → 希伯来—圣经传统
= 来源语境／共享区域传统／可能传播／结构相似

希伯来—圣经传统 → 后世犹太／基督教／伊斯兰／世俗文化
= 文本传承／翻译／解释／重述／改编
```

洪水、创世、婴儿获救、王权、智慧训诫等平行材料只有在传播链证据足够时才升级为历史传播；结构相似本身不构成直接借用证明。

→ [[12 母题与跨文化关系/02 传播、借用与结构相似]]
