# 与 QT8.2 的叙事组件映射

Pilot V0 先建立来源材料 → 四类对象的第一轮映射。

## 创世—伊甸故事群

- `motif`：创世、神人边界、禁忌越界、知识与后果
- `plot_pattern`：赋予秩序／命令 → 越界 → 认识变化 → 逐出
- `symbol`：伊甸园、树／果实等候选，需通过 symbol 准入规则

## 该隐与亚伯

- `motif`：兄弟冲突、嫉妒、亲族暴力、放逐
- `archetype`：背叛／弑亲兄弟候选
- `plot_pattern`：竞争 → 暴力 → 追问／审判 → 放逐与标记

## 洪水—挪亚

- `motif`：洪水灾变、被保全者、灾后重建、盟约
- `plot_pattern`：世界失序 → 灾变 → 少数保存 → 新秩序
- `symbol`：方舟候选

## 亚伯拉罕／祖先故事群

- `motif`：召唤、离乡、应许、迟延、不育与后裔、牺牲试炼
- `archetype`：祖先／信念试炼者候选
- `plot_pattern`：召唤 → 迁徙 → 应许 → 多次危机 → 家族延续

## 出埃及—摩西

- `motif`：压迫、解放、神圣召唤、旷野试炼、盟约
- `archetype`：立法者／解放者／先知型带领者候选
- `plot_pattern`：压迫 → 召唤 → 对抗 → 出走 → 穿越 → 旷野 → 立约
- `symbol`：旷野、约柜等候选

## 王权与所罗门

- `motif`：王权合法性、智慧王、圣殿、王国分裂
- `archetype`：智慧王／圣王候选；所罗门可评估命名型文化原型
- `symbol`：圣殿候选

## 约伯

- `motif`：义人受苦、试炼、正义与不可理解性
- `archetype`：受苦义人候选
- `plot_pattern`：秩序预期 → 灾难 → 争辩／质询 → 认识边界被重置

> 以上均为来源映射，不意味着 QT8.2 实体已全部正式建档。
