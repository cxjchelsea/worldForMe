# 核心叙事循环与故事群

第一版先识别高连接故事群，不穷尽所有人物和单篇故事。

## A｜创世—伊甸—人类越界

创造与秩序 → 人类被置于边界规则中 → 越界 → 后果与逐出。

## B｜该隐与兄弟冲突

亲族关系 → 嫉妒／竞争 → 暴力 → 罪责、放逐与标记。

## C｜洪水与灾变后重建

普遍性失序 → 审判／毁灭 → 被保全者 → 新秩序／盟约。

## D｜祖先、应许与迁徙

召唤 → 离乡 → 应许 → 延迟／危机 → 家族延续与土地关系。亚伯拉罕、以撒、雅各、约瑟等形成连续但内部多样的祖先故事群。

## E｜出埃及—旷野—盟约

压迫 → 召唤带领者 → 出走 → 穿越边界 → 旷野试炼 → 立约／律法 → 共同体塑形。

## F｜定居—士师循环

失序／背离 → 外部压迫 → 呼求 → 拯救者出现 → 暂时恢复 → 再次失序。

## G｜王国、王权与圣殿

王权诉求 → 受膏／合法性 → 王朝建立 → 成功与失败 → 圣殿与中心化 → 王权受到先知和伦理秩序约束。

## H｜先知警告—灾难—流亡

失序／不义 → 警告 → 拒绝或延迟回应 → 国家灾难 → 流亡 → 对历史意义的重新解释。

## I｜复归与共同体重建

流亡／失地 → 复归希望 → 返回／重建 → 律法、圣殿与身份边界重新组织。

## J｜智慧与受苦义人

传统智慧秩序 → 无辜或难以解释的受苦 → 对报偿、正义与认识限度的追问。
