最大的区别在于：

SFE现在的主题体系本身就同时收录AI、Alternate History、Aliens、Afrofuturism等大量不同母题，所以科幻最适合用“坐标”而不是单标签理解。([科幻百科全书](https://sf-encyclopedia.com/category/theme?utm_source=chatgpt.com))

# 四十六、到这里：B级主库约235个阅读节点

相比之前500+节点，最大的变化不是简单“砍掉一半”。

> **每个作者不再追全集，每个类型保留足够代表作。**

阿西莫夫不需要整个机器人—帝国—基地宇宙；

但他们代表的重要类型必须留下。

所以这版更适合真正执行。

# 六十八、真正执行时仍然分三轮

## 第一轮：只读★

大约 **80本左右**。

目标不是：

> “我已经读了80本科幻。”

而是你能够看见：

> 《弗兰肯斯坦》和《克拉拉与太阳》为什么属于同一条问题史；

> 《世界大战》和《三体》之间第一接触观念怎样变化；

> 《我们》《1984》《使女的故事》为什么代表不同形式的控制恐惧；

> 为什么Cyberpunk是在反抗黄金时代；

> 为什么勒古恩、Butler会改变“什么东西可以成为科幻题材”。

------

## 第二轮：把◆补完

进入大约 **200—235个阅读节点**。

这就是我们现在确定的：

# **B级科幻文学图谱。**

此时主要流派已经基本都有坐标。

------

## 第三轮：个人深挖，不再膨胀公共书单

比如最终发现自己特别喜欢：

**Hard SF**

就深挖：

Clarke → Niven → Benford → Robinson → Egan → Watts → Reynolds。

如果喜欢：

**社会/人类学科幻**

就深挖：

Le Guin → Butler → Delany → Atwood → Jemisin。

如果喜欢：

**AI / 后人类**

就走：

Shelley → Čapek → Asimov → Dick → Gibson → Egan → Watts → Leckie → Ishiguro。

如果喜欢：

**文明尺度**

就走：

Stapledon → Asimov → Herbert → Banks → Simmons → Vinge → Liu Cixin → Tchaikovsky。

------

这样现在两个体系就统一了：

| 文学类别 | A级骨架 | B级系统  | C级总库      |
| -------- | ------- | -------- | ------------ |
| **推理** | ~70     | ~180–220 | 500+可继续扩 |
| **科幻** | ~80     | **~230** | 500+         |
| 恐怖     | 后续    | 后续     | 后续         |
| 奇幻     | 后续    | 后续     | 后续         |
| 武侠     | 后续    | 后续     | 后续         |

我认为这个尺度比之前的527节点更合适：**B级已经足以让你“每种类型都看过、主要历史节点都知道”，但又没有变成百科全书式收藏任务。**之后我们继续做恐怖、奇幻等文学类别时，也可以固定按同样的A级/B级/C级标准，不再来回变化。
