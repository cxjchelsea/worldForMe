# 支撑研究书目

本页保存“为什么这样理解这套传统”的现代研究入口，不与原典书单混合。

目标不是建立完整圣经学 bibliography，而是为 QC1.1.1 的几个核心问题提供最低限度、功能明确的研究入口：

```text
经卷结构／整体导论
文本形成／编纂／经典化
古代近东语境
文本批判／抄本／古代译本
文学结构
犹太解释与后世接受
跨宗教接受
```

---

## 1. 核心通识导论

### John J. Collins, *Introduction to the Hebrew Bible*

- `research_role`: general_introduction
- `scope`: Hebrew Bible / Second Temple context
- `use_for`: 全专题；尤其 10.01、10.02、10.08、11
- `evidence_level`: core
- 功能：建立希伯来圣经整体经卷结构、历史背景、文学与宗教问题的通识框架。
- 使用方式：优先作为“地图式导读”，不要求把每章当作唯一学术结论。

### Marc Zvi Brettler, *How to Read the Jewish Bible*

- `research_role`: historical_literary_reading
- `scope`: Hebrew Bible / Jewish Bible
- `use_for`: 10.01、10.03、10.05、11
- `evidence_level`: core
- 功能：帮助区分古代文本的历史—文学语境与后世教义性阅读。
- 使用方式：特别适合训练“来源文本 ≠ 后世唯一解释”的意识。

### Michael D. Coogan, *The Old Testament: A Historical and Literary Introduction to the Hebrew Scriptures*

- `research_role`: general_introduction
- `scope`: Hebrew Scriptures
- `use_for`: 经卷结构、历史背景、文学结构
- `evidence_level`: supporting
- 功能：适合作为 Collins 的替代／互补型整体导论。

## 2. 文本形成、编纂与经典化

### Konrad Schmid & Jens Schröter, *The Making of the Bible*

- `research_role`: textualization_and_canon
- `scope`: Hebrew Bible + New Testament formation overview
- `use_for`: 10.07、10.08、11
- `evidence_level`: core
- 功能：帮助建立“文本形成 → 编纂 → 经卷集合 → 经典化”的过程意识。
- 使用提醒：本专题只提取与希伯来圣经形成和经典化有关的部分，不把新约形成史混入来源层。

### James L. Kugel, *How to Read the Bible*

- `research_role`: interpretation_history
- `scope`: biblical interpretation
- `use_for`: 10.08、13.01
- `evidence_level`: core
- 功能：连接古代文本、早期解释传统与现代批判阅读，特别适合观察人物／故事如何被后续解释共同体重新塑形。

## 3. 五经与叙事形成

这一层用于深化《创世记》《出埃及记》《申命记》等核心材料的复杂形成史。

### 建议研究方向

- Pentateuch / Torah formation
- source / redaction / supplementary models
- Deuteronomy and Deuteronomistic traditions
- priestly materials

### 使用原则

这里尤其要遵守 QC1.1.1 已建立的争议治理：

```text
A｜较强共识
文本存在复杂形成与编辑史

B｜主流但存在竞争模型
某些大型编纂／编辑层解释

C｜具体学派重建
某一段精确属于某来源、某年代、某编辑者
```

以后新增具体专著时必须标记属于哪一级，不把某一种来源假说直接写成“圣经就是这样写成的”。

## 4. 古代近东比较

这一层直接服务 `12.02 传播、借用与结构相似`。

需要补强的主题：

- 美索不达米亚创世传统；
- 阿特拉哈西斯／《吉尔伽美什史诗》洪水传统；
- 埃及智慧文学；
- 古代近东王权与条约；
- 婴儿获救／英雄出生故事；
- 黎凡特宗教与神话语境。

### 研究时的固定问题

```text
相似对象是什么？
单个 motif 还是成组结构？
是否存在历史接触环境？
是否存在语言／文本证据？
是直接依赖、媒介传播、共享区域资源，还是仅结构相似？
```

目的不是寻找“圣经抄自哪里”，而是判断不同叙事之间最合理的关系等级。

## 5. 文本批判、死海古卷与古代译本

这是当前 Pilot 下一轮最值得补强的研究层之一。

重点问题：

- 马所拉文本传统是什么；
- 死海古卷提供了哪些文本见证；
- 七十士译本与希伯来文本之间如何比较；
- 为什么一些经卷存在不同古代文本形态；
- 现代校勘本如何在多个见证之间工作。

### 建议后续研究对象

- Emanuel Tov 的希伯来圣经文本批判研究
- Dead Sea Scrolls textual scholarship
- Septuagint studies

这些对象进入正式核心书目前，应进一步核证具体版本与适用范围。

## 6. 王权、历史书写与先知传统

服务：

- `10.05` 王权／流亡故事群
- `10.08` 内部演变
- `11` 《撒母耳记》《列王纪》《申命记》及先知文本角色

重点研究问题：

```text
王权如何被合法化又被批判？
大卫传统如何形成？
王国失败如何被解释？
申命／申命史框架如何组织历史？
先知文本如何连接政治危机、伦理批判与复归希望？
```

这部分以后可以按“Davidic kingship / Deuteronomistic History / prophetic literature”分别补书。

## 7. 流亡、波斯时期与第二圣殿时期

这层是理解“经典共同体如何形成”的关键背景。

重点研究：

- 巴比伦流亡；
- 波斯时期复归；
- 第二圣殿；
- 文士／律法与共同体身份；
- 希腊化环境；
- 多文本、多语言与解释共同体。

它直接支撑：

```text
历史危机
→ 叙事重组
→ 文本权威强化
→ 经卷集合
→ 持续解释
```

## 8. 后续犹太解释与接受史

### James L. Kugel

已经作为核心入口。

后续可进一步扩展：

- Second Temple interpretation
- Midrash / rabbinic interpretation

目的不是建立完整拉比文学专题，而是回答：

这与 QC2 命名型文化原型判断直接相关。

## 9. 基督教与伊斯兰接受

当前只建立研究方向，不把完整书目提前塞进 QC1.1.1。

### 基督教接受

关注：

- Hebrew Bible → Christian Old Testament 的重新定位；
- typology / allegory 等解释机制；
- 文学与视觉文化中的人物再造。

### 伊斯兰接受

关注：

- Qur'anic retelling；
- shared figures with transformed narrative functions；
- 后续解释传统。

这一部分必须保持：

```text
共享人物
≠ 同一文本谱系
≠ 同一故事版本
```

## 12. 书目治理字段

后续每本研究书至少记录：

```text
research_role
scope
use_for
evidence_level
methodological_position
```

建议值：

### research_role

- general_introduction
- historical_context
- ancient_near_east_comparison
- pentateuch_formation
- textual_criticism
- manuscript_studies
- translation_studies
- kingship_history
- prophetic_literature
- second_temple
- interpretation_history
- reception

### evidence_level

- core
- supporting
- specialized
- optional

### methodological_position

- broad_consensus
- mainstream_competing_model
- specific_reconstruction

这样可以避免“参考书越多越好”，让每一本书都对应专题中的具体问题。
