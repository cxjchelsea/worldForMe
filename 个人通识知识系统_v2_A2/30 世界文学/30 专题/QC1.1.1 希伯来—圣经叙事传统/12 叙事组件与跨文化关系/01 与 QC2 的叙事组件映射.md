# 与 QC2 的叙事组件映射

本页把 QC1.1.1 的来源材料映射到 QC2 的六类对象：`motif / tale_type / character_type / named_archetype / plot_pattern / symbol`。`tale_type` 待准入；下文若仍写 `archetype`，先按 `character_type` 读，命名型单独标明。

原则：

1. 先从来源传统内部识别，再进入跨文明比较；
2. 同一故事允许多标签；
3. 不把 theme 伪装成 motif；
4. 著名人物不自动成为 named archetype；
5. 故事中出现的物件不自动成为 symbol。

---

## A｜创世—伊甸—人类越界

### 来源结构

创造／区分 → 人类获得位置与限制 → 禁令 → 越界 → 认识与关系变化 → 逐出。

### QC2 映射

- `motif`
  - 创世与秩序建立
  - 神—人边界
  - 禁忌知识／禁令
  - 越界与后果
  - 失落家园
- `archetype`
  - 始祖
  - 越界者／诱惑者等只能在具体角色层继续核证
- `plot_pattern`
  - `秩序建立 → 命令 → 越界 → 认识变化 → 逐出`
- `symbol`
  - 伊甸园：高优先候选
  - 生命树／知识树：高优先候选
  - “禁果”：后世文化符号很强，但需注意来源文本并未把果实明确限定为苹果；来源层与后世图像定型必须分开

### 主要 QC2 母题簇

`QC2.1 / QC2.3 / QC2.12 / QC2.15`

### QC2 映射

  - 嫉妒
  - 罪责
  - 放逐
- `archetype`
  - 弑亲兄弟候选

## D｜巴别塔

### 来源结构

共同语言／聚集 → 建城筑塔 → “通天／扬名”企图 → 神圣干预 → 语言分化 → 人群分散。

### QC2 映射

- `motif`
  - 集体建造
  - 文明野心
  - 越界
  - 语言分化
  - 人群分散
- `archetype`
  - 暂不建立人物型原型
- `plot_pattern`
  - `聚集 → 大工程 → 越界／扬名 → 干预 → 分化／分散`
- `symbol`
  - 巴别塔：高优先级命名型文化符号候选

### 主要母题簇

`QC2.3 / QC2.4 / QC2.19 / QC2.20`

后世“巴别塔”经常脱离原故事成为语言分裂、现代技术工程、知识雄心或沟通失败的文化符号，因此特别适合后续 QC2 实体化研究。

# 命名型原型候选优先级

第一轮可按后续核证优先级分为：

**高优先：**摩西、约伯、该隐、所罗门、大卫。  
**中优先：**亚伯拉罕、约瑟、雅各、以斯帖。  
**暂不升级：**只在来源内部重要、但尚未证明形成稳定跨文本文化模型的人物。

这些优先级只是研究队列，不是本体结论。

# 映射治理

本页中的所有映射均表示：

```text
QC1.1.1 来源材料
→ QC2 候选组件
```

而不是：

```text
候选组件已正式建档
或
某一抽象原型只有希伯来—圣经来源
```

后续正式建设 QC2 时，需要把同一 motif／archetype／plot_pattern／symbol 在多个 QC1.1 来源传统中的证据放在一起比较，再决定实体边界。
