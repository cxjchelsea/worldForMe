# 文本谱系索引

QT8.1.1 的文本层不等于“圣经书卷目录”。本页解释不同文本、文本群、抄本与古代译本在叙事传统中的**功能角色**，并区分：

```text
叙事来源资源
≠ 现存经卷
≠ 编纂／解释框架
≠ 抄本见证
≠ 古代译本
≠ 后世经典边界
```

因此，本专题不以“哪本书最早”或“哪位作者一次写成”来组织文本谱系，而以“这些材料怎样保存、重组并进入经典共同体”来组织。

## 1. 核心经卷与文本群

| 文本／文本群 | 当前角色 | 在专题中的主要功能 |
|---|---|---|
| 《创世记》 | `core_narrative_compilation` | 创世、人类早期、洪水、祖先故事群的集中编排 |
| 《出埃及记》 | `core_narrative_compilation` | 摩西、出走、旷野前段、盟约与共同体形成 |
| 《申命记》及申命传统 | `interpretive_framework` | 盟约、律法、土地、忠诚与历史解释框架 |
| 《撒母耳记》 | `royal_narrative` | 扫罗—大卫、王权建立、合法性与王权危机 |
| 《列王纪》 | `historical_theological_reworking` | 王国兴衰、圣殿、国家失败与流亡解释 |
| 先知书文本群 | `prophetic_reworking` | 危机批判、审判、流亡与复归希望 |
| 《诗篇》／哀歌等诗性材料 | `liturgical_memory` | 礼仪、共同体记忆、哀悼、赞美与王权／圣殿想象 |
| 《约伯记》 | `wisdom_reworking` | 受苦义人、正义、报偿与认识限度 |

## 2. 文本见证与版本层

这些对象不是“故事来源文本”，而是帮助我们理解文本怎样被保存和流通：

| 对象 | 角色 | 为什么重要 |
|---|---|---|
| 死海古卷中的圣经抄本 | `manuscript_witness` | 显示第二圣殿时期存在多种文本形态与抄写传统 |
| 七十士译本（LXX） | `ancient_translation_witness` | 证明希伯来传统进入希腊语环境后发生翻译、文本与解释层变化 |
| 马所拉文本传统 | `medieval_textual_tradition` | 构成现代希伯来圣经校勘的重要文本基础之一，但不等于作者亲笔原稿 |

## 4. 数据层

`03 希伯来—圣经叙事传统文本.base` 聚合 `11 文本谱系/10 文本实体/` 下的专题—文本关系记录。

这些记录只说明“某文本／见证在 QT8.1.1 中承担什么角色”，不复制完整作品信息。

## 5. 治理原则

1. 故事存在时间不得等同于现存经卷形成时间。
2. “最早现存见证”不得自动写成“故事起源”。
3. 经卷内部可能包含多层材料，不把整卷压成单一作者、单一年代。
4. 抄本与译本用于研究文本传承和版本差异，不与叙事来源混为一类。
5. 经典边界在不同共同体中并不完全相同；QT8.1.1 以希伯来圣经／塔纳赫来源层为中心，其他经典形态作为接受与文本史关系处理。
