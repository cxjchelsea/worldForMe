# QC2 叙事组件映射索引

QC1.1.1 是“来源谱系层”，本页负责把已经在希伯来—圣经叙事传统内部出现的人物、故事、空间与文本组织方式，映射到 QC2 的四类对象，但不在这里提前把所有候选升级为正式 QC2 实体。

固定区分：

```text
motif       = 可跨故事复现的基本叙事单元
archetype   = 可被反复调用的角色／人物模型
plot_pattern = 事件关系与顺序结构
symbol      = 超出单一情节功能并形成稳定文化意义的意象／物件／空间
```

`theme` 仍主要由 QH 承担；例如“自由意志”“正义”“苦难”“忠诚”可以与本专题建立关系，但不应因此被重复建成 QC2 motif。

## 3. 命名型文化原型候选

首批高优先候选：

- **摩西**：立法者、解放者、先知型带领者；是否升级为 named archetype 需追踪犹太、基督教、伊斯兰及近现代政治／文学调用。
- **所罗门**：智慧王、审判者、建殿者，并在后世魔法、秘传、文学传统中获得新的形象层；需区分来源人物与后世所罗门形象。
- **约伯**：受苦义人／质询正义者；后世文学调用度高，值得优先核证。
- **该隐**：弑亲兄弟、被放逐者、反叛者等后世形象明显扩张；必须区分《创世记》来源角色与后世“该隐原型”。
- **亚伯拉罕**：祖先、受召者、信念试炼者；跨宗教重述很强，但“共同祖先人物”不自动等于单一原型。
- **大卫**：受膏王、战士、诗人王等多重后世模型；若进入 QC2 必须拆分具体原型关系。

判定门槛：

```text
来源人物知名
≠ 命名型文化原型

需要：
来源身份明确
+ 跨文本持续调用
+ 跨时代重写
+ 意义发生稳定扩展／再编码
```

## 4. symbol 准入治理

本专题尤其容易把宗教物件全部当成 symbol，因此必须严格执行 V1 规则。

候选可分三级：

### A｜高优先级符号候选

已有明显跨文本／跨时代复用潜力：

- 伊甸园
- 方舟
- 巴别塔
- 旷野
- 约柜
- 圣殿

### B｜条件候选

需要证明其超出本故事道具功能：

- 果实／树
- 彩虹
- 燃烧荆棘
- 海／穿越水域
- 王冠／受膏
- 祭坛

### C｜普通情节对象

某件衣物、武器、器皿、动物或建筑若只在单一场景发挥功能，不进入 QC2 symbol。
