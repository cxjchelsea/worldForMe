# 过去持续、遗忘与重写机制

TH7 的核心不是“作品发生在过去”，而是解释：**过去如何被保存、选择、传递、公共化、争夺、遗忘与重写，并因此持续进入现在与未来。**

统一机制：

```text
过去事件 / 经验
→ 留下痕迹与媒介
→ 被个人 / 家庭 / 共同体选择与解释
→ 形成可传递的记忆版本
→ 进入纪念、教育、档案、叙事与日常实践
→ 与沉默、遗忘和竞争版本发生冲突
→ 改变当下身份、责任与未来期待
```

## 一、过去如何留下痕迹

过去不会自动进入现在，必须借助媒介获得持续性。常见媒介包括：

- 身体习惯、口音、情绪与禁忌；
- 日记、书信、照片、影像与物件；
- 家庭故事、口述与沉默；
- 地名、建筑、墓地、纪念碑与仪式；
- 档案、教材、新闻、博物馆与文学叙事。

分析时先问：**这个过去依靠什么被保存？如果媒介消失，它还会怎样存在？**

## 二、记忆不是复印，而是重构

个人回忆受当下位置、情绪、后来获得的信息与自我叙述影响。文学中的记忆因此常表现为：

- 选择性回忆；
- 迟来的理解；
- 错认与自我保护；
- 同一事件的多个版本；
- 感官触发造成的非主动回返。

核心区分：**记忆不可靠，不等于记忆无价值。** 偏差本身可以显示人物当下如何理解过去。

## 三、家庭与代际如何传递过去

代际传递并不只靠“告诉下一代”。它也可以通过：

- 家庭秘密；
- 禁止谈论的名字与事件；
- 反复出现的情绪模式；
- 物件、照片、遗产与空间；
- 父母对子女未来的期待；
- 下一代对缺失信息的追索与想象。

因此：

```text
亲历者经验
→ 讲述 / 沉默 / 物件 / 行为模式
→ 下一代接收残缺过去
→ 重新解释
→ 形成新的家族记忆
```

这也是 TH6 与 TH7 的重要接口：**创伤本身归 TH6；创伤事件如何被家庭保存、沉默与继承归 TH7。**

## 四、私人过去如何变成公共记忆

个体经历只有经过选择和制度化，才会成为“我们共同记得的过去”。公共化媒介包括：

- 纪念日与仪式；
- 教材与官方历史；
- 博物馆、纪念碑与遗址；
- 新闻、电影与文学；
- 审判、调查与档案公开；
- 民间纪念和反官方叙事。

公共记忆的关键问题不是“历史真相是否存在”，而是：

1. 什么被选中？
2. 什么被排除？
3. 谁拥有解释权？
4. 什么版本获得重复传播的资源？

## 五、遗忘与沉默如何发生

遗忘至少有四种机制：

- **自然消退**：时间、死亡与媒介消失；
- **心理回避**：羞耻、痛苦、自我保护；
- **社会沉默**：家庭或共同体认为某事“不应说”；
- **制度性抹除**：档案封锁、审查、改名、删除纪念与官方否认。

因此“没人说”不能直接推导为“没人记得”。沉默可能正说明过去仍然具有力量。

## 六、历史版本为何不断被重写

重写并不自动等于伪造。新的证据、代际距离、身份位置和政治变化会改变解释框架。

```text
事件
→ 初始叙述
→ 档案 / 证言 / 纪念制度
→ 新证据或新一代出现
→ 旧版本被质疑
→ 竞争历史形成
```

TH7 关注的是“过去的意义如何变化”；如果重点是国家通过审查、警察或法律强制某一版本，则同时进入 TH5。

## 七、时间如何被经验，而不只是流逝

P6 必须保留，因为 TH7 不只是记忆研究。作品还可能让时间呈现为：

- 线性前进；
- 循环与重复；
- 停滞；
- 断裂；
- 多代叠加；
- 过去不断侵入现在；
- 未来期待反过来改变当下。

关键问题是：**人物生活在“现在”，还是被某种过去与未来共同组织？**

## 八、八组稳定结构张力

这些是专题内部比较维度，不是 `TH7.x`：

1. 记忆 ↔ 遗忘
2. 私人记忆 ↔ 公共历史
3. 亲历 ↔ 代际继承
4. 证言 ↔ 沉默
5. 档案 ↔ 口述
6. 官方版本 ↔ 竞争记忆
7. 连续时间 ↔ 断裂 / 回返
8. 保存过去 ↔ 重写过去

## 九、最小作品分析模板

分析一部作品时依次问：

1. 什么过去仍在作用？
2. 它通过什么媒介留下？
3. 谁记得，谁沉默，谁遗忘？
4. 记忆在个人、家庭与公共层之间如何移动？
5. 存在哪些竞争版本？
6. 过去怎样改变当下身份、责任与关系？
7. 作品如何组织时间经验？

如果作品只是以历史时期为背景，而上述链条并不重要，不应把 TH7 标为核心。
