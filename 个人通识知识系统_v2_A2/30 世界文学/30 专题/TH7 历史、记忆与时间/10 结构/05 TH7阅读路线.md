# TH7 阅读路线

阅读目标不是积累“记忆文学”书单，而是逐步获得六种能力：识别记忆重构、代际传递、公共记忆、遗忘机制、历史版本竞争与时间结构。

## 第一组：私人记忆如何被重构

**《追忆似水年华》 → 《喧哗与骚动》 → 《长日留痕》**

观察：感官触发、错认、迟来理解、自我保护和非线性时间。重点训练 P1/P6。

## 第二组：家庭如何保存与隐瞒过去

**《宠儿》 → 《喜福会》 → 《百年孤独》**

观察：秘密、口述、物件、名字、重复命运与沉默如何使过去跨代存在。重点训练 P2，并与 P4/P6联动。

## 第三组：创伤事件怎样进入后来的记忆

**《夜》/证言文学 → 《朗读者》 → 《奥斯特利茨》**

阅读时主动分轴：伤害、创伤与见证困境归 TH6；纪念、后代解释、缺失档案和历史版本归 TH7。

## 第四组：个人生命如何嵌入国家历史

**《午夜之子》 → 《百年孤独》 → 殖民/后殖民历史小说群**

观察：私人年表、家族史与国家叙事如何互相解释，又在哪里冲突。重点训练 P3/P5。

## 第五组：遗忘不是“没有记忆”

**《长日留痕》 → 《朗读者》 → 《1984》（边界案例）**

依次比较：个人自我保护式遗忘、代际羞耻与沉默、国家制度性改写。最后一类若重点落在审查和强制机制，要同时进入 TH5。

## 第六组：时间本身成为主题

**《喧哗与骚动》 → 《第五号屠场》（与 TH6 交叉） → 《百年孤独》**

比较主观断裂、创伤式时间与家族/历史循环。训练区分“叙事顺序复杂”与“时间经验本身是作品问题”。

## 推荐顺序

```text
私人记忆
→ 家庭与代际
→ 暴力后的记忆
→ 公共历史与版本竞争
→ 遗忘机制
→ 时间结构
```

## 每部作品的七问笔记模板

1. 哪个过去仍在作用？
2. 它通过什么媒介返回？
3. 谁记得 / 谁遗忘 / 谁沉默？
4. 它如何跨个人—家庭—共同体移动？
5. 有哪些竞争版本？
6. 过去如何改变现在与未来？
7. 时间被经验成什么形状？

完成这条路线后，应能够判断一部作品究竟是在“写历史背景”，还是在真正研究“过去如何持续存在”。
