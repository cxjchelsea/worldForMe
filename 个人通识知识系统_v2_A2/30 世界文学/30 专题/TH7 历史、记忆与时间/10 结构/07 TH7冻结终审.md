# TH7 冻结终审

## 结论

TH7「历史、记忆与时间」通过 V1 压力测试，可以保持一级叶节点，不建立 `TH7.x`。

## 六问冻结

1. P1 个人如何记住、重构并误认自己的过去
2. P2 家庭与代际如何保存、隐瞒并传递过去
3. P3 共同体与国家如何形成、争夺并纪念公共记忆
4. P4 人与社会为何遗忘、沉默、抹除或压抑过去
5. P5 历史如何被选择、解释、重写并形成竞争版本
6. P6 人如何经验时间，并让过去、现在与未来彼此进入

## 旧八维迁移

- 个人记忆 → P1
- 家族记忆 + 代际记忆 → P2
- 集体记忆 → P3
- 遗忘 → P4
- 历史重写 → P5
- 时间 → P6
- 历史创伤 → 不再独立治理；创伤归 TH6，创伤历史的记忆再按 P2/P3/P4/P5 进入 TH7。

## 正式投影

- 《喧哗与骚动》：P1 / P2 / P6
- 《午夜之子》：P1 / P2 / P3 / P5 / P6
- 《朗读者》：P1 / P3 / P4 / P5
- 《西线无战事》：P1 / P3（比较）
