# TH7 A级内容压力测试

## 一、测试目标

验证 TH7 是否真正具备“过去持续—记忆重构—代际传递—公共化—遗忘/重写—时间化”的解释力，而不是把所有历史题材、回忆叙事或非线性时间都吸收进来。

重点检查：

1. 六个核心问题是否覆盖稳定；
2. TH6/TH5/TY7 边界是否清楚；
3. 私人记忆、家庭记忆、公共历史和时间结构能否被统一解释；
4. 非西方、离散和后殖民作品能否进入；
5. 是否出现必须新增 `TH7.x` 的第二分类维度。

## 三、六个核心问题验收

| 核心问题 | 结果 | 说明 |
|---|---|---|
| P1 个人记忆与重构 | 通过 | 能稳定解释主观记忆、错认与迟来理解。 |
| P2 家庭与代际 | 通过 | 对离散、秘密、沉默与跨代继承有效。 |
| P3 公共记忆 | 通过 | 能覆盖国家、共同体、纪念与公共历史。 |
| P4 遗忘与抹除 | 通过 | 能区分自然消退、心理回避、社会沉默与制度性抹除。 |
| P5 历史选择与重写 | 通过 | 能处理新证据、代际距离、政治变化与竞争版本。 |
| P6 时间经验 | 通过 | 能解释循环、断裂、停滞、回返，而不是只做记忆附属项。 |

无稳定缺口要求新增第七问。

## 四、两条关键防扩张规则

### 规则一：历史题材不自动等于 TH7

只有当“过去如何被记住、遗忘、解释或继续作用”成为作品问题时，TH7 才进入核心。

```text
发生在历史时期 ≠ TH7
重构历史题材 ≠ TH7 必然核心
过去作为当下问题持续存在 → TH7
```

### 规则二：非线性叙事不自动等于时间主题

倒叙、多线叙事、跳跃时间首先可能只是叙事技术。只有当作品借此研究记忆、重复、停滞、断裂或过去/未来如何进入现在时，才进入 P6。

因此 TY 的叙事机制与 TH7 的时间主题保持可分。

## 五、TH6—TH7 接口验收

压力测试表明接口可以稳定维持：

```text
事件中的伤害、恐惧、身体与创伤 → TH6
创伤为何反复侵入当下 → TH6
事件如何被保存、沉默、家庭传递 → TH7
社会如何纪念、否认和争夺历史解释 → TH7
国家用审查、法律、档案控制强制某版本 → TH5
```

《宠儿》《朗读者》《奥斯特利茨》《第五号屠场》均可兼标，但没有出现无法分工的结构冲突。

## 六、是否需要新增 TH7.x

结论：**不需要。**

作品差异可以由六问、六大机制和八组张力承接。私人记忆、代际记忆、公共记忆、遗忘、历史重写与时间并非互斥类别，而是同一“过去如何持续”的不同环节与尺度。

## 七、A级验收结论

### 结论：通过

TH7 已满足成熟知识地图要求：

- 有稳定纳入边界；
- 六个核心问题覆盖完整；
- 有统一的保存—重构—传递—公共化—遗忘/重写—时间化机制；
- 有八组稳定张力；
- 能跨个人、家庭、国家、殖民/后殖民、离散与现代灾难记忆比较；
- 能正确拒绝单纯历史题材和纯叙事时间技巧；
- 与 TH6、TH5、TY7 的接口稳定；
- 无需新增 `TH7.x`。

因此 TH7 可正式升级为 **A 级成熟主题知识地图**。
