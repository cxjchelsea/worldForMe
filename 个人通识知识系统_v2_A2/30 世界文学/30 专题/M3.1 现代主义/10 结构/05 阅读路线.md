# 阅读路线

第一轮先形成四个支柱：

1. Joyce / Woolf：意识、时间与小说形式；
2. Eliot / Pound / 现代主义诗歌；
3. Kafka / 中欧：制度、异化与主体危机；
4. Faulkner / Harlem / Global Modernism：现代主义不是单一欧洲中心。

> 时间 / 都市 / 语言 / 女性 / 殖民 / 神话方法
