# 传播、借用与符号复用

## 1. 关系必须按证据区分

巴别塔特别容易出现“看到高塔就认为是 Babel”的过度识别，因此本专题固定：

```text
source naming / explicit textual reference
≠ symbol reuse
≠ iconographic similarity
≠ historical transmission
```

## 2. `explicit_reference`

当作品明确使用 Babel / Tower of Babel 名称、直接引用来源故事或有可核证文本指向时，可以使用：

```yaml
relation_type: explicit_reference
```

Borges《The Library of Babel》属于这一类。

## 3. `symbol_reuse`

当作品明确继续调用已形成的 Babel 文化符号，并以新媒介重新组织其形象／意义时，可以使用：

```yaml
relation_type: symbol_reuse
```

Bruegel《The Tower of Babel》在本 Pilot 中用于验证视觉 symbol reuse。

## 4. iconographic inheritance 暂不混入 work relation

文化符号模板原本提出 `iconographic_inheritance`，但 Shared Data Layer 当前 work relation_type 尚未正式包含这一词。

Pass A 不立即扩展枚举。视觉上的构图继承、复制、变奏应在有具体作品链和图像学证据后再决定：

```text
是否需要 iconographic_inheritance
vs
是否 symbol_reuse + evidence 即已足够
```

## 5. 普通视觉相似不是巴别塔引用

例如：

- 螺旋塔；
- 巨型未完建筑；
- 向天空延伸的城市；
- 多语言环境；

若没有 Babel 命名、来源关系或可证的文化调用，只能保持：

```text
independent_or_unknown
```

或完全不建 Babel relation。

## 6. 历史传播

任何“某文化的高塔故事来自巴别塔”之类历史传播主张，都必须另有独立证据；不能由视觉或功能相似推出。

## 7. Pass A 结论

```text
explicit_reference / symbol_reuse boundary
= SUPPORTED_SO_FAR

iconographic_inheritance
= OPEN_FOR_PASS_B
```
