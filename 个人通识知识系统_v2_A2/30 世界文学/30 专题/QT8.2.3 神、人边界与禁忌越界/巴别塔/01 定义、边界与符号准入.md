# 定义、边界与符号准入

## 1. 工作定义

“巴别塔”进入 QT8.2 symbol 层，不是因为《创世记》中出现了一座塔，而是因为 **Babel / Tower of Babel 作为被命名、可识别的文化对象，在后世反复被重新调用，并形成跨文本、跨时代、跨媒介的稳定意义族。**

## 2. 三层必须分离

```text
source object
= 《创世记》11 中建造的城与塔

source-story function
= 统一工程、立名／拒绝分散、神圣干预、语言变乱与分散

cultural symbol
= 后世可脱离完整故事而被调用的 Babel 符号
```

因此普通的高塔、摩天楼或“多人说不同语言”的场景，都不能只凭视觉／主题相似自动记为巴别塔符号复用。

## 3. Pass A 准入证据

### A｜来源对象可追踪

QT8.1.1 已建立正式巴别塔故事群，《创世记》11:1–9 是 defining source text。

### B｜跨时代重复调用

Bruegel 1563 年《The Tower of Babel》显示该来源对象已经能够形成独立、可识别的视觉主题。

### C｜跨媒介语义转用

Borges 1941 年《The Library of Babel》保留 Babel 命名锚点，却把 literal tower 改写为近乎总体化的宇宙图书馆，使符号进入语言、知识与信息秩序问题。

### D｜稳定意义族可识别

当前至少可识别：语言／沟通分裂、总体化的人类工程、工程被中断或失败。

## 4. “傲慢”治理

后世常把 Babel 解释为 human pride / hubris 的典型象征，但本专题不把它写成《创世记》11 唯一、无争议的原始意义。

更稳妥的来源层描述是：

```text
共同语言
+ 建城与高塔
+ 为自己立名
+ 避免分散
→ 神圣干预
→ 语言混乱与分散
```

“傲慢／僭越”属于重要接受史解释和稳定意义候选，需要与来源文本本身分层。
