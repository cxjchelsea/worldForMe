## 2. Pieter Bruegel the Elder, *The Tower of Babel* (1563)

```yaml
relation_type: symbol_reuse
evidence_level: documented
```

保留：

- Babel 来源指向；
- 塔与集体建造；
- 巨型工程及其未完成／中断感。

变化：

- 来源文本没有固定视觉塔形；
- Bruegel 将其发展成高度复杂、巨型化的建筑—城市图像。

数据：[[20 数据层/03 作品/01 Bruegel-Tower-of-Babel-symbol-reuse]]

## 3. Jorge Luis Borges, *The Library of Babel* (1941)

```yaml
relation_type: explicit_reference
evidence_level: documented
```

保留：

- Babel 命名锚点；
- 语言／符号系统的混乱、不可穷尽或难以统一解释；
- 总体化工程的想象。

变化：

- literal tower / city 被 universal library 替代；
- 符号重心转向知识总体性、组合无限、信息秩序与解释困难。

数据：[[20 数据层/03 作品/02 Borges-Library-of-Babel-explicit-reference]]

## 4. Pass A 暴露的 work-schema 信号

通用字段：

```text

```

可以保存基础信息，但 symbol 实例还经常需要直接回答：

```text

```

因此三者目前作为 **symbol-specific optional extension candidate**，不在 Pass A 直接冻结 Shared Data Layer。
