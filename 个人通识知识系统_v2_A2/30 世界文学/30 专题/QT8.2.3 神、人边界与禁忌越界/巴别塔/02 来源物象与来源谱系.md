# 来源物象与来源谱系

## 1. QT8.1 回指

正式来源：

```text
QT8.1.1 希伯来—圣经叙事传统
→ D｜巴别塔：统一、越界与语言分散
→ 《创世记》11:1–9
```

`source_status = reference_topic`。

## 2. 来源文本中的对象

最低来源链：

```text
人类共享一种语言
→ 在示拿地定居
→ 用砖与石漆建城和塔
→ “为自己立名”并避免分散
→ 神圣介入
→ 语言被变乱
→ 人群分散
→ 城名与 Babel / confusion 发生叙事性关联
```

## 3. 不做的倒灌

来源页不把后世已经成熟的下列解释直接写回原始文本：

- “现代技术乌托邦失败”；
- “信息过载”；
- “知识总体性”；
- “民族主义／帝国主义”作为唯一意义；
- “傲慢”作为穷尽性的单一解释。

这些属于后世符号化与语义漂移层。

## 4. 来源对象与历史建筑

Babel 故事位于古代近东城市—高塔文化环境中，但本 Pilot 不把某一具体考古建筑直接等同于《创世记》的巴别塔，也不以未经充分核证的“原型建筑”替代文本来源。
