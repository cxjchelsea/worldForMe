# 性、欲望与性规范

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.2 性、欲望与性规范**

## 1. 专题定位

本专题研究**性欲、性行为、性取向与性身份如何被经验、命名、允许、禁止和规训，以及这些规范怎样改变主体的自由、羞耻、隐匿、关系与归属**。

TH3.2 的核心并不是“作品里有没有性”，也不是“人物是否相爱”，而是：

> **一种欲望或性关系如何从私人经验变成可被命名、评价、允许或惩罚的社会问题？主体又如何在这些规范中形成、隐藏或重写自己的性生活与性身份？**

纳入测试：如果拿掉作品中的性规范、性禁忌、性身份分类、同意结构或性行为治理，人物冲突是否会发生根本变化？若不会，一般不作为本专题核心。

统一关系：

```text
欲望 / 身体感受 / 亲密实践
→ 被语言和身份范畴命名
→ 被区分为正常 / 异常、正当 / 禁忌、可见 / 不可见
→ 同意与权力决定关系是否具有自主性
→ 家庭、宗教、医学、法律、教育与舆论执行规范
→ 主体产生羞耻、隐匿、公开、伪装、协商或反抗
→ 新关系实践、身份共同体与制度变化重写规范
```

可压缩为：

`欲望经验 → 命名与分类 → 同意结构 → 规范执行 → 身份与关系后果 → 隐匿/公开/反抗 → 规范再生产或变迁`

1. 欲望经验 ↔ 社会命名

6. 道德判断 ↔ 个体自主

## 3. 为什么不继续拆坐标

压力测试重点检验“性欲 / 同意 / 性身份 / 性规范”是否需要拆成子坐标。结果显示它们在大量作品中形成同一冲突链：

```text
欲望出现
→ 被命名或无法被命名
→ 被社会判断
→ 关系的同意与权力被检验
→ 身份被分类、隐藏或公开
→ 制度与共同体介入
→ 主体服从、协商、逃离或重写规则
```

若拆为“性欲”“同性身份”“性道德”“性自主”等多个坐标，同一批核心作品会稳定重复命中，坐标辨识度反而下降。

因此 TH3.2 继续保持叶节点，不新增 `TH3.2.x`。冻结的是坐标结构，不是知识增长。

## 4. 与相邻主题的边界

- **TH2.1 爱情与欲望**：具体对象之间的爱、迷恋、等待、占有与求而不得归 TH2.1；欲望是否被允许、怎样被定义、羞耻化或禁止归 TH3.2。
- **TH2.2 婚姻与亲密关系**：关系如何维持、承诺、背叛、协商归 TH2.2；婚内/婚外性为何被赋予不同合法性，以及性自主如何受规范限制归 TH3.2。
- **TH3.1 性别与身体**：身体怎样被性别化并转化为社会资格归 TH3.1；性行为、性取向、性身份分类、性禁忌与性规范归 TH3.2。
- **TH1.1 自我认同与主体性**：一般“我是谁”归 TH1.1；“我的欲望如何被命名，以及这个命名是否让我成为某种被承认/排斥的人”归 TH3.2。
- **TH5 权力、制度与秩序**：制度如何运作归 TH5；制度专门管理性行为、性身份、贞洁、色情、同性关系或性道德时可兼标 TH3.2。
- **TH6 战争、暴力与创伤**：性暴力造成的伤害、强迫与创伤归 TH6；同意如何成立、权力差为何使性关系失去自主性归 TH3.2。
- **TH8 信仰、伦理与超越**：一般罪、伦理责任和宗教价值判断归 TH8；当这些价值具体规定何种欲望/性行为被视为纯洁、罪恶、可接受或不可接受时进入 TH3.2。

## 5. 最小分析模板

分析一部 TH3.2 作品时至少追问：

1. 人物实际经验到了什么欲望或性关系？
2. 这种经验能否被命名？使用了什么语言与身份分类？
3. 谁认为它正常、异常、道德、不道德或不可说？
4. 关系中的同意是否真实成立？年龄、经济、身份、性别或权力差是否改变同意？
5. 哪些家庭、宗教、医学、法律或社会机制执行规范？
6. 人物因此选择隐匿、伪装、公开、协商还是反抗？
7. 是否形成替代关系、共同体或新的生活方式？
8. 作品最终是在再生产旧规范，还是让规范发生松动、转化或重写？

如果作品只有爱情、性描写或身体经验，却没有稳定进入“命名—规范—同意—身份/关系后果”链条，一般不作为 TH3.2 核心。
