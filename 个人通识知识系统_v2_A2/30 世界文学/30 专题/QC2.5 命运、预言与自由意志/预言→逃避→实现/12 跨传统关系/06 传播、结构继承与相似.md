# 传播、结构继承与相似

## 1. 四种关系必须分开

```text
structural_inheritance
historical_transmission
structural_similarity
functional_similarity
```

### structural_inheritance

后世作品具有足够完整的节点对应，且有文本／创作证据支持其继承或重组既有结构。

### historical_transmission

讨论结构或故事材料在传统之间传播，需要独立历史证据；不能由节点相似度替代。

### structural_similarity

两个故事具有相似节点顺序，但传播关系未建立。

### functional_similarity

结构在叙事中的功能相近，例如都制造悲剧反讽，但具体槽位可能不同。

## 2. 同一传统内部也不能偷懒

Cronus、Oedipus、Acrisius 都属于希腊传统，不意味着三者之间必然存在明确的直接文本继承链。

Pilot C 第一轮只判定：

```text
shared plot-pattern abstraction
```

而不是：

```text
A 文本直接复制 B 文本
```

## 3. structural_inheritance 的最低要求

后世作品若要进入正式 `qc2_work_reference / structural_inheritance`，至少需要：

```text
核心 S1 / S2 / S3 均可识别
+
节点顺序保持
+
作品或研究证据能支持结构调用／继承
```

若只是“角色听到预言，后来预言成真”，但没有规避行动，不足以成立。
