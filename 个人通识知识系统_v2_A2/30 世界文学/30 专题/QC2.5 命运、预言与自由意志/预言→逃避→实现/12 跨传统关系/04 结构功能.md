# 结构功能

## 1. 悲剧反讽

人物以为自己正在阻止未来，但观众能够逐步看到行动与预言之间形成新的因果链。

```text
知道预言
→ 采取理性规避
→ 结果越来越靠近预言
```

这会制造强烈的 dramatic irony。

## 2. 命运与行动的张力

本结构并不自动回答“自由意志是否存在”。它只是把问题形式化为：

> 人物针对未来知识作出的行动，究竟改变了未来，还是成为未来的一部分？

因此结构与“命运／自由意志”主题高度相关，但不能被主题替代。

## 3. 权力防御与代际冲突

Cronus、Laius、Acrisius 等实例都显示：预言经常以“下一代将威胁当前统治者／父辈”的形式出现。

因此该结构容易与：

- 王权更替；
- 父子冲突；
- 继承危机；
- 被遗弃儿童；

发生组合，但这些都不是结构本身的必选元素。

## 4. 身份信息的延迟

规避行为常通过遗弃、放逐、隐藏等方式制造身份断裂。这样一来，预言实现可以发生在人物并不知道彼此真实身份的情况下。

这一机制在 Oedipus 型叙事中尤其重要，但不能强行推广到所有实例。

## 5. 因果悖论感

当 `avoidance_backfire` 成立时，结构会产生：

```text
为了避免 X
→ 做了 Y
→ Y 成为 X 实现的条件之一
```

这是本 Pilot 最重要的强变体，但当前不把它提升为全部实例的最低 core slot。
