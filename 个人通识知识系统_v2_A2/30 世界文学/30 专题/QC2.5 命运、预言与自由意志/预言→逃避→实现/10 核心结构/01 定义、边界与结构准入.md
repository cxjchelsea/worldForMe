# 定义、边界与结构准入

## 1. 工作性定义

“预言 → 逃避 → 实现”是一个叙事结构：某个行动主体接收到关于未来结果的权威性预测，因为该结果具有威胁性而主动采取规避行动；结果最终仍然发生。

## 2. core_slots

最低准入需要同时满足：

```text
S1 authoritative_prediction
= 未来结果被明确预告，且足以驱动行动

S2 avoidance_action
= 至少一个行动主体因预言而采取防止／逃离／压制措施

S3 predicted_outcome_fulfilled
= 被规避的核心结果最终实现
```

缺少 S2，只是一般“预言实现”；缺少 S3，则属于“成功逃脱预言”“预言被改写／失效”等其他 terminal variant，不能直接作为本结构 full match。

## 3. 与 motif 的边界

```text
预言
命运
自由意志
宿命
```

都可以作为 motif / theme problem，但它们本身没有规定事件顺序。

本对象的识别单位是：

```text
prediction
→ response caused by prediction
→ eventual outcome
```

## 4. 与“自我实现预言”的边界

本结构不要求所有实例都满足现代社会科学意义上的 self-fulfilling prophecy。

只有当规避行动明显帮助制造结果时，才增加：

```text
avoidance_backfire
```

因此：

```text
fulfilled despite avoidance
≠
fulfilled through avoidance
```

两者都是本结构的 terminal variants，但因果强度不同。

## 5. 准入排除

以下不自动进入：

- 单纯收到预言后顺从它；
- 人物主动追求预言结果；
- 只有命运主题但没有明确预测节点；
- 后见之明式“仿佛早已注定”；
- 只有观众知道预言、角色从未因预言采取规避行动的结构。
