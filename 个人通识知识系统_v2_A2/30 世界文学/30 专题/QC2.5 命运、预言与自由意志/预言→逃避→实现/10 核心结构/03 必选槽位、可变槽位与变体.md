# 必选槽位、可变槽位与变体

## 1. core_slots

```text
S1 authoritative_prediction
→ S2 avoidance_action
→ S3 predicted_outcome_fulfilled
```

### S1 authoritative_prediction

预测必须在故事内部具有足够权威，使人物把它当成需要回应的未来威胁。

### S2 avoidance_action

行动必须明确由 S1 触发。可由：被预言者、父母、王者、共同体或代理者执行。

### S3 predicted_outcome_fulfilled

最终结果需与 S1 的核心命题相匹配；细节可以偏移。

## 2. optional_slots

- `concealment_or_exposure`：隐藏、囚禁、遗弃、放逐；
- `identity_displacement`：人物在异地／替代家庭中成长，身份信息断裂；
- `avoidance_backfire`：规避行动本身帮助制造最终实现条件；
- `delayed_recognition`：结果实现时，相关人物未立即知道身份或意义；
- `oracle_reconfirmation`：中途再次出现预言／神谕确认。

## 3. repeatable_slots

```text
renewed_avoidance_attempt
```

同一故事可以多次尝试规避。例如 Acrisius 先囚禁 Danae，后放逐母子，晚年又因惧怕神谕而离开 Argos。

因此结构允许：

```text
S1
→ S2a 规避
→ S2b 再规避
→ S2c 再规避
→ S3 实现
```

## 4. terminal_variants

### A. fulfilled_despite_avoidance

预言在规避失败后实现，但规避不是明显直接原因。

### B. fulfilled_through_avoidance

规避行为改变了人物位置、身份或关系，反而成为预言实现链的一部分。

### C. accidental_fulfillment

结果由意外完成，例如 Perseus 的铁饼击中 Acrisius。

这可作为 `fulfilled_despite_avoidance` 或 `fulfilled_through_avoidance` 的实现机制，而不是独立 core slot。

## 5. 当前模板反馈

Plot-pattern 模板的四分法得到支持：

```text
core_slots
optional_slots
repeatable_slots
terminal_variants
```

同时出现一个值得保留的新观察：

> `terminal_variants` 描述结局类型；`causal_variant` 描述规避与实现之间的因果关系。二者可能需要在 Pass B 判断是否拆成两个字段。
