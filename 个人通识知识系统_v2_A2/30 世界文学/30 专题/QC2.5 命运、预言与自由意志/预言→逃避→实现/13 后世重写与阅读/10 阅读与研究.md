# 阅读与研究

## 1. 最小来源路线

```text
Hesiod《Theogony》神代更替
→ Sophocles《Oedipus Tyrannus》
→ Apollodorus《Library》2.4 Perseus / Acrisius
→ 《毗湿奴往世书》Book V：Kamsa / Krishna
```

阅读时持续追踪：

- 预言由谁发出？
- 谁认为自己受到威胁？
- 谁采取规避行动？
- 规避是否重复？
- 规避是否造成身份／空间改变？
- 最终实现与原预言如何对应？
- 是 `fulfilled_despite_avoidance` 还是 `fulfilled_through_avoidance`？

## 2. 结构与主题分离

继续保持：

```text
“命运能否逃避？”
= theme / problem

“预言 → 规避 → 结果仍实现”

```

## 3. Pass B 的两个压力测试

### 3.1 非希腊来源

《毗湿奴往世书》中的 Kamsa / Krishna 支持同一最小结构可以在不同来源传统中独立抽取。

这支持：

```text
cross-tradition structural comparability
```

但不支持：

```text
historical transmission
```

### 3.2 后世作品 slot-level 记录

Grimm《魔鬼的三根金发》和普希金《贤明的奥列格之歌》证明：对 plot pattern 而言，`matched_slots / missing_slots / added_slots` 比单纯 `retained_features / modified_features` 更直接。

两者都只标记为：

```text
structural_similarity
```

因为当前证据证明结构匹配，但没有证明它们直接继承自希腊某个特定来源故事。

## 4. causal variants｜Pass B 结论

Pass A 的候选字段可以保留，并正式进入 plot-pattern 类型结构：

```text
causal_variants
```

当前至少区分：

```text
fulfilled_despite_avoidance
= 尽管规避发生，预言仍实现

fulfilled_through_avoidance
= 规避行为本身成为预言实现链的一部分
```

治理：

```text
causal_variants
≠ core_slots
```

因为 Oleg 等实例没有要求“规避行为直接造成结果”，所以 `avoidance_backfire` 不应提升为最低必选槽位。
