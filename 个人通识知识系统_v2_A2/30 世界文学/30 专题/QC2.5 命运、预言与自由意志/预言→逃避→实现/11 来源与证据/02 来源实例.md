## 2. 希腊来源组

### Cronus / Zeus

QC1.1.2 的“宇宙生成与神代更替”已经明确给出：

```text
预言威胁
→ 压制后代
→ 后代反抗
→ 新秩序
```

这一实例的关键在于：规避行动制造了持续的亲代—后代冲突，而 Rhea 对 Zeus 的保护使规避失败。

### Laius / Oedipus

Sophocles《Oedipus Tyrannus》中，Jocasta 回忆 Laius 曾得到“将死于自己孩子之手”的神谕，而新生儿随后被交由他人遗弃。成年 Oedipus 在不知道亲生身份的情况下杀死 Laius。

该实例同时存在两层规避：Laius 对婴儿的规避，以及 Oedipus 在得知自己将弑父娶母后离开 Corinth 的规避。后者强化了“行动者知道预言后改变行动”的结构。

### Acrisius / Perseus

Apollodorus《Library》2.4 中，Acrisius 得到“女儿之子将杀死自己”的神谕，因而囚禁 Danae，后又将 Danae 与 Perseus 放入箱中投入海上；Perseus 生存成长，最终在竞技会上意外以铁饼击中 Acrisius。

它证明：

```text
规避行动很强
+
最终实现可以是意外
```

## 3. Pass B 非希腊压力测试｜Kamsa / Krishna

《毗湿奴往世书》第五卷第一至第三章提供一个与希腊来源无须预设历史传播即可比较的实例：Kamsa 得知 Devaki 的第八个孩子将杀死自己，于是控制 Devaki / Vasudeva 的生育链并杀死孩子；Krishna 被秘密转移、幸存，后来完成预言结果。

抽象槽位：

```text
S1 authoritative_prediction
→ Devaki 第八子将杀死 Kamsa

S2 avoidance_action
→ 监禁、杀婴、控制出生链

S2a failed_suppression
→ Krishna 被转移并幸存

S3 predicted_outcome_fulfilled
→ Krishna 杀死 Kamsa
```

来源记录：[[20 数据层/01 来源/04 Vishnu-Purana-Kamsa-Krishna]]。

## 4. 跨传统结论

Pass B 支持：

```text
QC2_PLOT_PATTERN_CROSS_TRADITION_EXTRACTION = SUPPORTED
```

但只支持“同一个抽象 plot pattern 可从不同来源材料中抽取”，不支持：

```text
Greek source
→ historical transmission
→ Indian source
```

在没有独立传播证据时，最多只能说结构可比。结构相似不等于共同历史来源。

## 5. 对 core slot 的影响

四组来源共同支持：

```text
authoritative_prediction
action_to_avoid_or_suppress
predicted_outcome_fulfilled
```

但并不共同支持：

```text
avoidance_action directly causes fulfillment
```

因此 `avoidance_backfire` 继续保留为强变体，而不是 core slot。
