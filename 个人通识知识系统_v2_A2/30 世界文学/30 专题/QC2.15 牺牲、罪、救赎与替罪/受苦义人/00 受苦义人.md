# 受苦义人｜archetype Pilot B

> **定位：**研究“被叙事呈现为正直／虔敬，却遭遇与其可见行为不成比例或无法解释的苦难，并因此逼出报偿秩序、神意与认识限度问题”的角色模型。

## 1. 为什么这是 archetype，而不是 theme

`苦难 / 正义 / 报偿 / 神义` 是抽象问题，主要属于 QH；“受苦义人”则是承担这些问题的稳定角色模型。

```text
theme
→ 为什么好人会受苦？

archetype
→ 那个被塑造成“正直却受苦者”的叙事角色
```
