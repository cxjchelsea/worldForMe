# 原型化过程

## 1. 抽象原型的形成方式

“受苦义人”不是某一个人物被直接复制，而是多个文本中的角色功能被抽象比较后形成：

```text
具体受苦者
→ 正直／虔敬身份被文本强调
→ 苦难与罪责之间出现张力
→ 角色承担报偿秩序问题
→ 后续文本／研究不断把此角色功能识别为可复用模型
→ abstract archetype
```

## 2. 约伯的作用

约伯是该原型最强的来源实例之一，但不能反向规定所有受苦义人都必须：

- 有三位朋友；
- 采用法庭式辩论；
- 得到旋风中的神圣回应；
- 最终恢复双倍财产。

这些属于约伯文本的具体实现，不是 archetype 必选条件。

## 3. Ludlul 的压力测试价值

`Ludlul bēl nēmeqi` 能检验：

- 角色可同样具有正直／虔敬定位；
- 可以经历严重苦难与解释失败；
- 可以最终恢复；
- 但作品的宗教语汇、角色关系与收束方式不同。

因此 archetype 的定义必须抓取稳定角色功能，而不是复制《约伯记》的情节结构。

## 4. 当前结论

Pilot B 当前支持：

```text
archetype
= 跨实例稳定角色功能
≠ 某一经典人物的剧情模板
```
