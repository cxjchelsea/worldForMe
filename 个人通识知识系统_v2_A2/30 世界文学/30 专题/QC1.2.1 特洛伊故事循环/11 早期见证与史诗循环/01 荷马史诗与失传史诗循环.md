# 荷马史诗与失传史诗循环

## 1. 《伊利亚特》在循环中的位置

《伊利亚特》不是从帕里斯裁决讲到木马，而是把焦点压缩在战争末期的一段：阿喀琉斯与阿伽门农冲突、退出战斗、帕特罗克洛斯之死、阿喀琉斯复仇以及赫克托耳葬礼。

因此：

```text
特洛伊故事循环
⊃
《伊利亚特》叙事区段
```

而不是两者等同。

## 2. 循环史诗提供了哪些缺口

按现存古代摘要和残篇可建立一个粗略覆盖图：

| 文本见证 | 主要叙事区段 |
|---|---|
| 《塞浦路斯纪》 | 战争起因、远征集结与《伊利亚特》之前的战争材料 |
| 《伊利亚特》 | 阿喀琉斯愤怒至赫克托耳葬礼 |
| 《埃塞俄比亚纪》 | 彭忒西勒亚、门农、阿喀琉斯之死等 |
| 《小伊利亚特》 | 阿喀琉斯武器裁决、埃阿斯之死、菲罗克忒忒斯、木马准备等 |
| 《伊利昂毁灭》 | 木马、城破和特洛伊毁灭 |
| 《归返纪》 | 多位希腊英雄的归乡 |
| 《奥德赛》 | 奥德修斯归乡的高度独立展开 |
| 《忒勒戈诺斯纪》 | 奥德修斯更晚的后传传统 |

这个顺序是**叙事区段地图**，不是未经争议的作者／成书先后表。

## 3. 《奥德赛》为什么既属于又不完全属于

《奥德赛》明确以特洛伊战争后的归乡为背景，因此在 QC1.2.1 中属于 `nostos_branch` 的核心见证。

但奥德修斯漂泊、怪物、身份试炼和伊塔卡复归又具有强烈独立性，因此未来若建立“奥德修斯传统”，它完全可能同时进入另一个 QC1.2 专题。

这种一部作品同时参加多个具体叙事传统的情况是正常的，不能要求 taxonomy 互斥。

## 4. 一个关键证据纪律

CHS 对《塞浦路斯纪》等材料的研究强调，我们主要通过残篇、后世引用和古代剧情概要认识这些失传作品；因此专题可以讨论它们覆盖的故事，但不能把概要里的每个细节都视作可直接还原的原作措辞或完整结构。
