# 内部结构与核心变体

## 1. required_invariants｜必选不变量

Content Pass B 将 motif 的最低准入条件正式收紧为三项：

```text
R1｜large_scale_flood_disruption
大规模洪水改变或摧毁既有生活／共同体秩序

R2｜selective_survival_or_preservation
至少一部分生命、共同体成员或文明资源被有选择地保存

R3｜post_flood_order_transition
洪水之后进入新的秩序阶段，而不是单纯以灾害结束
```

只有“洪水造成毁灭”但没有 R2/R3，更适合放在一般灾变叙事，而不是本 motif。

## 2. optional_slots｜高频可选槽位

| 槽位 | 说明 | 是否必选 |
|---|---|---:|
| 灾变原因 | 暴力／罪责、神意、人类噪音、宇宙更新等 | 否 |
| 预警 | 神谕、秘密告知、观察、梦兆、无预警 | 否 |
| 保存媒介 | 船／方舟、山地、容器、神圣空间等 | 否 |
| 保存对象 | 家族、动物、种子、技艺、知识等 | 否 |
| 退水确认 | 放鸟、观察陆地、登陆、神谕等 | 否 |
| 灾后祭祀 | 对神圣秩序的回应 | 否 |
| 盟约／限制 | 新规则、人口控制、伦理限制等 | 否 |
| 再生方式 | 繁衍、重造人类、迁徙、制度重建 | 否 |

## 3. 三个当前来源的结构比较

### 《创世记》6–9

```text
世界暴力／败坏
→ 神圣审判
→ 挪亚获得指令
→ 方舟保存家庭与生命样本
→ 洪水
→ 退水／放鸟／登陆
→ 祭祀
→ 盟约与新的生活秩序
```

### 《阿特拉哈西斯》

```text
人神秩序危机
→ 洪水决定
→ 幸存者秘密获知
→ 造船保存生命
→ 洪水
→ 灾后祭祀
→ 重新安排人类繁衍／死亡秩序
```

它证明“新秩序”不必表现为《创世记》式盟约，仍可满足 R3。

### 奥维德《变形记》第一卷：丢卡利翁与皮拉

```text
人类败坏／朱庇特决定毁灭
→ 洪水覆盖世界
→ 丢卡利翁与皮拉作为幸存者
→ 洪水退去
→ 通过神谕与“母亲的骨头”谜语重新生成世人
```

这一版本没有“保存动物样本—灾后盟约”链条，却仍满足 R1–R3，因此很好地验证了必选不变量与可选槽位必须分离。

## 4. motif 与 plot_pattern 的边界

本 motif 允许不同作品拥有不同顺序、不同槽位，真正的 motif 是：

```text
洪水毁旧秩序
+
选择性保存
+
灾后进入新秩序
```

而：

```text
预警 → 建造 → 保存 → 洪水 → 退水 → 祭祀／重建
```

是更窄、更完整的 `plot_pattern` 候选。

因此 Content Pass B 支持：

```text
required_invariants = motif 准入
optional_slots = motif 变体描述
ordered_slots = plot_pattern 研究对象
```
