# 阅读与研究

## 1. 最小来源文本路线

```text
《创世记》6–9
→ 《阿特拉哈西斯》洪水段
→ 《吉尔伽美什史诗》第 XI 泥版
→ 奥维德《变形记》第一卷丢卡利翁／皮拉
```

阅读目标不是判断“哪一个才是真的”，而是比较：

```text
R1 洪水如何破坏旧秩序
R2 谁／什么被保存
R3 灾后怎样进入新阶段
+
哪些高频槽位出现或缺失
```

## 2. 文本史路线

优先区分：

- 故事传统形成；
- 某一文学版本形成；
- 现存泥版／抄本年代；
- 后世定型／重写；
- 现代校勘与翻译。

British Museum 78943 与 K.3375 可作为两个具体物质文本见证入口；奥维德《变形记》第一卷可作为希腊—罗马文学重写入口。

## 3. Content Pass B 已回答的问题

### Q1｜“预警”是不是 motif 必选条件？

不是。丢卡利翁／皮拉版本说明 motif 可以在没有近东式“预警—造船”核心链的情况下成立。

### Q2｜“方舟／船”是不是必选条件？

不是。它属于高频 `optional_slot`，并可能进一步形成独立 symbol / preservation 关系。

### Q3｜motif 和 plot_pattern 怎么分？

当前工作规则：

```text
required_invariants
→ motif 准入

optional_slots
→ motif 变体描述

ordered_slots
→ plot_pattern
```

### Q4｜来源专题不完整怎么办？

新增 `source_status`，至少区分：

```text
reference_topic
reference_topic_source_story_pending_index
external_source_pending_qt81_topic
external_source_verified_text_only
unknown_source_status
```

### Q5｜一对对象可以同时“结构相似”又“可能传播”吗？

可以，但必须拆成两条 relation record，每条独立记录 `relation_type + evidence_level`。
