# 作品实例与跨媒介使用

## 1. 本页职责

解释层只说明为什么某作品可以作为“洪水与灾后重建” motif 的证据；正式关系记录进入 `qc2_work_reference` 数据实体。

```text
解释层
→ 为什么属于该 motif／如何改写

数据层
→ one work + one component + one relation_type + one evidence_level
```

---

## 2. 来源／定型级实例

这些属于来源谱系，不作为后世 `qc2_work_reference`：

### 《创世记》6–9

- `work_role`: `defining_text`
- `retained_invariants`: R1 + R2 + R3
- 关键槽位：审判、方舟、生命保存、退水、祭祀、盟约。

### 《阿特拉哈西斯》洪水段

- `work_role`: `early_witness / defining_text`
- `retained_invariants`: R1 + R2 + R3
- 关键槽位：秘密预警、造船、生命保存、洪水、祭祀、灾后人口秩序调整。

### 《吉尔伽美什史诗》第 XI 泥版

- `work_role`: `defining_reworking`
- `retained_invariants`: R1 + R2 + R3
- 关键变化：洪水故事被嵌入吉尔伽美什对死亡和不死的追问，motif 的作品内功能发生变化。

### 奥维德《变形记》第一卷

- `work_role`: `later_defining_reworking`
- `retained_invariants`: R1 + R2 + R3
- `modified_slots`: 无方舟保存链作为核心；灾后通过丢卡利翁、皮拉执行神谕而重新生成人类。
- Pilot 价值：证明“方舟／船”不能成为 motif 的必选条件。

这些来源记录现已数据化为 `qc2_source_reference`：

## 3. 已核证后世实例

### Darren Aronofsky《Noah》(2014)

Paramount 明确将影片定位为对 Noah's Ark 圣经故事的改编，因此可建立：

```text
relation_type: direct_adaptation
evidence_level: documented
```

数据记录：[[20 数据层/03 作品/01 Noah-2014-direct-adaptation]]

### Margaret Atwood《The Year of the Flood》

小说把灾变称为 “Dry Flood”：保留“灾变—少数幸存—灾后世界”的文化框架，却把水灾改写为瘟疫／生物灾变。

因此同一作品建立两条原子记录：

```text
explicit_reference
+
separate record
motif_inversion
```

而不是一个混合字段。

数据记录：

- [[20 数据层/03 作品/03 The-Year-of-the-Flood-motif-inversion]]

## 4. 当前数据规则

后世作品只有在能够填写以下字段时才进入正式实例层：

```yaml
work: ...
source_component: WL-TOPIC-QC22-FLOOD
retained_features: []
modified_features: []
relation_type: ...
evidence_level: ...
source_evidence: ...
```

其中：

- `direct_adaptation` 必须有明确来源对象；
- `explicit_reference` 必须能指出明确调用；
- `structural_inheritance` 不能只因“有洪水”成立；
- `motif_inversion` 要能指出保留与反转的结构；
- `structural_similarity` 可以用于比较，但不能写成历史影响。

## 5. Pilot 结论

`qc2_work_reference` 已经通过两种不同压力测试：

```text
直接改编
→ Noah (2014)

同一作品具有两个不同关系
→ The Year of the Flood
→ explicit_reference / motif_inversion 分成两条记录
```

这支持 QC2 的 relation record 原子性设计。
