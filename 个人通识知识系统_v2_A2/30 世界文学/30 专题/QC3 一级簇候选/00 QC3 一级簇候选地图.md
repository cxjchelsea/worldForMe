# QC3 一级簇候选地图

> 这里管理“哪些问题域值得成为 QC3.x 一级簇”。不是具体文化模型目录，也不是要求把所有候选都建成正式节点。

## 当前结构

```text
已验证
└─ 英雄、战士与法外者文化模型

高优先候选
├─ 君王、统治者与合法秩序模型
├─ 家庭、亲属与代际角色模型
├─ 爱情、婚姻与性别角色模型
├─ 宗教角色与神圣生活模型
└─ 知识人、智者与文化权威模型

边界待验证
├─ 反叛者、革命者与政治行动模型
└─ 社会身份、阶层与边缘角色模型
```

## 使用原则

- 一级簇不是“重要主题列表”；
- 每个一级簇下面必须能长出多个彼此可区分的文化模型；
- 角色、关系、伦理、秩序/空间、后世重构是每个模型内部分析维度，不再做一级分类；
- 不批量建设，先 Admission，再做一个真实 Pilot。
