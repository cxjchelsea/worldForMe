# 成长谱系与核心机制

成长文学不能只用“少年 → 成人”这一条年龄线分类。更有效的模型是同时观察三层：

```text
历史形式
Bildungsroman / Künstlerroman / Coming-of-Age / YA / Anti-Bildungsroman
+
形成机制
家庭 / 教育 / 城市 / 职业 / 阶级 / 爱情 / 身体 / 创伤 / 国家
+
完成方式
整合 / 妥协 / 离开 / 迁移 / 拒绝 / 失败 / 保持未完成
```

因此 `growth_axes` 是实用多标签横轴，不等于一棵互斥子类型树。历史形式回答“这种成长叙事从哪里来”，形成机制回答“什么力量在塑造主体”，完成方式则决定作品是否仍相信存在稳定的成人位置。
