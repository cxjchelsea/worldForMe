# 定义、边界与命名型原型准入

## 1. 工作性定义

“所罗门王”作为 QT8.2 对象，不等于《列王纪》中的来源人物本身，而是一个在后世持续以 Solomon / Sulayman 等身份锚点被识别，同时不断吸附和重组“智慧王、审判者、圣殿建造者、知识权威、驱魔者／魔法王、统御超自然存在者”等功能的命名型文化原型。

## 2. named archetype 准入必须同时满足

```text
N1 来源人物可明确回指 QT8.1
N2 姓名／身份锚点跨时期持续可识别
N3 至少一个核心角色功能跨重写保持稳定
N4 后世出现超出来源文本的稳定特征选择或放大
N5 这些重写跨文本／传统／媒介，而不是一次孤立改编
N6 能区分来源人物史与原型化接受史
```

## 3. 不能仅凭什么准入

- 因为人物“很著名”；
- 因为后世有作品提到名字；
- 因为另一文明也有智慧王；
- 因为现代大众印象里所罗门“会魔法”；
- 因为一个后世文本把所有新特征都归给他。

## 4. 三层身份治理

```text
source_identity
= 《列王纪》等来源层中的所罗门

reception_identity
= 某一后世传统重新解释后的所罗门／Sulayman

named_archetype
= 跨多个接受层仍保持可识别身份锚点并形成稳定文化模型的“所罗门王”
```

## 5. 与近邻对象边界

```text
智慧王
= abstract_archetype，可由多个具体人物承载

所罗门王
= named_archetype，必须保留命名身份连续性

智慧
= trait / theme，不是 archetype

审判难题
= motif / plot_pattern candidate，不等于人物原型

魔法戒指
= symbol candidate，需单独准入
```

## 6. Pilot B.1 的关键压力

如果把“智慧、财富、圣殿、魔法、精灵”等所有所罗门相关内容简单堆在一起，专题会退化成人物百科。

因此真正要验证的是：

> 哪些特征构成身份锚点，哪些构成跨时代稳定功能，哪些只是某一接受传统新增的可变层。
