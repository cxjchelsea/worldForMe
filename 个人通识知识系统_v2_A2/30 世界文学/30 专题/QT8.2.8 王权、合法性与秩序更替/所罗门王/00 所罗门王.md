# 所罗门王｜named archetype Pilot B.1

> **定位：**研究希伯来—圣经来源人物所罗门如何从具体王者形象，经过智慧、审判、圣殿、知识与超自然权能等特征的选择、放大和重组，形成跨犹太、基督教、伊斯兰与秘传传统持续可识别的命名型文化原型。

## 1. Pilot B.1 为什么必须单独做

“受苦义人”验证的是多个人物实例可以抽象出同一角色功能；“所罗门王”测试的是相反问题：

```text
同一来源人物
→ 跨时代持续保留姓名／身份锚点
→ 特征不断选择、放大、删减与新增
→ 在新传统中仍被识别为“所罗门／Sulayman”
→ named archetype
```

因此：

```text
source figure Solomon
≠
named archetype Solomon
```

## 2. 来源层锚点

QT8.1.1 已将所罗门定位为：

- 智慧王；
- 圣殿建造者；
- 富强与国际声望的王；
- 同时也是王权扩张、负担与后续分裂伏笔的一部分。

这意味着来源人物本身并非单纯“完美智慧王”。命名型原型研究必须追踪后世究竟选择了哪些特征，又淡化了哪些张力。

## 3. Pass A 的原型化链

```text
《列王纪》中的所罗门
→ 智慧／审判／圣殿／财富／王权张力
→ 智慧文学中的“所罗门式作者权威”
→ 约瑟夫斯等晚期古代传统中的超自然智慧／驱魔关联
→ 《所罗门遗训》等文本中的魔法王／制魔者
→ 《古兰经》中的 Sulayman：先知王、智慧者、能统御风与精灵等受神授权力量
→ 中世纪—近代 Solomonic magic 中的权威名字
→ named archetype
```

当前只把这条链作为工作模型；每一层仍需分别保存 relation_type 与 evidence_level。
