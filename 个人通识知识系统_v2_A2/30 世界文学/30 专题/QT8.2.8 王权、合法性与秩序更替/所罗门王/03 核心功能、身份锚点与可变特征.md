# 核心功能、身份锚点与可变特征

## 1. identity_anchor｜身份锚点

命名型原型比抽象原型多一个必须层：**人物仍然要被识别为同一个文化名字。**

当前最低锚点：

- Solomon / 所罗门 / Sulayman 等姓名连续；
- 王者身份；
- 与智慧声望的稳定关联。

圣殿、魔法戒指、示巴女王等都很重要，但暂不列为“缺失即无法识别”的最低身份锚点。

## 2. core_functions｜稳定角色功能候选

- `wise_king_and_judge`：王权与卓越智慧／判断力结合；
- `sacral_royal_authority`：王权具有显著宗教／神圣授权维度；
- `builder_and_centralizer`：以大型神圣／政治工程塑造秩序，来源层以圣殿最突出；
- `knowledge_authority`：人物名字本身逐渐成为智慧、知识乃至隐藏知识的权威标记。

## 3. variable_features｜接受史可变层

| 特征 | 来源层 | 后世可能变化 |
|---|---|---|
| 财富与荣耀 | 强 | 被放大为世界王／传奇富王 |
| 示巴女王 | 来源故事存在 | 可发展为爱情、竞智、征服、宗教转化等不同叙事 |
| 智慧写作权威 | 后续关联增强 | 箴言、传道书、雅歌、《所罗门智训》等形成不同程度的所罗门式作者身份 |
| 驱魔／制魔 | 非来源层核心 | 晚期古代显著增强 |
| 魔法戒指 | 非来源层核心 | 后期成为高辨识度传奇物件 |
| 统御精灵／自然力量 | 非希伯来来源层核心 | 伊斯兰接受中高度突出 |

## 4. 命名型原型的稳定公式

工作模型：

```text
identity_anchor
+
至少一组稳定 core_functions
+
可大量漂移的 variable_features
=
named archetype continuity
```

所以命名型原型可以变化很大，但不能只剩名字空壳；反过来，一个匿名“智慧王”即使功能相似，也不能自动记为所罗门王原型的历史后裔。
