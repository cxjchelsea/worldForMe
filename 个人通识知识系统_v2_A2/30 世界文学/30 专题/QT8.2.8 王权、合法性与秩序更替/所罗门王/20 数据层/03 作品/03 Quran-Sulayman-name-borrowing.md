# 《古兰经》中的 Sulayman｜figure_rewriting

本记录表达命名人物在新的经典共同体中保持可识别身份，同时其先知身份、神学位置、超自然权能和具体叙事被系统重组。

因此：

```text
shared named figure
≠ same narrative
≠ same theological function
```

但这也不只是借名，故使用 `figure_rewriting`。
