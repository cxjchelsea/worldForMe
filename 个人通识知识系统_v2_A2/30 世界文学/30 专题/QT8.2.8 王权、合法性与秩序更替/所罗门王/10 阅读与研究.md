# 阅读与研究

## 1. 最小阅读路线

```text
《列王纪》中的所罗门
→ 所罗门智慧传统／伪托作者权威
→ Josephus《犹太古史》8.42–49
→ 《所罗门遗训》
→ 《古兰经》中的 Sulayman
→ Solomonic magic / Key of Solomon 传统
```

阅读时持续追问：

- 姓名／王者身份是否连续？
- 哪些来源特征被保留？
- 哪些特征被放大？
- 哪些新特征第一次进入？
- 新增特征是否后来继续被复制？
- 人物是故事角色，还是已经成为知识／权威标签？

## 2. 当前研究入口

### 来源与智慧王

- QT8.1.1 的所罗门来源人物、王权故事群与《列王纪》文本记录；
- David Firth, “The Solomonic Connection”，用于比较 Kings / Chronicles 中的智慧王形象。

### 魔法／驱魔原型化

- Dennis C. Duling 对 Josephus *Antiquities* 8.42–49 的研究；
- Jesse Rainbow 对 `Solomon magus` 传统与《所罗门遗训》的研究；
- *Testament of Solomon* 与后续 Solomonic magic 研究。

### 伊斯兰接受

- 《古兰经》相关 Sulayman 段落与学术研究；
- 重点区分 Quranic narrative 与后续中世纪 Muslim storytellers 的扩展。

```yaml

```

用于回答：经过大幅重写后，什么仍保证这个人物被识别为同一个命名文化角色？

### REVISE CANDIDATE

Shared Data Layer 的 work relation 可能需要增加：

```text

```

因为 named archetype 的典型接受关系经常是“同一命名人物被系统重构”，比 `character_or_name_borrowing` 更强，又不等于整部作品的 `direct_adaptation`。

当前仅记录为候选，不在单一 Pass 中直接冻结共享词汇。

### DEFER

- `identity_anchor` 是否成为 named archetype 稳定字段，待 Pass B 再验证；
- `figure_rewriting` 是否正式加入共享 relation_type，待真实数据压力测试后决定；
- 正式 `qt82_component_relation` 等待 target component 准入。
