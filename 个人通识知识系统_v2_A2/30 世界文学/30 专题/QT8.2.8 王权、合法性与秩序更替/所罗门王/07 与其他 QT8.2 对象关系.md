# 与其他 QT8.2 对象关系

## 1. abstract archetype 候选

### 智慧王

所罗门是“智慧王”最强实例之一，但：

```text
所罗门王 named_archetype
≠
智慧王 abstract_archetype
```

未来若“智慧王”完成独立准入，可建立正式 component relation。

### 神圣王／天选之王

来源层中的受神授权王权与后世先知王形象可以连接这一抽象原型，但仍等待对应对象正式建档。

## 2. motif 候选

- 智慧审判／难题裁决；
- 王权繁荣与过度扩张；
- 建造神圣中心；
- 知识与隐藏知识；
- 人与超自然存在的控制关系。

## 3. plot_pattern 候选

```text
继承合法性
→ 获得智慧／权威
→ 建造与繁荣
→ 权力扩张
→ 张力／失衡
→ 死后秩序断裂
```

这属于来源层王权结构候选，不等于 named archetype 本身。

## 4. symbol 候选

- 所罗门印／戒指；
- 圣殿；
- 王座；
- “所罗门之钥”作为秘传知识权威符号。

都必须通过 symbol 自身准入后才能成为正式 component target。
