# 原型化与身份漂移过程

## 1. 命名型原型不是一次完成

“所罗门王”并不是在来源文本中一次性具备后世全部形象，而是在长期接受中逐层累积：

```text
历史／文学王者
→ 智慧王与审判者
→ 圣殿建造者与秩序中心
→ 智慧作品的权威名字
→ 掌握隐藏／超自然知识者
→ 驱魔者与制伏恶灵的王
→ 伊斯兰传统中的先知王 Sulayman
→ 中世纪—近代秘传传统中的魔法权威
```

## 2. 特征选择

后世每次重写都不会平均继承所有来源特征。

例如：

- 智慧文学更强调“智慧／作者权威”；
- Josephus 所见传统强化“智慧可处理恶灵”的方向；
- 《所罗门遗训》进一步把所罗门写成以神授权物控制恶魔、组织建殿工程的魔法王；
- 《古兰经》中的 Sulayman 把王权、先知身份、智慧和对风／精灵等受神授权的统御重新组合；
- 后世 grimoires 又把“Solomon”进一步变成仪式魔法的权威签名。

## 3. identity drift 不等于身份断裂

命名型原型允许显著漂移，只要仍存在足够身份锚点与功能连续性：

```text
姓名连续
+
王者／智慧身份连续
+
若干核心功能被保留
→ 可以继续视作所罗门原型的重写
```

但如果只出现“一个智慧王”而没有任何 Solomon / Sulayman 身份连接，就只能讨论 `functional_similarity`，不能自动写成所罗门传播。

## 4. Pilot B.1 新发现

抽象原型主要问：

```text
哪些角色功能跨人物稳定？
```

命名型原型还必须多问两件事：

```text
什么让我们仍然认出“这是同一个文化人物”？
哪些后世新增特征已经稳定到足以成为该名字的一部分？
```

因此 `identity_anchor` 是 named archetype 的专属稳定字段候选。
