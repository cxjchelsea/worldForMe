# 跨传统重写与关系置信度

## 1. 本 Pilot 的关键关系不是“相似人物”，而是命名人物的连续重写

与抽象原型不同，所罗门王很多后世材料具有明确的姓名连续：Solomon / Sulayman。

因此优先使用：

```text
explicit_reference
character_or_name_borrowing
figure_rewriting（当前 schema 候选）
```

而不是仅使用 `functional_similarity`。

## 2. 当前 schema 暴露出的缺口

Shared Data Layer 的 `qt82_work_reference.relation_type` 当前包括：

```text
direct_adaptation
explicit_reference
character_or_name_borrowing
structural_inheritance
motif_inversion
symbol_reuse
plot_pattern_inversion
```

但 named archetype 的典型情况往往是：

> 后世作品继续使用同一命名人物，却对其角色功能进行大规模重写。

这与单纯 `character_or_name_borrowing` 不完全相同，也不必是整部作品的 `direct_adaptation`。

因此 Pilot B.1 提出非破坏性候选：

```text
figure_rewriting
```

在正式修改共享 schema 前，Pass A 数据记录仍优先使用现有最接近关系，并在说明中保留该观察。

## 3. 伊斯兰接受治理

```text
Hebrew Bible Solomon
→ Quranic Sulayman
```

可以确认是共享命名人物在新经典共同体中的再叙述，但不能写成：

```text
same narrative sequence
same theological function
same textual genealogy
```

## 4. 魔法传统治理

所罗门与魔法／驱魔的联系有可追踪的晚期古代文本史，但：

```text
晚期古代所罗门魔法传统
≠ 《列王纪》已经直接描写所罗门为 grimoire magician
```

后者属于后世特征放大与重组。

## 5. 相似王者仍需另判

其他传统中的智慧王、神圣王、魔法王只能先记录为：

```yaml
relation_type: functional_similarity
evidence_level: documented | similarity_only
```

除非有独立证据证明其确实通过 Solomon / Sulayman 传统传播。
