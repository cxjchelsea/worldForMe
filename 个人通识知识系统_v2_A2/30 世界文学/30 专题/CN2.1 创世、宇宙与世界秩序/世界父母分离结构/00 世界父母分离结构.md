# 世界父母分离结构｜叙事结构

> **一句话理解：**天地像一对紧密结合的父母；后代或生命被挤在中间，直到一次分离行动把可居住的空间打开。

## 怎样辨认

需要按这个顺序发生：

```text
世界父母紧密结合
→ 后代／生命受到压迫或限制
→ 发生分离行动
→ 天地空间展开
```

它比 [[../天地分离/00 天地分离|天地分离]] 更严格。只出现“天和地被分开”，还不够；必须看得到父母关系、受压的后代，以及一次把空间打开的分离行动。

## 当前来源

- Māori 的 Rangi / Papa：四个环节都完整
- 埃及的 Nut / Geb / Shu：完整或接近完整；当前还没有单独的埃及 CN1.1 节点
- [[CN1.1.2 希腊—罗马神话传统]]：Gaia / Ouranos / Kronos 是强变体——后代受压和分离行动都很清楚，但“宇宙空间由此展开”的写法与 Māori、埃及不同
