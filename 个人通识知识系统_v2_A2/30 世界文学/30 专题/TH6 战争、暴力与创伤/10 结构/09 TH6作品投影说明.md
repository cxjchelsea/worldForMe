# TH6 作品投影说明

## 正式专题 ID

TH6 继续复用稳定 ID：

```text
WL-TOPIC-Q6-WAR
```

该 ID 是历史兼容 ID；当前语义已升级为完整 TH6「战争、暴力与创伤」。

## 新作品字段

```yaml
violence_trauma_role: 骨架 | 比较 | 边界
violence_trauma_priority: ★ | ◆ | △
violence_trauma_problems:
  - P1
violence_trauma_note: "..."
```

## 旧战争字段

以下字段继续保留，不批量删除：

```yaml
war_priority:
war_history_stage:
war_axes:
```

它们只描述战争文学子域的历史位置和机制，不等于完整 TH6 问题结构。

## 投影原则

- 战争作品：可同时保留 `war_*` 与新增 `violence_trauma_*`。
- 非战争暴力作品：只新增 TH6 新字段，不伪造 `war_*`。
- 作品仅因“背景里发生战争/暴力”不自动进入 TH6；必须满足暴力发生、伤害或余波是不可替代问题。
- 现有中央实体较长时，不为凑数量进行大范围覆盖；只修改能安全核验的作品。
