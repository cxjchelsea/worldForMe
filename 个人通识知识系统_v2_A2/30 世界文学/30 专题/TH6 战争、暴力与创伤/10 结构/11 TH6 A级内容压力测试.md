# TH6 A级内容压力测试

## 一、测试目的

本测试不再验证“TH6 是否应该作为叶节点”，而验证升级后的知识地图能否真正跨越战争、奴役、国家暴力、群体暴力、亲密关系暴力与创伤叙事，同时保持与 TH4、TH5、TH7、TH8 的边界。

重点检查：

1. **解释覆盖**：不同暴力作品是否能进入“敌我化/正当化 → 卷入 → 身体伤害 → 关系破坏 → 创伤 → 责任/循环 → 见证”的机制。
2. **非战争覆盖**：TH6 是否真正超出旧“战争文学”框架。
3. **边界稳定**：不会把贫困、一般制度压迫、犯罪、历史苦难都自动判成 TH6。
4. **形式解释力**：创伤叙事中的碎片、重复、沉默等形式能否被解释，而不把所有非线性叙事都称为创伤。
5. **旧资产兼容**：战争文学旧思想史和问题横轴能否作为专题内部子域保留，而不与新 TH6 冲突。
6. **抗拆分能力**：是否真的需要新增 `TH6.x`。

## 二、验收标准

- 核心作品能够由七问和七大机制解释；
- 不同暴力情境的差异可由八组张力和跨传统框架承接；
- 邻界作品能够被判定为复合、局部或非核心；
- 只有出现大量稳定、互斥且无法由机制/张力承接的作品群，才考虑拆分坐标。

## 四、七个核心问题覆盖结果

| 核心问题 | 结果 | 说明 |
|---|---|---|
| P1 卷入/加害/旁观/共谋 | 通过 | 战争、种族灭绝、荣誉暴力、校园/群体暴力均能使用。 |
| P2 身体与日常 | 通过 | 能防止宏大政治叙事遮蔽实际伤害。 |
| P3 家庭、关系与共同体破坏 | 通过 | 《宠儿》《半轮黄日》及亲密关系暴力尤其证明必要性。 |

## 五、压力测试发现的两个边界警告

### 1. “结构性伤害”不能无限扩大 TH6

贫困、阶级不平等、歧视、制度限制都可能给人造成真实伤害，但如果没有形成较明确的**强制、身体威胁、暴力实施、持续恐惧或创伤性余波**，应优先由 TH4、TH5、TH3 等分析。

因此不能建立：

```text
一切不平等 = 暴力 = TH6
```

否则 TH6 会失去边界。

更稳妥的是：

```text
结构位置 / 资源不平等 → TH4
制度规则 / 强制授权 → TH5
身份分类 / 排斥 → TH3
具体伤害及其创伤余波 → TH6
```

### 2. “创伤”不能成为所有破碎叙事的万能解释

时间跳跃、碎片叙事、不可靠叙述本身不足以判断创伤。只有当形式与作品中的极端伤害、无法安置的过去、重复侵入或沉默机制形成稳定关系时，才应作为 TH6 的创伤形式分析。

这两条不是新增机制，而是防止 TH6 过度扩张的使用规则。

## 六、旧战争文学资产兼容性结果

结论：**旧资产不应删除，也不应继续治理整个 TH6。**

最合理的层级是：

```text
TH6：战争、暴力与创伤（统一主题）
│
├─ 七问 + 暴力发生与余波机制：上层解释框架
│
├─ 旧战争文学思想史：战争子域历史纵轴
├─ 旧二十条战争问题：战争子域细粒度横轴
├─ 旧跨体裁/文明比较：战争子域扩展材料
│
└─ 非战争暴力作品：直接由 TH6 统一框架进入
```

因此已有知识被保留，同时避免“战争文学 = TH6”的历史兼容问题重新控制新结构。

## 七、是否需要新增 TH6.x

结论：**不需要。**

不同作品的差异来自：

- 暴力的正当化方式不同；
- 组织者与加害者关系不同；
- 伤害规模与技术不同；
- 身体/关系/共同体破坏不同；
- 创伤与责任处理方式不同；
- 见证条件不同。

这些都属于机制和比较维度，不构成稳定互斥的第二坐标树。

战争、奴役、家庭暴力、国家暴力、群体暴力也不应变成 `TH6.1/TH6.2/...`，因为同一作品经常跨越多个暴力情境，而真正可复用的是七问与机制链。

## 八、A级验收结论

### 结论：**通过。**

TH6 已满足 A 级知识地图标准：

- L1：边界清楚，并保留战争文学/历史文学专门边界资产；
- L2：七个核心问题稳定；
- L3：形成从暴力可实施化到创伤、责任、见证的完整机制；
- L4：八组张力可以跨作品比较；
- L5：能够横跨古典战争、现代战争、种族灭绝、奴役、殖民、国家、内战、亲密关系和群体暴力；
- L6：阅读路线从战争书单升级为机制学习路线；
- 边界测试能拒绝“有战争背景/有谋杀/有贫困/有制度压迫 = TH6”的误判；
- 旧战争文学资产被成功整合为专题内部子域，而非删除；
- 没有新增 `TH6.x` 的必要。

因此 TH6 可正式由原来的 B-/已有资产型专题升级为 **A 级成熟主题知识地图**。
