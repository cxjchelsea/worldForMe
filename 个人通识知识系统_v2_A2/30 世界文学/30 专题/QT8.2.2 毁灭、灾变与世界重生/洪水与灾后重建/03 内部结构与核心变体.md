# 内部结构与核心变体

## 1. 核心不变量

第一轮 Pilot 暂定三个核心不变量：

```text
A 大规模水灾破坏旧秩序
B 少数生命／共同体资源被保存
C 洪水之后出现新的秩序阶段
```

如果只具备 A，而没有 B/C，则更适合归入一般灾变叙事。

## 2. 可变槽位

| 槽位 | 可变问题 |
|---|---|
| 灾变原因 | 人类暴力／失序、神意、噪音、未知原因等 |
| 预警机制 | 神谕、秘密告知、观察、无预警 |
| 幸存者选择 | 德性、特殊关系、偶然、血缘或功能选择 |
| 保存媒介 | 船／方舟、山地、神圣空间、其他方式 |
| 保存对象 | 家族、动物、种子、工艺、文化资源 |
| 洪水终止 | 神意、自然退水、时间完成 |
| 灾后确认 | 放鸟、观察陆地、祭祀、盟约、重新繁衍 |
| 新秩序 | 盟约、祭祀、人口限制／繁衍、政治或宇宙秩序 |

## 3. 当前两组来源的差异价值

希伯来—圣经材料突出：

```text
世界失序／暴力
→ 审判
→ 挪亚与生命保存
→ 灾后盟约与新秩序
```

阿特拉哈西斯传统则非常适合检验“灾变原因与灾后人口秩序并不相同，但仍可属于同一 motif”这一点。

《吉尔伽美什史诗》第 XI 泥版又把洪水叙事嵌入吉尔伽美什寻找不死答案的更大叙事中，因此同一洪水 motif 可以在新的作品结构中承担不同功能。

## 4. Pilot 判断

这说明 motif 的定义不能依赖某一个传统中的具体神学解释，而应抓住跨来源仍能保持的叙事关系。
