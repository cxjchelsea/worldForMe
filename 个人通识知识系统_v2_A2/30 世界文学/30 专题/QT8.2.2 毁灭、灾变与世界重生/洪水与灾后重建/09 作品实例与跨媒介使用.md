# 作品实例与跨媒介使用

## 1. Pilot A 原则

本页不追求数量，只收能验证 motif 边界、文本角色或关系模型的实例。来源级文本与后世重写分开。

## 2. 来源／定型级实例

### 《创世记》6–9

- `work_role`: `defining_text`
- `retained_invariants`: R1 + R2 + R3
- 关键槽位：审判、方舟、生命保存、退水、祭祀、盟约。

### 《阿特拉哈西斯》洪水段

- `work_role`: `early_witness / defining_text`
- `retained_invariants`: R1 + R2 + R3
- 关键槽位：秘密预警、造船、生命保存、洪水、祭祀、灾后人口秩序调整。

### 《吉尔伽美什史诗》第 XI 泥版

- `work_role`: `defining_reworking`
- `retained_invariants`: R1 + R2 + R3
- 关键变化：洪水故事被嵌入吉尔伽美什对死亡和不死的追问，motif 的作品内功能发生变化。

### 奥维德《变形记》第一卷

- `work_role`: `later_defining_reworking`
- `retained_invariants`: R1 + R2 + R3
- `modified_slots`: 无方舟保存链作为核心；灾后通过丢卡利翁、皮拉执行神谕而重新生成人类。
- Pilot 价值：证明“方舟／船”不能成为 motif 的必选条件。

## 3. 后世实例的数据规则

后世作品只有在能够填写以下字段时才进入正式实例层：

```yaml
work: ...
source_component: WL-TOPIC-QT822-FLOOD
retained_invariants: []
modified_slots: []
relation_type: ...
evidence_level: ...
source_evidence: ...
```

其中：

- `direct_adaptation` 必须有明确来源对象；
- `explicit_reference` 必须能指出文本／创作者明确调用；
- `structural_inheritance` 不能只因“有洪水”成立；
- `structural_similarity` 可以记录比较，但不能写成影响。

## 4. 后世实例候选池（尚未正式收入）

可以后续核证三种不同压力测试：

1. **明确诺亚／洪水改编**：测试 `direct_adaptation`；
2. **生态／气候洪水叙事**：测试 R1–R3 是否仍成立，以及是结构继承还是仅相似；
3. **“方舟逻辑”但无洪水**：测试它是否其实属于 symbol / preservation motif，而不该继续算洪水 motif。
