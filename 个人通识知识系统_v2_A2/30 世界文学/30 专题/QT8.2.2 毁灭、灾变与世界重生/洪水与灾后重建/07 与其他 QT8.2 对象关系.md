# 与其他 QT8.2 对象关系

## 1. archetype

当前候选：

- 洪水幸存者
- 第二祖先／重建者
- 被选中保存生命者

这些目前只作为 `archetype_candidate`，尚未独立建档。

## 2. plot_pattern

高连接结构：

```text
失序／灾变决定
→ 预警／选择幸存者
→ 保存生命资源
→ 洪水毁灭
→ 退水／着陆
→ 灾后确认
→ 新秩序
```

注意：该结构比 motif 定义更完整，因此属于 plot_pattern 接口，而不是 motif 本身的唯一形式。

## 3. symbol

当前候选：

- 方舟／船
- 洪水
- 虹（希伯来—圣经传统）
- 山／着陆地点
- 鸟类探查

只有在跨文本、跨时代形成稳定可识别文化意义后才进入 symbol 层。

## 4. 其他 motif

可能关联：

- 世界毁灭与重生
- 神人边界与审判
- 少数幸存者
- 新祖先与重新繁衍
- 盟约／灾后秩序

## 5. 关系治理

建议后续关系实体使用：

```text
co_occurs_with_motif
carried_by_archetype
organized_by_plot_pattern
represented_by_symbol
```

Pilot A 暂不因为“可以想象出关系”就批量建实体。
