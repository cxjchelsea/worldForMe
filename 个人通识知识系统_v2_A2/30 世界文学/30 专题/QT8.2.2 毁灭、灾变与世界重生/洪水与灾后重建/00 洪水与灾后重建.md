# 洪水与灾后重建｜motif Pilot A

> **定位：**比较不同来源传统中“世界／共同体因大规模水灾被毁坏，少数生命被保存，随后建立新秩序”的叙事单元；重点研究核心不变量、主要变体、文本见证与传播证据，而不是寻找未经证实的单一起源。

## 当前 Pilot 范围

第一轮只建立两个已经可以较稳妥处理的来源入口：

1. [[../../QT8.1.1 希伯来—圣经叙事传统/00 希伯来—圣经叙事传统|QT8.1.1 希伯来—圣经叙事传统]]：以《创世记》6–9 的洪水—挪亚叙事为核心来源入口；
2. 古代美索不达米亚洪水传统：以《阿特拉哈西斯》洪水段与《吉尔伽美什史诗》第 XI 泥版中的乌特那庇什提姆洪水叙事作为第一轮比较文本。

古代美索不达米亚来源尚未在 QT8.1 建立独立 Reference Topic，因此本 Pilot 将其标记为 `external_source_pending_qt81_topic`，不假装来源层已经完整。

## 四类对象边界

本页研究的是 `motif`：

```text
失序／灾变原因
→ 大洪水
→ 少数生命被保存
→ 洪水退去
→ 灾后秩序重建
```

相关但不是同一对象：

- `archetype`：洪水幸存者／第二祖先；
- `plot_pattern`：失序 → 毁灭 → 幸存 → 重建；
- `symbol`：方舟、洪水、虹等只在达到符号准入门槛后单独建档；
- `theme`：审判、正义、毁灭与更新等仍主要属于 QH。
