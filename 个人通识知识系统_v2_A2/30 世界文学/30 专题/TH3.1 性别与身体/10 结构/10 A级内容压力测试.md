# TH3.1 A级内容压力测试

## 一、测试目标

在 V1 已冻结六问的基础上，本轮不再测试坐标拆分本身，而测试 TH3.1 是否已经具备 A 级专题应有的解释能力：

1. 能否同时解释性别角色、生殖身体、审美凝视、疾病/残障、衰老与身体治理，而不退化成“泛身体主题”；
2. 能否处理女性、男性、性别流动与非性别化身体；
3. 能否与 TH3.2、TH3.3、TH2、TH4、TH5、TH6 稳定分工；
4. 六个核心问题是否仍足以覆盖扩展作品组；
5. 是否出现需要新增 `TH3.1.x` 的稳定分叉。

## 二、统一强判据

强命中至少存在以下链条中的后半段：

```text
身体差异 / 性别位置
→ 社会赋义或制度分类
→ 角色、资格、空间、资源或行动边界改变
→ 主体产生身体经验与回应
```

仅有女性主角、性爱、疾病、受伤、外貌描写或身体变化，不足以强命中。

## 三、20 组作品测试

### A. 核心组

1. **《玩偶之家》**：P1/P5/P6。妻职与母职不是人物背景，而是法律、经济和家庭资格的性别脚本；离开意味着退出被规定的角色。
2. **《觉醒》**：P1/P3/P6。婚姻、母职、性别期待与身体自主形成稳定冲突。
3. **《使女的故事》**：P1/P3/P5/P6。国家按生殖能力分类身体，并直接决定岗位、服饰、行动和社会身份。
4. **《金锁记》**：P1/P2/P3/P5。婚姻市场、家庭角色、身体价值与生育/继承交织。
5. **《素食者》**：P2/P4/P5/P6。身体拒绝被家庭和医学重新解释、控制，身体成为主体反抗和被病理化的场所。
6. **《钟形罩》**：P1/P4/P5/P6。精神健康、医学经验与“正常女性人生”互相定义。
7. **《紫色》**：P1/P2/P5/P6。女性身体同时受性别、种族、暴力与家庭关系塑造，适合作为交叉机制核心样本。
8. **《宠儿》**：P2/P3/P5/P6。奴役制度把女性身体、劳动、生殖和母职纳入所有权关系；同时强交叉 TH3.3/TH6/TH7。
9. **《最蓝的眼睛》**：P2/P6。肤色、外貌与白人美貌标准把身体评价转化为自我价值，是 P2 的极强样本。
10. **《奥兰多》**：P1/P2/P6。身体与性别变化使社会角色、资格和他人目光改变，同时检验主体连续性。

### B. 扩展组：证明不是“女性文学”

11. **《变形记》**：P2/P4/P5。身体变化改变劳动能力、家庭价值、空间资格和照料关系。其核心不必是性别，证明 TH3.1 的“身体—社会身份”部分具有独立解释力；但不能因此把所有身体变形作品自动纳入。
12. **《弗兰肯斯坦》**：P2/P6，邻核心。被制造身体因外貌被定义为怪物，社会凝视改变其承认与共同生活可能；科学创造本身不是 TH3.1 的职责。
13. **《献给阿尔吉侬的花束》**：P4/P5/P6，邻核心。认知能力、医学干预、正常性判断与社会位置关联；重点在能力被怎样评价和治理，而非单纯医学实验。
14. **《一日长于百年》类老年/衰老样本以《斯通纳》作边界比较**：衰老和身体下降存在，但若身体变化不持续组织人物资格与承认，TH3.1 不应仅因“老去”强命中。由此证明衰老必须经过社会后果判据。

### C. 兄弟与邻域边界组

15. **《查泰莱夫人的情人》**：非核心。身体和性爱突出，但主要问题是欲望、性关系与性规范，优先 TH3.2 / TH2.1；“身体出现很多”不是 TH3.1 判据。
16. **《孽子》**：复合但 TH3.2 更强。性少数身份、欲望合法性和性规范是主轴；只有当性别化身体、外部目光或身体资格成为独立结构时才加 TH3.1。
17. **《傲慢与偏见》**：边界。性别化婚姻资格与女性经济位置明显，但作品的爱情、婚姻、阶级机制更强；不能因女性婚姻处境自动把 TH3.1 升为核心。
18. **《愤怒的葡萄》**：非核心/局部。劳动身体、饥饿和疲惫大量出现，但核心是阶级、劳动、迁徙与生存结构，优先 TH4/TH3.5。身体受苦本身不足。
19. **《1984》**：非核心/局部。国家控制身体、性和日常行为，但制度权力是主机制，优先 TH5；只有具体身体规训与身体资格成为分析中心时才进入 TH3.1。
20. **《夜》**：非核心/复合。极端身体伤害、饥饿和衰弱非常突出，但主要解释轴是暴力、创伤与见证，归 TH6/TH7；不能把“身体遭受极端伤害”自动等同 TH3.1。

## 四、六问复核

### P1 性别角色与社会期待如何规定人生脚本
稳定。可覆盖婚姻、职业、母职、男性气质、公共/私人角色等，无需拆分。

### P2 身体如何被观看、命名、评价并赋予社会价值
稳定。能够统一美貌、肤色、体型、年龄、身体差异和可欲性等，不恢复旧“外貌标准”独立问题。

### P3 生育、母职与身体自主如何发生冲突
稳定且不可被 P1/P5 吸收。生殖身体具有从身体能力到家庭/国家义务的独特转换机制。

### P4 疾病、残障、疼痛与衰老如何改变身体经验和社会位置
稳定。扩展测试证明它必须保留，但只有进一步改变社会参与、照料、劳动或承认时才进入 TH3.1，从而避免泛身体化。

### P5 家庭、医学、法律与制度如何控制身体
稳定。与 TH5 的边界可执行：制度为何运转归 TH5；制度怎样具体分类、检查和限制身体归 P5。

### P6 人如何反抗、重写或重新占有自己的性别与身体
稳定。能够覆盖退出角色、拒绝病理化、重建身体价值、生殖自主和性别自我定义。

**未出现第七问题证据。**

## 五、三类高风险误判

### 误判 1：女性主角 = TH3.1
错误。必须证明性别角色或身体赋义持续改变人物的生活资格与行动边界。

### 误判 2：身体受苦 / 生病 / 变老 = TH3.1
错误。只有当身体状态进一步改变社会位置、参与条件、照料关系或承认方式时才进入核心。

### 误判 3：性欲 / 性行为 = TH3.1
错误。欲望对象、性行为、性取向和性规范首先检查 TH3.2；性别角色、身体评价、生殖、身体资格与身体自主才是 TH3.1。

## 六、关键边界最终复核

```text
性别脚本 / 身体赋值 / 生殖身体 / 身体资格 / 身体控制 → TH3.1
性欲 / 性行为 / 性取向 / 性禁忌 / 欲望合法性           → TH3.2
种族与族群分类                                       → TH3.3
婚姻与亲密关系本身                                   → TH2.2
家庭 / 亲子结构本身                                  → TH2.3 / TH2.4
资源、劳动与阶级                                     → TH4
制度权力与规则运行                                   → TH5
具体暴力、身体伤害与创伤                             → TH6
```

复合标注允许存在，但每个专题只解释自己的机制。

## 七、是否需要拆分“性别 / 身体”

不需要。

原因不是二者概念相同，而是文学中的稳定核心机制高度重合：

```text
性别位置通常借身体被识别和管理
身体差异只有进入社会赋义后才成为本专题问题
```

拆为两个坐标会使《使女的故事》《觉醒》《紫色》《奥兰多》《宠儿》等稳定双重命中，而疾病/残障身体仍需依赖同一“身体 → 社会赋义 → 身份后果”模型。

因此复杂性继续留在专题内部，而不是新增 `TH3.1.x`。
