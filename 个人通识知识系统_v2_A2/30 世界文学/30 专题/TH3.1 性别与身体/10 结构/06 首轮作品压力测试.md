# 首轮作品压力测试

## 1. 测试目标

检验 TH3.1 是否应继续作为叶节点，以及七个候选问题是否彼此独立。重点测试：

- “性别”与“身体”是否必须拆成两个子坐标；
- P2“身体被观看/评价”与 P5“美貌/外貌标准”是否重复；
- 疾病、残障、衰老是否会把 TH3.1 扩张成泛身体主题；
- TH3.1 与 TH3.2、TH1.1、TH5、TH6 的边界是否可执行。

## 2. V1 作品组

### 骨架 9 部

1. 《玩偶之家》：P1 / P6 / P7 —— 性别角色、婚姻制度与主体退出。
2. 《觉醒》：P1 / P3 / P7 —— 妻职、母职、身体自主与离开既定女性人生脚本。
3. 《金锁记》：P1 / P5 / P6 —— 女性身份、婚姻身体、外貌/价值与家庭结构控制。
4. 《使女的故事》：P1 / P3 / P6 / P7 —— 性别分类、生殖身体、国家制度控制与反抗。
5. 《紫色》：P1 / P2 / P6 / P7 —— 黑人女性身体、暴力、命名权与自我重建。
6. 《宠儿》：P2 / P3 / P6 / P7 —— 奴隶制对女性身体、母职与身体所有权的极端控制。
7. 《钟形罩》：P1 / P2 / P4 / P6 —— 女性角色、医学诊断、精神疾病与社会期待。
8. 《素食者》：P2 / P4 / P6 / P7 —— 身体拒绝、医学/家庭控制与身体自主。
9. 《奥兰多》：P1 / P2 / P7 —— 性别身份、身体变化、社会角色与重新定义。

### 比较 5 部

10. 《最蓝的眼睛》：P2 / P5 —— 凝视、美貌标准、种族化身体；检验 P2/P5 重叠。
11. 《变形记》：P2 / P4 —— 身体变化、劳动能力与家庭价值；检验“非性别身体”是否仍能进入 TH3.1。
12. 《简·爱》：P1 / P6 / P7 —— 女性独立与社会角色，但主体性/爱情同样强。
13. 《到灯塔去》：P1 —— 性别角色存在，但作品不应因此整体被 TH3.1 吞没。
14. 《孽子》：P1 / P2 / P7 —— 性别化身体与社会排斥存在，同时测试与 TH3.2 的边界。

### 边界测试 1 部

15. 《查泰莱夫人的情人》：身体与性欲高度突出，但核心更偏性欲、性规范与亲密关系，因此主要归 TH3.2 / TH2.1；不能因“身体”出现频繁就自动归 TH3.1。

## 3. 结果

### 3.1 TH3.1 不需要拆成“性别”和“身体”两个子坐标

《玩偶之家》《使女的故事》《紫色》《奥兰多》《素食者》等都显示：性别社会位置通常通过身体被观看、管理、限制和解释而实现。若拆成两个子坐标，同一批核心作品会稳定双重命中，降低坐标辨识度。

《变形记》提供了重要边界：非性别化身体只有在身体变化持续改变劳动能力、家庭位置和社会承认时才进入 TH3.1；“身体出现”本身不是命中条件。

### 3.2 P2 与 P5 应合并

《最蓝的眼睛》《金锁记》《紫色》说明，美貌、肤色、体型和外貌标准本质上都是“身体如何被观看、命名、评价并转化为社会价值”的具体机制。P5 没有足够独立的问题结构。

结论：**P5 删除，其内容并入 P2。**

### 3.3 P4 保留

疾病、残障、疼痛和衰老不能被 P2 简单替代。P2 讨论身体被社会解释；P4 讨论身体能力与感知条件本身如何改变人与空间、劳动、照料和公共生活的关系。《钟形罩》《变形记》《素食者》提供独立证据。

### 3.4 P6 与 P7 独立

制度如何控制身体，与主体如何重新取得身体解释权，是“控制机制 / 回应机制”两个不同问题。《使女的故事》《素食者》《玩偶之家》均可区分。

## 4. 冻结建议

候选 7 问题调整为 **6 问题**：

1. 性别角色与社会期待如何规定人生脚本
2. 身体如何被观看、命名、评价并赋予社会价值
3. 生育、母职与身体自主如何发生冲突
4. 疾病、残障、疼痛与衰老如何改变身体经验和社会位置
5. 家庭、医学、法律与制度如何控制身体
6. 人如何反抗、重写或重新占有自己的性别与身体

未发现需要第七问题或稳定第二维的证据。
