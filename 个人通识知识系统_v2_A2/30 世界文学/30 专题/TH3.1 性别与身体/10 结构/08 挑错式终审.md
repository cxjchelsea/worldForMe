# 挑错式终审

## 1. TH3.1 是否过宽

风险：标题同时包含“性别”和“身体”，看似可能容纳一切身体经验。

终审规则：身体只有在稳定改变**社会身份、行动能力、被承认方式或归属**时才进入 TH3.1。单纯身体描写、疾病情节、情色身体或暴力创伤不自动命中。

结论：在这一限制下，TH3.1 仍具有足够坐标辨识度。

## 2. TH3.1 与 TH3.2

- 性别角色、身体被观看、生殖身体、医学/制度控制 → TH3.1。
- 性欲、性行为、性取向、性禁忌与性规范本身 → TH3.2。
- 同一作品可兼标，但必须分别证明两种机制都构成核心问题。

《查泰莱夫人的情人》作为负向边界表明：身体书写强烈并不意味着自动归 TH3.1。

## 3. TH3.1 与 TH1.1

- “我是谁、我是否真实” → TH1.1。
- “身体/性别如何成为我被社会允许成为什么人的条件” → TH3.1。

《奥兰多》《紫色》可同时命中，但二者分析单位不同。

## 4. TH3.1 与 TH3.3

种族化身体会产生重叠：肤色、毛发、面貌既是身体经验，也是种族分类机制。

处理规则：
- 核心是身体被评价、审美化、羞耻化 → TH3.1 P2。
- 核心是种族群体边界、歧视、族群位置 → TH3.3。

因此《最蓝的眼睛》可作为 TH3.1↔TH3.3 的双向边界锚点。

## 5. TH3.1 与 TH5 / TH6

- 制度为何拥有权力、如何维持秩序 → TH5。
- 制度如何具体作用于身体并限制行动 → TH3.1 P5。
- 暴力、战争、创伤本身 → TH6。
- 暴力在身体上留下的后果如何改变身份与能动性 → TH3.1。

## 6. 是否需要第七问题

未发现稳定缺口。外貌/美貌已并入 P2；性别身份转换可由 P1/P2/P6覆盖；身体劳动可按 P4/P5处理，若核心是劳动制度则归 TH4。
