# 阅读路线

本路线不是“女性文学书单”，而是逐步建立一种分析能力：**从性别角色，进入身体赋义，再进入身体治理、交叉身体位置与主体重新占有。**

## 第一阶段：识别性别人生脚本

### 《玩偶之家》
训练问题：
- 妻子、母亲、丈夫分别被期待成什么样？
- 性别角色怎样与经济、法律和家庭资格连接？
- 娜拉的离开为什么不仅是“寻找自我”，也是退出一套性别化人生脚本？

目标：学会从“人物性格”转向“角色结构”。

## 第二阶段：区分身体经验与社会评价

### 《觉醒》 + 《金锁记》
比较：
- 女性身体如何在婚姻、生育、审美和家庭评价中获得社会意义；
- 人物自己的身体感受与家庭/社会对身体的解释哪里冲突；
- “身体自主”为什么同时涉及情感、经济和社会资格。

目标：学会使用三层模型：

```text
身体事实
→ 社会赋义
→ 身份与行动后果
```

## 第三阶段：理解生殖身体与制度治理

### 《使女的故事》
训练：
- 生殖能力怎样被重新定义为公共资源；
- 身体分类怎样决定岗位和社会身份；
- 宗教、法律、医学、家庭如何共同进入身体；
- 抵抗究竟争取的是抽象自由，还是具体身体决定权。

目标：建立 TH3.1 ↔ TH5 的边界。

## 第四阶段：理解身体拒绝、病理化与“正常”

### 《素食者》 + 《钟形罩》
比较：
- 当人物拒绝既定生活方式时，为什么身体会成为冲突场；
- 家庭或医学如何把偏离重新解释为疾病、异常或需要纠正；
- 身体照料什么时候转化为身体控制。

目标：理解“正常身体/正常人生”不是纯医学事实，也可能是社会规范。

## 第五阶段：进入交叉身体位置

### 《紫色》 + 《宠儿》 + 《最蓝的眼睛》
比较：
- 性别如何与种族、奴役历史、审美标准、暴力叠加；
- 同一个身体为什么会同时承担性别与种族意义；
- 如何避免把种族问题全部吸收到性别主题中。

目标：练习复合命中而不混淆主题职责：

```text
种族分类 → TH3.3
暴力创伤 → TH6
身体价值 / 身体所有权 / 身体自主 → TH3.1
```

## 第六阶段：打破“TH3.1 = 女性主题”

### 《奥兰多》 + 《变形记》
比较：
- 身体变化是否改变社会角色、资格与他人目光；
- 身体身份与主体连续性之间是什么关系；
- 非性别化身体在什么情况下仍可进入 TH3.1。

目标：确认本专题的真正中心是“身体如何成为社会身份与能动性的场所”，而不是人物性别本身。

## 第七阶段：高级比较——重新占有身体到底改变了什么

回看《玩偶之家》《觉醒》《素食者》《使女的故事》《奥兰多》，统一追问：

1. 主体拒绝了什么身体/性别解释？
2. 实际获得了哪些决定权？
3. 只是个人离开，还是关系和制度也改变？
4. 新的身体身份是否获得承认？
5. 作品把解放理解为独立、重新命名、重新使用身体，还是建立新的共同体？

## 最短阅读路线

若只保留六部：

```text
《玩偶之家》
→ 性别脚本
《觉醒》
→ 母职与身体自主
《使女的故事》
→ 生殖与制度治理
《素食者》
→ 身体拒绝与病理化
《紫色》
→ 交叉身体位置
《奥兰多》
→ 身体变化、性别流动与身份连续性
```

## 阅读时始终避免三种自动归类

- 女性主角 ≠ TH3.1；
- 疾病/身体受苦 ≠ TH3.1；
- 性欲或性关系突出 ≠ TH3.1，后者应优先检查 TH3.2 / TH2.1 / TH2.2。
