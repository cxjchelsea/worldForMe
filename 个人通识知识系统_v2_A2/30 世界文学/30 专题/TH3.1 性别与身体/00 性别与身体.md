# 性别与身体

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.1 性别与身体**

## 专题定位

本专题研究**性别化的社会位置与身体经验如何共同决定一个人能如何生活、被怎样观看、被允许做什么，以及主体能否重新定义自己的身体、性别角色与行动边界。**

TH3.1 的核心不是“作品里有女性/男性人物”，也不是“作品大量描写身体”，而是：**身体如何被赋予社会意义，并进一步改变人物的角色、资格、空间、资源、照料关系与被承认方式。**

纳入测试：如果拿掉作品中的性别角色、身体被观看/控制/限制/经验的方式，人物的社会位置、自由边界或被承认方式是否会发生根本变化？若不会，一般不作为本专题核心。

## L1｜定义与边界

见 [[10 结构/01 定义与边界|定义与边界]]。

最小判据：

```text
身体差异 / 性别位置
→ 被社会解释和赋值
→ 改变角色、资格、行动或承认
```

只有“身体存在”或“人物具有某种性别”不足以构成核心命中。

## L3｜统一作用机制

见 [[10 结构/03 身体与社会身份机制|身体与社会身份机制]]。

```text
身体特征 / 性别位置 / 身体能力
→ 社会目光、语言和规范对身体赋义
→ 家庭、医学、法律、宗教与制度放大这些意义
→ 形成性别脚本、正常性标准与身体资格
→ 改变空间、劳动、生育、照料、资源与被承认方式
→ 主体顺从、内化、协商、隐藏、拒绝或重新占有身体
→ 身体与性别秩序被再生产或重写
```

可以压缩为：

> **身体差异 → 社会赋义 → 规范化 → 资格与行动边界 → 主体回应 → 再生产或重写。**

## L4｜八组稳定张力

这些是专题内部比较维度，不新增坐标：

- 身体经验 ↔ 社会解释
- 自我感受 ↔ 他人凝视
- 身体自主 ↔ 身体控制
- 性别脚本 ↔ 个体生活选择
- 正常身体 ↔ 偏离身体
- 生育义务 ↔ 生殖自主
- 照料 / 依赖 ↔ 独立 / 能动性
- 身体被占有 ↔ 身体重新占有

## L5｜跨传统比较

见 [[10 结构/04 跨传统比较|跨传统比较]]。

比较的不是“哪里更父权”，而是：

1. 什么身体差异被社会赋予关键意义？
2. 谁规定合格的女性/男性/身体应当是什么？
3. 这种规范通过家庭、宗教、医学、法律、劳动或审美中的哪一种机制生效？
4. 身体差异具体改变了什么资格和生活机会？
5. 身体经验与社会解释在哪里发生冲突？
6. 主体能否重新命名、使用或占有自己的身体？

## 与相邻主题的边界

- **TH3.2 性、欲望与性规范**：性欲、性行为、性取向、禁忌与欲望合法性本身归 TH3.2；身体因性别角色、凝视、生育、医疗或制度控制而改变社会位置归 TH3.1。
- **TH3.3 种族与族群**：种族化身体可以兼标，但群体分类、种族边界与差别待遇本身归 TH3.3。
- **TH1.1 自我认同与主体性**：泛化的“我是谁”归 TH1.1；身体/性别如何成为社会承认与行动条件归 TH3.1。
- **TH2.2 婚姻与亲密关系**：关系内部权力与协商归 TH2.2；这些权力如何建立在性别分工和身体位置上可进入 TH3.1。
- **TH2.3 / TH2.4**：家庭与亲子结构本身归 TH2；母职、生育身体和照料义务如何改变身体自主归 TH3.1。
- **TH4 社会、阶级与劳动**：资源和劳动结构归 TH4；身体能力、性别身体如何改变可进入的劳动与资源位置时可复合进入 TH3.1。
- **TH5 权力、制度与秩序**：制度权力本身归 TH5；制度如何把规则落实到身体分类、检查、生殖、医疗和行动限制时进入 TH3.1。
- **TH6 战争、暴力与创伤**：具体伤害与创伤归 TH6；暴力如何通过身体改变身份、自由和被承认方式时进入 TH3.1。
