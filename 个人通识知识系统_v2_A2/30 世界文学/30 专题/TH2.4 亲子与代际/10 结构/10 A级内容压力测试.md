# A级内容压力测试

## 1. 测试目标

本轮不重新设计七问题，而是检验 TH2.4 是否已经具备 A 级解释力：

- 能否跨父子、父女、母子、母女、祖孙工作；
- 能否处理血缘、收养、替代照料、缺席父母与成年后的关系；
- 能否稳定区分 TH2.3 家庭系统、TH2.5 成长过程、TH1.1 主体性、TH7 记忆、TH6 创伤；
- 能否解释老年照料与角色逆转；
- 能否挡住“有父母子女就自动命中”的扩张。

| 《父与子》 | P2 / P3 / P4 / P7 | 价值冲突、情感依恋和分离并存，证明“世代冲突”必须落回具体关系。 |
| 《推销员之死》 | P2 / P3 / P4 / P7 | 检验父母未竟愿望如何变成子代压力，并区分期待与强制。 |

## 3. 边界与复合样本

| 作品 | 判断 | 边界理由 |
|---|---|---|
| 《杀死一只知更鸟》 | TH2.4 + TH2.5 | 父女关系的照料与价值示范属于 TH2.4；孩子认识社会和形成判断能力属于 TH2.5。 |
| 《小妇人》 | TH2.4 + TH2.5 | 母女关系重要，但成长本身也有独立结构，不能全部压到亲子关系。 |
| 《红楼梦》 | TH2.3 强，TH2.4 局部强 | 父子/母子期待明确，但更大的单位仍是家族系统。 |
| 《金锁记》 | TH2.3 + TH2.4 + TH3.1 | 家庭结构、母子控制和性别制度分别承担不同解释职责。 |
| 《孽子》 | TH2.4 + TH3.2 / TH1.1 | 父子逐出与疏离属于 TH2.4；性身份规范与主体身份另有独立问题。 |
| 《卡拉马佐夫兄弟》 | TH2.4 + TH8 / TH6 | 父子敌意与失职是亲子机制；罪责、暴力和伦理问题不能被 TH2.4 吞并。 |

## 4. 高风险负向样本

| 作品 | 不应自动命中 TH2.4 的原因 |
|---|---|
| 《简·爱》 | 原生家庭伤害和替代照料重要，但持续的亲子/代际关系不是作品主轴。 |
| 《傲慢与偏见》 | 父母与女儿存在，但核心更偏爱情、婚配与家族资源，不应因“有父母意见”自动命中。 |
| 《包法利夫人》 | 有母女与家庭背景，但作品主要分析婚姻不满、欲望与意义耗损。 |
| 《1984》 | 国家塑造青年和家庭关系，但核心是制度权力；不是亲子关系本身。 |
| 《老人与海》 | 老人与男孩有类亲子式情感，但不存在稳定的纵向亲属/替代照料结构，不应因年龄差自动归入。 |

## 5. 七问题复核

- **P1 独立**：关系建立不能被“有血缘”替代；收养、替代照料和缺席父母持续提供独立问题。
- **P2 / P3 分离**：父母希望孩子成为什么，与通过什么权威手段要求孩子服从，是两个层次。
- **P3 / P4 分离**：有权威冲突不代表孩子已经进入独立分离；低冲突关系同样可能面对放手问题。
- **P4 / TH2.5 分离**：TH2.4 问“成长怎样改变亲子关系”；TH2.5 问“孩子自身怎样成长”。
- **P5 / TH2.3 / TH7 分离**：具体上一代—下一代的传递归 TH2.4；家族网络归 TH2.3；记忆机制本身归 TH7。
- **P6 独立**：老去、疾病、失能让照料方向逆转，不能被一般“照料”或 P7“重新理解”替代。
- **P7 独立**：它容纳和解、无法修复、死后理解、维持距离与接受终结，不等于“最终和好”。

## 6. 关键防扩张规则

```text
有父母子女
≠ TH2.4

有家庭教育
≠ TH2.4

儿童受父母影响
≠ TH2.4

父母去世
≠ TH2.4

两代人价值观不同
≠ TH2.4
```

真正需要满足的是：**具体纵向亲属关系本身持续成为作品的解释对象，上一代与下一代怎样照料、期待、控制、分离、传递或重新理解彼此具有不可替代性。**

## 7. 与 TH2.3 / TH2.5 的最小判别

```text
这个家庭整体怎样分配资源、角色、家名和义务？
→ TH2.3

上一代与下一代怎样相互期待、依赖、控制、分离和重估？
→ TH2.4

孩子自身怎样学习、社会化、获得能力并成为成人？
→ TH2.5
```

同一作品可多标，但每个标签必须有独立问题和独立机制证据。

## 8. 第八问题与第二维测试

候选项包括“兄弟姐妹代际代理”“教师/导师替代父母”“生育决定”“成年子女赡养伦理”。检验后均可被现有问题或相邻主题吸收：

- 兄弟姐妹不是纵向代际关系，通常进入 TH2.3 家庭系统；
- 导师只有真正承担长期替代照料并被作品写成准亲子关系时，才可作为 P1 比较样本，无需新增问题；
- 生育决定本身优先 TH3.1 / TH2.2；孩子出生后关系建立才进入 TH2.4；
- 赡养伦理已由 P6 稳定承担。

因此没有第八问题，也没有统一第二内部维度。
