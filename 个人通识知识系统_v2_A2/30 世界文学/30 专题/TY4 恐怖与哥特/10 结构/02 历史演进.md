# 历史演进

```text
民间鬼故事 / 超自然母体
→ 18世纪 Gothic
→ 19世纪鬼故事、吸血鬼、科学怪物、双重人格
→ Weird Fiction
→ Lovecraft / Cosmic Horror
→ 20世纪中期心理与家庭恐怖
→ 1960—80年代现代 Horror 类型爆发
→ Literary / Social / Queer / Eco / Tech Horror
→ 全球本土恐怖传统复兴
```

历史变化的关键不是“怪物越来越多”，而是恐惧对象不断移动：从外部超自然，进入身体、心理、家庭、制度、殖民历史、媒介和生态。

`11 历史细分/` 保存八个稳定区块；这里负责解释变化逻辑，不把横向恐惧机制硬排成线性时间。
