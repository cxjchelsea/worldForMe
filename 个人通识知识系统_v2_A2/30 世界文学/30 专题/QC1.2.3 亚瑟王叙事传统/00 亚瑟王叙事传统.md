# 亚瑟王叙事传统

> QC1.2 第一个 `figure_tradition` 验证样板。这里研究的不是“亚瑟王完整故事”，而是**亚瑟如何成为一个不断吸附人物、故事和文本循环的叙事中心。**

## 一句话定位

```text
来源环境：QC1.1.4 凯尔特—不列颠传说传统
        ↓
中心人物：Arthur
        ↓
共享王廷／世界框架
        ↓
梅林、兰斯洛特、高文、圣杯骑士、特里斯坦、莫德雷德等人物／子传统
        ↓
多语言、多文类、跨时期重组
```

## 本专题的候选六层结构

```text
10 中心人物、边界与亚瑟王廷框架
11 早期亚瑟与编年史定型

```

它有意保留 10–15 六层外壳作为比较起点，但把原 `narrative_cycle` 的“核心叙事核／分支”改造成“中心人物／人物网络／子传统”，用于测试 figure_tradition 是否需要新的稳定职责。

## 当前核心作品锚点

| 作品 | 专题角色 |
|---|---|
| 《不列颠诸王史》 | 连贯亚瑟传记与编年史定型 |
| Wace《布鲁特传奇》 | 法语俗语化与圆桌早期见证 |
| 《兰斯洛特：大车骑士》 | 兰斯洛特子传统关键早期定型 |
| 《佩尔西瓦尔或圣杯故事》 | 佩尔西瓦尔／圣杯子传统关键起点 |
| 《亚瑟王之死》 | 晚期英语大型集成 |

大型循环与组合材料不强制伪装为单一作品：

- Lancelot-Grail / Vulgate Cycle → `cycle_witness`
- Post-Vulgate → `cycle_witness`
- Prose Tristan → `story_witness / cycle-linked witness`

## 当前人物／子传统网络

```text
Arthur
├─ Merlin
├─ Guinevere
├─ Lancelot
├─ Gawain
├─ Perceval / Galahad / Grail quest
├─ Tristan / Iseult
├─ Mordred
└─ Round Table / Camelot world framework
```

这里的连线表示“属于同一叙事网络／王廷框架”，不自动表示人物由某一文本首次创造，也不自动表示各子传统彼此直接派生。

子传统状态候选：

```text
embedded
semi_independent
independent_candidate
```

当前初步判断：Lancelot 为 `semi_independent`；Grail 与 Tristan–Iseult 为 `independent_candidate`。
