# 亚瑟王叙事传统

> QC1.2 第一个冻结的 `figure_tradition` 样板。这里研究的不是“亚瑟王完整故事”，而是**亚瑟如何成为一个不断吸附人物、故事和文本循环的叙事中心。**

## 一句话定位

```text
来源环境：QC1.1.4 凯尔特—不列颠传说传统
        ↓
中心人物：Arthur
        ↓
共享王廷／世界框架
        ↓
梅林、兰斯洛特、高文、圣杯骑士、特里斯坦、莫德雷德等人物／子传统
        ↓
多语言、多文类、跨时期重组
```

## 本专题冻结的六层结构

```text
10 中心人物、边界与亚瑟王廷框架
11 早期亚瑟与编年史定型
```

它与 `narrative_cycle` 共享 10–15 六层产品壳，但中层职责已经证明不同：人物网络、子传统自治和多层 witness 是 `figure_tradition` 的关键能力。

```text
│
├─ Estoire del Saint Graal
```

上层为 `cycle_witness`，五个组成文本为 `component_witness`。

## 当前人物／子传统网络

```text
Arthur
├─ Merlin
├─ Guinevere
├─ Lancelot
├─ Gawain
├─ Perceval / Galahad / Grail quest
├─ Tristan / Iseult
├─ Mordred
└─ Round Table / Camelot world framework
```

这里的连线表示“属于同一叙事网络／王廷框架”，不自动表示人物由某一文本首次创造，也不自动表示各子传统彼此直接派生。

子传统状态：

```text
embedded
semi_independent
independent_candidate
```

当前代表性判断：Lancelot 为 `semi_independent`；Grail 与 Tristan–Iseult 为 `independent_candidate`。
