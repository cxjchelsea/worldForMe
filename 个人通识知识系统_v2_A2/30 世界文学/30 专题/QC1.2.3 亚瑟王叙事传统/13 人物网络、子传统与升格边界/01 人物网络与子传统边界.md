# 人物网络与子传统边界

亚瑟传统最需要区别于 narrative_cycle 的，是“人物网络”。

## 1. 当前核心人物网络

| 人物／子传统 | 当前角色 | 是否立即独立 QC1.2 |
|---|---|---|
| Arthur | central_figure / 王廷合法性中心 | 本专题核心 |
| Merlin | 预言、王权建立、历史时间连接 | 否，先保留核心人物节点 |
| Guinevere | 王后、爱情／忠诚／王国危机接口 | 否 |
| Lancelot | 骑士典范、爱情冲突、王国瓦解关键人物 | 否，但强独立候选 |
| Gawain | 王廷亲族／骑士伦理、多文本人物 | 否 |
| Perceval | 圣杯求索早期核心人物 | 与圣杯子传统共同观察 |
| Galahad | 散文圣杯传统中的理想骑士 | 否 |
| Tristan | 被吸收到亚瑟世界的强独立故事传统 | HOLD；更适合未来独立 story_tradition |
| Mordred | 王国终结与内部背叛接口 | 否 |
| Holy Grail | 强 story_tradition + QC2 symbol/motif 接口 | 未来独立评估 |

## 2. 不能简单建“人物百科”

人物只有在能解释传统结构时才进入本层。重点不是生平资料，而是：
- 何时进入亚瑟文本世界；
- 在不同阶段承担什么功能；
- 与亚瑟中心的距离如何变化；
- 是否形成可脱离本专题独立追踪的传统生命。

## 3. 子传统的三种状态

```text
embedded
→ 主要依赖亚瑟王廷才能成立

semi_independent
→ 在亚瑟世界中高度发展，但已有独立谱系价值

independent_candidate
→ 即使脱离本专题，也能建立完整 QC1.2
```

当前可暂定：
- Merlin / Gawain：embedded → semi_independent 观察；
- Lancelot：semi_independent；
- Holy Grail：independent_candidate；
- Tristan-Iseult：independent_candidate。

## 4. figure_tradition 的新结论

传统同一性可以由“中心人物 + 共享世界 + 人物关系网络”维持，而不要求每个文本都讲同一套事件。这是本专题相对 QC1.2.1 / 1.2.2 最重要的新验证点。
