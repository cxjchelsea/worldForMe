# QC2 映射与阅读路线

## 1. 当前可稳定输出的 QC2 组件

- 正统王权与王权证明；
- 理想王国／共同体及其崩解；
- 骑士荣誉与忠诚冲突；
- 求索／试炼；
- 圣物与神圣目标；
- 禁忌爱情与忠诚冲突；
- 预言与命运；
- 内部背叛；
- 王之归来／未死之王；
- 圆桌／平等共同体的象征结构。

QC1.2.3 只记录这些组件在亚瑟传统中的具体历史形态；跨传统抽象仍由 QC2 负责。

## 2. 证据纪律

必须区分：

```text
明确文本改写／编纂
明确引用／借名
有研究支持的来源关系
共享亚瑟材料
人物／故事被吸收到亚瑟王廷
独立平行
弱结构相似
未知
```

人物在后期文本中共同出现，不代表其早期传统必然共同起源。

## 3. 推荐阅读路线

### 路线 A：理解亚瑟如何成为中心人物
1. 《不列颠诸王史》
2. Wace / Brut 相关材料
3. Chrétien de Troyes 代表 romance
4. Lancelot-Grail / Vulgate Cycle
5. 《亚瑟王之死》

### 路线 B：理解人物网络如何扩张
1. Arthur chronicle stage
2. Lancelot
3. Perceval / Grail
4. Merlin
5. Tristan integration
6. Malory synthesis

### 路线 C：从作品反查传统
遇到任何亚瑟相关作品时，先判断它主要调用：
- Arthur central figure；
- court/world framework；
- 某人物子传统；
- Grail / quest 等 QC2 component；
- 某一个明确早期文本。

不要只因为出现 Camelot、Excalibur 或 Round Table 就自动判定为历史上的直接改写关系。

## 4. 本专题的验收重点

coverage review 时重点检查：
- 中心人物模型是否真的比 chronology 更有效；
- figure_network 是否需要正式数据实体；
- subtradition 的升格门槛是否可执行；
- Works Base 是否足以表达“亚瑟不是主角但作品仍属于传统”；
- 是否需要独立的人物 Base。
