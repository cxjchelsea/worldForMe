# 符号化过程

## 1. 工作链

```text
《创世记》11 的城／塔／Babel 来源对象
→ 后世以 Babel / Tower of Babel 名称持续重述
→ 视觉艺术将高塔、集体施工、巨大城市工程稳定化为高辨识图像
→ Babel 名称可脱离完整来源故事继续使用
→ 文学与现代文化把它转用到语言、知识、沟通和总体化工程问题
→ 形成跨媒介文化 symbol
```

## 2. 不是“图像越像塔，符号性越强”

symbol continuity 主要依赖：

- 明确的 Babel 命名／来源引用；
- 可识别的来源关系；
- 稳定意义被保留或有证据可追踪地转化。

因此普通螺旋塔、未完建筑、巨型城市工程不能仅因外形像 Bruegel 的画就自动进入 Babel symbol network。

## 3. Bruegel 的位置

Pieter Bruegel the Elder 的《The Tower of Babel》(1563) 不是符号起源，而是重要的**视觉定型与再传播节点**：高塔、密集城市、集体建造工程获得高度可识别的图像形态，并在后世被大量复制和变奏。

## 4. Borges 的位置

《The Library of Babel》进一步证明 symbol 可以离开 literal tower：

```text
Tower / city
→ Library / universe

language fragmentation
→ signs / books / interpretation / information order

collective totalizing project
→ total library / total knowledge imagination
```

这种变化不是“同一个故事的直接改编”，而是明确借用 Babel 的文化名称和意义场进行语义转用。
