# 后世重写与跨媒介复用

## 1. Pass A 不追求作品大全

当前只选择能够验证“符号跨媒介”和“意义漂移”的代表节点。

## 2. 视觉艺术：Bruegel

Pieter Bruegel the Elder《The Tower of Babel》(1563)：

```text
来源故事中的 tower / city project
→ 巨型建筑、密集城市与持续施工的视觉化
→ Babel 成为可独立识别的视觉主题
```

它适合验证：

- source episode 可被视觉媒介重新组织；
- 视觉形象可以强化“宏大工程／未完成工程”意义；
- 后世不能反过来用 Bruegel 的塔形定义 Genesis 的原始物象。

## 3. 文学：Borges

Jorge Luis Borges《The Library of Babel》(1941)：

```text
Babel as tower/city
→ Babel as library/universe

language confusion
→ signs, books, interpretation

universal project
→ total knowledge / combinatorial totality
```

这是一种显著的 `meaning_shift`：Babel 的辨识不再依赖塔本身，而依赖命名和意义场。

## 4. Pass B 要继续测试什么

至少补一个与“绘画 + 文学”明显不同的媒介／公共语境实例，重点不是增加数量，而是检验：

- stable meanings 是否还能成立；
- 是否出现真正的 inverted meaning；
- `symbol_reuse` 与 `iconographic_inheritance` 是否需要拆分；
- work reference 是否需要 `symbolic_meaning / meaning_shift / evidence_medium` 专属字段。

## 5. 当前结论

cross-media reuse
= SUPPORTED_SO_FAR

semantic drift
= SUPPORTED_SO_FAR

full symbol acceptance
= NOT_YET
