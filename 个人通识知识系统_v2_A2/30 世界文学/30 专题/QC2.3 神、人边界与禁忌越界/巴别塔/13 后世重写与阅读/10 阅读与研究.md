# 阅读与研究

## 1. 最小阅读／观看路线

```text
《创世记》11:1–9
→ QC1.1.1 的巴别塔故事群
→ Bruegel《The Tower of Babel》(1563)
→ Borges《The Library of Babel》(1941)
```

阅读时持续追问：

- 当前材料是在重讲来源故事，还是已经在调用文化符号？
- Babel 名称／来源锚点是否还存在？
- 哪些意义被保留？
- 哪些意义是后世新增？
- literal tower 是否仍然必要？
- 当前关系是 `explicit_reference`、`symbol_reuse`，还是只有视觉／功能相似？

## 2. Pass A 模板反馈

### KEEP

- source object 与 symbol 分离；
- symbol 必须有跨文本／时代／媒介复用证据；
- `admission_evidence / stable_meanings / meaning_shifts`；
- 来源状态与 `qc2_source_reference`；
- work relation 原子性；
- 普通视觉相似不能自动升级为 symbol reuse。

### ADD CANDIDATE

symbol work reference 可能需要允许：

```yaml
symbolic_meaning: []
meaning_shift: []
evidence_medium: textual | visual | material | ritual | media
```

这些字段能比通用 `retained_features / modified_features` 更直接表达 symbol 的复用方式，但目前只由一个 Pilot 的两条后世记录支持，暂不冻结。

### REVISE

文化符号模板需要显式继承 Shared Data Layer，并把 `source_status / qc2_source_reference / qc2_work_reference` 写入完成判定。

### DEFER

- `iconographic_inheritance` 是否正式加入 relation vocabulary；
- symbol-specific work fields 是否升级；
- 一个新的不同媒介／公共语境实例；
- 正式 `qc2_component_relation`，等待有意义 target 准入。
