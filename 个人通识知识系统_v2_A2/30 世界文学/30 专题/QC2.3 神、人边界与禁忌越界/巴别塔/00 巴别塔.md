# 巴别塔｜symbol Pilot D

> **定位：**研究《创世记》11:1–9 中的巴别城／高塔如何从一个来源故事中的建筑与工程，逐步成为可脱离原情节、跨文本与跨媒介反复调用的文化符号。
>
> **Acceptance：**`ACCEPTED_REFERENCE_SYMBOL_V0`
>
> **Acceptance Review：**[[QC2｜Pilot D 巴别塔 Acceptance Review]]

## 1. source object 与 symbol

```text
QC1.1 source object / source episode
= 统一语言的人群建城与高塔，随后语言被变乱并发生分散

QC2 symbol
= “巴别塔／Babel”作为可复用文化符号，持续承载语言混乱、集体统一工程、文明野心、失败的总体化工程等意义
```

本专题不把“故事里有一座塔”直接等同于 symbol。准入依赖后世反复调用和稳定意义族。

## 2. 来源层最低事实

QC1.1.1 已正式建立“巴别塔：统一、越界与语言分散”故事群，其核心结构为：

```text
统一语言／共同工程
→ 建城与高塔
→ 神圣回应
→ 语言分散
→ 人群散布
```

来源层尤其强调“为自己立名”与“不致分散”的共同体工程。后世常见的“傲慢／hubris”解释可以研究，但不能倒灌成唯一的来源文本意义。

## 3. Pass A 的符号化证据

```text
《创世记》11:1–9
→ defining source episode

Pieter Bruegel the Elder《The Tower of Babel》(1563)
→ visual symbol reuse / iconographic stabilization

Jorge Luis Borges《The Library of Babel》(1941)
→ explicit named reference + semantic redeployment
```

Bruegel 证明“巴别塔”能够成为高度可识别的视觉形象；Borges 则证明 Babel 可以脱离 literal tower，进入语言、知识总体性与信息秩序问题。

## 4. Pass B｜跨媒介压力测试

新增：

```text
Alejandro González Iñárritu《Babel》(2006)
→ explicit_reference / documented
→ evidence_medium: media
→ literal tower absent
→ communication / incommunicability becomes the dominant modern emphasis
```

该实例把 Babel 直接用于现代电影标题与概念框架。建筑物象和建塔情节均不再承担识别功能，但“语言／沟通分裂”仍保持高度连续，因此进一步支持：

```text
symbol continuity
≠ literal object continuity
≠ visual-form continuity
```

它同时说明 `stable_meanings` 是整个 symbol network 中跨接受节点仍可识别的意义族，不要求每个后世实例同时承载全部意义。电影案例稳定支持 `language_confusion_and_fragmentation`；`communication_failure` 则作为该节点的现代语义重心记录为 `meaning_shift`。

本轮没有出现足够清楚的 inverted / contested meaning，新案例主要属于既有意义族的现代重新加权。

## 5. 当前稳定意义与漂移

### stable meanings｜工作层

- 语言混乱、沟通断裂与符号系统分裂；
- 集体性的人类统一／上升工程及其边界；
- 被中断、失败或不可完成的总体化工程。

### meaning shifts｜工作层

- 从建筑／城市工程转向知识总体性；
- 从语言分裂转向信息过载、不可判定与知识秩序；
- 从神学叙事转向现代文明、技术或制度工程隐喻；
- 在现代电影语境中进一步重心化为跨语言、跨文化与人际层面的 communication failure。

这些意义不是互相排斥的单一“标准答案”。

## 6. Pass B schema 决策

三组真实媒介记录现在分别为：

```text
Bruegel
→ evidence_medium: visual

Borges
→ evidence_medium: textual

Iñárritu, Babel (2006)
→ evidence_medium: media
```

在三种媒介中，以下字段均能提供独立于 `relation_type / retained_features / modified_features` 的解释价值：

```text
symbolic_meaning
meaning_shift
evidence_medium
```

因此：

```text
QC2_SYMBOL_WORK_MEANING_FIELDS
= ACTIVE_OPTIONAL_EXTENSION
```

`iconographic_inheritance` 不升级。现有证据足以证明 Bruegel 的视觉定型作用，但不足以仅凭视觉相似建立一条独立核证的后世图像继承链；因此继续禁止把 similarity 自动升级为 inheritance。

```text
QC2_ICONOGRAPHIC_INHERITANCE_RELATION
= NOT_PROMOTED / REQUIRES_DOCUMENTED_VISUAL_CHAIN
```
