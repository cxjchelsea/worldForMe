# 文本、视觉与媒介证据

## 1. 证据必须分层

symbol 允许跨文学、视觉艺术和其他媒介建立证据，但不同证据类型不能互相替代。

```text
textual source evidence
≠ visual reception evidence
≠ later literary reuse evidence
≠ material / ritual evidence
```

本 Pass A 不建立未经核证的 ritual_use 或 material_culture 记录。

## 2. textual source｜《创世记》11:1–9

作用：证明 Babel 来源对象和原始故事关系。

可确认的核心是统一语言、建城与塔、立名／避免分散、神圣介入、语言变乱与分散。

证据角色：`defining_source_text`。

## 3. visual witness｜Bruegel, The Tower of Babel (1563)

作用：证明 Babel 已成为可独立表现的视觉主题；巨大塔体、密集城市与集体施工被视觉化，并形成后世高度可识别的经典图像之一。

证据角色：`visual_reuse / iconographic_stabilization`。

治理：Bruegel 的具体建筑外观不能被倒写为 Genesis 的原始塔形。

## 4. later literary reuse｜Borges, The Library of Babel (1941)

作用：证明 Babel 可以在不出现 literal Tower of Babel 故事情节的情况下继续工作。Babel 名称被转入无尽图书馆、符号组合、知识总体性与信息秩序问题。

证据角色：`explicit_reference / semantic_redeployment`。

## 5. Pass A 的最低证据链

```text
source text
→ visual reuse
→ later literary semantic redeployment
```

这一链足以支持“巴别塔已经超出单一故事道具”的初步判定，但最终 Acceptance 仍需要 Pass B 检查更多复用形态和意义稳定性。
