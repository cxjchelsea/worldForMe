# Iñárritu《Babel》(2006)｜explicit_reference / media

该片把 `Babel` 直接置于标题，并在戛纳官方资料中明确以圣经 Babel 作为概念入口；影片跨摩洛哥、墨西哥、日本等空间组织彼此牵连的人物，并把重点落在语言、文化与关系中的“不沟通／无法互相理解”。

它适合作为 Pilot D Content Pass B 的非文学、非绘画压力测试，因为 literal tower 已完全退出，而 Babel 仍通过命名锚点与“语言／沟通断裂”意义族保持连续。

本记录因此使用 `explicit_reference`，而不是仅凭主题相似判定 `symbol_reuse`；同时首次以真实 `media` 记录测试 `symbolic_meaning / meaning_shift / evidence_medium` 三个候选字段。

该实例支持：

```text
stable meaning
→ language_confusion_and_fragmentation

meaning shift
→ communication_failure
```

它不提供 Bruegel 或其他具体 Babel 图像的视觉继承证据，因此不能用于推出 `iconographic_inheritance`。
