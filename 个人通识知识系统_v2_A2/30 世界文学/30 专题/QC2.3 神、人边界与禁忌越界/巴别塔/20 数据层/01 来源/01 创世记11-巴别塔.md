# 《创世记》11:1–9｜巴别塔来源记录

本记录只负责把 QC2 symbol 回指到 QC1.1.1 已正式索引的巴别塔故事群。

来源核心关系：

```text
统一语言／共同工程
→ 建城与高塔
→ 为自己立名／避免分散
→ 神圣回应
→ 语言变乱
→ 人群散布
```

不得把后世的知识总体性、现代技术工程或单一“傲慢”解释写入 source reference 作为原始文本事实。
