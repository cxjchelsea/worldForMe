# 与 QC2 的叙事组件映射

本页负责把 QC1.1.2 的具体来源材料映射到 QC2 的四类叙事组件。它不是独立的母题百科，也不在这里提前创建所有 QC2 实体。

核心原则：

> **QC1.1.2 保存“谁、什么故事、在哪些文本中”；QC2 保存“这个材料被抽象成什么可跨传统比较的叙事组件”。**

---

## 1. 映射格式

正式关系建议统一写成：

```text
来源对象
├─ source_story_group
├─ source_text_or_witness
├─ motif
├─ archetype
├─ plot_pattern
├─ symbol
├─ primary_qc2_cluster
└─ mapping_confidence
```

注意：四类组件不要求全部存在。不得为了填满字段强行制造 archetype 或 symbol。

---

## 2. 普罗米修斯故事群

### 来源层

主要来源入口：赫西俄德传统，以及后续希腊文学中的重写。

### QC2 映射

- `motif`
  - 神人边界
  - 禁忌越界
  - 文化馈赠／文明能力获得
  - 越界后的惩罚
- `archetype`
  - 抽象：文化英雄
  - 抽象：反叛者／越界者
  - 命名型：`Prometheus` 作为后世文化原型候选
- `plot_pattern`
  - 获取／夺取神圣资源 → 向人类转移 → 神圣秩序回应 → 长期惩罚
- `symbol`
  - 火
- `primary_qc2_cluster`
  - [[QC2.3 神、人边界与禁忌越界]]
- `secondary_cluster`
  - [[QC2.4 造物、创造与失控]]（仅在后世“Promethean creation”语境中条件关联）

### 治理提醒

普罗米修斯后世常与“创造者／人造生命”联结，但这不是所有早期希腊版本的核心内容。不能从《弗兰肯斯坦》的“The Modern Prometheus”反向覆盖早期来源层。

## 3. 《奥德赛》与奥德修斯故事群

### QC2 映射

- `motif`
  - 归乡
  - 漂泊
  - 身份隐藏与身份确认
  - 诱惑／停滞与继续旅程
  - 怪物／异域边界
- `archetype`
  - 抽象：智谋型英雄
  - 抽象：归乡英雄（候选，需要 QC2 判断是否有必要独立）
  - 命名型：`Odysseus / Ulysses` 文化原型候选
- `plot_pattern`
  - 战争结束／离乡 → 海上漂泊 → 多重试炼与诱惑 → 身份隐藏 → 返回家园 → 识别与秩序恢复
- `symbol`
  - 船／海路
  - 弓（身份确认与资格）
  - 家园／床等具体符号可后续按稳定性再判定
- `primary_qc2_cluster`
  - [[QC2.12 流浪、放逐与寻找家园]]
- `secondary_cluster`
  - [[QC2.6 英雄诞生、试炼与归乡]]
  - [[QC2.13 怪物、异类与文明边界]]

### 治理提醒

不要把《奥德赛》直接等同于所有“英雄之旅”。“离乡—试炼—归乡”可以作为比较结构，但不意味着后世所有此类故事都历史上来源于《奥德赛》。

## 5. 阿特柔斯家族／《俄瑞斯忒亚》故事群

- `symbol`
  - 血／宫殿等仅作候选，暂不自动 canonicalize
- `primary_qc2_cluster`
  - [[QC2.9 家族、血缘与代际冲突]]
- `secondary_cluster`
  - [[QC2.18 战争、围城、复仇与文明冲突]]

### 关键价值

这一故事群尤其适合展示：一个古老复仇母题如何在具体文学文本中被重新组织成关于制度、正义和共同体秩序的问题。

## 11. 一个来源对象如何多标签归属

以普罗米修斯为例：

```text
普罗米修斯（QC1.1 来源人物／故事群）
│
├─ motif
│  ├─ 禁忌越界
│  ├─ 文化馈赠
│  └─ 惩罚
│
├─ archetype
│  ├─ 文化英雄
│  └─ 反叛者
│
├─ plot_pattern
│  └─ 获取神圣资源 → 转交人类 → 惩罚
│
└─ symbol
   └─ 火
```

这就是 QC1.1 与 QC2 不需要重复建人物档案的原因：

- QC1.1 保存普罗米修斯属于哪套来源传统、在哪些文本中出现、版本如何变化；
- QC2 保存“文化英雄”“禁忌越界”“火”等跨传统组件以及后世如何继续调用它们。

## 12. 当前 Pilot 结论

QC1.1.2 已证明四类组件可以同时工作，但它们必须保持类型边界：

```text
故事内容 ≠ motif
人物 ≠ archetype
事件顺序 ≠ plot_pattern
道具 ≠ symbol
```

只有当来源材料表现出重复、稳定或后世高复用性时，才值得进入 QC2 canonical component 层。

下一步不是为这里每个词立即创建 QC2 实体，而是在更多 QC1.1 来源传统完成后，横向比较哪些组件真正值得成为 canonical node。
