# 支撑研究书目

本页保存“为什么这样理解这套传统”的现代研究入口，不与原典、定型文本或推荐原典混为一个书单。

## 1. 使用原则

支撑研究至少覆盖四种功能：

1. **来源与版本追踪**：帮助确认某个故事较早见于何处、有哪些文学与图像版本。
2. **神话与宗教语境**：帮助理解神话、祭祀、城邦、节庆与宗教实践之间的关系。
3. **文本与文学重写**：帮助理解史诗、悲剧、神话编纂与罗马文学如何重新组织传统材料。
4. **罗马传统与接受**：避免把罗马简单当成“希腊神话换名版”。

## 2. Pilot V1 核心研究入口

### Timothy Gantz, *Early Greek Myth: A Guide to Literary and Artistic Sources*

- 功能：来源追踪／版本比较／文学与图像见证工具书
- 用途：非常适合核查某个希腊神话人物或故事在哪些早期文学、艺术材料中出现，以及不同版本如何发展。
- 在本专题中的优先级：**核心工具书**

### Fritz Graf, *Greek Mythology: An Introduction*

- 功能：神话学导论／神话与诗歌、祭祀、戏剧关系
- 用途：帮助理解“神话不是固定故事百科，而是在不同历史与社会语境中被不断讲述和重组”的方法论。
- 在本专题中的优先级：**核心导读**

### Walter Burkert, *Greek Religion*

- 功能：古希腊宗教史／仪式与信仰语境
- 用途：为本专题的“历史文化环境”“口传、仪式与表演机制”提供宗教史支撑，避免只从文学文本反推实际宗教。
- 在本专题中的优先级：**核心背景书**

### Mary Beard, John North, Simon Price, *Religions of Rome*

- 功能：罗马宗教史／宗教制度与实践
- 用途：帮助区分罗马本土宗教制度、祭祀实践与对希腊文化材料的吸收，支撑“希腊 ≠ 罗马”的边界治理。
- 在本专题中的优先级：**罗马背景核心书**

### T. P. Wiseman, *The Myths of Rome*

- 功能：罗马神话与早期罗马叙事研究
- 用途：补足罗马建城、祖先、共和国早期故事等本土叙事维度，避免 QT8.1.2 被希腊材料完全占据。
- 在本专题中的优先级：**罗马神话专题入口**

## 3. 阅读顺序建议

若目标是搭建通识地图而不是做古典学专门研究，可按：

`Graf → Burkert（选读） → Gantz（按故事查） → Beard / North / Price（罗马部分） → Wiseman（罗马神话深化）`

Gantz 更适合作为持续查证工具，而不是要求从头通读。

## 4. 书目治理

后续新增研究书时至少标记：

- `research_role`：source_guide / religion_context / literary_reworking / roman_context / reception / methodology
- `scope`：Greek / Roman / Greco-Roman / comparative
- `use_for`：本专题具体服务哪些页面
- `evidence_level`：core / supporting / optional

不因为一本书“谈希腊神话”就自动列入核心书目；必须说明它解决本专题中的什么问题。
