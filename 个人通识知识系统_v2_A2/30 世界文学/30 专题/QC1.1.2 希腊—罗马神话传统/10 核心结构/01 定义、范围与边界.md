# 定义、范围与边界

## 核心问题

> 我们究竟把哪些材料视为“希腊—罗马神话传统”，为什么？

## 1. 一句话定位

“希腊—罗马神话传统”不是古代世界中一套统一、封闭、具有固定正典的神话体系，而是一个现代研究上的复合入口：它以古希腊多地域、多版本的神话—英雄—祭祀叙事为主要源层，并把罗马本土宗教与传说、对希腊神话的吸收、神祇对应、文学重写及后世拉丁传播纳入同一条“古典神话”谱系中考察。

因此，本专题研究的对象不是“所有希腊罗马宗教”，也不是“所有古典文学”，而是：

```text
叙事传统
+ 宗教／仪式语境
+ 英雄与地方传说
+ 史诗／戏剧／编纂中的保存与重写
+ 希腊 → 罗马 → 后世欧洲的文本传播
```

## 2. 为什么把希腊与罗马放在一起

### 2.1 可以合并研究的部分

希腊与罗马之间存在长期、可建立历史证据的文化接触。罗马作家大量使用希腊神话题材，并把许多希腊神祇、英雄和故事纳入拉丁文学；后世欧洲又往往通过拉丁文本、尤其奥维德等人的重述接触“古典神话”。

因此，从**文本传播与后世接受史**看，希腊—罗马确实构成一条强关联谱系。

### 2.2 必须拆开描述的部分

但不能反向假设：

> Jupiter = Zeus，所以罗马宗教就是换了名字的希腊宗教。

罗马拥有自己的国家祭祀、家族宗教、地方神祇、建城传说与政治宗教传统；希腊世界本身也没有一个中央教会、唯一圣典或完全统一的神谱版本。

所以本专题统一使用以下治理原则：

```text
希腊源层
→ 罗马吸收／对应／重写
→ 后世“古典神话”复合传统
```

而不是：

```text
希腊神话 = 罗马神话
```

## 3. 内容边界

### 3.1 核心纳入

- 创世、神代更替与奥林匹斯诸神相关叙事
- 英雄传说与英雄家族故事群
- 特洛伊战争及其前后叙事
- 归乡、远征、冥界、变形、诅咒等重要故事循环
- 与神话高度交织的史诗、抒情诗、悲剧与后期神话编纂
- 与具体城邦、圣所、节庆、祭祀有关且能解释叙事传播的宗教材料
- 罗马建城、祖先、王权等本土传说中与古典神话网络发生重要关系的部分
- 罗马文学对希腊材料的再组织、政治化与审美化重写

### 3.2 条件纳入

以下材料只有在能解释神话传统时才纳入：

- 历史书写
- 哲学文本
- 古代地理志与旅行记
- 图像、器物和考古材料
- 魔法、神谕与秘仪材料

它们不是因为“属于古希腊罗马”就自动进入本专题，而是因为能够补充某个故事、仪式、地方版本或传播机制。

### 3.3 不作为本专题主体

- 完整古希腊宗教史
- 完整罗马宗教史
- 全部希腊罗马文学史
- 纯历史人物传记
- 后世所有古典题材文学作品

这些内容只建立桥接，详细研究回到相应 T / R / M / G / QT 专题。

## 4. “神话、传说、宗教、文学”如何区分

本专题不强迫古代材料符合现代文类边界，但需要标记其功能差异。

| 对象 | 本专题中的工作定义 | 典型关注点 |
|---|---|---|
| 神话 myth | 涉及神祇、宇宙秩序、人神关系并具有传统权威的叙事 | 世界如何形成、神如何行动、秩序如何建立 |
| 英雄传说 heroic legend | 以英雄、家族、战争、远征、建城等为中心的传统叙事 | 英雄身份、地方记忆、家族谱系 |
| 宗教叙事 religious narrative | 与具体祭祀、圣所、节庆或仪式实践密切关联的故事 | 故事如何解释或支持实践 |
| 文学重写 literary rewriting | 作者在既有传统上进行有意识的选择、组合、反转和再创作 | 版本差异、作者意图、政治与审美重构 |

一个对象可以同时拥有多种属性，不要求单标签归属。

## 5. 时间边界：四种时间必须分开

研究神话最容易出现的错误，是把“现存文本年代”直接当成“故事起源年代”。本专题固定区分：

1. **传统形成期**：某一叙事可能已经在口传、祭祀或地方记忆中流通的时期；通常只能谨慎推断。
2. **早期文本见证期**：目前可以实际指向的较早书面证据。
3. **文学定型期**：某一版本因史诗、戏剧、编纂或文学名作而获得强影响力的时期。
4. **后世接受定型期**：现代读者熟悉的形象可能在罗马、中世纪、文艺复兴乃至近现代才进一步固化。

因此：

```text
故事存在时间
≠ 最早现存文本时间
≠ 某一经典版本创作时间
≠ 后世通行形象形成时间
```

## 6. 空间边界

“希腊世界”不等于现代希腊国界。本专题需要覆盖古代希腊语文化网络及其重要接触区，包括爱琴海诸岛、小亚细亚希腊城邦、南意大利和西西里等区域；罗马阶段则进一步进入意大利与地中海帝国网络。

因此空间组织优先依据：

```text
语言网络
+ 城邦／圣所网络
+ 殖民与迁徙
+ 海上交通
+ 帝国扩展
```

而不是现代国界。

## 7. 本专题与其他节点的边界

- **QT8.1**：保存来源传统、故事群及文本形成史。
- **QT8.2**：从本专题抽取 motif / archetype / plot_pattern / symbol，进行跨文明比较。
- **QT8.3**：当英雄／法外者等原型进入具体社会并形成成熟文化传统时，转入文化传统层。
- **G / QT 类型专题**：奇幻、冒险、战争等后世文类不在这里重复建设。
- **T / R / M**：文学史、地域文学史、思潮史只做桥接。

## 8. Pilot 判定

本专题采用“复合传统、分层描述”的方案：

> **合并研究传播链，拆开研究宗教与地方语境。**

这既保留“古典神话”作为后世文化共同资源的历史事实，又避免把希腊和罗马压扁成一套没有内部差异的神话百科。
