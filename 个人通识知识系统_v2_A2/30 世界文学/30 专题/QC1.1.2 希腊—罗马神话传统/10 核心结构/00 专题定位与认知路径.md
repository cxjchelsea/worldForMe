# 专题定位与认知路径

## 1. 这个专题研究什么

QC1.1.2 是一个 **QC1.1 来源传统专题**。它研究的对象不是“希腊神话人物大全”，也不是把后世常见神话故事整理成唯一版本，而是：

> **希腊—罗马神话叙事作为一组长期形成、保存、书写、改写与传播的共享叙事资源，是怎样获得历史生命的？**

本专题首先关心来源环境与传统内部结构，其次追踪故事群、文本见证、罗马重写和后世传播，最后把可复用的 motif / character type / named archetype / plot pattern / symbol 映射到 QC2。

## 2. 最小认知路径

阅读本专题时优先沿下列链条理解，而不是按神祇姓名逐项记忆：

```text
传统边界与形成环境
↓
世界观、神祇与人物系统
↓
核心叙事循环与故事群
↓
口传／仪式／表演与文本化
↓
早期见证、定型文本与罗马重写
↓
内部版本差异与文本谱系
↓
传播、借用与跨文化关系
↓
QC2 叙事组件映射
↓
后世接受、再创作与阅读路线
```

这条路径是专题的认知顺序，不要求现有文件夹按同样编号重新排列。物理目录继续保持稳定，由主页、Canvas 和结构 Base 负责把已有材料组织成这条路径。

## 3. 四个现有内容模块如何理解

| 现有模块 | 在 QC1.1 研究路径中的作用 |
|---|---|
| `10 核心结构` | 传统边界、历史文化环境、世界观、人物系统、故事群、口传与文本化等来源结构 |
| `11 内部文本与传统` | 早期文本见证、定型经典、关键重写与阅读入口 |
| `12 母题与跨文化关系` | QC2 组件映射、传播证据与结构相似的区分 |
| `13 后世传播与阅读` | 后世接受、跨轴桥接与实际阅读路线 |

因此，本次重构不把旧内容搬进一组新的 `10—20` 文件夹，而是在稳定路径上建立新的认知导航。

## 4. 与 QC1.2 的边界

QC1.1.2 负责回答：

> **希腊—罗马这一来源传统提供了哪些重要叙事资源，它们如何形成和保存？**

当某一个故事群已经值得独立追踪自身的跨文本生命史时，应进入 QC1.2，而不是继续无限扩写在本专题中。例如：

```text
希腊—罗马来源传统
→ 特洛伊故事群（本专题识别其位置与主要结构）
→ 若需独立追踪战争前因、史诗循环、悲剧重写、罗马继承与后世再创作
→ 升格为 QC1.2 候选专题
```

因此，[[05 核心叙事循环与故事群]]承担的是“识别与定位”，不是替代未来 QC1.2 的完整谱系研究。

## 5. 与 QC2 的边界

QC1.1.2 保存来源材料、文本见证和传统内部关系；QC2 保存从多个故事中抽象出来的可复用叙事组件。

例如：

```text
Prometheus 相关故事与古代文本见证 → QC1.1.2
“越界获取知识／技术”             → QC2 motif
“火”作为长期文化符号             → QC2 symbol（满足准入条件后）
Prometheus 作为命名文化模型       → QC2 named_archetype（满足准入条件后）
```

详见 [[../../12 母题与跨文化关系/00 叙事组件映射索引|QC2 叙事组件映射索引]]。

## 6. 与其他轴的分工

- **T**：希腊—罗马材料在世界文学时间史中的位置与时期变化；
- **R**：西亚—地中海及欧洲区域文学传统中的历史空间关系；
- **M**：这些材料在不同时期思想、美学与知识结构中的再解释；
- **QT**：史诗、悲剧等文类如何组织这些材料；
- **QH**：命运、权力、欲望、知识等抽象主题问题；
- **40 作品**：具体作品实体与作品级事实。

QC1.1.2 不复制这些轴的内容，只保存与“来源传统及其谱系”有关的接口。

## 7. 专题完成标准

本专题不以“收录全部神话故事”为完成标准。能够稳定回答以下问题，即具备成熟 QC1.1 专题的基本能力：

1. 这个来源传统的边界和形成环境是什么？
2. 它的世界结构、人物系统和高连接故事群是什么？
3. 口头、仪式、表演与书写如何共同参与传统保存？
4. 哪些文本是较早见证、关键定型或罗马重写？
5. 同一故事为什么存在多个版本，哪些差异具有解释价值？
6. 哪些跨文化联系有传播证据，哪些只是结构相似？
7. 哪些叙事组件应映射到 QC2，而不是继续堆在来源专题中？
8. 哪些故事群已经值得升格为 QC1.2 独立谱系专题？
9. 如何用最少阅读形成对这一传统的结构性理解？
