# 阅读路线

首轮作品压力测试使用 15 部作品：9 部骨架、5 部比较、1 部边界测试。路线围绕“意义如何建立、失效与被回应”组织，而不是按存在主义文学史排列。

## 第一层：最短骨架路线

1. **《悉达多》**：意义是继承答案、个人经验，还是自己生成？
2. **《恶心》**：既有意义失去必然性后，世界为何显得无根据？
3. **《等待戈多》**：世界不回应时，等待和重复如何耗损意义？
4. **《局外人》**：世界沉默是否必然等于虚无？
5. **《活着》**：意义来源不断被剥夺以后，为什么仍继续活？
6. **《老人与海》**：如果结果失败，行动本身还能否有意义？

这六部依次建立：

```text
意义来源
→ 既有意义崩塌
→ 世界无回应与重复
→ 荒诞意识
→ 苦难后的继续生活
→ 行动本身的价值
```

## 第二层：意义来源的不同答案

- **《浮士德》**：知识、经验、欲望与持续追求是否能构成值得活的生活？
- **《卡拉马佐夫兄弟》**：若世界包含不可接受的无辜受苦，宗教或伦理意义还能否成立？
- **《神曲》**：以一个“世界具有超越秩序”的文本反向校准现代荒诞模型。

比较重点：

> 意义是被发现、被继承、被体验、被创造，还是需要由超越秩序保证？

## 第三层：崩塌、重复与边缘案例

- **《城堡》**：目标始终存在却不可抵达，制度性延宕如何制造意义耗损？
- **《地下室手记》**：拒绝功利与理性预设，是否等于成功创造意义？
- **《人间失格》**：自我、关系与社会角色同时失效时，“活着的理由”如何瓦解？
- **《伊凡·伊里奇之死》**：死亡逼近怎样使职业、体面与成功突然失去意义？

## 第四层：无保证条件下的行动

- **《鼠疫》**：苦难没有终极解释时，照护、团结和反抗是否仍值得？
- **《活着》**：继续活着是否必须先获得一个宏大解释？
- **《老人与海》**：行动价值是否必须由成功证明？

这组专门压力测试 P7，防止“荒诞”自动滑向虚无主义。

## 边界测试

### 《1984》

制度可以制造、控制和摧毁人的意义框架，但作品不可替代的核心仍是权力如何生产现实与主体。因此它作为负向边界说明：

> **意义受到控制 ≠ 意义与荒诞就是作品的主问题。**

## 七问题覆盖

| 问题 | 主要压力作品 |
|---|---|
| P1 意义从何而来 | 《悉达多》《浮士德》《卡拉马佐夫兄弟》《神曲》《伊凡·伊里奇之死》 |
| P2 世界是否回应意义需求 | 《局外人》《恶心》《等待戈多》《城堡》《地下室手记》 |
| P3 既有意义何时崩塌 | 《恶心》《活着》《浮士德》《人间失格》《伊凡·伊里奇之死》 |
| P4 人能否自行创造意义 | 《恶心》《悉达多》《浮士德》《老人与海》《地下室手记》 |
| P5 重复、日常与劳动为何耗损意义 | 《等待戈多》《城堡》《地下室手记》 |
| P6 苦难、偶然与不公如何挑战意义 | 《活着》《卡拉马佐夫兄弟》《鼠疫》《神曲》 |
| P7 在无保证世界里为何仍继续 | 《局外人》《等待戈多》《活着》《老人与海》《鼠疫》《人间失格》 |

## 首轮结构判断

- P1 与 P4 暂不合并：前者追问意义来源，后者追问主体是否能主动赋义；《神曲》与《老人与海》几乎给出相反方向的答案。
- P2 与 P7 暂不合并：前者描述“世界不给保证”，后者追问“人怎样回应这种无保证”；《等待戈多》《鼠疫》尤其能区分二者。
- P5 虽覆盖最少，但《等待戈多》《城堡》《地下室手记》显示“重复/延宕/日常耗损”并不只是一般意义崩塌，而有稳定经验结构；冻结终审时应重点复核。
- P6 与 QH6/QH8 可保持边界：本专题不解释苦难如何发生，也不维护神学体系，只追问苦难是否使原有意义框架失效。
- 未出现必须新增的第八问题。
- 尚未出现需要升格为 `12` 层的稳定第二维。
