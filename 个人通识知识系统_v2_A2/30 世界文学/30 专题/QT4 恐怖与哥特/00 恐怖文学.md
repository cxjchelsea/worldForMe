# 恐怖文学

> 路径：世界文学 → Q轴 → QT 类型与叙事传统 → QT4 恐怖与哥特 → **恐怖文学**

## 专题定位

恐怖文学不是“让人害怕的故事”这么简单。它把无法被社会、家庭、身体或理性安全吸收的东西转化成叙事压力：

```text
鬼魂 / 诅咒 / 怪物
→ 身体边界与双重人格
→ 宇宙未知与理性失效
→ 家庭、心理与社会制度
→ 种族、性别、殖民、生态与技术恐惧
```

Gothic、Horror、Weird、Dark Fantasy 会重叠，但不能互相替代。

## 核心问题

> **什么东西使一个时代感到自身的边界正在失效，而文学如何把这种不安转化成鬼魂、怪物、身体、空间、心理或制度？**
