## 结论

`PASS`

QC1.2.2 的边界、核心见证、北欧—德语分支、人物变体、后世重构与 QC2 接口已经足以构成一个可用并可进入 stage freeze 的 QC1.2 专题。

1. 《蒂德雷克萨迦》已从“可选材料”提升为关键桥接／比较见证，并建立中央作品实体；

# 1. 核心边界检查

## PASS

当前专题没有退化为“齐格弗里德人物传”，也没有膨胀为“泛日耳曼英雄传说大全”。

保留的核心范围是：

1. 沃尔松家族背景；
2. 西格鲁德／齐格弗里德英雄成长与屠龙；
3. 宝藏及其诅咒／占有；
4. 布伦希尔德／布伦希尔特相关婚姻、身份错置与冲突；
5. 英雄死亡；
6. 古德伦／克里姆希尔德婚姻与复仇；
7. 勃艮第／尼伯龙根群体毁灭；
8. 后世对这一材料群的重组。

判断：边界稳定，可冻结。

# 3. 《蒂德雷克萨迦》的结构角色

## PASS

《蒂德雷克萨迦》的价值不是为了增加一部名作，而是填补模型中的桥接缺口。

它现在正式承担：

```text
bridge_witness / comparative_witness
```

使用规则：

- 不画成直接传承箭头；
- 不视为北欧与德语两大分支的简单混合版；
- 用于观察大陆英雄材料进入古诺斯文本环境后的重新组织；
- 与《尼伯龙根之歌》《沃尔松格萨迦》等比较时单独记录证据等级。

---

# 4. 分支模型检查

## PASS

QC1.2.2 证明 QC1.2 不能只有 chronology，还必须允许 branch。

本专题目前需要：

```text
传统整体
├─ 北欧文本分支
├─ 德语文本分支
├─ 跨文本比较见证
└─ 后世再生产
```

但 branch 不是 geography 的别名。它综合语言、文本环境、体裁、叙事组织方式、人物功能与价值结构。

因此未来 QC1.2 通用模型应保留 `branches` 能力，但不要求所有专题都必须有多个清晰语言分支。

---

# 5. 人物对应检查

## PASS

本专题已经证明“人物对应”不能简化成统一标准名。

推荐继续保持：

```text
传统中的人物功能位置
↙                 ↘
北欧文本人物       德语文本人物
```

而不是：

```text
Sigurðr = Siegfried
Guðrún = Kriemhild
Brynhildr = Brünhild
```

更准确的问题是：

- 两者是否属于可比较的共享人物传统？
- 哪些事件、关系和功能相同？
- 哪些发生重构？
- 哪些只存在于某一分支？

当前人物比较模型足够支撑专题，无需建立独立“人物百科”。

---

# 6. 事件对应是否需要独立数据层

## 当前结论：暂不需要

可以识别一条高复用事件链：

```text
英雄成长／屠龙
→ 宝藏
→ 婚姻与身份错置
→ 英雄死亡
→ 女性复仇
→ 勃艮第／尼伯龙根毁灭
```

但现阶段这些事件仍主要服务于：

1. 比较不同文本如何重组同一材料；
2. 向 QC2 抽象母题与结构组件。

因此当前放在 `13 人物对应与关键变体` 与 `15 QC2` 中即可。

只有未来多个 QC1.2 专题反复需要结构化事件对应时，才升级独立 `event_variant` 数据结构。
