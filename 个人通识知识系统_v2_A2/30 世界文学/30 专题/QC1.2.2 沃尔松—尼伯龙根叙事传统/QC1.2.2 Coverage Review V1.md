# QC1.2.2 Coverage Review V1

## 结论

`PASS_WITH_PATCH`

QC1.2.2 的边界、核心见证、北欧—德语分支、人物变体、后世重构与 QC2 接口已经足以构成一个可用的 QC1.2 专题；不需要继续以“材料越多越完整”为目标扩张。

但在进入 stage freeze 前，需要完成一个明确补丁：

> **把《蒂德雷克萨迦》（Þiðreks saga）从“可选材料”提升为关键桥接／比较见证。**

它的价值不在于证明一条简单的“德语 → 北欧”直接传承链，而在于它保存并重新组织了与尼伯龙根—沃尔松人物群相关的材料，可以帮助比较同一叙事资源在不同文本环境中的重构。

---

# 1. 核心边界检查

## PASS

当前专题没有退化为“齐格弗里德人物传”，也没有膨胀为“泛日耳曼英雄传说大全”。

保留的核心范围是：

1. 沃尔松家族背景；
2. 西格鲁德／齐格弗里德英雄成长与屠龙；
3. 宝藏及其诅咒／占有；
4. 布伦希尔德／布伦希尔特相关婚姻、身份错置与冲突；
5. 英雄死亡；
6. 古德伦／克里姆希尔德婚姻与复仇；
7. 勃艮第／尼伯龙根群体毁灭；
8. 后世对这一材料群的重组。

判断：边界稳定，可冻结。

# 2. 文本见证覆盖检查

## 当前核心见证

| 见证 | 当前角色 | 覆盖判断 |
|---|---|---|
| 《诗体埃达》相关英雄诗 | 北欧早期核心诗歌见证群 | 必要，已覆盖 |
| 《沃尔松格萨迦》 | 北欧连续叙事核心重述 | 必要，已覆盖 |
| 《散文埃达》相关材料 | 辅助编纂见证 | 必要但非主干，已覆盖 |
| 《尼伯龙根之歌》 | 德语分支核心定型 | 必要，已覆盖 |
| 《蒂德雷克萨迦》 | 跨语言／跨文本桥接与比较见证 | **应升级为关键见证** |
| 瓦格纳《尼伯龙根的指环》 | 近现代重大结构性重写 | 后世生命锚点，保留 |

## 为什么需要《蒂德雷克萨迦》

它不是为了增加一个“第五部名作”，而是填补目前模型中的结构性缺口：

```text
诗体埃达 / 沃尔松格萨迦
        ↘
       共享英雄材料的不同重组
        ↗
尼伯龙根之歌
```

当前结构能比较两端，却缺少一个能够显示“德语英雄材料在北欧文本环境中如何被再组织”的重要中间见证。《蒂德雷克萨迦》正适合承担这一认知角色。

因此：

- 不把它画成直接传承箭头；
- 不把它视为两大分支的简单混合版；
- 将其标记为 `bridge_witness / comparative_witness`；
- 当前无需为了它扩建新的物理目录。

判断：主要见证覆盖 `PASS_WITH_PATCH`。

# 3. 分支模型检查

## PASS

QC1.2.2 证明 QC1.2 不能只有 chronology，还必须允许 branch。

本专题至少需要：

```text
传统整体
├─ 北欧文本分支
├─ 德语文本分支
└─ 后世再生产
```

但 branch 不是 geography 的别名。它实际上综合了：

- 语言；
- 文本环境；
- 体裁；
- 叙事组织方式；
- 人物功能；
- 价值结构。

因此未来 QC1.2 通用模型中应保留 `branches`，但不预设所有专题一定存在两个或多个清晰语言分支。

---

# 4. 人物对应检查

## PASS

本专题已经证明“人物对应”不能简化成统一标准名。

推荐继续保持：

```text
传统中的人物功能位置
↙                 ↘
北欧文本人物       德语文本人物
```

而不是：

```text
Sigurðr = Siegfried
Guðrún = Kriemhild
Brynhildr = Brünhild
```

更准确的问题是：

- 两者是否属于可比较的共享人物传统？
- 哪些事件、关系和功能相同？
- 哪些发生重构？
- 哪些只存在于某一分支？

当前人物比较模型足够支撑专题，无需建立独立“人物百科”。

---

# 5. 事件对应是否需要独立数据层

## 当前结论：暂不需要

可以识别一条高复用事件链：

```text
英雄成长／屠龙
→ 宝藏
→ 婚姻与身份错置
→ 英雄死亡
→ 女性复仇
→ 勃艮第／尼伯龙根毁灭
```

但现阶段这些事件仍主要服务于：

1. 比较不同文本如何重组同一材料；
2. 向 QC2 抽象母题与结构组件。

因此当前放在 `13 人物对应与关键变体` 与 `15 QC2` 中即可。

只有未来出现以下情况才升级独立 `event_variant` 数据结构：

- 多个 QC1.2 专题都需要系统记录事件对应；
- 人物页无法承载事件版本差异；
- 检索经常要求“同一事件在不同文本中的版本”。

当前不提前建模。

# 6. 后世生命覆盖检查

## PASS_FOR_CURRENT_NEED

当前使用瓦格纳《尼伯龙根的指环》作为重大再生产锚点是合理的。

后续可按真实阅读需要加入 William Morris 等现代重写，但不需要为了“完整接受史”批量补作品。

这里的最低目标已经达到：证明 QC1.2 必须记录传统如何在新的文类、媒介、审美与政治语境中重新组合，而不是只做中世纪文本谱系。
