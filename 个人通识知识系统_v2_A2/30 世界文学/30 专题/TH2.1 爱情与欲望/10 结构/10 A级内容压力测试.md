# A级内容压力测试

## 一、测试目标

本轮不重开已冻结的七个核心问题，而检验 TH2.1 是否已经能够稳定解释不同传统中的爱欲关系，并与 TH2.2、TH2.3、TH3.2、TH1.1、TH1.3 等相邻主题保持可操作边界。

核心判据：

> **一个具体他者为什么成为欲望、依恋与价值中心；主体是否真正看见对方、是否得到回应，以及这种爱欲怎样在非对称、占有、社会阻碍、自我改变、时间与失去中被重构。**

## 二、统一机制压力测试

```text
具体他者进入注意与想象
→ 被赋予欲望、依恋或价值
→ 主体形成关于对方的认识 / 投射
→ 寻求回应、确认与相互性
→ 遭遇非对称、拒绝、社会阻碍或关系冲突
→ 发展为协商、占有、嫉妒、牺牲、越界或自我改变
→ 爱欲关系被实现、延宕、拒绝或失去
→ 时间、距离与记忆继续重构欲望对象
```

这条链不要求每部作品完整出现，但至少必须有“具体对象 + 爱欲关系机制”成为不可替代中心。

## 四、七问题复核

### P1 为什么会爱上某个人

稳定。它处理对象选择性，不等于一般欲望出现。

### P2 爱的是对方还是自己的想象

稳定。投射可以在对象已经确定后长期独立运作，无法并入 P1。

### P3 为什么常常不对称、求而不得

稳定。核心是相互性缺失，而不是控制欲本身。

### P4 为什么与占有、嫉妒和支配纠缠

稳定。关系已经存在或被想象为存在时，对唯一性、排他性与控制的要求具有独立解释力。

### P5 如何与身份、阶级、禁忌和社会规范冲突

稳定，但继续保持严格入口：必须是**外部结构正在阻断或重塑一段具体爱欲关系**。外部结构本身分别由 TH3/TH4/TH5 解释。

### P6 是否要求改变自己、牺牲自己或越过边界

稳定。只处理爱欲对主体自我边界提出的代价，不接收一般伦理牺牲或家庭义务。

### P7 如何因时间、距离、失去而转化

稳定。关键是欲望对象和爱欲本身被重构，不是长期共同生活本身。

## 五、兄弟节点边界

### TH2.1 ↔ TH2.2

```text
为什么偏偏是这个人？
我是否真正看见并欲望这个人？
我希望这个人如何回应？
→ TH2.1

关系建立以后怎样承诺、协商、共同生活、维持或破裂？
婚姻作为制度怎样组织双方？
→ TH2.2
```

**恋爱进入婚姻 ≠ 两个标签自动同时成立。** 只有作品同时持续分析“具体爱欲”与“长期关系运行”时才兼标。

### TH2.1 ↔ TH2.3

爱欲进入婚配、继承、家族联盟后，家族资源、血缘和结构本身 → TH2.3；具体两人的欲望与相互性 → TH2.1。

### TH2.1 ↔ TH3.2

```text
我欲望的是谁、是否得到回应？
→ TH2.1

这种欲望 / 性行为 / 性身份为何被允许或禁止？
同意与性规范怎样成立？
→ TH3.2
```

## 六、域外边界

- TH1.1：爱情改变自我不自动命中；只有“我是谁”被独立重构时兼标。
- TH1.3：求而不得不自动等于孤独；只有连接失败本身成为持续经验问题时兼标。
- TH4：阶级阻碍爱情可兼标，但阶级资源结构仍由 TH4 解释。
- TH5：法律、制度禁止关系时，制度机制归 TH5；具体爱欲遭遇阻断才归 TH2.1。
- TH8：宗教禁令、伦理责任可影响爱情，但信仰与善恶体系仍由 TH8 解释。
