# 爱情与欲望

> 路径：世界文学 → TH 主题与人类问题 → TH2 亲密关系、家庭与成长 → **TH2.1 爱情与欲望**

## 1. L1：专题定位与边界

本专题不是 Romance 类型小说史，也不把婚姻、性行为、失恋、家庭关系或情色描写自动视为“爱情与欲望”主题。

本专题真正研究的是：**为什么某个具体他者会成为主体欲望、依恋和价值的中心；主体是否真正看见对方、如何期待回应，以及这种爱欲怎样在相互性、投射、占有、社会阻碍、自我改变、时间和失去中改变双方。**

最小纳入测试：如果拿掉“为什么偏偏是这个人、我是否真正看见这个人、我希望这个人怎样回应，以及爱欲本身怎样被改变”之后，作品的主要冲突或意义结构是否仍基本成立？若仍成立，一般不作为 TH2.1 核心。

### 关键边界

```text
为什么偏偏是这个人？
我是否真正看见并欲望这个人？
我期待这个人怎样回应？
→ TH2.1

关系建立后怎样承诺、协商、共同生活、维持或破裂？
婚姻制度怎样组织双方？
→ TH2.2

这种性欲 / 性行为 / 性身份为什么被允许、禁止和命名？
→ TH3.2
```

因此：恋爱进入婚姻不自动兼标 TH2.2；有性描写也不自动进入 TH2.1。

## 3. L3：统一爱欲关系机制

```text
具体他者进入注意与想象
→ 被赋予欲望、依恋或价值
→ 主体认识 / 理想化 / 投射对方
→ 寻求回应、确认与相互性
→ 遭遇非对称、拒绝、社会阻碍或关系冲突
→ 协商、占有、嫉妒、牺牲、越界或自我改变
→ 爱欲关系被实现、延宕、拒绝或失去
→ 时间、距离与记忆继续重构欲望对象
```

机制详见 [[10 结构/03 爱欲关系与作用机制|爱欲关系与作用机制]]。

最重要的判断是：**欲望对象不是静态的。** 人既可能逐渐真正认识对方，也可能不断用想象、过去和自我需要重新制造“我所爱的那个人”。

## 4. L4：稳定结构张力

当前 A 级比较保留八组张力：

- 看见他者 ↔ 投射想象
- 相互性 ↔ 非对称
- 欲望 ↔ 承认
- 亲密 ↔ 占有
- 自主 ↔ 依赖
- 私人爱欲 ↔ 社会许可
- 自我保存 ↔ 自我改变 / 牺牲
- 关系现实 ↔ 时间、距离与记忆重构

这些张力是分析工具，不新增 `12` 层。

## 5. L5：跨时间、传统与形式比较

跨传统比较不问“哪个时代更自由恋爱”，而统一追问：

1. 什么使某个他者成为不可替代对象？
2. 爱被理解为选择、命运、义务、激情还是修养？
3. 主体能够怎样认识对方，哪些部分主要来自投射？
4. 什么算作回应、承诺与拒绝？
5. 谁拥有决定一段关系是否合法、可见、可持续的权力？
6. 爱要求主体改变多少，又在哪里必须保留自我边界？
7. 时间、距离、婚配、失去与死亡怎样重写欲望对象？
8. 不同文学形式怎样改变“爱的人”与“被爱的对象”之间的信息差？

详见 [[10 结构/04 跨时间、传统与形式比较|跨时间、传统与形式比较]]。
