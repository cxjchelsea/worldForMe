# 阅读路线

本专题的阅读目标不是“把所有身份相关作品读完”，而是用少量作品建立关于主体性的六种基本问题直觉。

第一版语料库由 **16 部作品**组成：10 部骨架、5 部比较、1 部边界测试。作品实体全部复用 `40 作品/`，本页只规定阅读功能，不复制作品数据。

### 骨架推荐顺序

若希望用最少阅读建立结构，先读：

1. 《堂吉诃德》——自我是发现还是创造；
2. 《地下室手记》——主体为何会自我欺骗并分裂；
3. 卡夫卡《变形记》——身体与角色怎样支撑人格连续；
4. 《红楼梦》——把“独立个人”从默认模型降为一种历史答案；
5. 《看不见的人》——社会身份怎样进入主体内部；
6. 《奥兰多》——把身体、性别、时间与连续性重新打开。

其余四部用于补强同一骨架中的不同路径。

## 第二层：比较阅读

| 作品 | 比较功能 |
| --- | --- |
| [[../../../40 作品/1984|1984]] | 与 QH5 比较：制度如何通过语言、记忆与监控改造主体。 |
| [[../../../40 作品/局外人|局外人]] | 与 QH1.5 / 存在主义比较：真实性是否等于拒绝社会情感表演。 |
| [[../../../40 作品/长日将尽|长日将尽]] | 与 QH7 比较：记忆如何维护职业人格，同时制造自我欺骗。 |
| [[../../../40 作品/午夜之子|午夜之子]] | 与 QH3/QH7 比较：个人自我、家族叙事与国家历史能否拆开。 |
| [[../../../40 作品/宠儿|宠儿]] | 与 QH7 比较：历史创伤如何进入身体、人格连续性与主体重建。 |

优先形成四组对照：

- **发现自我 vs 创造自我**：《红楼梦》/《堂吉诃德》；
- **内在真实性 vs 社会可识别性**：《地下室手记》/《局外人》/《人间失格》；
- **身体连续性 vs 流动主体**：卡夫卡《变形记》/《素食者》/《奥兰多》；
- **个人自我 vs 历史—社会位置**：《看不见的人》/《午夜之子》/《宠儿》。

## 第三层：边界测试

- [[../../../40 作品/瓦解|瓦解]]：暂列“边界测试”，而不是骨架。它用来检查共同体角色、殖民断裂和男性身份何时仍主要属于 QH3 / 历史专题，何时才真正成为个人主体危机。

如果后续阅读发现其主要意义仍然是殖民共同体与文化身份，而主体性只是结果，应保留多专题关联但将 QH1.1 优先级继续维持为 `△`；不要为了覆盖非洲文学而强行升格。

## 六问题覆盖检查

第一版语料库已经覆盖：

1. **自我如何形成**：红楼梦、看不见的人、奥兰多、午夜之子、瓦解；
2. **真实自我与自我欺骗**：堂吉诃德、哈姆雷特、地下室手记、罪与罚、人间失格、局外人、长日将尽；
3. **分裂、异化与失去自我**：地下室手记、罪与罚、变形记、人间失格、素食者、1984、宠儿；
4. **角色、面具与他者目光**：红楼梦、堂吉诃德、哈姆雷特、人间失格、看不见的人、长日将尽；
5. **记忆、身体与人格连续性**：变形记、素食者、奥兰多、1984、长日将尽、午夜之子、宠儿；
6. **自我重建与成为**：红楼梦、堂吉诃德、哈姆雷特、罪与罚、看不见的人、素食者、奥兰多、宠儿。

没有任何一个核心问题只依赖单一时代或单一文学传统。

## 继续扩展的门槛

第一版不再以数量为目标。新增作品至少应满足一项：

- 提供现有 16 部没有的新答案，而非重复已有主体危机；
- 补足当前明显不足的传统、文体或时代；
- 对某一专题边界形成真正压力；
- 证明一个横向机制已经稳定到值得建立 `12 机制与变体/`。

若只是“也谈身份/自我”，留在作品库的普通 Q 坐标即可，不进入本专题核心语料。
