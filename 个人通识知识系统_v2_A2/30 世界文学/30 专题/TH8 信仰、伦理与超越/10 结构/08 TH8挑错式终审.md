# TH8 挑错式终审

## 目标

主动寻找七问之间的重复、TH8 与相邻主题的污染，以及是否存在必须新增的第八问题。

## P1 与 P5 不合并

- P1：还能不能信？神圣如何被经验？
- P5：如果神/正义秩序成立，为什么无辜者仍受苦？

一个人可以坚定相信神却仍无法解释苦难，因此二者独立。

## P3 与 P4 不合并

- P3：行动之前/当下，我应当做什么？
- P4：越界之后，罪责怎样被承认、悔改、宽恕或救赎？

伦理判断和罪后修复属于不同阶段。

## P6 与 P7 不合并

- P6：终极秩序是否存在于死亡之后？
- P7：人在此生是否能通过慈悲、爱、牺牲、修行或神秘经验超越自我？

非来世型超越证明 P7 不能并入 P6。

## TH8 ↔ TH1.5

最危险的污染是把所有存在主义问题都塞进 TH8。

规则：
- “世界有没有意义？” → TH1.5。
- “一个有神/终极正义的世界为何允许恶？” → TH8 P5。
- “我能否自己创造意义？” → TH1.5。
- “救赎/神圣是否提供超越个人生命的意义？” → TH8。

## TH8 ↔ TH5

- 法律和制度认定什么是正义 → TH5。
- 良知为何要求人违抗法律 → TH8 P3。
- 宗教机构如何统治/处罚 → TH5。
- 信仰如何成为实践 → TH8 P2。

## TH8 ↔ TH6

- 具体暴力行为后的加害责任、幸存罪责、复仇 → TH6。
- 一般伦理/宗教意义上的罪、忏悔、宽恕、救赎 → TH8 P4。

## TH8 ↔ TH3.4

- 宗教作为族群、民族、文化身份 → TH3.4。
- 宗教作为关于神圣、终极真理和实践的信仰 → TH8。

## 是否需要第八问题

“宗教制度”“希望”“牺牲”“神圣/世俗”“解脱”均可由现有问题承接，没有形成一套独立且跨传统稳定的问题簇。

## 结论

```text
ADVERSARIAL_REVIEW = PASS
MERGE_REQUIRED = FALSE
EIGHTH_PROBLEM = NOT_JUSTIFIED
TH8.x_REQUIRED = FALSE
```
