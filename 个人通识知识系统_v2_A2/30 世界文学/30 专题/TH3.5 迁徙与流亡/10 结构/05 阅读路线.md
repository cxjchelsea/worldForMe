# 阅读路线

TH3.5 的阅读目标不是积累“移民文学”书单，而是逐步获得判断**位移怎样重组人的生活**的能力。

## 第一阶段：先理解为什么离开

建议作品：

- 《追风筝的人》
- *Exit West*
- 《愤怒的葡萄》

重点问题：

- 人为什么离开？
- 是主动追求机会，还是被战争、政治、贫困逼走？
- “选择离开”到底有多大自由？

这一阶段先建立 P1 / P2 的区别：

```text
为什么走
≠
能不能自由决定走
```

## 第二阶段：理解边境、身份与移动资格

建议作品：

- *Exit West*
- 《同情者》
- 《英国病人》

重点观察：

- 谁可以跨越边界？
- 谁必须等待、隐藏或证明自己？
- 到达以后是否拥有停留权？
- 身份资格怎样改变安全与未来规划？

目标：把迁徙理解成“移动权与停留权的分配”，而不只是地理运动。

## 第三阶段：理解离开怎样制造生活断裂

建议作品：

- 《移民》
- 《同名人》
- 《布鲁克林》

重点观察：

- 原来的职业、关系、语言环境和社会地位失去了多少？
- 人为什么在新地方需要重新学习生活？
- 同一个人在迁徙前后的社会价值为什么会改变？

目标：掌握 P3 的核心：

```text
空间变化
→ 资源、关系和制度连接发生断裂
```

## 第四阶段：理解“到达”为什么不等于“安顿”

建议作品：

- *Exit West*
- 《美国佬》
- 《布鲁克林》

重点观察：

- 工作、住房、证件和社会网络怎样重新建立？
- 临时身份为什么可能持续多年？
- 安顿需要哪些制度和社会资源？

目标：从“移民到哪儿”转向“怎样重新接入一个社会”。

## 第五阶段：理解迁徙如何重组家庭与代际

建议作品：

- 《喜福会》
- 《同名人》
- 《追风筝的人》

重点区分：

- 家庭冲突本身 → TH2.3；
- 迁徙让家庭跨国、分离、延迟团聚 → TH3.5；
- 第二代文化认同 → TH3.4。

这一阶段训练避免把“移民家庭”一次性全标到多个主题。

## 第六阶段：理解为什么回返不是回到原点

建议作品：

- 《美国佬》
- 《追风筝的人》
- 《故乡》（边界阅读）

重点问题：

- 人能否实际返回？
- 返回需要什么法律、经济和社会条件？
- 原地方、原关系和返回者本人是否已经改变？

这里要建立 TH3.5 / TH3.6 的稳定边界：

```text
能不能回去、如何回去 → TH3.5
回去以后这里还是不是“家” → TH3.6
```

## 第七阶段：理解迁徙可能没有终点

建议作品：

- 《移民》
- *Exit West*
- 《同情者》

重点观察：

- 一次迁移是否又引出下一次迁移？
- 人是否长期处于临时状态？
- 是否同时生活在多个地点和关系网络中？

目标：摆脱“原乡 → 新国家 → 定居”的单线模型。

## 第八阶段：用负向作品校准边界

建议对照：

- 《我的名字叫红》：跨文化接触强，但移动过程不是核心 → TH3.4 优先。
- 《看不见的人》：城市空间移动很多，但迁徙不是主要因果机制 → TH3.3 等优先。
- 《故乡》：返乡存在，但中心是地方陌生化与故乡感 → TH3.6 优先。
- 《奥德赛》：漫游和返乡极强，但需要具体判断其核心是否是长期迁徙生活结构，而不能因为“走了很多地方”自动标 TH3.5。

## 最小阅读记录模板

每读一部候选作品，可记录：

```text
离开原因：
自主程度：
移动/边境限制：
失去的生活连续性：
异地安顿方式：
跨地家庭/关系：
与原地的联系：
返回条件：
最终状态：定居 / 返回 / 再迁移 / 长期悬置
TH3.5 优先级：核心 / 次核心 / 邻界
```

## 完成标准

完成 TH3.5 阅读路线后，应能够稳定做到：

- 不把旅行当成迁徙主题；
- 不把“故事发生在国外”当成迁徙主题；
- 区分离开动机与移动自由；
- 看见边境、证件、停留权对人物生活的影响；
- 看见迁移造成的资源与关系断裂；
- 区分移民第二代的文化身份与第一代迁移经验；
- 区分“能否回去”和“哪里是家”；
- 理解迁徙可能是循环、跨地、长期悬置，而不是一次位移事件。
