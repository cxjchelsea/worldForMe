# 跨传统比较

## 一、比较原则

TH3.5 不能被缩减为“现代国际移民文学”。迁徙、流亡与离散在不同历史环境中可能由战争、帝国、殖民、劳工市场、宗教迫害、教育机会、家庭网络或国家边界共同塑造。

比较重点不是把人物按“移民 / 难民 / 流亡者 / 侨民”分类，而是用同一套过程问题比较不同移动结构：

```text
为什么离开？
谁拥有离开和停留的决定权？
跨越了什么边界？
失去了哪些连续性？
靠什么重新生活？
关系怎样跨地维持？
能否返回？
移动最终是否结束？
```

## 二、前现代放逐、流徙与侨居

现代护照和国境出现以前，流放、战争迁徙、宗教放逐、商旅侨居同样会改变人的生活结构。

重点观察：

- 谁拥有放逐与准许返回的权力；
- 距离如何切断政治、亲族与财产关系；
- 侨居者如何依赖商贸、宗教或族群网络；
- “回乡”是否由王权、战争或家族秩序决定。

不要用现代移民法概念强行解释所有前现代移动。

## 三、帝国与殖民迁移

帝国和殖民秩序会制造多种并不对称的流动：

- 殖民官员和军人移动；
- 契约劳工、奴役人口和被强制迁移者；
- 殖民教育带来的中心城市迁移；
- 港口、种植园、矿区和铁路造成的人口重组；
- 殖民边界改变原有移动路线。

统一追问：

```text
谁可以自由移动？
谁被运输、驱赶或限制？
谁能把移动转化为机会？
谁在移动中失去土地、家庭和身份保障？
```

与 TH3.7 的边界：殖民等级和自我理解归 TH3.7；殖民秩序如何具体制造迁移、驱逐和流动限制归 TH3.5。

## 四、战争、迫害与难民经验

战争、内战、种族清洗与政治迫害产生的移动往往具有高度被迫性。

重点比较：

- 离开是否突然发生；
- 是否存在安全通道；
- 难民营、临时住所和等待状态；
- 身份文件、庇护资格与被遣返风险；
- 家庭成员失散；
- 回返是否现实可能。

与 TH6 的边界：暴力和创伤本身归 TH6；暴力造成的逃亡、难民化和长期流徙归 TH3.5。

## 五、经济与劳工迁移

经济迁移不应被简单称为“完全自愿”。

需要比较：

- 土地、债务、失业和工资差异怎样推动离开；
- 招工制度和中介怎样控制移动；
- 临时劳工身份是否限制家庭团聚；
- 汇款怎样维持原地家庭；
- 劳动资格能否转化为长期居留；
- 迁移是一次性上升，还是循环性的谋生方式。

这里与 TH4 高度相交：TH4 分析劳动和阶级结构；TH3.5 分析这些结构为什么使“移动”成为生存策略。

## 六、教育、专业与主动迁移

留学、专业工作和职业迁移能检验 TH3.5 是否过度等同于苦难。

重点问题：

- 人是否真正拥有目的地选择；
- 学历和职业资格能否跨国转换；
- 暂时停留是否转化为长期定居；
- 家庭计划是否随职业流动改变；
- 返回是否仍是预期终点。

高资源迁徙依然属于 TH3.5，只要位移持续重组生活结构。

## 七、移民家庭与第二代

第一代与第二代必须区分。

### 第一代

通常直接经历：

```text
离开 → 移动 → 断裂 → 安顿 → 跨地联系
```

### 第二代

未必经历过迁徙本身。

因此第二代作品如果主要讨论语言、父母传统与双文化身份，优先 TH3.4；只有父母迁移造成的跨国家庭、返乡安排、身份制度和持续跨地生活仍然直接组织人物命运时，TH3.5 才继续强命中。

这条规则可以防止“移民家庭后代 = 永久 TH3.5”。

## 八、离散共同体与跨国生活

有些人物不再沿着“原乡 → 新国家 → 定居”单线移动，而是长期生活在多地网络中。

典型结构包括：

- 多次迁移；
- 双地家庭；
- 周期性返回；
- 跨国经营；
- 多国身份；
- 持续汇款和照料；
- 原地、新地同时构成生活中心。

此时 TH3.5 的问题不再是“最终属于哪里”，而是：

> **生活如何被持续组织在多个地点之间。**

“属于哪种文化”仍归 TH3.4，“哪里是家”仍归 TH3.6。

## 九、内部迁移与城市化

TH3.5 不要求必须跨国。

农村—城市、区域搬迁、强制安置、国内流亡等，只要位移显著改变：

- 户籍/资格；
- 劳动机会；
- 家庭结构；
- 社会网络；
- 回返条件；

同样可以成为 TH3.5 核心。

但城市中的普通走动、旅行或换住所并不足够。

## 十、环境与灾害迁移

环境灾害、海平面变化、干旱、洪水等可能迫使人口离开。

这里不需要建立新的坐标子类，而继续用同一机制判断：

```text
离开压力
→ 移动能力差异
→ 原生活断裂
→ 新地安顿
→ 关系与生计重组
→ 返回可能性
```

## 十一、固定横向比较表

| 比较维度 | 要问的问题 |
|---|---|
| 离开原因 | 战争、政治、经济、教育、家庭、环境还是混合压力？ |
| 自主程度 | 谁真正拥有选择？ |
| 移动制度 | 谁控制通道、证件、边境与停留？ |
| 断裂程度 | 财产、职业、关系、语言、资格失去多少？ |
| 安顿方式 | 靠工作、家庭、社群、国家还是临时救助？ |
| 跨地关系 | 汇款、通信、照料、探亲怎样维持？ |
| 时间结构 | 临时、长期、循环还是永久悬置？ |
| 返回条件 | 法律、资源、战争、时间变化允许返回吗？ |

这个比较框架用于连接不同历史与地域，不用于生成 `TH3.5.x`。
