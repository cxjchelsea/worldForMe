# A级内容压力测试

## 一、测试目标

本轮不再测试 TH3.5 是否应成为叶节点；V1 已经冻结。本轮测试的是：

1. 六个核心问题是否足以解释不同迁徙类型；
2. 统一机制是否不仅适用于现代跨国移民；
3. TH3.4 / TH3.6 / TH3.7 与 TH4 / TH5 / TH6 的边界是否可操作；
4. “旅行、异地背景、思乡、少数族裔身份”是否会被错误吸入 TH3.5；
5. 是否出现必须新增第七问或 `TH3.5.x` 的稳定证据。

## 二、统一检验模型

```text
离开压力 / 迁移动机
→ 行动自由与可移动性
→ 边境、证件与通道
→ 原生活连续性断裂
→ 异地生计、资格与安全重建
→ 家庭与关系跨地重组
→ 与原地持续联系 / 疏离
→ 回返、再次迁移或长期悬置
```

不是每部作品都必须覆盖全部阶段，但如果作品无法解释“位移如何改变人物生活结构”，TH3.5 通常不能作为核心。

## 四、六个核心问题复核

### P1 人为什么离开原有生活空间

稳定。战争、经济、教育、政治迫害、家庭与机会迁移均能落入。

### P2 自愿迁徙与被迫流亡如何改变行动自由

稳定，且不能与 P1 合并。

关键区别：

```text
为什么想走
≠
是否拥有决定走、去哪、留下和返回的能力
```

### P3 离开如何造成关系、财产与生活连续性的断裂

稳定。经济迁移、战争难民和长期流亡都能复用。

### P4 移民、难民与流亡者如何在异地生存

稳定。需要理解为“重新接入社会”，包括住房、劳动、资格、语言、网络和安全，不限于贫困移民。

### P5 跨国迁徙如何重组家庭、爱情与代际关系

稳定，但标题中的“跨国”在具体使用时应允许国内远距离迁移中的同构机制。坐标名称无需修改；内容层已经泛化到“跨地关系”。

与 TH2.3 的边界稳定：家庭本身归 TH2.3；移动迫使关系跨地重组归 P5。

### P6 人能否返回，又为何可能再也回不去

稳定，必须保留。

《美国佬》《追风筝的人》《移民》《故乡》对照证明：

```text
实际返回条件 → TH3.5
“这里还是不是家” → TH3.6
```

## 五、三类高风险误判

### 误判1：人物去了很多地方，所以是 TH3.5

错误。

旅行、冒险、差旅、游历只有在位移长期重组生计、资格、关系与返回条件时才稳定进入 TH3.5。

### 误判2：故事发生在异国，所以是 TH3.5

错误。

异国只是空间背景。必须存在“离开—移动—断裂—安顿/回返”的独立问题。

### 误判3：人物想念故乡，所以是 TH3.5

错误。

思乡、地方依附、返乡陌生化优先 TH3.6；TH3.5 只保留实际移动、安顿与返回条件。

## 六、与 TH3 兄弟节点的边界压力测试

| 问题 | 优先节点 |
|---|---|
| 被社会重新种族化、差别待遇 | TH3.3 |
| 迁移后如何处理双文化身份 | TH3.4 |
| 离开、边境、异地安顿、再次移动 | TH3.5 |
| 哪里是家、返乡后的地方归属 | TH3.6 |
| 殖民关系制造中心/边缘身份等级 | TH3.7 |

《美国佬》《同名人》《喜福会》证明多个节点可以兼标，但不能因为“移民背景”机械全命中。

## 七、与域外主题的边界压力测试

### TH4

《愤怒的葡萄》：

- 土地、贫困、劳动市场 → TH4；
- 因此发生的跨区域迁移、临时安顿、家庭移动 → TH3.5。

### TH5

边境、签证、难民制度如何被国家设计 → TH5；这些规则怎样限制人物移动和停留 → TH3.5。

### TH6

战争、迫害、暴力与创伤 → TH6；由此发生的逃亡、难民化、长期离散 → TH3.5。

### TH7

迁徙历史如何被记忆、讲述与代际继承 → TH7；迁徙过程本身 → TH3.5。

## 八、跨传统检验

本轮覆盖：

- 前现代漫游/放逐边界样本；
- 战争与政治流亡；
- 难民迁移；
- 经济与劳工迁移；
- 国内迁移；
- 第一代与第二代移民家庭；
- 跨国返回与持续迁移；
- 殖民/后殖民移动。

统一机制可以工作，没有发现只能由新的子坐标承接的稳定问题。

## 九、是否需要拆 TH3.5

不需要。

“移民 / 难民 / 流亡 / 离散 / 劳工迁移 / 教育迁移”等身份与原因差异虽然重要，但它们的文学解释仍然稳定共享：

```text
离开
→ 移动自由差异
→ 断裂
→ 安顿
→ 关系重组
→ 回返 / 再迁移
```

将其拆成多个坐标只会增加重复命中，真正的复杂度应继续由专题内部机制与比较维度承担。
