# 迁徙与流亡

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.5 迁徙与流亡**

## 专题定位

本专题研究**人为何离开原有生活空间，迁移、流亡、离散与跨境生活如何改变其安全、关系、身份与生活结构，以及离开之后能否返回或重新安顿**。

纳入测试：如果拿掉“离开、移动、跨境、流亡或长期异地生活”这一处境，作品的主要冲突是否会发生根本变化？若不会，一般不作为本专题核心。

## 为什么不继续拆坐标

V1 压力测试显示“移民 / 难民 / 流亡 / 离散”在文学中常通过同一条移动机制链发生：离开 → 边境与身份限制 → 生活断裂 → 异地安顿 → 关系重组 → 回返或继续迁移。若按身份类型拆成多个子坐标，同一作品会稳定重复命中。因此 TH3.5 保持叶节点。

## 关键边界

- **TH3.4 民族与文化身份**：迁徙以后“我属于哪种文化”归 TH3.4；离开、跨境与异地生活本身归 TH3.5。
- **TH3.6 故乡与归属**：对故乡的情感、家园感与地方归属归 TH3.6；是否能实际返回、返回受阻与返乡后的迁移处境归 TH3.5。
- **TH3.7 殖民身份**：殖民权力造成的移动与流放可兼标，但殖民者/被殖民者身份结构本身归 TH3.7。
- **TH2.3 家庭与家族**：家庭系统本身归 TH2.3；跨国移动如何拆散或重组家庭归 TH3.5。
- **TH6 战争、暴力与创伤**：战争和暴力本身归 TH6；战争导致逃亡、难民化和长期离散时进入 TH3.5。
