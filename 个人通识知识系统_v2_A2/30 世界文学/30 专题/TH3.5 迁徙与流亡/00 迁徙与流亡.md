# 迁徙与流亡

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.5 迁徙与流亡**

## 专题定位

本专题研究**人为何离开原有生活空间，移动、跨境、流亡、迁移与长期异地生活如何重组安全、身份资格、生计、家庭关系与生活连续性，以及人物能否返回、为何无法返回，或为何即使返回也无法恢复原来的生活。**

TH3.5 的核心不是“人物去过别的地方”，而是：

> **位移本身是否成为人物生活结构发生变化的因果机制。**

纳入测试：如果拿掉作品中的离开、移动、跨境、流亡或长期异地生活，作品的主要冲突是否会发生根本变化？若不会，一般不作为本专题核心。

## L1：定义与边界

见：[[10 结构/01 定义与边界|定义与边界]]。

三个最重要的排除规则：

1. **旅行不等于迁徙**：短期旅行、游历、冒险如果不改变生活结构，不构成 TH3.5 核心。
2. **异地背景不等于迁徙主题**：故事发生在海外、边境或异乡，不代表“移动过程”本身重要。
3. **思乡不等于迁徙主题**：如果核心是“哪里是家、为何想念故乡”，优先进入 TH3.6；TH3.5 关心的是离开、跨境、安顿与回返如何改变生活。

## L3：统一作用机制

见：[[10 结构/03 迁徙与流亡机制|迁徙与流亡机制]]。

TH3.5 的统一机制可以概括为：

```text
离开压力 / 迁移动机
→ 能否自主决定离开
→ 边境、证件与移动条件
→ 原生活连续性断裂
→ 异地生计、身份与安全重建
→ 家庭与关系跨地重组
→ 与原地持续联系 / 疏离
→ 回返、再次迁移或长期悬置
→ 迁徙成为新的生活结构
```

这个模型适用于经济迁移、教育迁移、政治流亡、战争难民、劳工迁移、帝国/殖民迁移与当代跨国生活，但不预设这些经验彼此相同。

## L4：八组稳定张力

1. **自愿 ↔ 被迫**
2. **可移动 ↔ 被困住**
3. **合法身份 ↔ 不稳定身份**
4. **离开 ↔ 留守**
5. **断裂 ↔ 连续联系**
6. **安顿 ↔ 临时性**
7. **返回 ↔ 无法返回**
8. **一次性迁移 ↔ 循环/持续迁移**

这些张力不是新的 TH3.5 子类，而是阅读不同迁徙作品时可重复使用的比较维度。

## L5：跨传统比较

见：[[10 结构/04 跨传统比较|跨传统比较]]。

固定比较问题：

- 为什么离开？
- 谁决定能不能走？
- 谁决定能不能留下？
- 移动后首先失去什么？
- 人靠什么在异地重新生活？
- 家庭与关系怎样跨地重组？
- 与原地怎样保持联系？
- 回返是否可能，又意味着什么？

## 与 TH3 兄弟节点的判别

```text
谁把我划入哪一群，并因此怎样对待我？ → TH3.3
我如何理解自己的文化共同体归属？     → TH3.4
离开、跨境、流亡本身改变了什么？     → TH3.5
哪里被经验为家？                     → TH3.6
殖民关系怎样制造身份等级？           → TH3.7
```

### TH3.4 ↔ TH3.5

- “迁移后我属于哪种文化” → TH3.4。
- “迁移本身怎样改变生活结构” → TH3.5。

### TH3.5 ↔ TH3.6

- “能否实际回去、回去受到什么限制” → TH3.5。
- “哪里仍然被经验为家、返乡为何陌生” → TH3.6。

### TH3.5 ↔ TH3.7

- 殖民驱逐、帝国迁移、殖民劳工流动中的“移动过程” → TH3.5。
- 殖民者/被殖民者、中心/边缘身份等级 → TH3.7。

## 与域外主题的接口

- **TH2.3 家庭与家族**：家庭结构本身归 TH2.3；迁徙如何拆散或重组家庭归 TH3.5。
- **TH4 社会、阶级与劳动**：贫困、就业和阶级位置归 TH4；这些压力导致迁移时可兼标 TH3.5。
- **TH5 权力、制度与秩序**：签证、边境、驱逐、身份资格和难民制度的制度运行归 TH5；这些制度如何规定迁徙者能否移动与安顿时 TH3.5 保留迁移经验一侧。
- **TH6 战争、暴力与创伤**：战争、迫害和暴力归 TH6；它们造成逃亡、难民化和长期离散时进入 TH3.5。
- **TH7 历史、记忆与时间**：迁徙史如何被记忆和继承归 TH7；移动经验本身归 TH3.5。

## 为什么不继续拆坐标

V1 与 A 级压力测试均显示，“移民 / 难民 / 流亡 / 离散 / 劳工迁移 / 循环迁移”虽然制度位置不同，却稳定共享同一条过程链：

```text
离开 → 移动受限 → 生活断裂 → 异地安顿 → 关系重组 → 回返/继续迁移
```

如果按身份类型继续拆成 `TH3.5.x`，大量作品会重复命中，而且分析收益主要来自过程机制而不是身份分类，因此不拆。
