# 经验尺度与作用机制

TH1.1 的中心不是假设每个人体内都存在一个等待被发现的“真我”，而是研究：**主体如何把经历、身体、记忆、关系、角色与行动组织成一个能够被自己承认为“我”的结构，以及这个结构怎样在冲突中维持、断裂或重建。**

## 一、统一机制

```text
经验 / 身体 / 记忆 / 关系 / 社会角色
→ 感知、命名与自我叙述
→ 他者目光、角色期待与现实行动进行外部检验
→ 一致 / 冲突 / 否认 / 断裂
→ 表演、自欺、反思、选择、离开或重新叙述
→ 人格连续性维持、瓦解或重建
```

抽象模型：

> **自我材料 → 自我解释 → 外部检验 → 冲突/断裂 → 主体回应 → 连续性/重构。**

## 二、五个经验尺度

这些尺度不是发展阶段，而是可以同时作用、相互矛盾的来源。

### 1. 内在感受与欲望

主体首先可能通过情绪、欲望、感知和反思产生“这才像我 / 这不像我”的判断。但内在感受并不自动等于真实自我；主体也可能误解、否认或浪漫化自己的欲望。

### 2. 身体与感知

身体提供经验连续的重要锚点，但身体改变并不必然使人格消失。文学常通过变形、疾病、衰老、性别变化等逼问：

> 身体变了以后，什么仍使“我”保持为我？

身体的社会位置本身优先归 TH3.1；只有当它进一步逼迫主体回答人格连续性问题时，才进入 TH1.1。

### 3. 记忆与自我叙述

主体把过去组织成故事，从而产生连续性：

```text
过去经验
→ 被选择、解释与排列
→ 形成“我是怎样成为现在这个人的”叙述
→ 支持或破坏当前自我
```

因此记忆不是纯粹档案；错误记忆、选择性遗忘和重新叙述同样能够维持人格。公共记忆与历史版本归 TH7，本专题只处理记忆怎样成为人格连续性的条件。

### 4. 他者目光与关系承认

主体并不能完全脱离他者形成：姓名、关系角色、赞许、羞耻、排斥和承认都会成为自我材料。

但：

> **被别人认作什么 ≠ 我只能成为什么。**

这正是 TH1.1 与 TH3 的接口：TH3 研究社会如何定位主体；TH1.1 研究主体怎样接受、拒绝或重新解释这种定位。

### 5. 角色、行动与社会世界

人通过子女、伴侣、职业、阶级、国民等角色行动。角色并不天然虚假：稳定角色也可以成为人格组成部分。真正的主体危机通常发生在：

```text
角色要求
≠
主体能够承认的自我
```

## 三、六类作用机制

### 1. 自我形成：继承、模仿与试验

自我很少凭空生成。主体通常先继承家庭、语言、价值、角色和社会评价，再通过模仿、试错、冲突与选择逐渐形成自我理解。

### 2. 自我叙述：把碎片变成“我的人生”

主体通过回忆、解释、命名和因果化把彼此分散的经历编入一个故事。文学可以揭示：这种故事既是自我形成的必要条件，也可能成为自我欺骗的工具。

### 3. 承认与角色表演

主体需要一定程度的他者承认，却也可能为了获得承认而持续扮演并不属于自己的角色。要区分：

- 社会角色是否只是工具；
- 角色是否已经被主体内化；
- 人物是否知道自己在表演；
- 去掉角色后是否还有可识别的自我。

### 4. 分裂、异化与失去自我

当行动、身体、语言、职业或角色长期被主体体验为“不属于我”，会产生异化。更严重时，不同自我叙述无法整合：

```text
我认为自己是谁
≠
我实际做了什么
≠
别人认为我是谁
≠
我希望自己成为谁
```

这时主体可能进入否认、自我憎恶、双重生活、人格断裂或无力行动。

### 5. 自我欺骗：主动维持无法成立的自我

自我欺骗不是单纯“不知道真相”，而常是主体借叙述、习惯、角色和选择性记忆维持一个已经受到现实反证的自我版本。

因此需要问：

> 人物不知道，还是某种程度上知道却拒绝知道？

### 6. 主体重建：不是找回原来的自己

自我重建通常不是恢复一个从未改变的“本真自我”，而是重新组织材料：

```text
承认断裂
→ 重新解释过去
→ 承担某些行动与责任
→ 放弃无法维持的角色
→ 形成新的关系和行动方式
→ 建立新的自我连续性
```

所以“成为自己”既可能是发现，也可能是创造。

## 四、八组稳定张力

1. **发现自我 ↔ 创造自我**：自我是已有本质，还是在行动与叙述中被建立？
2. **内在感受 ↔ 他者承认**：仅仅自我确信是否足够成为某种主体？
3. **真实 ↔ 表演**：角色和面具何时遮蔽自我，何时本就是自我的组成部分？
4. **连续性 ↔ 断裂**：身体、记忆和价值发生变化后，凭什么仍说是同一个人？
5. **多重角色 ↔ 自我整合**：多重身份不必导致分裂，关键在能否被主体共同承认。
6. **自我认识 ↔ 自我欺骗**：内省既能揭示自己，也可能生产更复杂的辩护。
7. **被定义 ↔ 自我命名**：外部命名如何进入自我，又如何被重新解释？
8. **继承既有自我 ↔ 重新成为**：人物能否摆脱由过去、家庭和角色给定的版本？

## 五、判定模板

分析一部作品时至少问：

1. 人物用什么材料理解“我是谁”？
2. 这个自我版本主要来自继承、他者承认还是自主创造？
3. 哪些现实经验开始反驳它？
4. 人物如何处理自我叙述与现实之间的矛盾？
5. 身体、记忆、角色和行动中，什么维持人格连续？
6. 人物最终是在维持、失去，还是重新建立自我？

如果作品只有明确的社会身份冲突、爱情关系、行动选择或意义危机，却没有形成上述“自我解释—检验—连续性/重构”结构，就不应把 TH1.1 当作默认标签。
