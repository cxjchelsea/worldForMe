# TH1.1 A级内容压力测试

## 一、测试目标

本轮不再检验“TH1.1 是否应该存在”，而检验它是否已经具备 A 级知识地图要求：

1. 六个核心问题能否覆盖跨时代、跨传统、跨形式作品；
2. “主体性”是否能被统一机制解释，而不是一个泛化的“身份”兜底词；
3. 与 TH1.2 / TH1.5 / TH2.5 / TH3 / TH5 / TH7 的边界能否执行；
4. 是否出现需要新增第七问题或继续拆 `TH1.1.x` 的结构证据。

## 二、统一机制待检验模型

```text
经验 / 身体 / 记忆 / 关系 / 社会角色
→ 主体感知、命名并形成自我叙述
→ 他者承认、现实行动和角色要求进行检验
→ 一致 / 冲突 / 否认 / 断裂
→ 表演、自欺、反思、选择或重新叙述
→ 人格连续性维持、瓦解或重建
```

## 三、核心与扩展作品压力

### 1. 《堂吉诃德》——核心

- 自我并非单纯被发现，而通过阅读、命名、服饰、行动和叙述主动制造。
- 他者不承认并不能立即消灭这一自我版本。
- 强命中 P1 / P2 / P4 / P6。

**测试价值**：证明“创造自我”不能被排除在主体性之外。

### 2. 《红楼梦》——核心

- 个体自我与家族、礼法、情感关系交织。
- “成为自己”并不简单等于脱离关系网络。
- 强命中 P1 / P4 / P6。

**测试价值**：阻止 TH1.1 把现代西方独立个人主义设为唯一成熟主体模型。

### 3. 《哈姆雷特》——核心/复合

- 角色义务、内省、行动和自我理解互相冲突。
- 与 TH1.2 相邻，但主体问题在于“这些冲突使我成为谁”。

### 4. 《地下室手记》——核心

- 过度自觉不产生透明自我，反而制造自我否定、反讽和行动瘫痪。
- 强命中 P2 / P3 / P4。

**测试价值**：证明“自我认识”与“自我欺骗”必须保持张力。

### 5. 《罪与罚》——核心/复合

- 人物以观念建立特殊自我，现实行动与罪责随后击穿这一版本。
- 重建不是简单恢复旧自我，而需要承认现实和责任。

### 6. 《变形记》——核心/复合

- 身体发生极端变化，但记忆、自我感和关系连续性最初仍存在。
- 家庭和劳动角色的丧失逐步改变主体的位置。

**边界**：身体社会赋义归 TH3.1；“身体变了我还是不是我”归 TH1.1。

### 7. 《人间失格》——核心

- 面具与迎合最初用于获得社会承认，最终成为主体无法确认自身的机制。
- 强命中 P2 / P3 / P4。

### 8. 《看不见的人》——核心/复合

- 外部种族分类不断向主体提供互相冲突的自我模板。
- 人物必须在他者定义与自我命名之间重新组织自身。

**边界**：种族化机制归 TH3.3；分类如何进入“我是谁”归 TH1.1。

### 9. 《素食者》——核心/复合

- 身体拒绝既可被读作自主，也可表现为主体与社会/身体关系的极端断裂。
- 强迫我们避免把“反抗规范”自动等同于“主体性增强”。

### 10. 《奥兰多》——核心

- 身体、性别和历史时间不断变化，叙事仍维持人格连续。
- 强命中 P1 / P5 / P6。

**测试价值**：证明人格连续性不应被等同于身体不变。

### 11. 《长日将尽》——核心比较

- 记忆不断维护“忠诚管家”的人格叙述，又逐步暴露其自我欺骗。
- 强命中 P2 / P4 / P5。

**边界**：记忆公共化与历史版本归 TH7；记忆怎样维持人格归 TH1.1。

### 12. 《宠儿》——核心比较

- 极端暴力与创伤破坏身体、记忆、关系和人格连续。
- 主体重建必须把无法被安置的过去重新纳入自身。

**边界**：暴力/创伤本身归 TH6，记忆传递归 TH7，自我连续性与重建归 TH1.1。

### 13. 《午夜之子》——核心比较

- 个体生命被家庭与国家历史不断叙事化。
- 个人自我并非历史之外的纯私人核心。

**边界**：文化身份归 TH3.4，历史叙事归 TH7；两者如何构成主体自我叙述才进入 TH1.1。

## 四、强边界反例

### 14. 《1984》——复合但非纯主体性作品

国家以语言、记忆和监控重塑主体，可进入 TH1.1；但制度为何有这种能力、如何运行，仍主要归 TH5。

**结论**：主体被改造 ≠ TH1.1 可以吞掉制度主题。

### 15. 《局外人》——邻界

默尔索拒绝社会期待的情感表演，涉及真实性；但作品更强的问题是世界、意义、荒诞和社会判断。

**结论**：表现“做真实的自己” ≠ 自动以 TH1.1 为核心；需判断作品中心究竟在“我是谁”还是“世界有没有意义”。

### 16. 《瓦解》——邻界/复合

共同体、男性角色和殖民冲突确实冲击奥孔科沃的自我，但作品的大量核心结构仍属于 TH3.4 / TH3.7。

**结论**：角色或文化身份危机只有进入主体自我连续性时才兼标 TH1.1。

### 17. 《玩偶之家》——边界校准

诺拉离开既定妻职可被解释为主体重建，但作品同时强命中 TH2.2 / TH3.1 / TH1.2。

**结论**：“离开社会角色”不是 TH1.1 的充分条件；关键是作品是否持续追问主体如何重新定义自己。

### 18. 《霍乱时期的爱情》——非核心

人物有长期自我叙述与人生选择，但作品中心仍是爱情对象、等待与关系历史。

**结论**：人物有个性、有内心、有长期人生 ≠ TH1.1。

### 19. 《愤怒的葡萄》——非核心/局部

迁徙、贫困、劳动和家庭解体会改变人物自我，但作品更稳定的结构是 TH4 / TH3.5。

**结论**：处境改变人物 ≠ 必须把主体性升为核心主题。

### 20. 《百年孤独》——非核心/局部

人物身份与家族重复、记忆和历史循环相连，但整部作品更稳定地落在家族、历史记忆、孤独等问题上。

**结论**：复杂人物谱系不自动等于主体性主题。

## 五、三类高风险误判

### 误判 1：只要人物“寻找自我”就标 TH1.1

“寻找自我”是过宽描述。必须出现稳定的自我解释、真实性、角色冲突、人格连续或重构问题。

### 误判 2：所有社会身份冲突最终都可以归主体性

如果这样处理，TH1.1 会重新吞掉 TH3。治理规则：

```text
社会怎样给人物定位
→ TH3

人物怎样把这些定位组织进“我是谁”
→ TH1.1
```

只有第二层成为独立核心时才兼标。

### 误判 3：反抗角色或规范 = 成为真实自我

作品可能展示失败、瓦解、逃避、自欺或新的角色依附。TH1.1 不预设“反抗 = 主体解放”。

## 七、是否需要继续拆坐标

不需要。

“真实性”“异化”“人格连续”“自我重建”等虽然都可成为庞大哲学专题，但在作品坐标层，它们高度交叉于同一主体问题：

> **主体怎样形成一个可被自己承认、能够跨经验与变化维持或重建的‘我’？**

继续拆 `TH1.1.x` 会使同一批核心作品稳定重复命中，降低坐标辨识度。复杂度应由机制、张力和作品比较组承担。
