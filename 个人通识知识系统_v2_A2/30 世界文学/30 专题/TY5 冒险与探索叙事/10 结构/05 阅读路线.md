# 阅读路线

第一轮不要追求把所有海岛、丛林、极地、少年冒险都读一遍，而要建立七步演变：

Quest → 航海 → Robinsonade → 19世纪历史/Frontier → 科学与Lost World → 反帝国/反Adventure → 当代生态与类型融合。

## 三轮阅读

- **第一轮：核心骨架 ★** —— 看见冒险如何从探索/征服世界转向质疑冒险者的解释权。
- **第二轮：系统扩展 ◆** —— 选择 Sea、Survival、Treasure、Lost World、Frontier、Polar 等结构补全横轴。
- **第三轮：批评对读** —— 用 Empire / Masculinity / Companionship / Return / Anti-Adventure 等问题重读经典。
