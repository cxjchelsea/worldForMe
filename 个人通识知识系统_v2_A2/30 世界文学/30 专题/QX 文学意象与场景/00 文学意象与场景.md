# 文学意象与场景

> QX 的日常阅读入口。作品级事实只维护在 `40 作品` 的 `qx` YAML；这里负责把这些事实渲染成可浏览、可比较的文学意象知识。

## 一句话定位

```text
20 节点：QX 是什么、边界与规则是什么
30 专题：如何浏览、比较和研究跨作品意象
40 作品：某部作品实际上有哪些意象（唯一事实源 + 自动生成可读视图）
```

总说明与当前有效规则：[[../../20 节点/Q 主题/QX 意象/QX 文学意象与场景]]。

## 三种主要进入方式

### 1. 看一部作品有哪些意象

→ [[05 作品意象一览|作品 → 意象]]

按作品列出主导、核心和显著意象。点击作品名后，作品页正文会直接出现自动生成的 **“文学意象”** 区，包括：

- 意象对象；
- 所属 QX 分类；
- 显著性；
- 具体表现；
- 叙事功能；
- 文本依据；
- 已激活时的跨作品专题链接。

### 2. 看一个意象出现在哪些作品

→ [[04 意象关系索引|意象 → 作品]]

先按 20 个一级类浏览，再按具体意象聚合作品。相同对象会汇总到一行，并显示作品数、作品、最高强度、常见功能以及对应的已激活专题。

> 当前 04 仍按作品 YAML 中的原始 `object` 字符串聚合；未来完成 object normalization 后，同义 / 近义对象会进一步合并。

### 3. 看整个 QX 关系网络

→ [[01 文学意象与场景.canvas]]

用于观察 QX 总体结构、作品入口和已激活专题。

## 自动生成机制

```text
40作品/qx YAML
      ↓
scripts/_qx_index_build.py
      ↓
├─ 作品正文「文学意象」区
├─ 04 意象 → 作品
└─ 05 作品 → 意象
```

GitHub Actions 会在作品 `qx` 或已激活专题发生变化时自动刷新这些视图。

因此以后只需要维护：

```text
作品事实 → 40作品 YAML
跨作品解释 → QX x.x 专题
```

不要手工编辑作品页中的 `QX:GENERATED` 区块，也不要手工维护 04 / 05。
