# QX Pilot｜五部经典作品意象试标

> 本文件用于检验 `QX_RELATION_SCHEMA = DRAFT_V1.1` 是否适合真实作品标注。
>
> 本轮不限制每部作品的意象数量，只保留**明确、可解释、有作品内证据、值得未来跨作品比较**的对象。
>
> 除已经存在的 `QX1.1 文学中的雨` 外，其余对象暂按候选意象记录，不伪造 QX 叶节点编号。

---

## 00｜Pilot 目标

本轮选择五部差异较大的已读经典：

| 作品 | 主要测试价值 |
|---|---|
| 《百年孤独》 | 高密度、重复型、世界状态型、家族与历史型意象 |
| 《红楼梦》 | 极高密度、器物—空间—植物—梦境—社会仪式复合网络 |
| 《1984》 | 权力装置、私人空间、身体恐惧与制度性物件 |
| 《基督山伯爵》 | 情节驱动、空间转换、身份转换、财富与复仇物件 |
| 《第一炉香》 | 都市感官、服饰、宅邸、香气、社交场景与欲望空间 |

本轮重点检查：

1. `salience` 是否够用；
2. `function` 是否覆盖真实文学功能；
3. `meaning` 是否会失控；
4. `mode` 是否提供额外信息；
5. `phase / scope / evidence` 是否值得长期保存；
6. 是否需要新增关系字段；
7. 不限制数量后是否会明显产生标签膨胀。

### 01.2 初步判断

《百年孤独》验证了：

- `dominant` 有存在必要，但应极少使用；
- `mode` 对“反复制作的小金鱼”“长期降雨”“最终解读羊皮卷”区分明显；
- `phase` 对时代分段型小说有很高价值；
- `scope` 可以区分“人物绑定”与“整个世界状态”；
- 同一作品超过 5 个明确意象并不会自动造成噪声。

### 02.2 初步判断

《红楼梦》证明：

- 不设数量上限是必要的；如果强行限制为 5 个，会丢失大量彼此独立的有效信息；
- `scope` 非常有用：玉绑定宝玉，泪绑定宝黛关系，大观园作用于整个人物共同体；
- 某些对象天然跨 QX 一级类，应坚持“主归属 + 交叉连接”；
- “大观园”提醒我们 QX 不应只收狭义物象，也应收具有稳定感知边界和文学功能的空间对象。

### 03.2 初步判断

《1984》证明：

- `function = 权力标识` 很重要，应保留；
- 器物与空间往往共同构成制度环境；
- `transformative` 非常有价值：镇纸和楼上房间的意义都因结局发生反转；
- QX 能很好地区分“抽象主题：权力 / 监控”和“具体承载物：电幕 / 海报 / 房间”。

| **服饰 / 化装 / 身份外观** | QX14 服饰与身体装饰 | core | 身份标识；遮蔽；人物塑造；情节推动 | 多重身份；表演；社会可塑性 | recurrent；character_bound；transformative | 伯爵复仇阶段；唐泰斯多重身份 | 唐泰斯以不同身份、外观和社会角色进入不同关系网络，使复仇依赖“被看见为什么人”的可控性 |

### 04.2 初步判断

《基督山伯爵》证明：

- QX 不只适合“象征性强”的文学，也适合情节型小说；
- 同一对象可以同时承担现实机制和象征意义，如宝藏首先是复仇资源，其次才是财富 / 命运象征；
- `singular_pivotal` 对裹尸袋这种“一次出现但决定整部作品”的意象非常必要；
- `phase` 对“囚徒 → 伯爵”这种身份分期明显的作品很有价值。

### 05.2 初步判断

《第一炉香》证明：

- 感官性对象（香气）可以成为真正的 QX 核心节点，QX 不应只收视觉物象；
- `function = 身份标识 / 权力标识 / 关系映射` 对都市婚恋与阶层小说非常有用；
- “服饰”可能过粗，未来若跨作品材料足够，可再研究是否拆出“衣橱 / 华服 / 首饰”等子对象；
- 社交场景完全值得纳入 QX，只要它具有可感知、可重复比较的场景结构，而不是抽象“社会关系”。

# 06｜跨五部作品的 Schema 检验

## 06.1 salience

当前三级：

```text
significant
core
dominant
```

**结论：暂时够用。**

五部作品中均能自然区分：

- `significant`：有明确功能但非作品识别核心；
- `core`：重要解释入口；
- `dominant`：几乎组织作品的一整条意义网络。

暂不建议增加第四级。

---

## 06.2 function

当前词表总体覆盖良好。

本轮高频项：

```text
空间塑造
人物塑造
关系映射
世界状态
身份标识
权力标识
情节推动
情节转折
结构标记
伏笔 / 预示
主题承载
象征强化
边界 / 阈限
```

**结论：function 结构有效。**

暂未发现必须新增的新一级功能词。

---

## 06.3 meaning

本轮 meaning 差异很大：

- 雨 → 衰败 / 停滞 / 历史断裂
- 玉 → 命 / 身份 / 情缘 / 真与假
- 电幕 → 监控 / 权力 / 私人空间消失
- 宝藏 → 财富 / 能力 / 复仇资源
- 香 → 欲望 / 沉溺 / 短暂迷醉

**结论：meaning 必须继续保持开放词表。**

不适合强行枚举，但应在未来做同义词归并。

---

## 06.4 mode

本轮证明以下 mode 都有真实区分价值：

- `recurrent`
- `climactic`
- `character_bound`
- `relation_bound`
- `spatial_bound`
- `period_bound`
- `transformative`
- `contrastive`
- `ritualized`
- `singular_pivotal`

**结论：mode 建议保留。**

尤其 `singular_pivotal` 很重要：它避免“必须反复出现才算意象”的误区。

---

## 06.5 phase

五部作品均出现有效使用：

- 《百年孤独》：早期马孔多 / 香蕉公司阶段 / 后期衰败；
- 《红楼梦》：大观园繁盛期 / 抄检后；
- 《1984》：私人反抗期 / 审讯期；
- 《基督山伯爵》：囚徒阶段 / 伯爵阶段；
- 《第一炉香》：进入梁宅前后。

**结论：保留，但允许自然语言，不做严格枚举。**

---

## 06.6 scope

scope 在本轮区分出：

```text
人物
人物关系
家族
宅邸 / 空间
城镇
社会制度
整个世界
```

**结论：有明显价值。**

同一“意象重要”可能作用尺度完全不同，scope 可以防止这种差异丢失。

---

## 06.7 evidence

本轮所有有效标注都能以“关键场景 / 重复事件 / 结构呼应”给出证据。

**结论：evidence 应继续作为正式关系的强烈建议字段。**

不要求逐字引用原文，但至少应能让未来复核者定位“为什么这么标”。

# 07｜Pilot 暴露出的一个新问题：是否需要 manifestation 字段

本轮出现一个反复问题：

QX 节点可能叫“雨”，但作品中的具体形态并不只是“雨”：

```text
《百年孤独》：持续多年的长雨
其他作品可能是：暴雨 / 细雨 / 雷雨 / 雨夜
```

同样：

```text
“服饰”
→ 华服 / 制服 / 婚纱 / 丧服

“花”
→ 落花 / 海棠 / 菊 / 玫瑰
```

这些具体形态：

- 不一定值得拆成独立 QX 节点；
- 但只记录 `object = 雨 / 花 / 服饰` 又会损失信息。

因此 Pilot 建议新增一个**候选字段**：

```yaml
manifestation:
```

定义：

> **该 QX 对象在当前作品中的具体可感知形态。**

例如：

```yaml
object: 雨
manifestation: 持续数年的连绵暴雨
```

```yaml
object: 花
manifestation: 落花 / 葬花场景中的花瓣
```

```yaml
object: 服饰
manifestation: 梁太太为薇龙准备的华服与衣橱
```

### 当前状态

```text
manifestation = CANDIDATE_FIELD
```

暂不立即写入冻结 schema，建议再用若干作品验证。

# 08｜数量规则检验

本轮每部作品记录数量：

| 作品 | 明确 QX 关系数 |
|---|---:|
| 《百年孤独》 | 8 |
| 《红楼梦》 | 11 |
| 《1984》 | 9 |
| 《基督山伯爵》 | 9 |
| 《第一炉香》 | 8 |

这不是为了凑数量，而是按“明确 / 有功能 / 有证据”筛选后的自然结果。

结果说明：

> **固定 0–5 或 5–8 上限不适合 QX。**

《红楼梦》明显需要比一般作品更多关系，而《第一炉香》虽然篇幅短，仍有多个高度集中的感官与社会意象。

因此当前数量治理继续采用：

```text
QUANTITY_CAP = NONE
QUALITY_GATE = REQUIRED
```

# 09｜五部作品之间已经出现的跨作品关系

Pilot 还没有建立正式跨作品模式，但已经能看到一些值得未来追踪的连接。

## 09.1 空间作为暂时世界

```text
《红楼梦》：大观园
《1984》：楼上房间
《第一炉香》：梁宅
《基督山伯爵》：基督山岛
```

它们并不“象征同一件事”，但都说明：

> 空间可以形成独立于外界规则的临时生活秩序，并在作品中承担关系重组功能。

这可能成为未来 QX7 的跨作品比较模式。

## 09.2 器物作为身份核心

```text
《红楼梦》：通灵宝玉
《1984》：日记 / 镇纸
《基督山伯爵》：宝藏 / 钻石
《第一炉香》：华服 / 首饰
```

共同点不是意义相同，而是：

> 具体物件参与“人物是谁、能成为谁、别人如何看他 / 她”的身份构造。

## 09.3 封闭空间 → 人物转换

```text
伊夫堡 → 唐泰斯成为基督山伯爵
楼上房间 / 101室 → 温斯顿的私人自我建立并被摧毁
大观园 → 青春共同体形成并解体
梁宅 → 薇龙的身份和欲望结构改变
```

这说明未来作品距离分析可以不依赖“共有同一个物象”，而比较：

```text
QX 一级类别
+ function
+ meaning
+ mode
+ scope
```
