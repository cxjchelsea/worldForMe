# QX Pilot｜第二批五部作品意象试标

> 本文件继续检验 `QX_RELATION_SCHEMA = DRAFT_V1.1`，重点压力测试：感官与体感、自然—科技复合空间、QX/QH/QC 边界、整体意象网络、碎片化叙事中的一次性强意象。
>
> 本轮继续执行：**不设数量上限；只记录明确、可解释、有作品内证据、值得未来跨作品比较的对象。**
>
> 除已经存在的正式 QX 叶节点外，其余对象保持候选状态，不伪造编号。

---

## 00｜Pilot 目标

| 作品 | 主要测试价值 |
|---|---|
| 《局外人》 | 阳光、热、海、汗、身体感受直接参与叙事，测试感官/体感和 manifestation |
| 《海底两万里》 | 海洋、深海、潜艇、光、黑暗、生物等共同构成自然—科技复合空间 |
| 《小王子》 | 玫瑰、狐狸、星星、沙漠、井等高度象征化，测试 QX/QH/QC 边界 |
| 《银河铁道之夜》 | 夜、银河、列车、河流、光等形成整体感知世界，测试“意象簇”问题 |
| 《夜晚的潜水艇》 | 当代碎片化、非线性、一次性强形象较多，测试 QX 是否依赖重复性 |

本轮重点检查：

1. `meaning` 是否应从“建议必填”降为可选；
2. `manifestation` 是否应正式加入 schema；
3. 感官/体感是否需要独立分类或仅作为属性层；
4. 是否需要 `imagery_constellation` / 意象簇；
5. `singular_pivotal` 能否覆盖一次性但高权重的意象；
6. QX 与 QC / QH 的边界是否足够清楚。

### 01.2 Pilot 信号

- `manifestation` 很有必要：同为“太阳”，这里真正关键的是“正午、刺眼、灼热、反光”的具体形态。
- “热”证明现有 20 类更偏对象分类，对**体感/感官状态**适配不足。
- `meaning` 并非每条都需要强解释；汗、热等对象的物质作用可能比象征意义更重要。
- QX 需要允许“现实物质条件型意象”，不能把所有对象象征化。

- `manifestation` 仍然重要，例如“海”可细分为深海、极地海域、海底森林等具体形态，而无需新建大量节点。

### 03.2 QX / QH / QC 边界测试

以“玫瑰”为例：

- `QX`：玫瑰作为具体植物如何出现、被照料、被比较、被记忆；
- `QH`：爱、责任、独特性、关系如何形成；
- `QC`：相遇—建立纽带—分离—重新理解关系若形成稳定跨作品结构，才进入叙事模式层。

结论：**QX 应停止在“具体对象如何被文学化”的层面，不继续把抽象主题和完整叙事结构吞进来。**

### 04.2 Pilot 信号

单条 `HAS_IMAGERY` 可以标出银河、夜、列车、星光，但它们之间还存在稳定组合：

```text
夜
+ 银河
+ 列车
+ 星光
+ 河流感
= 整体“夜间宇宙旅程”感知世界
```

这表明未来可能存在派生概念：

```text
IMAGERY_CONSTELLATION / 意象簇
```

但当前证据仍不足以升级 schema。暂时只作为派生分析，不增加正式字段。

# 05｜《夜晚的潜水艇》

## 05.1 试标原则说明

本书为短篇小说集，不同篇章的意象不一定共享同一叙事世界。因此本轮把“作品”视为**整部集子层**，但只记录在集子中具有高辨识度、跨篇或标题级强度的形象；若未来进入正式精标，应下沉到单篇作品层，以避免把不同短篇的局部形象错误聚合成统一母题。

| **夜** | QX2 天体与天空 / QX11 光影交叉 | core | 氛围塑造；时间标记；边界 / 阈限 | 隐秘；想象；记忆；现实松动 | recurrent；period_bound | 标题篇及多个夜间经验 | 夜间环境常给现实世界提供变形、回忆和想象进入的条件 |

| **电影 / 银幕 / 影像** | QX16 书写、知识与媒介 | core | 记忆触发；世界建构；媒介转换；前后回声 | 想象；观看；现实重写 | recurrent_across_collection；transformative | 多篇与个人经验 / 记忆 | 集子中媒介经验经常成为现实和想象互相转化的入口，影像不只是背景文化消费 |
| **旧物 / 收藏物** | QX15 器物与日常物件 | significant | 记忆触发；人物塑造；时间标记 | 过去；私人历史；残留 | recurrent_across_collection | 多篇记忆性叙事 | 某些旧物、遗留物件承担把现在拉回过去的记忆功能 |
| **城市夜景 / 街道** | QX8 城市与现代性场景 | significant | 空间塑造；氛围塑造；人物行动条件 | 漂移；匿名；现实感与幻觉边界 | recurrent_across_collection；spatial_bound | 当代城市经验 | 城市空间常与夜、影像、记忆互相叠加，形成现实并不稳定的感知环境 |
| **声音 / 音乐 / 广播式媒介声** | 当前分类不足，暂挂 QX16 媒介 | significant | 记忆触发；氛围塑造；时间标记 | 过去；距离；私人经验 | recurrent_across_collection | 多篇媒介与记忆场景 | 声音型媒介提示现有 QX 对听觉对象缺少自然主归属 |

### 05.3 Pilot 信号

- `singular_pivotal` 与“标题级强形象”应区分；建议未来考虑 `title_bound` 是否属于 mode。
- 短篇小说集暴露出**作品粒度问题**：QX 正式标注最好落在单篇 Work，而不是自动把整本集子视为单一叙事作品。
- 听觉对象再次暴露感官分类不足，说明“感官”问题不是《第一炉香》的香气或《局外人》的热感孤例。

# 06｜第二批跨作品观察

## 06.1 manifestation 候选字段再次获得支持

五部作品都显示，“对象名”不足以保存真正可比较的文学差异：

| object | manifestation 示例 |
|---|---|
| 太阳 | 正午、刺眼、灼热、反光 |
| 海 | 深海、极地海域、海底森林周边 |
| 星星 | 遥远星群、可听见/可记忆的星空、旅途坐标 |
| 夜 | 沙漠之夜、银河旅程之夜、都市想象之夜 |
| 水 | 井水、海水、天河、下潜水域 |

建议：`manifestation` 从候选字段提升为 **STRONGLY_SUPPORTED_CANDIDATE**，但在两批总审查前仍不正式冻结。

## 06.2 meaning 不宜必填

《海底两万里》的舷窗、电光、冰层，《局外人》的汗与热等对象，文学价值首先来自物质作用、感官条件或空间功能。

因此：

```text
meaning = OPTIONAL_CANDIDATE
```

比“建议必填”更符合实际。

## 06.3 感官问题从孤例变成稳定信号

第一批已有：

- 《第一炉香》：香气 / 嗅觉

第二批新增：

- 《局外人》：热、眩光、汗、身体不适
- 《夜晚的潜水艇》：声音 / 音乐 / 媒介声

因此现有 QX 一级分类对：

```text
嗅觉
听觉
触觉
温度 / 体感
```

缺乏自然主归属。

暂不新增 QX21。更合理的待评估方案有两种：

1. 新增“感官与感觉”一级类；
2. 保持对象按物质类别归属，把感官作为 `perceptual_channel` 关系属性。

第二种方案更可能避免分类树膨胀，留待总审查决定。

## 06.4 意象簇是派生关系，不急于成为新节点层

《银河铁道之夜》证明多个对象可形成稳定组合；《百年孤独》《红楼梦》其实也存在同类现象。

候选表达：

```text
IMAGERY_CONSTELLATION
```

但它更像从多条 `HAS_IMAGERY` 关系中计算/归纳出的上层结构，而不是作品标注时必填字段。

当前状态：

```text
IMAGERY_CONSTELLATION = DERIVED_CONCEPT_CANDIDATE
```

# 07｜第二批对 Schema 的结论

| Schema 项 | 第二批结论 |
|---|---|
| `qx_id` | 保留；无正式节点时允许 candidate |
| `object` | 保留，必填 |
| `salience` | 保留，三级仍够用 |
| `function` | 保留，必填，覆盖度良好 |
| `meaning` | 建议降为可选 |
| `mode` | 保留，仍有高区分度；可能补 `title_bound` |
| `phase` | 保留，可选 |
| `scope` | 保留，可选 |
| `evidence` | 保留，强烈建议 |
| `manifestation` | 两批均反复需要，强支持加入 |
| `perceptual_channel` | 新候选；可能比新增“感官类”更优 |
| `imagery_constellation` | 作为派生分析候选，不进入作品级必填 schema |

# 08｜两批 Pilot 后的待审问题

在正式冻结 `QX_RELATION_SCHEMA_V1` 前，建议集中评审以下 6 项：

1. `manifestation` 是否正式加入；
2. `meaning` 是否改为可选；
3. 是否新增 `perceptual_channel`；
4. `mode` 是否加入 `title_bound`；
5. 小说集/短篇集是否必须下沉到单篇 Work 标注；
6. `IMAGERY_CONSTELLATION` 是否作为未来派生分析模型，而非手工标签。
