# 文本证据与关键定型

## 1. 第一轮文本角色

| 文本 | 结构实例 | 本专题角色 |
|---|---|---|
| Hesiod《Theogony》 | Cronus / Zeus 神代更替 | `early_instance / defining_cosmic_variant` |
| Sophocles《Oedipus Tyrannus》 | Laius / Oedipus | `defining_tragic_instance` |
| Apollodorus《Library》2.4 | Acrisius / Perseus | `mythographic_witness / defining_variant` |

## 2. Hesiod《Theogony》

QT8.1.2 已把神代更替列为核心故事群，并明确抽取出：

```text
预言威胁 → 压制后代 → 后代反抗 → 新秩序
```

本专题只取其中“预言驱动规避而最终失败”的结构，不把整个神代更替压缩成单一 plot pattern。

## 3. Sophocles《Oedipus Tyrannus》

作品中 Jocasta 明确回忆 Laius 得到将死于自己儿子之手的神谕，婴儿随后被遗弃；成年 Oedipus 在不知道身份的情况下杀死 Laius。

该文本对“预言知识—规避行动—身份断裂—实现”的悲剧结构进行了高度集中化，因此可作为 `defining_tragic_instance`。

## 4. Apollodorus《Library》2.4

Acrisius 因神谕而囚禁 Danae，随后又把母子投入海中；Perseus 生存，后来在竞技会上意外杀死 Acrisius。

这个版本对 Pilot 的价值在于：

```text
fulfillment
可以是 accidental
而不是 intentional
```

## 5. 证据治理

当前只支持：

```text
这些文本保存／定型了可比较的结构实例
```

不支持：

```text
Sophocles 发明了该结构
Apollodorus 的版本一定直接来自 Sophocles
三个实例彼此存在单一路径传播
```

来源文本年代、故事传统年代和现代抽象出的 plot pattern 必须分开。
