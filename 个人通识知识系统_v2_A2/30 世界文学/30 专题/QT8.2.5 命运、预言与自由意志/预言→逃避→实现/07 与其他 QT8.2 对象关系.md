# 与其他 QT8.2 对象关系

## 1. motif 候选

- 预言／神谕
- 命运不可逃
- 父子／代际权力冲突
- 身份隐藏
- 遗弃儿童

其中只有“预言／命运”与本结构高频共现，但它们仍然是 motif，不等于 plot pattern。

## 2. archetype 候选

- 被预言者
- 惧怕继承者的旧王
- 被遗弃后归来的后代
- 悲剧英雄

这些角色可以执行结构槽位，但结构本身不要求固定人格或身份。

## 3. symbol 候选

- 神谕地点／预言媒介
- 十字路口（三岔路）
- 密室／塔／箱子

这些必须经过 symbol Pilot 的准入，不能因故事著名自动升级。

## 4. 与已正式 QT8.2 component 的关系

当前正式接受的组件包括“洪水与灾后重建”“受苦义人”“所罗门王”，但本 Pilot 暂未发现需要强行建立的直接语义边。

因此：

```text
qt82_component_relation
= DEFERRED_BY_MEANINGFUL_TARGET_GATE
```

这不同于“没有关系能力”；只是避免为了测试 schema 而制造低价值边。

## 5. 未来最自然的正式关系

当“预言／命运冲突” motif 或“被预言者” archetype 正式准入后，本对象可使用：

```text
contains_motif / carries_motif
typically_enacted_by_archetype
```

具体 relation_type 需与 Shared Data Layer 词汇对齐后再落数据。
