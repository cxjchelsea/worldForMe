# 预言 → 逃避 → 实现｜plot_pattern Pilot C

> **定位：**研究一个行为主体在得知具有约束力的预言／神谕后，为避免其实现而采取行动，但预言最终仍然实现的顺序结构。

## 1. 最小结构

```text
S1 权威性预言／神谕出现
→ S2 受威胁者采取规避行动
→ S3 被预言的结果最终实现
```

更强的反讽变体是：

```text
S1 预言
→ S2 规避
→ S2a 规避行为重塑因果条件
→ S3 预言恰恰经由规避链实现
```

因此本 Pilot 不把“规避行为必须直接造成结果”设为最低必选槽位，而把它作为 `avoidance_backfire` 强变体进行测试。

## 2. 为什么这是 plot_pattern，不是 motif

```text
预言／命运／自由意志
= motif / problem domain

预言出现 → 行动者规避 → 预言仍实现
= 有先后关系的 plot_pattern
```

对象的核心不是“存在预言”，而是**预言如何改变人物行动，并形成一个可重复的顺序结构**。

## 3. 第一轮来源压力测试

QT8.1.2 希腊—罗马神话传统提供三个差异明显的实例：

```text
Cronus / Zeus 神代更替
→ 预言威胁 → 吞食后代 → Zeus 被保全 → 旧王被推翻

Laius / Oedipus
→ 弑父预言 → 遗弃婴儿／身份断裂 → 成年后相遇 → 预言实现

Acrisius / Perseus
→ 外孙杀王预言 → 囚禁 Danae／放逐母子／后来逃离 Argos → 体育竞赛意外死亡 → 预言实现
```

它们共享最小槽位，但规避行为如何参与最终结果并不完全相同。
