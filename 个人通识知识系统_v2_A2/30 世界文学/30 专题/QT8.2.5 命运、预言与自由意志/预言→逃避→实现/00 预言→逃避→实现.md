# 预言 → 逃避 → 实现｜plot_pattern Pilot C

> **定位：**研究一个行为主体在得知具有约束力的预言／神谕后，为避免其实现而采取行动，但预言最终仍然实现的顺序结构。

## 1. 最小结构

```text
S1 权威性预言／神谕出现
→ S2 受威胁者采取规避行动
→ S3 被预言的结果最终实现
```

Pass B 之后，`avoidance_backfire` 没有升级为 core slot，因为不同实例证明：

```text
fulfilled_despite_avoidance
≠
fulfilled_through_avoidance
```

也就是说，预言可以“尽管被规避仍然实现”，也可以“正因为规避链而实现”。

## 2. 为什么这是 plot_pattern，不是 motif

```text
预言／命运／自由意志
= motif / problem domain

预言出现 → 行动者规避 → 预言仍实现
= 有先后关系的 plot_pattern
```

对象的核心不是“存在预言”，而是**预言如何改变人物行动，并形成可重复的顺序结构**。

## 3. 来源压力测试

### 希腊—罗马来源组

```text
Cronus / Zeus
Laius / Oedipus
Acrisius / Perseus
```

### 非希腊来源压力测试

```text
《毗湿奴往世书》
Kamsa / Devaki / Krishna
```

印度实例证明，同一抽象顺序可以从另一个来源传统中独立抽取；但这不构成希腊—印度历史传播的证据。
