# 作品实例

## 1. 来源级结构实例

当前正式来源实例：

```text
Hesiod《Theogony》
→ Cronus / Zeus

Sophocles《Oedipus Tyrannus》
→ Laius / Oedipus

Apollodorus《Library》2.4
→ Acrisius / Perseus
```

它们进入 `qt82_source_reference`，不与后世 work reference 混用。

## 2. 后世作品记录规则

每条正式 `qt82_work_reference` 至少记录：

```yaml
matched_slots: []
missing_slots: []
added_slots: []
relation_type: structural_inheritance | plot_pattern_inversion | ...
evidence_level: documented | strongly_supported | probable | possible | similarity_only | unknown
```

Shared Data Layer 当前 work schema 主要使用 `retained_features / modified_features`。Pilot C 暴露出一个 plot-pattern 专属数据需求：

```text
matched_slots / missing_slots / added_slots
```

Pass A 暂不修改共享 schema，等待 Pass B 用真实后世作品判断：

- 是否将这些字段作为 `plot_pattern` 类型的允许扩展字段；
- 还是继续映射到 retained / modified features。
