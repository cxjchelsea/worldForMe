# 后世变形与反结构

## 1. 可观察的结构变形

### 1.1 节点压缩

```text
预言
→ 一次规避
→ 实现
```

减少身份漂移与中间试炼，突出因果反讽。

### 1.2 规避重复

```text
预言
→ 多次规避
→ 每次都改变条件
→ 最终实现
```

可增强必然感和悲剧递进。

### 1.3 实现方式偏移

预言的核心命题实现，但人物此前理解的细节错误，从而形成“字面实现／解释落差”。

### 1.4 规避本身成为原因

这是强反讽型：

```text
避免 X 的行动
→ 创造 X 的条件
```

## 2. 反结构候选

### A. 预言被成功规避

```text
预言 → 规避 → 预言失效
```

这不是本结构 full match，而是 `plot_pattern_inversion` 候选。

### B. 角色拒绝规避

```text
预言 → 接受／主动配合 → 实现
```

缺失核心 S2，应归入其他结构。

### C. 预言因被知晓而主动实现

如果人物追求预言，而非逃避它，则属于另一种 self-fulfilling pattern。
