# 奇幻文学

> 路径：世界文学 → Q轴 → QT 类型与叙事传统 → QT3 奇幻 → **奇幻文学**

## 专题定位

奇幻的核心不是“有没有魔法”，而是：**作品让超自然、神话力量或第二世界成为叙事现实的一部分，并建立一套读者需要接受的世界规则。**

本专题不把奇幻压成“托尔金式中世纪欧洲世界”，而同时追踪：

```text
历史纵轴
+
子类型 / 世界结构 / 审美分叉
+
神话重述 / 全球传统 / 跨类型边界
```

## 核心问题

> **当现实法则可以被重新书写时，一个第二世界如何获得内部可信度；而这种异世界又怎样重新讨论权力、历史、身份与欲望？**
