# 阅读路线

TH3.3 的阅读路线不按“黑人文学 / 亚裔文学 / 移民文学”分书单，而按分析能力递进。目标是读完以后能够从作品中重建“分类—赋值—制度化—跨界—共同体—重写”机制。

## 第一阶段：先看见“分类不是事实，而是社会动作”

### 《越界》（Passing）

重点：可见性、passing、血统与社会读取。

阅读问题：

- 为什么同一个身体可以在不同场景被读成不同种族？
- 谁拥有判断身份的权力？
- passing 给人物带来的不是简单自由，而是什么新的风险？

训练能力：把“人物是什么种族”改写成“人物如何被种族化”。

### 《杀死一只知更鸟》

重点：分类如何预先改变可信度、司法判断和社区关系。

训练能力：看见群体标签怎样成为行动之前的社会判决。

## 第二阶段：从分类进入凝视、刻板印象与自我内化

### 《最蓝的眼睛》

重点：审美标准、肤色、身体价值和内化。

阅读问题：

- 外部群体等级如何变成个人对身体的评价？
- 为什么“想变得像主流群体”并不只是个人审美？
- TH3.3 与 TH3.1 性别/身体在哪里交叉？

### 《土生子》

重点：犯罪想象、恐惧、社会预设和行动空间。

训练能力：分析一个群体如何先被叙述成某种人，再按照这种叙述被治理和解释。

## 第三阶段：看群体边界怎样进入制度和空间

### 《阳光下的葡萄干》

重点：住房隔离、家庭上升与空间边界。

### 《看不见的人》

重点：公共可见性、政治组织、社会角色和种族化期待。

训练能力：不把歧视只理解为个人偏见，而是追踪它怎样进入住房、教育、组织、司法和公共生活。

## 第四阶段：从制度进入历史遗产和共同体再生产

### 《宠儿》

重点：奴隶制、身体、家庭断裂、记忆与群体历史。

分析时分层：

- 奴隶制作为种族化身份制度 → TH3.3；
- 具体身体暴力和创伤 → TH6；
- 过去如何被记忆并进入下一代 → TH7。

### 《归家》（Homegoing）

重点：跨代家族、种族位置、奴隶制遗产和不同社会环境中的身份变化。

训练能力：看群体边界如何跨代再生产，而不是只分析某一个人物受到歧视。

## 第五阶段：进入迁徙、族群化与兄弟节点边界

### 《美国佬》

重点：跨国移动前后，同一人物的“黑人身份”如何发生社会意义变化。

固定拆分：

- 移动本身 → TH3.5；
- 在美国被重新种族化 → TH3.3；
- 文化共同体与尼日利亚/美国身份 → TH3.4；
- 哪里是家 → 只有作品稳定追问时才进入 TH3.6。

### 《同名人》

重点：姓名、族群身份、家庭、同化和第二代。

它特别适合防止 TH3.3 吞掉 TH3.4：如果作品核心更多是文化继承、家庭传统与孟加拉/美国文化身份，则 TH3.4 可以高于 TH3.3。

### 《喜福会》

重点：族群身份、代际与文化传递。

训练能力：区分“群体成员资格”与“文化共同体内容”。

## 第六阶段：进入殖民交叉，但拒绝把殖民等同于种族

### 《瓦解》

重点：殖民权力、文化共同体、文明等级与身份冲击。

阅读时必须分别问：

- 殖民者 / 被殖民者关系是否是核心？→ TH3.7
- 伊博文化、传统和共同体身份是否是核心？→ TH3.4
- 是否形成稳定的种族/族群分类和差别待遇？→ 成立时才 TH3.3

训练能力：避免“后殖民作品 = TH3.3 + TH3.4 + TH3.7”机械全标。

## 第七阶段：从个人跨界进入群体边界的重写

回看《看不见的人》《美国佬》《他们眼望上苍》等作品，比较：

```text
隐藏 / passing / 同化
→ 改变个人被读取方式

重新命名 / 集体组织 / 文化重估 / 平权行动
→ 改变群体再现或群体秩序
```

训练能力：区分 P4“穿越已有边界”和 P6“改变边界本身”。

## 建议顺序

```text
《越界》
→ 《杀死一只知更鸟》
→ 《最蓝的眼睛》
→ 《土生子》
→ 《阳光下的葡萄干》 / 《看不见的人》
→ 《宠儿》 / 《归家》
→ 《美国佬》 / 《同名人》 / 《喜福会》
→ 《瓦解》
→ 回看跨界与重写作品群
```

## 每部作品的固定阅读卡

1. **分类依据**：人物为什么被认作某一群体？
2. **分类者**：谁有权命名？
3. **赋值**：这个群体被想象成什么样的人？
4. **现实后果**：分类怎样影响空间、资格、劳动、关系、司法？
5. **人物策略**：认同、隐藏、passing、同化、混合还是反抗？
6. **共同体**：家庭、语言、记忆、社群如何维持身份？
7. **变化结果**：人物位置变了，还是群体边界变了？
8. **兄弟节点校验**：文化、迁徙、故乡、殖民问题是否真正独立成立？

## 完成标准

完成本路线后，应能够：

- 不把种族/族群当作天然属性，而分析分类过程；
- 区分刻板再现与制度差别待遇；
- 区分个人 passing 与群体边界改变；
- 看见群体身份既受外部排斥塑造，也由内部共同体生产；
- 比较美国、移民社会、殖民社会、混血社会等不同分类机制；
- 稳定区分 TH3.3 与 TH3.4/3.5/3.6/3.7；
- 在 TH4/TH5/TH6/TH7 同时出现时保持分析层级清晰。
