# 首轮作品压力测试

## 目标

检验六个候选问题是否足以覆盖不同种族/族群文学经验，并测试：

- P1“分类”与 P2“他者化再现”是否可独立；
- P4“跨界/同化”与 P6“反抗/重写”是否应合并；
- P5 是否会被 TH3.4 或 TH7 吞掉；
- TH3.3 是否需要拆成“种族”与“族群”两个子坐标。

## V1 语料：15 部

### 骨架作品（9）

1. **《杀死一只知更鸟》** — P1 / P2 / P3；种族分类、社区偏见与司法制度直接相连。
2. **《最蓝的眼睛》** — P1 / P2 / P5；白人审美被内化为身体价值，检验 P2 与 TH3.1 的边界。
3. **《宠儿》** — P1 / P3 / P5 / P6；奴隶制将种族分类制度化，并通过家庭与记忆持续传递。
4. **《看不见的人》** — P1 / P2 / P3 / P6；社会“看不见”与政治组织共同检验再现和制度。
5. **《土生子》** — P2 / P3 / P6；刻板犯罪想象与结构性隔离共同塑造人物行动空间。
6. **《越界》（Passing）** — P1 / P2 / P4；passing 直接暴露种族分类的社会建构性。
7. **《美国佬》** — P1 / P2 / P4 / P6；迁徙前后种族位置变化，检验 TH3.3 与 TH3.5 的边界。
8. **《归家》（Homegoing）** — P1 / P3 / P5 / P6；跨代家族结构展示种族身份与奴隶制遗产的传递。
9. **《紫色》** — P1 / P2 / P5 / P6；种族与性别交叉，检验 TH3.3 与 TH3.1。

### 比较作品（5）

10. **《喜福会》** — P1 / P4 / P5；族群身份、家庭传递与同化，检验 TH3.3 与 TH3.4/TH3.5。
11. **《同名人》** — P1 / P4 / P5；姓名、移民家庭与文化适应，偏向族群而非种族等级。
12. **《阳光下的葡萄干》** — P1 / P3 / P6；住房隔离、家庭与社会上升。
13. **《地下铁道》** — P1 / P3 / P6；种族制度与逃离结构，校准 TH3.3 与 TH6/TH7。
14. **《他们眼望上苍》** — P2 / P5 / P6；黑人共同体内部、性别与自我表达的交叉比较。

### 边界测试（1）

15. **《瓦解》** — 殖民冲击、传统共同体和文化等级非常突出，但核心并非现代种族分类本身；主要用于校准 TH3.3 与 TH3.4、TH3.7。若作品分析重点转向殖民话语制造的族群/种族等级，可兼标 TH3.3，但不作为默认骨架。

## 挑错结果

### 1. P1 与 P2 不合并

- P1：谁被划入哪一类、边界依据是什么；
- P2：这一类被赋予什么刻板价值、如何被观看和叙述。

《越界》可强命中 P1 而不必同等强命中制度再现；《最蓝的眼睛》则强命中 P2。两者可独立。

### 2. P4 与 P6 不合并

- P4 是在既有边界内隐藏、跨越、passing、同化或协商；
- P6 是公开挑战边界和等级本身，争取新的群体秩序。

passing 可能并不挑战种族秩序，只是个人穿越它，因此必须独立。

### 3. P5 不能被 TH3.4/TH7 替代

P5 不研究文化传统或记忆本身，而研究这些机制怎样让“某个族群身份”在代际中持续存在。只要分析焦点仍是群体边界与成员资格，P5 保留。

### 4. 不拆“种族 / 族群”

核心作品跨越种族化分类、族裔身份、移民共同体与混合归属，但六个问题稳定复用。拆成两个子坐标将造成《美国佬》《喜福会》《同名人》等作品重复命中，坐标收益不足。
