# TH3.3「种族与族群」A级内容压力测试

## 一、测试目标

本测试不再验证“TH3.3 这个坐标是否存在”，而验证升级后的 L1–L6 是否真正具备解释力、比较力和边界稳定性。

重点检查：

1. 六问能否继续覆盖不同种族/族群经验；
2. “分类 → 赋值 → 制度化 → 跨界 → 共同体 → 重写”机制能否跨传统成立；
3. 是否过度依赖美国黑人经验；
4. 是否会把移民、文化身份、故乡和殖民背景机械吞进 TH3.3；
5. 是否会把阶级不平等、制度权力和暴力后果误认为“种族主题本身”；
6. 是否出现必须新增 `TH3.3.x` 或第七核心问题的证据。

## 二、压力测试判定原则

一个作品要把 TH3.3 作为核心，至少应稳定存在以下链条中的两至三段以上：

```text
被群体分类
→ 被附加刻板价值
→ 分类造成现实差别待遇
→ 人物被迫处理群体边界
```

仅满足以下情况不够：

- 作者或人物属于少数族群；
- 故事发生在殖民地；
- 人物发生跨国迁移；
- 作品描写某种文化传统；
- 作品出现贫困、歧视或暴力；
- 作品有身份认同问题。

## 四、六个核心问题复核

### P1 人如何被划分为种族或族群成员

跨样本稳定。passing、血统、肤色、姓名、口音、祖籍、宗教等都可进入，不需要再拆“种族分类”和“族群分类”。

**结论：保留。**

### P2 刻板印象、凝视与再现如何制造他者

《最蓝的眼睛》《土生子》《看不见的人》等证明 P2 不等于 P1。分类回答“你是哪一类”，P2 回答“这一类被想象成什么样的人”。

**结论：保留。**

### P3 隔离、歧视与制度如何把群体边界变成现实

住房、司法、劳动、教育、公共空间、奴隶制等均稳定命中。与 TH5 的分工可操作：TH5 分析制度运行，P3 分析制度为何按群体分类分配现实位置。

**结论：保留。**

### P4 混血、跨界、伪装与同化如何挑战群体边界

《越界》《美国佬》《同名人》证明跨界策略具有独立解释力，而且 passing 并不必然挑战群体秩序。

**结论：保留。**

### P5 家庭、记忆与共同体如何传递族群身份

《归家》《喜福会》《宠儿》证明 P5 不能由 TH3.4 或 TH7 完全替代。只要焦点是“谁算群体成员、边界如何代际持续”，P5 独立成立。

**结论：保留。**

### P6 人如何反抗种族化秩序并重写群体归属

与 P4 稳定区分：P4 是人物在既有边界中移动；P6 是重新命名、重估或改变群体边界/秩序。

**结论：保留。**

### 是否需要第七问

压力样本中没有出现反复且无法由六问承接的机制。

候选“交叉性”不应新增为第七问，因为它不是 TH3.3 内部独立问题，而是 TH3.3 与性别、阶级、殖民、制度等其他主题同时作用的分析方式。

候选“空间”也不需要独立成问，住房、隔离和公共空间已经是 P3 的现实载体。

**结论：无需第七问。**

## 五、三项高风险误判测试

### 误判 1：移民 = 种族/族群

不成立。

```text
发生迁移 / 流亡 / 跨境
→ TH3.5

进入新社会后被重新分类为某族群，并由此获得差别待遇
→ TH3.3
```

《美国佬》可双强命中；《同名人》更偏文化/代际时，TH3.3 应降级。

### 误判 2：殖民 = 种族

不成立。

```text
殖民者 / 被殖民者、文明 / 野蛮、中心 / 边缘
→ TH3.7

殖民秩序进一步生产稳定种族/族群分类并分配待遇
→ TH3.3
```

《瓦解》证明殖民身份主题可以很强而 TH3.3 只次要或局部成立。

### 误判 3：少数族裔人物 = TH3.3

不成立。

身份背景只有在作品使“群体分类及其后果”成为稳定冲突时才进入 TH3.3。人物来自某族群但作品不讨论边界、待遇、成员资格或群体再生产，不能自动标注。

## 六、与 TH4–TH7 的交叉测试

### TH3.3 ↔ TH4

- 种族化造成职业/财富差异 → TH3.3；
- 劳动、资本、贫困和阶级位置怎样组织生活 → TH4。

同一作品可兼标，但不能把所有种族不平等都只解释为阶级，也不能把所有阶级差异都种族化。

### TH3.3 ↔ TH5

- 谁制定、执行法律和制度 → TH5；
- 制度为什么按群体分类人物、产生何种群体后果 → TH3.3。

### TH3.3 ↔ TH6

- 群体被构造成敌人、低等者、可排斥者 → TH3.3；
- 伤害、杀戮、酷刑、恐惧、创伤与见证 → TH6。

### TH3.3 ↔ TH7

- 群体过去如何被记住、遗忘、争夺 → TH7；
- 记忆怎样维持成员资格和共同体边界 → TH3.3 P5。

上述接口均未出现系统性冲突。

## 七、跨传统能力结果

升级后的框架不再依赖单一“白/黑二元种族模型”，可以处理：

- 奴隶制和隔离社会；
- passing 与混血；
- 移民社会族群化；
- 犹太身份的宗教/族群/种族化变化；
- 亚裔离散经验；
- 拉丁美洲混血与肤色等级；
- 殖民社会种族化；
- 原住民成员资格；
- 种族灭绝与族群暴力前的敌我分类。

共同分析单位始终是：

```text
差异如何成为分类依据
→ 分类如何获得价值
→ 分类如何产生现实后果
→ 人如何在边界中行动
```

因此跨传统能力通过。

## 八、抗拆分测试

没有发现需要：

- 拆成“种族 / 族群”两个子坐标；
- 增加“混血”“移民族群”“少数族裔”等子坐标；
- 将 intersectionality 建成第二维；
- 新建 TH3.3.x。

复杂度可以稳定由六问、机制、八组张力、跨传统比较和作品投影承担。

## 九、最终结论

```text
TH3.3_A_LEVEL_CONTENT_TEST = PASS
L1_L6 = COMPLETE
SIX_PROBLEMS = STABLE
SEVENTH_PROBLEM_REQUIRED = FALSE
CROSS_TRADITION = PASS
SIBLING_BOUNDARIES = PASS
TH4_TH7_BOUNDARIES = PASS
TH3.3.x_REQUIRED = FALSE
MATURITY = A
```

TH3.3 可正式认定为 **A 级成熟主题知识地图**。

最稳定的知识模型为：

```text
差异
→ 分类
→ 赋值
→ 制度化 / 日常化
→ 差别待遇
→ 跨界 / 内化 / 同化
→ 共同体再生产
→ 反抗与边界重写
```

本轮同时验证了 TH3 后续建设的工作方式：不修改已冻结的七叶坐标，而在每个叶节点内部补齐机制，并用兄弟节点反例作为 A 级验收条件。
