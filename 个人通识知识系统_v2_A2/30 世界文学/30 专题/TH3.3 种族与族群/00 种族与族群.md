# 种族与族群

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.3 种族与族群**

## 专题定位

本专题研究**种族化与族群边界如何被制造、命名、继承与制度化，以及人物如何在这些边界中被他者化、排斥、同化、内部化或重新建立群体归属**。

纳入测试：如果拿掉作品中的种族/族群分类、群体边界及其社会后果，人物的权利、空间、关系或归属是否会发生根本变化？若不会，一般不作为本专题核心。

## 为什么不继续拆坐标

压力测试显示，“种族”与“族群”虽然概念来源不同，但在文学中常通过同一条机制链被体验：被分类 → 被凝视和再现 → 在制度中获得差异待遇 → 内化或跨越群体边界 → 通过记忆、家庭和共同体维持身份 → 反抗或重写归属。若拆成两个子坐标，大量核心作品会稳定重复命中，因此 V1 不新增 `TH3.3.x`。

## 与相邻主题的边界

- **TH3.4 民族与文化身份**：国家、语言、传统、民族文化和文化共同体本身归 TH3.4；以种族化/族群化分类和群体边界为核心归 TH3.3。
- **TH3.7 殖民身份**：殖民者/被殖民者的身份、文化等级和殖民话语归 TH3.7；殖民体系进一步制造或固化种族/族群边界时可兼标 TH3.3。
- **TH5 权力、制度与秩序**：制度权力本身归 TH5；制度按种族/族群分配权利、空间和资格时进入 TH3.3。
- **TH6 战争、暴力与创伤**：暴力和创伤本身归 TH6；暴力如何服务于种族边界和群体等级时进入 TH3.3。
- **TH7 历史、记忆与时间**：历史记忆本身归 TH7；记忆如何维持族群身份和共同体边界时进入 P5。
