# 种族与族群

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.3 种族与族群**

## 专题定位

本专题研究**社会如何把肤色、血统、祖籍、姓名、宗教、语言、口音等差异转化为稳定的种族/族群分类，如何给这些分类附加价值并制造现实边界，以及人物如何在这些边界中被他者化、排斥、同化、内化、跨越或重新建立群体归属**。

纳入测试：如果拿掉作品中的种族/族群分类、群体边界及其社会后果，人物的权利、空间、关系、行动可能或归属是否会发生根本变化？若不会，一般不作为本专题核心。

TH3.3 不是“少数族裔人物作品库”，也不是“任何移民/殖民作品的默认标签”。分析必须能够指出具体的**分类—赋值—现实后果**链。

## L3：统一作用机制

```text
可被识别的差异
→ 分类与命名
→ 刻板赋值与他者化
→ 边界制度化 / 日常化
→ 差别待遇与机会结构
→ 内化、隐藏、passing、同化或混合
→ 家庭 / 记忆 / 社群再生产
→ 反抗、重新命名与边界重组
```

这里必须区分三个不同问题：

- “人物属于哪个群体？”只是背景信息；
- “别人怎样把人物划入某群体？”开始进入 TH3.3；
- “这种分类怎样持续改变人物的现实处境与行动？”才构成成熟的 TH3.3 分析。

## L4：八组稳定张力

1. **自我认定 ↔ 外部分类**：身份由本人还是他者决定？
2. **可见 ↔ 隐藏**：身份是否可以 passing、伪装或被误认？
3. **本质化 ↔ 社会建构**：差异被说成天然还是历史制造？
4. **同化 ↔ 差异保存**：获得接纳是否要求放弃群体特征？
5. **passing ↔ 边界重写**：个人越界是否真正改变秩序？
6. **污名 ↔ 自豪**：被贬低身份如何重新获得价值？
7. **外部排斥 ↔ 内部共同体**：群体凝聚来自共享文化还是外部压力？
8. **固定边界 ↔ 情境变化**：同一身份为何随地点与时代改变意义？

这些张力不新增坐标层，只用于作品比较。

## TH3 兄弟节点边界矩阵

TH3 域级冻结已经确认七叶稳定；本专题只把既有边界显化为阅读时可操作的判别表：

| 节点 | 最核心的问题 | 一句话判断 |
|---|---|---|
| **TH3.3 种族与族群** | 谁把我划入哪一群，并因此怎样对待我？ | 外部群体分类与现实后果 |
| **TH3.4 民族与文化身份** | 我如何成为或理解某文化共同体的一员？ | 语言、传统、民族叙事、文化真实性 |
| **TH3.5 迁徙与流亡** | 离开、迁移、跨境或流亡怎样改变生活？ | 移动过程与异地生存 |
| **TH3.6 故乡与归属** | 哪里被经验为家，我还能否回去？ | 地方依附、失乡、返乡、新家 |
| **TH3.7 殖民身份** | 殖民关系怎样制造身份等级并进入自我理解？ | 殖民者/被殖民者、中心/边缘、文明/野蛮 |

对于典型移民作品，应按下面顺序拆开：

```text
跨境移动发生了什么？ → TH3.5
进入新社会后怎样被族群化/种族化？ → TH3.3
人物怎样继承或重写文化共同体？ → TH3.4
人物把哪里当作家？ → TH3.6
如果上述关系受殖民等级组织 → 再判断 TH3.7
```

不允许因为“移民背景”一次性全部命中。

## 与域外主题的接口

- **TH1.1 自我认同与主体性**：泛化“我是谁”归 TH1.1；社会群体分类成为主体危机来源时兼入 TH3.3。
- **TH3.1 性别与身体**：性别化身体和身体控制归 TH3.1；肤色、外貌等被用作种族分类时归 TH3.3。交叉性不意味着二者合并。
- **TH4 社会、阶级与劳动**：资源、劳动和阶级位置归 TH4；种族分类进一步限制住房、工作和财富机会时可兼标。
- **TH5 权力、制度与秩序**：规则与机构怎样运作归 TH5；规则为何按种族/族群分配资格归 TH3.3。
- **TH6 战争、暴力与创伤**：具体伤害和创伤归 TH6；某群体为何被构造成可攻击对象归 TH3.3。
- **TH7 历史、记忆与时间**：过去如何被保存、争夺和重写归 TH7；这些记忆如何维持族群成员资格归 TH3.3 P5。
- **TH8 信仰、伦理与超越**：信仰价值本身归 TH8；宗教标签被外部当作族群分类依据时可进入 TH3.3。

## 为什么不继续拆坐标

“种族”与“族群”概念来源不同，但作品压力测试显示它们经常共享同一条文学机制：

```text
被分类
→ 被赋值
→ 被差别对待
→ 在边界中行动
→ 由共同体继续传递
→ 反抗或重写
```

若拆成两个子坐标，《美国佬》《喜福会》《同名人》以及大量混合/离散作品会稳定重复命中，坐标收益不足。因此仍不新增 `TH3.3.x`。

## 作品分析最低模板

1. 分类依据是什么？
2. 谁拥有命名权？
3. 群体被赋予什么刻板价值？
4. 分类如何进入空间、资格、劳动、关系或司法？
5. 人物如何处理自身的可见性和群体成员资格？
6. 家庭/社群怎样保存或改变边界？
7. 反抗改变个人位置还是群体秩序？
8. 与 TH3.4–TH3.7 的其他问题是否独立成立？

若无法回答前四项中的至少两到三项，而只能指出作品“有某族裔人物”，一般不应把 TH3.3 设为核心。
