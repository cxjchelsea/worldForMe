# 阅读路线

科幻专题很容易因为子类型和母题过多而失控，因此本页只维护**选择方法**，不复制静态长书单。

## 第一轮：建立历史骨架

目标不是打卡数量，而是看见科幻怎样从科学幻想进入类型制度，再从技术乐观不断扩展到社会、身体、语言、生态与全球未来。

操作：打开 [[../03 科幻作品.base|科幻作品数据库]] → **核心骨架 ★**，并配合 [[02 历史与流派演进]] 阅读。

## 第二轮：补系统扩展

使用 **系统扩展 ◆** 视图，补重要作者第二入口、次级传统、全球地域和历史阶段的缺口。

不要因为某位作者特别喜欢，就直接把作者全集塞进公共B级地图；作者深挖应留给个人阅读分支。

## 第三轮：沿一个“类型机制”深挖

先阅读 [[03 类型谱系与核心机制]]，明确自己追的是子类型还是母题。

### Hard SF
Clarke → Niven → Benford → Robinson → Egan → Watts → Reynolds

### 社会 / 人类学科幻
Le Guin → Butler → Delany → Atwood → Jemisin

### AI / 后人类
Shelley → Čapek → Asimov → Dick → Gibson → Egan → Watts → Leckie → Ishiguro

### 文明尺度
Stapledon → Asimov → Herbert → Banks → Simmons → Vinge → Liu Cixin → Tchaikovsky

### 时间与因果
Wells → Asimov → Willis → Chiang → 当代时间战争／多宇宙写作

## 第四轮：跨专题对读

选择一个交叉问题：

- 科幻 × 反乌托邦：技术与制度如何共同塑造人？
- 科幻 × 恐怖：知识为什么会制造恐惧？
- 科幻 × 推理：特殊规则能否成为公平推理条件？
- 科幻 × 冒险：未知空间何时从行动舞台变成思想实验？

入口见 [[04 跨类型与地域桥接]]。

## 四个未实体化阅读入口

以下仍作为选读提示，不为了凑数量污染中央作品库：

- ◆ Fredric Brown等黄金时代短篇选读（原文第239行）
- ★ 星新一短篇精选（原文第622行）
- ◆ 夏笳短篇精选（原文第686行）
- ◆ Solarpunk代表短篇选集（原文第820行）
