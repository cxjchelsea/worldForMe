# 类型谱系与核心机制

科幻最容易出现的分类错误，是把**历史运动、子类型、母题和跨类型混合**全部放在同一层。

例如：

```text
Hard SF      = 更接近子类型 / 写作取向
AI           = 核心母题 / novum
Cyberpunk    = 历史运动 + 美学 + 子类型传统
Space Opera  = 类型模式
科幻推理     = 跨类型混合
```

它们当然可以一起作为作品标签使用，但在知识地图里必须知道彼此不是同一种东西。

## 1. 历史运动与类型传统

这些概念主要回答“科幻史在什么时候、以什么出版和美学方式发生转向”：

- Scientific Romance / 早期科学幻想
- Pulp SF
- Golden Age
- New Wave
- Cyberpunk / Post-Cyberpunk
- New Space Opera

它们首先属于 [[02 历史与流派演进]] 的时间纵轴。

## 2. 子类型与叙事模式

这些概念主要回答“作品用什么约束和叙事发动机组织科幻想象”：

- **Hard SF**：科学约束本身参与故事结构。
- **Space Opera**：以星际空间承载帝国、文明、战争和冒险。
- **Military SF**：军队、战争机器、士兵伦理与政治共同体进入核心。
- **Social / Anthropological SF**：把文化、制度、性别、亲属关系当成可外推变量。
- **Dystopian SF**：通过技术／制度条件推演压迫性社会秩序，同时与独立的反乌托邦专题交叉。
- **Biopunk / Biotech SF**：生命工程、基因、身体设计和生物资本。
- **Climate / Eco SF**：生态系统和气候成为文明条件，而不只是背景。
- **Post-apocalyptic SF**：以灾变后的社会重建为主要世界条件。

## 3. 核心母题 / 思想实验变量

这些更接近“作品改变了什么条件”：

- AI / 机器人
- 第一接触
- 时间旅行
- 后人类
- 平行世界 / 架空历史
- 文明尺度
- 世代飞船
- 巨构 / Big Dumb Object
- 语言与认知

同一个子类型可以使用多个母题；同一个母题也可以出现在完全不同的子类型里。

## 4. 跨类型混合

科幻并不会因为与其他类型混合而失去身份：

- 科幻 × 推理
- 科幻 × 恐怖 / Weird
- 科幻 × 冒险
- 科幻 × 历史 / Alternate History
- Science Fantasy
- 文学科幻 / 类型边界写作

## 5. `sf_themes` 为什么仍然保持扁平多标签

作品数据库里的 `sf_themes` 是**查询字段，不是完整本体论**。为了实际筛选方便，它可以同时容纳：

> Hard SF、AI、Cyberpunk、太空歌剧、后人类、科幻推理……

知识层则由本页解释它们分别属于什么层级。这样不需要大规模重写现有作品 Properties，也不会把数据库便利性误认为文学理论层级。
