# 武人伦理、忠诚与共同体

私人暴力若要成为“英雄暴力”，通常需要一套超越个人欲望的伦理语言。但不同传统要求英雄忠于不同对象。

| 传统 | 主要伦理／忠诚对象 |
|---|---|
| 武侠 | 义、承诺、知己、师徒、江湖、家国 |
| Knight | 主君、封建义务、荣誉、信仰、宫廷爱情 |
| Samurai | 主从、家／藩、义理、仇讨、个人之道 |
| Western | 自我责任、社区、生存伦理、有限法律 |
| Gaucho | 地方生活方式、自由、伙伴、土地／边疆共同体 |
| Outlaw | 民间共同体、受压迫者、伙伴集团 |
| Pirate | 船员契约、临时共同体、利益与自由 |
| Swashbuckler | 伙伴、个人荣誉、爱情、秘密政治忠诚 |

## 关键问题

- 忠诚对象发生冲突时，英雄选择什么？
- 伦理是制度赋予的，还是英雄自己宣布的？
- 独行侠真的是孤独个人，还是仍依赖共同体评价才能成为英雄？
- “背叛”在不同传统里为什么拥有完全不同的道德重量？

这条轴特别适合比较武侠的“义”、Knight的Honor、Samurai的忠诚／义理与Western的个人—社区关系，而不是把这些词简单翻译成同一个“荣誉”。
