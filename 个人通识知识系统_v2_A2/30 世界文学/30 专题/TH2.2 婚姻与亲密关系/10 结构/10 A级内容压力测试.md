# A级内容压力测试

本轮不重新决定七个核心问题是否存在——这一点已由 V1 冻结——而是检验升级后的统一关系循环、八组结构张力和跨主题边界是否能够稳定解释不同传统、不同关系形态与负向样本。

## 一、测试标准

A 级通过需要同时满足：

1. 七个既有问题继续保持独立解释力；
2. 统一机制可以解释“关系如何持续、失衡、修复或退出”；
3. 婚姻不是必要条件，夫妻身份也不是充分条件；
4. TH2.1 / TH2.3 / TH2.4 / TH3.1 / TH3.2 / TH1.1 / TH1.3 边界可操作；
5. 不因单部作品新增第八问题或 TH2.2.x；
6. 能解释维持良好、缓慢磨损、严重失衡、修复失败与主动退出，而不是只解释“失败婚姻”。

## 三、七问独立性复核

### P1 承诺 vs P3 共同生活分配

不合并。

- P1：什么使双方把现在变成未来义务；
- P3：这些义务实际怎样被分配成钱、时间、家务和照料。

《米德尔马契》与《围城》都能证明：即使承诺形式相同，日常落实方式也可完全不同。

### P2 边界 vs P5 权力

不合并。

- P2 即使在平等关系中也成立：亲密需要决定“共享到哪里”；
- P5 只在谈判能力、资源、依赖或退出能力出现稳定不对称时成立。

《玩偶之家》两者都强，而《到灯塔去》可以在没有显性制度强制的情况下继续提供 P2 证据。

### P4 信任/背叛 vs P6 修复

不合并。

P4 解释损伤如何发生，P6 解释损伤之后发生什么。

```text
知道真相
≠ 承认责任
≠ 原谅
≠ 恢复信任
≠ 继续关系
```

### P6 修复 vs P7 继续/结束

不合并。

关系可能：

- 无法完全修复但继续；
- 修复部分伤害后仍结束；
- 原谅但不复合；
- 结束原关系后以新边界保持联系。

因此“能不能修”与“应不应该继续”是两个问题。

## 四、统一机制压力测试

### 机制链是否只适用于婚姻？

否。

只要关系出现：

```text
持续性承诺
+ 共享生活 / 资源
+ 稳定边界协商
+ 信任依赖
+ 真实退出成本
```

即使无法律婚姻，也可完整运行 TH2.2 机制。

### 是否所有婚姻都运行完整机制？

也否。

文学中婚姻可以只是：

- 结局；
- 人物背景；
- 家族联盟；
- 财产安排；
- 社会身份标签。

只有当两人持续关系如何运行成为稳定问题，才进入 TH2.2。

## 五、八组张力压力测试

八组张力均能在多部作品中独立出现：

```text
承诺 ↔ 可退出性
亲密 ↔ 自主
共享 ↔ 私人边界
平等 ↔ 分工
照料 ↔ 负担
信任 ↔ 监控
依赖 ↔ 支配
修复 ↔ 退出
```

它们不应升格为第二内部分类，因为同一作品往往同时跨越多组张力，而且张力与七核心问题高度交叉。

结论：

```text
SECOND_DIMENSION = NOT_JUSTIFIED
```

## 六、相邻主题边界测试

### TH2.1 ↔ TH2.2

高风险误判：有恋人、结婚、出轨、分手。

稳定规则：

```text
对象为何成为欲望中心、是否得到回应 → TH2.1
双方形成持续关系后如何共同生活 → TH2.2
```

《傲慢与偏见》是负向边界；《安娜·卡列尼娜》《包法利夫人》《霍乱时期的爱情》允许兼标，但必须分别写出两条独立问题。

### TH2.2 ↔ TH2.3

```text
两个人之间的承诺、分工、信任、权力、修复 → TH2.2
婚姻连接家族、血缘、财产、继承、姻亲位置 → TH2.3
```

《金锁记》《源氏物语》证明二者可同时存在，但不能互相替代。

### TH2.2 ↔ TH2.4

```text
伴侣如何一起承担育儿 → TH2.2 可进入
父母如何对待、塑造、控制或伤害孩子 → TH2.4
```

### TH2.2 ↔ TH3.1

```text
性别制度如何定义男女位置 → TH3.1
这种位置如何进入某段关系并改变劳动、资源、发言权和退出能力 → TH2.2
```

### TH2.2 ↔ TH3.2

```text
性规范、性身份、性同意和禁忌本身 → TH3.2
性亲密如何影响一段长期关系的信任、忠诚和边界 → TH2.2
```

### TH2.2 ↔ TH1.1 / TH1.3

- “关系中的我能保留多少自己”可属于 TH2.2；
- “我到底是谁”独立成为主题时进入 TH1.1；
- “关系结束后我与世界的连接怎样断裂”进入 TH1.3。

## 七、高风险误判清单

```text
有夫妻 / 情侣
≠ TH2.2

以结婚收尾
≠ TH2.2

发生婚外情
≠ TH2.2

有家庭冲突
≠ TH2.2

角色受性别制度压迫
≠ TH2.2

关系维持很久
≠ TH2.2

人物非常爱对方
≠ TH2.2
```

必须进一步证明：**持续关系本身如何组织双方行动、资源、边界、信任和退出。**

## 八、是否需要第八问题？

本轮没有发现七问无法容纳的稳定问题。

可能候选均可被已有结构吸收：

- 性亲密 → P2/P4/P5 + TH3.2 接口；
- 生育 → P3/P5 + TH2.4 接口；
- 疾病/照料 → P3/P5/P6；
- 远距离 → P1/P2/P4；
- 法律婚姻 → P1/P5/P7 + TH5 或 TH2.3 接口；
- 再婚/复合 → P6/P7。

因此：

```text
EIGHTH_PROBLEM = NOT_REQUIRED
TH2.2.x = NOT_REQUIRED
```
