# 首轮作品压力测试

本轮目的不是建立“失败婚姻书单”，而是检验七个问题能否同时解释关系的持续、共同生活、失衡、修复与结束。语料故意包含长期维持、照料、修复、破裂以及负向边界文本。

## V1 语料：15 部

### 骨架 9 部

| 作品 | 主要问题 | 结构功能 |
|---|---|---|
| 《玩偶之家》 | P2 / P3 / P4 / P5 / P7 | 经济秘密、角色不平等与主体独立集中爆发，直接测试退出阈值。 |
| 《米德尔马契》 | P1 / P2 / P3 / P5 / P6 / P7 | 婚姻错配、日常伦理、理解增长与关系重组，防止专题只由破裂定义。 |
| 《到灯塔去》 | P2 / P3 / P5 / P6 | 长期夫妻关系、情绪照料与依赖，提供非背叛型持续亲密模型。 |
| 《围城》 | P1 / P2 / P3 / P4 / P5 / P7 | 婚后琐事、角色期待、金钱与冲突如何持续磨损关系。 |
| 《安娜·卡列尼娜》 | P1 / P4 / P5 / P7 | 承诺、忠诚、婚外关系、社会评价与离开旧关系的代价。 |

### 边界测试 1 部

| 作品 | 边界判断 |
|---|---|
| 《傲慢与偏见》 | 婚姻是叙事终点，但作品主结构集中于相遇、判断、误解、重新认识与婚配选择，基本停在持续共同生活开始之前，因此不作为 TH2.2 核心。 |

## 七问题冻结判断

- **P1 / P3 保持分离**：持续义务的形成与日常资源分配是不同解释任务。
- **P2 / P5 保持分离**：自主边界可在无明显支配时存在；P5 处理结构性不对称。
- **P4 / P6 保持分离**：信任受损是破坏机制，P6 是损伤后的响应。
- **P6 / P7 保持分离**：能否修复与是否值得继续不是同一判断。
- **P5 严格限界**：性别制度本身归 TH3.1；家族、继承与姻亲制度本身归 TH2.3。
- **P7 严格限界**：TH2.2 只处理关系内部继续/结束的判断；结束后的孤独归 TH1.3。
- **P6 独立性通过**：虽然覆盖相对较薄，但《米德尔马契》《到灯塔去》《简·爱》《霍乱时期的爱情》提供了理解、调适、重新协商与重建等不同模型，足以保留。
- **未出现第八问题，也未出现稳定第二维。**
