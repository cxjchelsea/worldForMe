# 婚姻与亲密关系

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH2 亲密关系、家庭与成长 → **TH2.2 婚姻与亲密关系**

## L1｜专题定义与边界

本专题不是婚姻制度史，也不把出现夫妻、情侣、同居者或家庭的作品自动纳入。它研究的是：

> **当两个人把关系组织成具有持续性的共同生活后，承诺、边界、劳动与资源、信任、照料、权力、冲突、修复与退出如何共同决定这段关系能否继续，以及双方在其中能否仍然作为主体存在。**

这里的“亲密关系”不限于法律婚姻。未婚同居、长期伴侣、事实婚姻以及其他稳定共享生活形式，只要作品真正分析它们如何持续运作，都可进入 TH2.2。

### 纳入测试

如果拿掉“这段关系如何被持续经营、协商、损伤、修复、重建或结束”，作品的主要冲突或意义结构是否会发生根本变化？

- 会 → TH2.2 可能成立；
- 不会 → 夫妻/伴侣身份多半只是人物背景。

### 三层判断

```text
人物是夫妻 / 伴侣
→ 背景

作品展示两人共同生活
→ 开始进入 TH2.2

共同生活中的承诺、资源、边界、信任、权力与退出
持续改变双方行动能力和关系结构
→ 成熟 TH2.2 分析
```

## L3｜统一关系机制

```text
形成持续性承诺
→ 共享时间、空间与未来预期
→ 把关系落实为劳动、金钱、照料与角色分配
→ 在共享生活中不断协商“我”与“我们”的边界
→ 通过信息开放、忠诚与可预期性维持信任
→ 资源差异、依赖与退出能力沉淀为权力结构
→ 冲突、背叛、失职或外部压力暴露既有结构
→ 双方承认伤害、重新协商并改变行动，或拒绝修复
→ 继续、重建、重新定义或退出关系
↺ 新状态再次改变承诺、边界、资源与信任
```

核心不是“关系有没有矛盾”，而是：

> **一段亲密关系如何把感情转换成长期共同生活，又如何把长期共同生活反过来改造双方。**

详见 [[10 结构/03 持续亲密关系与作用机制|持续亲密关系与作用机制]]。

## L4｜稳定结构张力

当前 A 级版本保留八组高解释力张力：

| 张力 | 核心问题 |
|---|---|
| 承诺 ↔ 可退出性 | 关系越稳定，是否越难离开？ |
| 亲密 ↔ 自主 | “我们”是否吞没“我”？ |
| 共享 ↔ 私人边界 | 伴侣是否有权知道、参与和决定一切？ |
| 平等 ↔ 分工 | 分工是否建立在自由协商上，还是固化了不平等？ |
| 照料 ↔ 负担 | 照料何时是关系资源，何时成为单向义务？ |
| 信任 ↔ 监控 | 寻求安全感何时转化成控制？ |
| 依赖 ↔ 支配 | 相互依赖何时变成一方无法拒绝或离开？ |
| 修复 ↔ 退出 | 能修复是否意味着应该继续？ |

关键判断：

> **关系持续，不等于关系良好；关系结束，也不等于关系失败。**

文学真正值得比较的是：谁为“维持关系”承担代价，谁拥有重新定义关系的能力。

## L5｜跨时间、传统与形式比较

TH2.2 不把现代自由恋爱、一夫一妻、独立核心家庭当作默认标准。比较时统一追问：

1. 谁能够决定进入和退出关系？
2. 什么使关系获得社会、法律或共同体承认？
3. 谁承担家务、金钱、生育、照料与情绪劳动？
4. 双方分别保有多少财产、职业、空间与身体自主？
5. 忠诚、秘密与背叛在该传统中怎样定义？
6. 关系内部的不平等由什么资源制造？
7. 伤害如何被承认，什么算真正修复？
8. 继续、离开或重新结盟分别需要付出什么代价？

详见 [[10 结构/04 跨时间、传统与形式比较|跨时间、传统与形式比较]]。

## 与相邻主题的边界

### TH2.1 爱情与欲望 ↔ TH2.2 婚姻与亲密关系

```text
为什么偏偏是这个人？
我是否真正看见对方？
对方是否回应我的爱欲？
→ TH2.1

我们已经形成持续关系以后，
怎样承诺、分工、信任、照料、冲突、修复或离开？
→ TH2.2
```

**结婚不是 TH2.2 的充分条件，恋爱也不是 TH2.2 的必要条件。**

### TH2.2 ↔ TH2.3 家庭与家族

- 两个伴侣之间共同生活怎样运行 → TH2.2；
- 婚姻如何连接两个家族、配置继承、血缘、姻亲和代际位置 → TH2.3。

### TH2.2 ↔ TH2.4 亲子与代际

- “我们怎样一起承担育儿责任”可进入 TH2.2；
- “父母怎样塑造、控制、照料或伤害子女”进入 TH2.4。

### TH2.2 ↔ TH3.1 性别与身体

- 性别秩序本身怎样规定男女位置 → TH3.1；
- 性别分工如何在一段具体伴侣关系中制造资源、劳动和退出能力的不对称 → TH2.2。

### TH2.2 ↔ TH3.2 性、欲望与性规范

- 性欲、性行为、性身份、性禁忌和同意规范本身 → TH3.2；
- 性亲密如何改变伴侣间信任、边界、忠诚与权力 → TH2.2。

### TH2.2 ↔ TH1.1 / TH1.3

- 关系内部如何协商主体边界 → TH2.2；
- “我是谁、我能否成为自己”独立成为主问题 → TH1.1；
- 关系结束以后连接断裂与孤独经验 → TH1.3。

## 高风险误判

以下均不能自动进入 TH2.2：

```text
出现夫妻 / 情侣
≠ TH2.2

故事以结婚收尾
≠ TH2.2

发生婚外情
≠ TH2.2

家庭矛盾
≠ TH2.2

角色因为性别受到压迫
≠ TH2.2
```

必须进一步证明：**持续亲密关系本身的运行机制正在组织作品的主要问题。**
