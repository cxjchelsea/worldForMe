## 2. collection_tradition 的证据纪律

必须区分：

```text
collection attestation
story attestation
manuscript family
recension
print edition
translation layer
oral / written source layer
later reception
```

禁止：

- 因现代版本常见而断言早期手稿必有；
- 因故事具有“中东风格”就推定它属于集合；
- 把加朗、后期埃及印本或任一现代译本当作整个传统的唯一标准；
- 把两个版本故事相似自动解释为直接抄袭。

## 3. 阅读路线 A：先理解集合本身

```text
框架叙事
→ 早期手稿见证
→ 版本／recension 差异
→ story membership
→ 加朗转折
→ 印本与全球传播
```

适合第一次建立整体认识。

## 4. 阅读路线 B：追一个具体故事

```text
选择具体故事
→ 查最早可证 attestation
→ 查哪些 manuscript / recension 收录
→ 查何时进入翻译层
→ 查全球传播
→ 判断是否需要独立 story_tradition
```

这条路线特别适合《阿拉丁》《阿里巴巴》等成员归属复杂的故事。

## 5. 阅读路线 C：比较版本

```text
选两个具体版本／译本
→ 对比底本
→ 对比成员目录
→ 对比故事顺序／嵌套
→ 对比删改与新增
→ 对比面向的读者与文化功能
```

## 6. 本专题的长期成功标准

不是回答“真正的一千零一夜到底有哪1001个故事”，而是让系统能够回答：

> **某个故事在什么见证层进入这个集合、为什么今天会被视为《一千零一夜》的成员，以及不同版本之间的集合边界为什么不同。**
