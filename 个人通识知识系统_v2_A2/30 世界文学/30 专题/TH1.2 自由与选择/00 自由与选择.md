# 自由与选择

> 路径：世界文学 → TH 主题与人类问题 → TH1 自我、存在与生命 → **TH1.2 自由与选择**

## 专题定位

本专题不讨论抽象哲学上的“自由意志能否被证明”，也不把所有政治压迫、伦理判断或人生抉择都收进来。

它研究的是：**人在命运、欲望、关系、制度、资源、身体与不确定性的限制中，究竟还拥有什么行动空间；一个决定怎样成为“我的行动”，又为什么使我承担后果。**

最小判据：如果拿掉“可选范围、约束、决断、行动归属、不可逆后果或责任”后，作品的核心冲突仍基本成立，则一般不作为 TH1.2 核心。

## A级统一机制

```text
处境与可选范围
→ 约束与动机
→ 判断 / 犹豫 / 拒绝 / 决断
→ 行动或不行动
→ 承诺与不可逆性
→ 后果与责任
→ 承担 / 否认 / 补偿 / 再选择
```

更抽象地说：

> **可能性 → 约束 → 决断 → 行动 → 后果 → 责任 → 再选择。**

这不是线性公式：拒绝、延宕、沉默和不行动也可能改变后果，因此它们同样可能构成行动位置。

## 核心边界

- **TH1.1 自我认同与主体性**：TH1.1 问“我是谁、如何成为自己”；TH1.2 问“我能做什么、为什么这样做、这个行动是否属于我”。
- **TH1.5 意义与荒诞**：意义危机可以触发选择，但“世界有没有意义”不等于“行动是否属于我”。
- **TH5 权力、制度与秩序**：TH5 解释制度如何产生限制；TH1.2 解释人在限制中还剩什么能动性。
- **TH6 战争、暴力与创伤**：极端伤害本身归 TH6；极端处境怎样扭曲选择空间与责任判断归 TH1.2。
- **TH8 信仰、伦理与超越**：TH8 追问什么是应当、善恶与义务；TH1.2 追问主体是否真正作出选择并承担后果。
