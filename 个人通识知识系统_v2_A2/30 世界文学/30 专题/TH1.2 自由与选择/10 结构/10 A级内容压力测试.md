# TH1.2 A级内容压力测试

## 目标

检验六个核心问题是否足以覆盖自由、选择、拒绝、行动、责任与受限能动性，并与 TH1.1、TH1.5、TH5、TH6、TH8 保持稳定边界。

## 统一检验链

```text
处境与可选范围
→ 约束与动机
→ 判断 / 犹豫 / 拒绝 / 决断
→ 行动或不行动
→ 承诺与不可逆性
→ 后果与责任
→ 承担 / 否认 / 补偿 / 再选择
```

## 四条防扩张规则

1. **人物做了重大决定 ≠ TH1.2。** 必须追问可选范围、约束、行动归属与责任。
2. **受到压迫 ≠ TH1.2。** 压迫机制本身优先 TH5；约束中的行动空间才进入 TH1.2。
3. **反抗 ≠ 自由。** 反抗也可能是冲动、强迫、模仿、自毁或被他者操纵。
4. **没有行动 ≠ 没有选择。** 延宕、沉默、逃避和拒绝都可能改变后果。

## 六问稳定性

- P1 自由是否可能：稳定。
- P2 选择如何发生：稳定。
- P3 犹豫、拒绝与不选择：不可并入 P2/P4。
- P4 行动、承诺与不可逆性：稳定。
- P5 责任、罪责与后果：不能由 TH8 替代；这里关注行动归属与承担。
- P6 受限处境中的能动性与反抗：稳定，是与 TH5/TH6 的关键接口。

没有出现必须新增第七问的证据。

## 边界结论

- TH1.1：选择怎样塑造“我是谁”可交叉；TH1.2 仍以行动归属为中心。
- TH1.5：意义危机可触发选择，但意义问题本身不归 TH1.2。
- TH5：制度解释约束来源；TH1.2 解释约束中的能动性。
- TH6：伤害/创伤归 TH6；强迫如何改变责任判断归 TH1.2。
- TH8：善恶/义务归 TH8；主体是否选择并承担后果归 TH1.2。
