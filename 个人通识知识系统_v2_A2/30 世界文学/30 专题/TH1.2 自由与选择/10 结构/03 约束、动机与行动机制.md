# 约束、动机与行动机制

TH1.2 不把自由理解成“完全没有约束”，而研究**人在具体约束中拥有怎样的有效选择空间，以及行动为什么仍然能够归属于主体。**

## 统一机制

```text
处境与可选范围
→ 外部 / 内部约束
→ 欲望、理由与价值冲突
→ 判断 / 犹豫 / 拒绝 / 决断
→ 行动或不行动
→ 承诺与不可逆性
→ 后果、归责与责任
→ 承担 / 否认 / 补偿 / 再选择
```

### 1. 可选范围不是客观选项数量

真正重要的是人物**实际能够识别、承担和实施**的选项。法律禁止、贫困、暴力威胁、家庭责任、身体状态、信息缺失和内化规范都会压缩有效选择空间。

因此“理论上可以离开”不等于现实中拥有可行的离开选项。

### 2. 约束不会自动取消能动性

约束可来自：
- 命运、预言与偶然；
- 法律、组织与国家制度；
- 家庭、共同体与身份期待；
- 阶级、资源与生计；
- 战争、暴力与强迫；
- 身体、疾病、心理与习惯；
- 主体自身已经作出的旧承诺。

分析重点不是“有没有约束”，而是：**约束压缩到什么程度？还剩哪些可以归属于主体的行动？**

### 3. 动机不等于理由，理由也不等于正当性

人物行动可能来自欲望、爱、恐惧、羞耻、利益、生存、义务、信仰、野心或反抗。文学常把“我为什么想这样做”“我怎样为自己解释”“这个理由是否足以承担后果”拆开。

### 4. 犹豫、拒绝和不行动具有行动效力

延宕、沉默、逃避、拒绝签字、拒绝服从、拒绝承担都可能改变事件。因此 P3 必须独立保留：**没有积极行动并不意味着没有选择位置。**

### 5. 决断把可能性变成主体行动

一个念头、冲动或预言只有通过某种接受、认领或实施，才真正成为行动。决断机制可以是理性权衡、冲动、习惯、模仿、自我辩护、偶然触发或他者推动。

### 6. 承诺与不可逆性

某些行动一旦公开、实施或伤害他人，就无法恢复到选择之前。承诺、犯罪、背叛、赴死、公开反抗等都把主体绑定到后续责任中。

### 7. 责任不能只看结果

责任判断至少要区分：
- 主体知道什么；
- 有哪些可选项；
- 是否受强迫；
- 是否具有行动能力；
- 是否预见后果；
- 是否主动认领行为；
- 事后是否承担、否认或转移责任。

这使“结果造成伤害”“主体有罪”“主体应承担多少责任”不再自动等同。

### 8. 再选择

行动之后仍可能出现承认、忏悔、补偿、坚持、逃避、重新解释与再次选择。自由不是一次性的“关键决定”，而可能是连续的行动链。

## 八组稳定张力

1. 自由 ↔ 决定论
2. 可选项 ↔ 强迫
3. 理由 ↔ 冲动
4. 犹豫 ↔ 决断
5. 拒绝 ↔ 服从
6. 行动 ↔ 不行动
7. 自主 ↔ 责任
8. 可撤回 ↔ 不可逆

这些是比较结构，不是 `TH1.2.x` 子坐标。

## 与相邻专题的机制边界

- 制度为什么限制行动 → TH5；限制之中人物还剩什么选择 → TH1.2。
- 什么是善恶、义务 → TH8；人物是否选择并承担行动 → TH1.2。
- 暴力如何伤害与留下创伤 → TH6；强迫怎样改变选择和责任 → TH1.2。
- 选择怎样改变“我是谁” → 可与 TH1.1 交叉，但两条机制仍独立。
