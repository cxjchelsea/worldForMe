# 权力、制度与秩序

> 路径：世界文学 → 作品坐标系统 → TH 主题 → **TH5 权力、制度与秩序**

## 专题定位

本专题研究**社会秩序如何获得合法性，规则怎样被制度化并进入人物生活，国家、法律、官僚、学校、宗教组织、军队、监狱、专业机构等如何通过分类、程序、监督、奖惩和强制持续运作，以及人物如何服从、利用、绕开、协商、反抗或重建这种秩序**。

纳入测试：如果拿掉制度化权力及其规则、程序、角色和执行机制，作品的核心冲突是否会发生根本变化？若不会，一般不作为 TH5 核心。

TH5 的目标不是建立“国家 / 法律 / 警察 / 暴君 / 监狱”题材表，而是理解一条关系链：

```text
合法性来源
→ 规则与分类
→ 机构 / 程序 / 角色
→ 监督、规训与自我调整
→ 奖励、排除与强制
→ 服从 / 绕行 / 协商 / 反抗
→ 改革、崩解或新秩序
```

换句话说，本专题真正追问的是：

> **一套秩序怎样从“有人有权命令”变成“即使没有统治者亲自出现，人们仍然按照规则行动”。**

## 七个核心机制

### 1. 合法性形成

权力需要说明“为什么有权要求服从”。传统、宗教、法律、革命、安全、专业知识、多数和公共利益都可能成为合法性来源。

### 2. 规则与分类

抽象权力通过法律、资格、身份、档案、标准和分类把复杂生活转成制度可处理对象。

### 3. 机构、程序与角色

角色分工、审批、档案、层级和责任分散使权力脱离具体个人而获得持续性。

### 4. 监督、规训与正常化

监视、审查、教育、宣传、考核和横向监督让人物预判规则，逐渐从外部服从转向自我调整。

### 5. 权利、排除与强制

制度不仅禁止，也分配保护、资格、申诉渠道和风险；当日常规则失效时，处罚、监禁、驱逐和例外权力暴露强制边界。

### 6. 服从、利用与反抗

人物并非只有服从或革命两种选择，还可能利用规则、绕开程序、申诉、协商、不合作、退出或组织反抗。

### 7. 制度再生产与变迁

学校、家庭、组织惯例、档案、法律与公共叙事让制度持续复制；改革、危机、运动和革命则可能重构秩序，但也可能只更换掌权者。

详见：[[10 结构/03 权力与制度运行机制|权力与制度运行机制]]。

## 八组稳定结构张力

TH5 不继续拆坐标，但可以长期围绕以下张力比较作品：

- 合法性 ↔ 强制
- 法律 ↔ 正义
- 人治 ↔ 非人格制度
- 可见权力 ↔ 匿名权力
- 保护 ↔ 控制
- 正常化 ↔ 偏离
- 程序 ↔ 例外
- 反抗 ↔ 再生产

这些张力不是新分类，而是专题内部第二知识维度。

## 跨传统比较框架

TH5 不默认现代民族国家是唯一制度模板。跨传统比较时统一追问：

1. 合法性从哪里来？
2. 谁制定、解释和执行规则？
3. 权力通过什么机构和程序进入日常？
4. 谁拥有申诉、谈判和退出能力？
5. 什么时候从程序转向强制或例外？
6. 变革究竟改变了掌权者、规则，还是整个权力机制？

可以据此比较：

- 古典城邦、神圣法与共同体秩序；
- 王权、等级、宗教与前现代司法；
- 帝国与官僚治理；
- 殖民统治与帝国行政；
- 现代法治国家与公民资格；
- 现代官僚社会与组织化生活；
- 极权、党国与高度动员型秩序；
- 革命、独立与新秩序重建；
- 福利、专业治理与技术制度；
- 数字监控与算法化治理。

详见：[[10 结构/04 跨传统比较|跨传统比较]]。

## 作品群与阅读路线

当前基础路线按理解机制递进：

```text
《安提戈涅》
合法性、法律与正义
        ↓
《审判》 / 《城堡》
匿名制度、程序与责任分散
        ↓
《美丽新世界》 / 《1984》
规训、欲望、监控与自我审查
        ↓
《使女的故事》
制度进入身体、家庭与身份
        ↓
《第二十二条军规》
程序互锁与系统性荒谬
        ↓
《等待野蛮人》
殖民分类、安全与例外强制
        ↓
《动物农场》
革命、制度再生产与新秩序
```

路线目标不是完成书单，而是获得一种能力：**看到作品中的权力时，能判断它究竟来自个人威势、社会规范，还是已经形成可重复执行的制度机制。**

详见：[[10 结构/05 阅读路线|阅读路线]]。

## 与其他 TH 专题的接口

### TH1.2 自由与选择

TH1.2 追问主体怎样理解和行使自由；TH5 追问规则、制度和组织怎样预先规定可行动范围。

### TH3 身份与归属

TH3 研究身份分类及归属本身；TH5 研究国家和组织怎样登记、认证、执行或惩罚这些分类。

### TH4 社会、阶级与劳动

TH4 关注资源占有、劳动义务、收益风险与社会位置；TH5 关注组织通过什么规则、资格和程序要求人物行动。

```text
工人必须出售劳动、缺乏议价能力 → TH4
工厂/国家通过规章、许可和惩罚规定其行动 → TH5
```

### TH6 战争、暴力与创伤

暴力造成的伤害和创伤进入 TH6；谁被授权使用强制、通过何种程序合法化暴力进入 TH5。

### TH7 历史、记忆与时间

记忆如何形成进入 TH7；国家如何通过档案、教育、审查和纪念制度规定公共记忆进入 TH5。

### TH8 信仰、伦理与超越

“什么是正义、责任和善”进入 TH8；制度如何把某种价值写入法律和规则并强制执行进入 TH5。

## 作品分析的最小模板

判断一部作品是否值得进入 TH5，可以直接回答七问：

1. 谁或什么机构能够制定、解释和执行规则？
2. 这种权力为什么被认为有权要求服从？
3. 它通过哪些分类、法律、程序和角色进入人物生活？
4. 人物怎样被监督、训练、奖励、排除或惩罚？
5. 制度何时从日常程序转向强制或例外？
6. 人物是在服从、利用、绕开、协商还是反抗？
7. 最终改变的是执行者、具体规则，还是整套秩序机制？

如果作品只能说明“有人有权势 / 社会有规范 / 发生了暴力”，却无法形成制度化权力链，一般不应把 TH5 作为核心主题。

## 关键边界

- **TH1.2 自由与选择**：个人如何选择归 TH1.2；制度为何限制其可行动范围归 TH5。
- **TH3**：身份分类及归属本身归 TH3；国家、法律和制度如何实施、认证或惩罚这些分类归 TH5。
- **TH4**：阶级、贫富、劳动与资源关系归 TH4；规则、组织和制度化权力归 TH5。
- **TH6 战争、暴力与创伤**：暴力、战争和创伤本身归 TH6；惩罚、警察、监狱、例外状态作为制度机制归 TH5。
- **TH7 历史、记忆与时间**：历史如何被记忆归 TH7；国家如何审查、改写和规定公共记忆可兼入 TH5。
- **TH8 信仰、伦理与超越**：正义是否道德、责任为何成立归 TH8；法律与制度如何定义合法/非法归 TH5。

## 冻结结论

TH5 保持叶节点；不新增 `TH5.x`，不建立稳定第二坐标维度。复杂度由 L1–L6 知识地图、六个核心问题、七个作用机制和八组结构张力承接。
