# 冻结终审

## 结构结论

TH5 保持一级叶节点，不建立 `TH5.x`。

六个问题全部保留：

1. P1 权力与合法性
2. P2 法律、正义、权利与罪
3. P3 官僚与程序
4. P4 监控、审查与规训
5. P5 惩罚、例外与强制
6. P6 反抗、革命与秩序重建

## 关键结论

- P4 / P5：独立。前者解释服从如何在日常中被制造，后者解释违抗后制度如何强制执行。
- P6 / TH6：独立。制度变革与合法性重建归 TH5；革命暴力和创伤归 TH6。
- P2 / TH8：独立。法律合法性归 TH5，道德正义归 TH8。
- P3 / TH1.5：独立。官僚程序作为制度支配归 TH5；一般重复、延宕与意义耗损归 TH1.5。
