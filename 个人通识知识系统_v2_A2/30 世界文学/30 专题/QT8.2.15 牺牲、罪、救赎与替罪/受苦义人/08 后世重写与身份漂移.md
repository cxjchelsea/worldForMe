# 后世重写与身份漂移

## 1. 本页职责

只记录“受苦义人”角色模型如何被后世明确调用、改写或反转，不建立完整苦难文学史。

## 2. 从来源角色到现代重写的主要漂移方向

```text
古代智慧／宗教文本中的义人
→ 现代家庭与社会生活中的无辜受难者
→ 对神义问题的怀疑者
→ 战争、迁徙、制度或随机灾难中的受害者
→ 把“解释苦难”本身变成被批判对象的角色
```

这些只是可观察路径；每个后世实例仍需单独证明与 Job／受苦义人模型的关系。

## 3. 当前核证的三个压力测试实例

### 3.1 Joseph Roth《Job / Hiob: Roman eines einfachen Mannes》

Roth 把约伯式受苦者重新编码为 Mendel Singer：一位东欧犹太教师，在迁徙、家庭破裂、死亡与信仰危机中承受连续苦难。

保留：

- 虔敬／正直身份；
- 连续且难以解释的苦难；
- 信仰与报偿秩序危机；
- 最终反转／恢复。

改变：

- 从古代智慧文本进入现代犹太移民经验；
- 苦难来源更多通过家庭、疾病、战争与迁徙实现；
- “约伯”由来源人物转化为现代普通人的文化角色模型。

### 3.2 Archibald MacLeish《J.B.》

《J.B.》明确把《约伯记》搬入现代戏剧环境，以 J.B. 作为 Job 的现代对应者。它保留无辜受难、神圣赌约、解释危机等关键结构，同时把结局答案重新组织为现代人的生存与爱。

这说明 archetype 可在：

```text
source figure
→ named modern stand-in
→ contemporary ethical / existential reframing
```

中保持可识别性。

### 3.3 Muriel Spark《The Only Problem》

该小说不是简单把 Harvey Gotham 写成“新版约伯”，而是让主角直接研究《约伯记》，同时让现实事件与 Job 问题形成平行与错位。

它测试的是另一种调用方式：

```text
角色模型
+
解释传统
+
元叙事式显式引用
```

因此它更适合记录为 `explicit_reference`，而不是强行归为直接改编。

## 4. archetype 的身份漂移可以拆成五个维度

| 维度 | 来源层 | 后世可能变化 |
|---|---|---|
| 正直的定义 | 虔敬／无明显罪责 | 普通人的伦理正直、无辜身份 |
| 苦难来源 | 神圣许可／不可解释秩序 | 战争、迁徙、制度、家庭、随机事件 |
| 解释者 | 朋友、智慧话语、宗教秩序 | 家人、学者、社会制度、意识形态 |
| 回应方式 | 哀诉、抗议、顺服、辩论 | 怀疑、拒绝、反讽、继续生活 |
| 结局 | 恢复或秩序重申 | 恢复、开放、拒绝和解、无意义化 |

## 5. 收录门槛

后世实例至少要能说明：

```text
preserved_features
modified_features
relation_type
evidence_level
```

若只能说“这个角色也很惨”，不进入正式 `qt82_work_reference`。

## 6. Pilot B 当前观察

三个现代实例显示，`受苦义人` 并不依赖同一具体剧情。可迁移的是：

```text
角色的伦理／虔敬资格
+
不成比例苦难
+
解释秩序危机
+
角色对不透明秩序的回应
```

因此 archetype 的跨时代稳定单位更接近**角色功能组合**，而不是完整事件顺序；这支持 `core_functions / variable_features` 模型继续保留。
