# 作品实例

## 1. 来源级实例

### 《约伯记》

- `work_role`: `defining_text`
- `preserved_features`: 正直身份、重大苦难、报偿解释危机、辩论／抗议、认识限度
- `source_status`: `reference_topic`

### `Ludlul bēl nēmeqi`

- `work_role`: `early_external_instance / defining_comparison`
- `preserved_features`: 虔敬身份、社会与身体苦难、解释失败、神明拯救／恢复
- `source_status`: `external_source_pending_qt81_topic`

来源级实例继续进入 `qt82_source_reference`，不与后世作品记录混用。

## 2. 已核证后世作品

### Joseph Roth《Job / Hiob: Roman eines einfachen Mannes》

现代小说把约伯式角色模型重新落到 Mendel Singer 的现代犹太家庭与移民经验中。

```yaml
relation_type: direct_adaptation
evidence_level: documented
```

保留：虔敬者身份、连续苦难、信仰危机、最终反转。

改变：人物、时代、地理与社会苦难机制全部现代化。

### Archibald MacLeish《J.B.》

作品公开以现代舞台重述《约伯记》，J.B. 明确承担 Job 的现代对应角色。

```yaml
relation_type: direct_adaptation
evidence_level: documented
```

保留：正直受难者、神圣赌约、苦难解释危机。

改变：现代戏剧／马戏场景、人物关系和最终回答方式。

### Muriel Spark《The Only Problem》

主角 Harvey Gotham 直接研究《约伯记》与“苦难问题”，小说又让现实事件与 Job 形成平行、偏移与解释互动。

```yaml
relation_type: explicit_reference
evidence_level: documented
```

该实例用于证明：archetype 的后世使用可以通过“明确解释／元叙事调用”发生，而不必始终是直接角色复制。

## 3. 为什么只收这三部

这三部构成三种清晰证据：

```text
Roth《Job》
→ 现代小说直接改写

MacLeish《J.B.》
→ 现代戏剧直接改写

Spark《The Only Problem》
→ 显式引用 + 元叙事重组
```

它们的关系都有公开资料明确支持，因此比“这个人物看起来也像约伯”的弱类比更适合作为 Pilot 数据。

正式作品实例使用共享：

```yaml

```

当前三部作品在母库中均未核证到唯一主作品节点，因此 `canonical_work: null`，不自行创建重复主节点。

若同一作品未来还需记录 `structural_inheritance`、`motif_inversion` 等第二种关系，应新增另一条 work reference，而不是在一条记录里合并多个 `relation_type`。
