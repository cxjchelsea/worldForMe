# CN1.2.1 Coverage Review V1

## 结论

`PASS / STAGE_FREEZE_CANDIDATE`

CN1.2.1 已完成首轮 coverage review。当前专题不追求穷尽全部特洛伊接受史，而以“核心边界稳定、主要见证与转折覆盖、CN2 接口可用、证据不确定性明确、足以服务当前阅读”为冻结标准。

---

# 1. 核心边界检查

## PASS

当前专题稳定区分：

- 特洛伊故事循环 ≠ 《伊利亚特》；
- 特洛伊循环 ≠ 阿特柔斯家族传统；
- 《奥德赛》作为归乡分支进入，但不等于整个 nostos 世界；
- 《埃涅阿斯纪》作为特洛伊幸存者—罗马继承重构进入，而非简单续集；
- 失传循环史诗只作为可证 textual witness，不伪装成完整现存作品。

判断：边界稳定，可冻结。

---

# 2. 叙事区段与文本见证覆盖

## PASS

当前七个中央作品锚点已经覆盖七个关键认知位置：

1. 战争前因与希腊出征；
2. 特洛伊战争核心；
3. 战争末期与城陷准备；
4. 希腊英雄归乡；
5. 阿伽门农归乡与阿特柔斯家族交叉；
6. 特洛伊陷落与战败者；
7. 特洛伊幸存者—罗马继承。

失传史诗循环作为 witness 层继续承担《伊利亚特》未覆盖区段的结构补全，不要求为每部失传史诗建立中央 work。

判断：主要区段与关键文本角色均已覆盖。

---

# 3. chronology 与 branch 模型

## PASS

特洛伊专题证明 chronology 对某些 narrative_cycle 非常重要：

```text
战争前因
→ 战争核心
→ 战争末期
→ 城陷
→ 归乡
→ 幸存者后续
```

但 chronology 只是一种强组织维度，不能被提升为所有 CN1.2 的统一骨架。

同时，专题中已经存在多个可识别 branch：归乡、战败者、阿特柔斯交叉、埃涅阿斯—罗马继承等。

判断：chronology / branch 能力均已验证。

# 4. 人物与叙事结构变体

## PASS

阿喀琉斯、奥德修斯、海伦、赫克托耳、阿伽门农、菲罗克忒忒斯、埃涅阿斯等人物已经被用于观察：

- 同一人物在不同文本中的叙事中心性；
- 道德评价与政治功能变化；
- 胜者／败者视角转换；
- 英雄功能如何被不同文类重组。

当前无需建立独立人物百科或统一 canonical identity 层。

# 5. 后世生命覆盖

## PASS_FOR_CURRENT_NEED

现阶段以《埃涅阿斯纪》承担最重要的跨语言、跨政治语境重构验证，已经足以证明：

> CN1.2 必须记录一个传统如何在后来的语言、共同体、文类和政治环境中获得新功能。

中世纪和现代特洛伊改写尚未系统穷尽，但这属于未来接受史扩展，不构成 stage freeze 的阻塞项。

未来只有在真实阅读反复需要某一接受史分支时才通过 reopen gate 扩展。
