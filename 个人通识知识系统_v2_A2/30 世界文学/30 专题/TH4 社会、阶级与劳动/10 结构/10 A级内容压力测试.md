# TH4 A级内容压力测试

## 一、测试目的

本测试不再验证“TH4 为什么是一个合理的叶节点”，而验证升级后的 L1–L6 知识地图是否真的具备解释力。

重点检查五件事：

1. **解释覆盖**：不同社会结构中的作品能否进入“资源 → 位置 → 机会 → 劳动/依赖 → 可见性 → 流动/再生产 → 行动”机制链。
2. **比较能力**：八组稳定张力是否能够让不同作品发生有效横向比较。
3. **边界稳定**：不会因为作品出现财富、职业、贫困、土地等元素就误判为 TH4 核心。
4. **跨传统能力**：框架不能默认十九世纪欧洲工资劳动是唯一模型。
5. **抗拆分能力**：遇到新作品时优先扩充机制解释，而不是继续新增 `TH4.x` 坐标。

## 二、验收标准

- **通过**：核心作品能够被五大机制解释，且主要差异可由现有张力承接。
- **边界通过**：邻界作品能够被判定为“次要命中 / 非核心”，不发生过度吸纳。
- **需修订**：出现稳定、跨多部作品的重要机制，而现有框架只能勉强容纳。
- **需拆分**：只有当大量作品形成稳定、互斥、可独立组织的第二分类维度时，才考虑新增坐标。此次测试默认不以此为目标。

## 四、六个核心问题覆盖结果

现有六问仍然成立，没有出现必须新增第七问的稳定缺口。

| 核心问题 | 压力测试结果 | 说明 |
|---|---|---|
| P1 阶级位置与生活机会 | 通过 | 几乎所有核心样本都能稳定使用，是 TH4 的入口问题。 |
| P2 贫困、财富与债务 | 通过 | 对《盖茨比》《包法利夫人》《愤怒的葡萄》等尤其有效。 |
| P3 劳动如何组织时间、身体与价值 | 通过 | 《艰难时世》《萌芽》《变形记》《骆驼祥子》证明解释力充分。 |
| P4 财产、资本与雇佣关系 | **通过但需扩义** | 标题可保留，但内容必须显式覆盖土地占有、租佃、债役、强制劳动、身份性劳动义务、国家配置等非标准雇佣关系。 |
| P5 社会流动 | 通过 | 能有效区分收入变化、生活方式变化、社会承认与结构开放。 |
| P6 空间排斥 | 通过 | 城市中心/边缘、住宅、社交空间、迁移空间都能稳定承接。 |

## 五、测试发现的唯一结构性缺口

### 缺口：现有劳动/财产模型仍带有“自由工资劳动”默认值

《活着》《白老虎》《柏青哥》以及殖民地、土地社会类作品说明：

```text
谁控制生产资源
≠ 一定表现为资本家拥有工厂

谁必须劳动
≠ 一定表现为自由劳动者出售劳动力
```

文学中的依赖关系还可能来自：

- 土地占有与租佃；
- 农奴、奴隶、契约劳工等非自由劳动；
- 债役与高额债务；
- 种姓、户籍、殖民身份等把人物固定在特定劳动位置的制度性约束；
- 家庭内部无酬劳动义务；
- 国家、集体或单位对资源、职业和生活资料的配置。

这不是新的 TH4 子节点，而是 **P4 与“劳动组织生活”机制需要补足的跨传统解释范围**。

## 六、是否需要新增 TH4.x

结论：**不需要。**

15 部作品没有形成必须拆分为稳定第二坐标维度的证据。

目前所有差异仍可被以下两层承接：

```text
TH4 统一坐标
↓
五大机制
↓
八组结构张力 + 六个核心问题
```

例如：

- 工厂工人、车夫、农民、服务员不是不同坐标，而是不同劳动组织方式；
- 地主制、工业资本主义、殖民劳动、社会主义重组不是不同主题坐标，而是不同历史生产与分配机制；
- 阶级与种族/性别/殖民身份交叉时，应与 TH3 等兼标，而不是把交叉身份吸收到 TH4 内部继续分叉。

因此“坐标停止向下拆分以后，由专题知识地图接管复杂度”的原则通过压力测试。

## 七、A 级验收结论

### 结论：**通过，但需完成一项小修订后正式标记为 A。**

TH4 已经满足成熟知识地图的主要要求：

- 有稳定边界，而非题材词表；
- 有六个核心问题；
- 有可重复使用的作用机制；
- 有稳定张力用于横向比较；
- 可以跨越工业资本主义、土地社会、殖民/迁移社会与社会主义重组；
- 能正确拒绝《便利店人间》《百年孤独》等“局部出现相关元素但并非核心”的过度吸纳；
- 遇到新现象时无需继续新增 `TH4.x`。

唯一必须修订的是：**把 P4 与劳动机制中的生产关系从“资本—雇佣”显式扩展到更普遍的“资源控制—劳动义务—收益/风险分配”模型。**

完成该修订后，TH4 可正式由 C 级可靠骨架升级为 **A 级成熟主题知识地图**，并作为 TH5、TH8、TH3 后续建设的内容模板。
