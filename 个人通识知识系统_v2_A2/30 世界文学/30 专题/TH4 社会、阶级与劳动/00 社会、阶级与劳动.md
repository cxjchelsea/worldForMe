# 社会、阶级与劳动

> 路径：世界文学 → 作品坐标系统 → TH 主题 → **TH4 社会、阶级与劳动**

## 专题定位

本专题研究**社会如何通过阶级位置、财富与贫困、劳动分工、财产与资本、上升通道以及空间排斥，把人物放进不同的生活机会之中，并使这种社会位置被继承、挑战、跨越或重新生产**。

纳入测试：如果拿掉人物所处的阶级、经济和劳动结构，作品中的核心冲突、选择或命运是否会发生根本变化？若不会，一般不作为本专题核心。

TH4 的目标不是建立“穷人 / 富人 / 工人 / 地主”等人物标签表，而是理解一套关系：

```text
资源与出身
→ 社会位置
→ 机会结构
→ 劳动与依赖关系
→ 日常生活与阶级可见性
→ 流动 / 坠落 / 再生产
→ 竞争、互助、团结或反抗
```

换句话说，本专题真正追问的是：

> **社会结构怎样进入一个人的时间、身体、住房、职业、婚姻、尊严、欲望与人生可能性。**

## 五个核心机制

### 1. 社会位置形成

出身、财产、教育、职业、社会关系以及其他制度化身份共同决定人物可进入的工作、婚姻、学校和空间。

核心问题不是“人物属于什么阶级”，而是：**哪些门向他开放，哪些门关闭，谁控制这些门。**

### 2. 劳动组织生活

劳动同时分配收入、时间、身体消耗、技能价值与依赖程度。因此职业不是人物背景，而可能直接塑造尊严、家庭关系、自我理解与行动能力。

### 3. 阶级再生产与社会流动

继承、教育、婚姻、职业门槛、住房、关系网络和风险承受能力使优势跨代延续；教育、迁移、职业、婚姻、资本积累等则提供不同程度的流动机会。

必须始终区分：

> **一个人物成功上升，不等于社会结构已经开放。**

### 4. 阶级的日常可见性

住房、城市空间、口音、礼仪、服饰、食物、身体、休闲和消费，把抽象社会位置变成文学中可以被看见、听见和感受到的差异。

### 5. 共同处境与集体行动

共同处境可能产生竞争、区分、服从、互助、团结或组织化反抗。成熟的 TH4 分析不仅观察人物如何被结构塑造，也观察他们何时把私人困境理解为共同问题。

详见：[[10 结构/03 社会阶级与劳动机制|社会阶级与劳动机制]]。

## 八组稳定结构张力

TH4 不继续拆坐标，但可以长期围绕以下张力比较作品：

- 身份等级 ↔ 经济阶级
- 尊严 ↔ 异化
- 流动 ↔ 再生产
- 财富 ↔ 社会承认
- 个人竞争 ↔ 集体团结
- 可见阶级 ↔ 隐形特权
- 生存劳动 ↔ 照料劳动
- 稳定生活 ↔ 不稳定与风险转移

这些张力不是新分类，而是帮助不同作品彼此发生关系的第二知识维度。

## 跨传统比较框架

TH4 不默认“十九世纪欧洲工业社会”是所有阶级问题的模板。比较不同文学传统时，统一追问五件事：

1. 谁控制核心资源？
2. 谁承担主要劳动和风险？
3. 社会位置怎样传给下一代？
4. 阶级怎样在日常生活中变得可见？
5. 改变位置的真实通道是什么？

在此框架下，可以比较：

- 前现代身份与土地秩序；
- 十九世纪城市与工业资本主义；
- 殖民地、种植园与资源开采经济；
- 农民社会与城乡迁移；
- 革命、社会主义与阶级重组；
- 福利社会、白领化与中产生活；
- 全球化、迁移与不稳定劳动。

详见：[[10 结构/04 跨传统比较|跨传统比较]]。

路线的目标不是完成书单，而是逐步获得一种能力：**看到一部作品时，能够重建人物所处的资源—位置—机会—劳动—流动关系。**

## 与其他 TH 专题的接口

### TH2.3 家庭与家族

家庭财产、继承和婚姻首先可能是家庭关系问题；当它们进一步决定人物在社会中的资源、身份和流动机会时，进入 TH4。

### TH3 身份与归属

性别、种族、族群等身份可能与阶级高度交叉，但不要把交叉误认为同一主题：

- “因为种族分类而被排除” → TH3.3；
- “因为资源、劳动位置和财产关系而处于不同生活机会” → TH4；
- 两者共同决定命运 → 兼标并分别分析机制。

### TH5 权力、制度与秩序

TH4 关注资源、劳动与社会位置；TH5 关注国家、法律、组织和制度性权威如何制定、执行和维持规则。

例如：

```text
工人依赖工资、缺乏议价能力 → TH4
国家禁止罢工、警察镇压工人 → TH5
```

### TH1.2 自由与选择

TH1.2 追问主体如何理解与行使自由；TH4 追问社会经济条件怎样预先缩窄可供选择的集合。

## 作品分析的最小模板

判断一部作品是否值得进入 TH4，可以直接回答七问：

1. 人物拥有什么、缺少什么资源？
2. 这些资源把他放在什么社会位置？
3. 这个位置开放或关闭了哪些机会？
4. 他通过什么劳动和依赖关系维持生活？
5. 阶级差异怎样在空间、语言、身体和消费中变得可见？
6. 他试图通过什么路径维持、上升或逃离？
7. 结果是流动、坠落、再生产，还是形成共同处境与集体行动？

如果作品只能说明“人物很穷 / 很富 / 有一份工作”，却无法形成这条机制链，一般不应把 TH4 作为核心主题。

## 关键边界

- **TH2.3 家庭与家族**：家庭财产与继承本身归 TH2.3；这些资源决定更广泛阶级位置时进入 TH4。
- **TH3.3 种族与族群**：种族化边界归 TH3.3；阶级、贫富与劳动关系归 TH4。
- **TH5 权力、制度与秩序**：国家与制度权力本身归 TH5；经济社会位置和劳动组织归 TH4。
- **TH1.2 自由与选择**：主体如何选择归 TH1.2；阶级条件如何缩窄选择集合归 TH4。

## 冻结结论

TH4 保持叶节点；不新增 `TH4.x`，不建立新的坐标层级。

但“冻结坐标”不等于“冻结知识”。后续扩展应继续发生在：

- 机制解释；
- 稳定结构张力；
- 跨传统比较；
- 作品群；
- 阅读路线；
- 与真实作品实体的投影关系。
