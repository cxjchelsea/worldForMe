# 财产、资本与雇佣关系如何制造依赖与剥削

关注**谁控制生产与生活所需的核心资源，谁因此承担劳动义务，以及劳动成果、风险与收益怎样被分配**。

“财产、资本与雇佣关系”是现代文学中最常见的一组表现，但 P4 不限于自由工资劳动。比较不同历史与地域传统时，也包括：

- 土地占有、租佃、地租与佃农依赖；
- 奴隶、农奴、契约劳工、债役等非自由劳动关系；
- 殖民身份、种姓、户籍等制度性身份对劳动位置的锁定；
- 家庭内部无酬劳动与由财产依赖形成的服从；
- 国家、集体、单位等对土地、职业、住房或生活资料的配置；
- 工厂、企业、工资与标准雇佣关系中的资本—劳动不对称。

因此 P4 更一般的分析式是：

```text
资源控制方式
→ 劳动义务 / 生计依赖
→ 议价能力差异
→ 收益与风险分配
→ 依赖、剥削或保障
```

## 边界

- P3 关注“劳动过程怎样塑造人的时间、身体、技能与价值”。
- P4 关注“谁控制关键资源、谁承担劳动义务，以及利益和风险如何分配”。
- 当国家法律、行政组织或强制机构本身成为核心问题时，同时进入 TH5；P4 仍保留其资源与劳动关系这一侧。
