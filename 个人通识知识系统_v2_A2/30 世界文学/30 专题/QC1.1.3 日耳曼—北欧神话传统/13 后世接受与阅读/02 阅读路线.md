# 阅读路线

## 路线 A｜最低成本通识骨架

```text
《诗体埃达》选读
→ 《散文埃达》核心部分
→ 《贝奥武夫》
→ 《沃尔松格萨迦》
→ 《尼伯龙根之歌》
```

这条路线对应：

`神话／英雄诗歌 → 体系化解释 → 早期英雄诗见证 → 古诺斯萨迦重述 → 德语英雄传统定型`

## 路线 B｜神话优先

1. 《诗体埃达》中的神话诗：先建立世界观、神祇和诸神黄昏；
2. 《散文埃达》的《欺骗古鲁菲》：观察斯诺里如何把材料组织成较连续体系；
3. 回到《诗体埃达》比较同一材料在诗歌与散文中的差异；
4. 再进入《丹麦人的事迹》等不同书写框架。

## 路线 C｜英雄传统优先

```text
《贝奥武夫》
→ 《诗体埃达》英雄诗选读
→ 《沃尔松格萨迦》
→ 《尼伯龙根之歌》
```

重点不是寻找一个“正确版本”，而是看英雄、龙、宝藏、复仇、婚姻与家族毁灭如何在不同语言和文类中重新组织。

## 阅读原则

- 不要求先读完整北欧神话工具书再读原典；
- 每读一部文本都问“它是什么年代、什么语言、什么书写环境中的见证”；
- 遇到沃尔松—尼伯龙根的版本差异，转入 QC1.2 做谱系，而不是在 QC1.1.3 里不断加细节；
- 现代奇幻可以作为兴趣入口，但不要用现代设定替代中世纪文本。
