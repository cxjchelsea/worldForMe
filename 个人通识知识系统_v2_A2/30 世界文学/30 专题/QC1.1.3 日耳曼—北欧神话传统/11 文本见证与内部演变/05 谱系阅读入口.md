# 谱系阅读入口

本页回答“读哪些文本最容易看见传统如何被保存和重组”，不等同于最终个人阅读顺序。具体读序见 [[../13 后世接受与阅读/02 阅读路线|13 阅读路线]]。

斯卡尔德诗歌不建单一作品实体；它作为独立见证进入 [[02 斯卡尔德诗歌与宫廷诗歌见证]]。

| 文本 | 谱系角色 | 进入后主要观察 |
|---|---|---|
| 《诗体埃达》 | 埃达诗歌汇集 | 神话诗／英雄诗如何保存不同层次的材料 |
| 《散文埃达》 | 体系化编纂 | 斯诺里如何为诗学目的整理神话知识，并引用更早诗句 |
| 《贝奥武夫》 | 早期英雄诗见证 | 古英语英雄传统、怪物与基督教书写环境如何共存 |
| 《沃尔松格萨迦》 | 萨迦重述 | 英雄诗材料如何被组织为连续传奇萨迦 |
| 《赫瓦拉尔萨迦与海德雷克王》 | 多层英雄材料编合 | 沃尔松之外的魔剑、谜语与哥特—匈人英雄层次如何被编合 |
| 《克拉基王萨迦》 | 平行英雄传统重写 | 同一片丹麦英雄记忆如何在古英语、拉丁史书与晚期萨迦中分别定型 |
| 《尼伯龙根之歌》 | 德语英雄传统定型 | 相近英雄资源如何在中古德语宫廷环境中重新定型 |
| 《丹麦人的事迹》 | 拉丁史书重写 | 旧传说如何被纳入基督教拉丁史学框架 |
| 《挪威列王传》 | 王统史学重构 | 神话与祖先传说如何被改写成王家历史前史 |

这九个入口覆盖诗歌汇集、体系化编纂、早期英雄诗、萨迦重述、多层英雄编合、平行传统重写、德语定型、拉丁史书重写、王统史学重构。斯卡尔德诗歌是贯穿《散文埃达》与王家萨迦的保存机制，不另占一个作品入口。
