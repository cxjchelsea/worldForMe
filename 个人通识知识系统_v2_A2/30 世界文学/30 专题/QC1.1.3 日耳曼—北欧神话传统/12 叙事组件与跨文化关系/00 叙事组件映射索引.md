# 叙事组件映射索引

QC1.1.3 负责说明组件在日耳曼—北欧来源传统中的具体材料；QC2 负责跨传统比较这些组件如何重复、变化和被后世调用。

## 高连接组件群

| 日耳曼—北欧材料 | QC2 主要问题群 |
|---|---|
| 世界形成、世界树、诸界 | QC2.1 创世、宇宙与世界秩序 |
| 诸神黄昏、火与洪水式毁灭、世界更新 | QC2.2 毁灭、灾变与世界重生 |
| 奥丁求知、符文与自我牺牲 | QC2.3 神、人边界与禁忌越界；QC2.15 牺牲、罪、救赎与替罪 |
| 神祇／巨人与秩序边界 | QC2.13 怪物、异类与文明边界 |
| 洛基的欺骗、变形与规则颠覆 | QC2.14 变形、分身与身份不稳定；QC2.16 欺骗、智慧、交易与规则颠覆 |
| 西格鲁德／齐格弗里德屠龙 | QC2.6 英雄诞生、试炼与归乡；QC2.13 怪物、异类与文明边界 |
| 诅咒宝藏、戒指与财富灾难 | QC2.17 求索、宝物与神圣目标 |

| 末日预言与不可逃避命运 | QC2.5 命运、预言与自由意志 |

这些映射表示“可比较的叙事组件”，**不表示其他文化传统从北欧材料直接借用，也不表示北欧材料必然来源于其他相似传统**。
