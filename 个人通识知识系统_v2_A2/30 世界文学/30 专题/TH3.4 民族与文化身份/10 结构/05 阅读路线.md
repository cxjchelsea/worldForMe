# 阅读路线

TH3.4 的阅读目标不是记住“不同文化”，而是逐步形成一种能力：**看到文化共同体如何被生产、要求忠诚、制造真实性判断，并被人物重新组合。**

## 第一阶段：先看共同体如何被传递

### 《同名人》
重点观察：姓名、家庭实践、代际教育、第二代选择。

训练问题：
- 一个名字为什么能承载文化记忆？
- 第二代没有亲历父母迁徙，为什么仍会面对文化身份问题？

### 《喜福会》
重点观察：家庭语言、母女叙事、饮食与日常实践如何传递文化。

训练问题：
- 家庭是不是一个微型文化传递系统？
- 文化继承为何总伴随误读与重新解释？

## 第二阶段：看“我们是谁”如何被共同叙事制造

### 《午夜之子》
重点观察：国家诞生、语言、宗教、历史叙事和个人身份怎样纠缠。

训练问题：
- 国家成立是否自动产生统一民族身份？
- 谁被包含进“我们”，谁被排除？

### 《雪》
重点观察：世俗主义、宗教、欧洲想象与土耳其民族身份之间的竞争。

训练问题：
- 共同体为什么要求忠诚？
- “现代”“落后”“真正的本国人”是谁定义的？

## 第三阶段：看传统与现代不是简单二选一

### 《我的名字叫红》
重点观察：奥斯曼细密画传统与欧洲视觉方式的冲突和混合。

训练问题：
- 学习外来形式等不等于背叛传统？
- 传统本身是否一直在变化？

### 《瓦解》
重点观察：传统共同体在外部制度和宗教冲击下如何分裂。

训练问题：
- 哪些传统真正维系共同体，哪些传统内部已有冲突？
- 文化变化究竟来自外部破坏，还是内部张力与外部压力共同作用？

同时校准 TH3.7：若重点转向殖民文明等级和被殖民者自我理解，应进入殖民身份。

## 第四阶段：看多重归属与文化翻译

### 《美国佬》
重点观察：跨国生活、口音、返回、文化真实性与身份情境变化。

训练问题：
- 同一个人在不同社会为什么会被要求证明不同的文化身份？
- 多重归属是否必须选边？

### 《微物之神》
重点观察：语言、宗教、阶层、家庭规范和后殖民文化资源的交叉。

训练问题：
- 文化身份如何与阶级、家庭和殖民遗产交叉，却仍保持独立分析问题？

## 第五阶段：从保存走向重写

### 《百年孤独》
重点观察：地方历史、外来现代性与拉丁美洲经验怎样被重新组织成文化叙事。

训练问题：
- 文化共同体是否需要统一、真实的过去？
- 文学能否主动创造新的“我们”的叙事？

这里同时校准 TH7：若焦点是过去怎样被记忆/遗忘，进入 TH7；若焦点是过去怎样定义共同体，进入 TH3.4。

## 第六阶段：做兄弟节点对照阅读

建议把同一作品拆成不同问题，而不是一次性全标：

```text
《同名人》
迁徙发生了什么？             → TH3.5（父母代更强）
第二代怎样理解文化归属？     → TH3.4
哪里被经验为家？             → TH3.6（若文本持续追问）
被外部社会族群化了吗？       → TH3.3（只有证据充分才进入）
```

```text
《瓦解》
传统共同体怎样延续和改变？   → TH3.4
殖民文明等级怎样进入身份？   → TH3.7
暴力和创伤本身怎样发生？     → TH6
```

## 建议主线

```text
《同名人》 / 《喜福会》
→ 《午夜之子》 / 《雪》
→ 《我的名字叫红》 / 《瓦解》
→ 《美国佬》 / 《微物之神》
→ 《百年孤独》
→ TH3.3 / TH3.5 / TH3.6 / TH3.7 对照阅读
```

## 完成标准

完成这条路线后，应能够：

- 不把国籍直接等同于文化身份；
- 不把有传统习俗直接等同于 TH3.4；
- 说明文化通过语言、家庭、教育、仪式与叙事怎样持续存在；
- 识别谁在定义“正统”“真正”“背叛”；
- 区分迁徙事实、种族化分类、文化归属和故乡归属；
- 理解多重身份不是简单 A+B，而是情境化的文化翻译；
- 解释传统如何在变化中延续，而不是只写“传统与现代冲突”。
