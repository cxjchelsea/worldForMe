# A级内容压力测试

## 一、测试目标

本轮不再测试“六问是否能用于分类”，而测试 TH3.6 是否已经具备成熟知识地图需要的内容能力：

1. 能否解释地方为什么成为家，而不只是描述地点；
2. 能否解释记忆故乡、返乡陌生化、失乡和新家形成；
3. 能否稳定切开 TH3.4 / TH3.5 / TH7；
4. 能否处理乡土、城市、迁徙、战争、殖民、家族祖宅等不同情境；
5. 能否拒绝“有故乡背景”“有返乡情节”“有大量风景描写”这类假阳性；
6. 是否出现必须新增第七问或 `TH3.6.x` 的证据。

## 二、统一判定模型

```text
具体地点
→ 身体熟悉 / 关系网络 / 日常实践 / 物质锚点
→ 家园感与地方依附
→ 离开后被记忆重新编码
→ 返回时与现实发生碰撞
→ 归属维持 / 陌生化 / 失效
→ 新地点可能重新形成归属
```

只有“地点”而没有“归属机制”，不足以作为 TH3.6 核心。

## 四、三类高风险误判

### 1. “作品发生在故乡/乡村” ≠ TH3.6

地点只是叙事背景时，不成立。

判断标准：作品是否持续研究“为什么这个地方是家、失去它意味着什么”。

### 2. “人物返乡” ≠ TH3.6

返乡可能只是剧情动作。

- 返回是否可行、如何返回 → TH3.5；
- 返回后是否还属于、为什么陌生 → TH3.6。

只有第二类问题稳定存在时，TH3.6 才强命中。

### 3. “大量乡土/城市风景描写” ≠ TH3.6

景观审美、环境描写甚至地方文化都不自动构成归属问题。必须出现人物与地点之间的依附、失效、返回或再归属机制。

## 五、六个核心问题复核

### P1 什么使一个地方成为家

通过。《呼啸山庄》《大地》《红楼梦》提供强证据。

### P2 记忆与想象如何建构故乡

通过。《远山淡影》《故乡》《喜福会》显示它不能被 P1 替代。

### P3 离开之后人与故乡关系如何变化

通过。《布鲁克林》《美国佬》《同名人》提供稳定证据。

### P4 为什么返乡产生陌生化与失落

通过。《故乡》《美国佬》显示“离开后的关系变化”与“实际返乡碰撞”可区分。

### P5 家园被毁坏、失去或夺走后人如何生活

通过。《宠儿》《追风筝的人》《愤怒的葡萄》《瓦解》说明其横跨战争、奴役、经济和殖民情境。

### P6 人能否在新的地方重新建立家与归属

通过。《布鲁克林》《同名人》《宠儿》提供独立证据。

**结论：六问完整，无第七问需要。**

## 六、关键兄弟节点边界复核

### TH3.5 ↔ TH3.6

```text
移动是否发生、能否走、能否留、能否实际返回
→ TH3.5

地方是否被经验为家、返回后是否仍有归属、新地能否成为家
→ TH3.6
```

边界通过。

### TH3.4 ↔ TH3.6

```text
我属于哪个文化共同体
→ TH3.4

哪里是我的家
→ TH3.6
```

文化可以跨地延续；家必须具有地点性。边界通过。

### TH7 ↔ TH3.6

```text
记忆怎样保存、选择、重写过去
→ TH7

记忆怎样让一个地点继续成为故乡
→ TH3.6
```

边界通过。

## 七、域外边界复核

- 土地作为资源、住房作为阶级机会 → TH4；土地/房屋作为家园锚点 → TH3.6。
- 驱逐、规划、产权制度 → TH5；这些制度怎样造成失乡 → TH3.6。
- 家园毁坏中的暴力与创伤 → TH6；毁坏后哪里还能成为家 → TH3.6。
- 殖民中心/边缘与身份等级 → TH3.7；殖民造成土地失去和地方断裂 → TH3.6。
- 家庭结构 → TH2.3；家庭空间为何成为家 → TH3.6。

均可稳定分工。

## 八、是否需要继续拆分

压力测试没有发现“乡土 / 城市 / 失乡 / 返乡 / 新家”需要成为新的坐标子叶。它们都可以由同一机制解释：

```text
归属形成
→ 距离与记忆
→ 现实碰撞
→ 失效 / 维持
→ 再归属
```

因此：

```text

TH3.6.x_REQUIRED = FALSE
SECOND_DIMENSION = NOT_JUSTIFIED
```
