# 故乡与归属

> 路径：世界文学 → 作品坐标系统 → TH 主题 → TH3 社会身份、身体与归属 → **TH3.6 故乡与归属**

## 专题定位

本专题研究**什么地方会被一个人经验为“家”，地方性归属如何通过身体熟悉、关系网络、日常实践、物质空间与记忆形成，又如何因离开、变化、毁坏、夺取与时间而松动、陌生化或被重新建立。**

纳入测试：如果拿掉“某个具体地方是否仍被人物经验为家、故乡或归属空间”这一层，作品的主要意义是否明显改变？若不会，一般不作为本专题核心。

总体关系：

```text
居住、关系、日常与地方物质
→ 形成身体熟悉与可预期生活
→ 地方被赋予记忆与身份意义
→ 离开后通过距离与想象被重新编码
→ 返回时与现实变化发生碰撞
→ 在毁坏、夺取或社会变化中失去归属
→ 旧家被哀悼、重估，或在新地点重新建立归属
```

## 五个核心机制

1. **地方依附形成**：身体熟悉、关系、劳动、日常路线和物质环境让空间变成“家”。
2. **故乡记忆重构**：离开后，记忆会选择、理想化、压缩甚至神话化原来的地方。
3. **返乡陌生化**：人变了、地方也变了，返回因此可能暴露“记忆故乡”与“现实故乡”的裂缝。
4. **失乡与剥夺**：战争、驱逐、拆迁、殖民、家族衰败或环境变化可以摧毁归属的物质和关系基础。
5. **再归属**：新的地点只有在日常、关系、承认和时间沉淀后，才可能真正从“住处”变成“家”。

## 八组稳定张力

- 熟悉 ↔ 陌生
- 留下 ↔ 离开
- 记忆故乡 ↔ 现实故乡
- 拥有 ↔ 被夺走
- 私人家园 ↔ 公共空间
- 祖居 ↔ 新家
- 连续性 ↔ 断裂
- 归属 ↔ 无家状态

## 与 TH3.5 的核心区分

```text
是否能离开、怎样移动、能否实际返回
→ TH3.5

哪里被经验为家、回去后为何仍不属于、怎样建立新家
→ TH3.6
```

“返乡”同时可能命中两者，但问题不同：**返乡作为移动行为**属于 TH3.5；**返乡后的熟悉/陌生与归属危机**属于 TH3.6。

## 关键边界

- **TH3.5 迁徙与流亡**：是否离开、如何移动、能否实际回返归 TH3.5；某处是否仍被经验为“家”归 TH3.6。
- **TH3.4 民族与文化身份**：文化共同体成员资格归 TH3.4；具体地方、家园与地方感归 TH3.6。
- **TH2.3 家庭与家族**：家族网络与亲属结构归 TH2.3；祖宅、村庄或城市如何成为家园空间归 TH3.6。
- **TH7 历史、记忆与时间**：记忆机制本身归 TH7；记忆如何把地点保存为故乡归 TH3.6。
- **TH3.7 殖民身份**：殖民权力与身份等级归 TH3.7；土地和家园被夺走后如何造成失乡归 TH3.6。
- **TH4 社会、阶级与劳动**：住房、土地的经济分配归 TH4；这些条件如何改变“能否把某地当成家”时可兼标 TH3.6。

## A 级验收原则

专题必须能够做到：

1. 不把“作品发生在乡村/城市”自动理解为 TH3.6；
2. 不把“返乡情节”自动理解为故乡主题；
3. 不把风景、乡土描写本身当作归属分析；
4. 能解释地方为什么成为家、又为什么失效；
5. 能区分“回得去”与“回去后仍属于”；
6. 能比较祖居、城市街区、殖民土地、流亡后的第二故乡和新家建立。
