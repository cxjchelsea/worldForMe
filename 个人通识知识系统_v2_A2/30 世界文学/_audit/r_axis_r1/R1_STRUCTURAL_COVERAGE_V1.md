# R1 Structural Coverage Audit V1

> 目标：判断 R1「西亚—地中海古老传统」是否已经由足够的作品支撑其自身文学史结构，而不是先追求 T0–T6 数量均衡。
>
> 本审计只读。除此前已完成的 4 本补书、1 本 R1→R4 纠正和 `r1_tradition` enrichment 外，本文件不新增或修改 canonical Work。

## 1. 审计原则

R1 的完整度不以“总书数”或“每条传统书数相同”为目标，而以**结构槽位 coverage**为目标。

每条内部传统根据自身文学史定义若干必须被作品锚定的结构槽位：

- 奠基 / 早期文本
- 成熟核心形式
- 该传统独有或特别重要的文类
- 文学制度 / 传播方式
- 关键历史转型
- 现代延续（若该传统延续到现代）
- 跨传统桥梁作品

一个槽位至少有 1 部可信作品锚点即记为 `COVERED`；只有边缘或间接锚点记为 `PARTIAL`；没有作品锚点记为 `MISSING`。

数量均衡不构成目标。例如古埃及不需要与现代阿拉伯文学拥有相同作品数；古埃及需要覆盖墓葬文本、叙事、智慧/教诲等自身关键结构，而现代阿拉伯文学需要覆盖古典诗歌、adab/maqāma、旅行、Nahda、现代小说与后殖民文学等更长链条。

---

## 2. 总体结论

当前 R1 已经有足够作品形成**可识别骨架**，但还不足以视为结构性完成。

### 当前强项

- 两河：神话、宇宙论、英雄史诗和神祇叙事已经形成明显核心群。
- 古埃及：墓葬文本与中王国叙事已有较好锚点。
- 黎凡特—迦南/乌加里特：三大乌加里特叙事群已基本到位。
- 古希腊：史诗、赫西俄德传统、悲剧、柏拉图对话均很强。
- 希伯来—犹太：圣经文本、末世文本、中古哲学与现代希伯来小说起点均已有锚点。
- 阿拉伯：前伊斯兰诗歌、maqāma、旅行、民间叙事、20 世纪小说和巴勒斯坦文学已有连续骨架。
- 波斯：史诗、浪漫叙事、苏菲诗、教诲文学、鲁拜和现代主义小说都有代表。

### 当前主要缺口

1. **古希腊不是书少，而是文类不完整**：缺抒情诗、旧喜剧、历史书写、希腊化文学。
2. **罗马作品高度集中于维吉尔和奥维德**：缺喜剧、讽刺、史书、抒情和小说。
3. **古埃及缺智慧 / 教诲文学锚点**。
4. **两河缺智慧文学与城市哀歌锚点**。
5. **希伯来—犹太缺拉比 / 塔木德解释传统与中古希伯来诗歌锚点**。
6. **阿拉伯缺《古兰经》这一语言—修辞—经典化中心锚点，也缺 Nahda 的明确作品节点**。
7. **波斯缺哈菲兹式 ghazal 顶峰、近代/现代诗歌转型和现代社会小说的第二锚点**。
8. **土耳其—奥斯曼仍是最明显薄弱传统**：缺早期安纳托利亚神秘诗、Divan 宫廷诗、Tanzimat、Servet-i Fünun / 晚奥斯曼现代小说等关键层。
9. **跨传统网络已有个别桥梁作品，但还没有形成明确的“翻译—改写—多语帝国”作品链。**

因此当前问题不是“84 本太少”，而是**结构槽位覆盖不均**。

# 4. 跨传统网络覆盖

|---|---|---|---|

| 印度寓言 → 波斯中介 → 阿拉伯 adab | COVERED | 《卡里来和笛木乃》 | 很好的桥梁作品 |
| 波斯爱情叙事 → 土耳其语 / 奥斯曼改写 | COVERED | 内扎米与福祖里的《莱拉与马吉农》 | 已形成双节点 |
| 阿拉伯语 ↔ 波斯语中古双语文学场 | PARTIAL | Rumi / Saadi / maqāma 等间接体现 | 缺明确双语作者 / 翻译节点 |
| 希伯来 / Judeo-Arabic 世界 | PARTIAL | 《库萨里》 | 可补 Maimonides，但是否作为“文学”Work需边界审查 |
| 古典知识的希腊→叙利亚语/阿拉伯语翻译链 | MISSING | 无作品锚点 | 应优先用专题机制节点解释，不一定新增哲学/科学 Works |
| Ottoman 多语帝国文学场 | PARTIAL | Fuzuli、Evliya、后期土耳其作品 | 缺典型 Divan 文学锚点 |
| Nahda 翻译 / 留学 / 印刷网络 | MISSING | 无 | 应补塔赫塔维等 |

**结论：跨传统网络不需要每种机制都用一部“文学名著”强行支撑。** 对于翻译机构、教育网络、科学/哲学翻译等，应优先由结构节点承担；只有当具体文本本身具有文学史意义时才新增 Work。

# 6. 关于作品总量的判断

当前 R1 并不需要从约 84 本扩张到数百本。

按本审计，第一轮真正不可替代的结构缺口大约需要 **15–25 个新增或重新映射的 Work 锚点**。其中部分候选很可能已经存在于 `40 作品/`，应先搜索 canonical library，再决定新增。

因此建议目标不是：

```text
R1 = 150 本 / 200 本
```

而是：

```text
九条传统的核心结构槽位 >= 85% COVERED
跨传统关键网络均有文本或结构节点承担
不存在为了数量重复堆叠同一作者 / 同一文类
```

达到这个标准后，R1 才可进入 `r1_priority / r1_role` 的统一分层与最终阅读路线设计。
