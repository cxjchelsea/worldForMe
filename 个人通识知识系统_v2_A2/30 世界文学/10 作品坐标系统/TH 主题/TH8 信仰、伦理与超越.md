# TH8 信仰、伦理与超越

> 路径：作品坐标系统 → TH 主题与人类问题 → **TH8 信仰、伦理与超越**

## 定义

研究**人在面对神圣、善恶、罪责、苦难、死亡与自身有限性时，如何形成或失去信仰，如何判断应当怎样行动，如何理解宽恕、救赎与终极意义，并是否可能通过爱、牺牲、慈悲或神秘经验超越狭窄的自我**。

## 边界

- “人生是否有意义、世界是否荒诞”本身 → TH1.5；问题进一步进入神、信仰、神义或终极救赎 → TH8。
- 法律规定何为合法、制度怎样执行正义 → TH5；超越法律的善恶、良知、义务与伦理责任 → TH8。
- 因具体暴力事件产生的加害、共谋、幸存罪责 → TH6；一般意义上的罪、悔改、宽恕、救赎与伦理责任 → TH8。
- 宗教作为民族文化身份、仪式传统与共同体标记 → TH3.4；宗教作为信仰实践、神圣经验和终极判断 → TH8。
- 死亡作为生命有限性与存在终点 → TH1.4；死亡后的审判、来世、永生与终极救赎 → TH8。

## 叶节点判断

V1 压力测试与挑错式终审显示，信仰、伦理、罪责、苦难、来世与超越可以由同一“终极价值与超越性判断”问题域稳定统摄。拆成“宗教 / 伦理 / 超越”会导致大量核心作品稳定多重命中，因此不建立 `TH8.x`。
