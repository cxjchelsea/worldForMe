# TH 轴级总终审

## 结论

TH「主题与人类问题」完成 V1 轴级总终审。现有 TH1—TH8 可以作为世界文学作品主题坐标的高覆盖核心结构整体冻结；当前没有足够证据新增 TH9、TH10，也没有一级域需要合并、继续拆分或上移新的中间层。

TH 的目标不是穷尽文学中所有可讨论对象，而是提供一组**高覆盖、可比较、可稳定标注的“作品主要在思考什么”坐标**。作品可以多重命中，但每个命中都必须回答一个独立的人类问题。

## 一、八个一级域的最小判定

| 一级域 | 最小判定问题 |
|---|---|
| TH1 自我、存在与生命 | 作品是否主要追问“作为一个人，我是谁、如何选择、如何面对孤独、死亡和意义”？ |
| TH2 亲密关系、家庭与成长 | 作品是否主要追问人与亲密他人、家庭、代际及成长之间的关系如何形成和变化？ |
| TH3 社会身份、身体与归属 | 作品是否主要追问身体、性规范、群体分类、文化共同体、迁徙、地方与殖民位置如何定义“我属于哪里、被看作什么人”？ |
| TH4 社会、阶级与劳动 | 作品是否主要追问阶级、贫富、劳动、财产与社会流动如何规定人的生活机会？ |
| TH5 权力、制度与秩序 | 作品是否主要追问国家、法律、官僚、规则与制度化权力如何组织、限制和惩罚人？ |
| TH6 战争、暴力与创伤 | 作品是否主要追问暴力如何发生、被承受，并怎样留下身体、关系与心理余波？ |
| TH7 历史、记忆与时间 | 作品是否主要追问过去如何被记住、遗忘、重写，并继续存在于现在？ |
| TH8 信仰、伦理与超越 | 作品是否主要追问神圣、善恶、罪、苦难、救赎、来世与超越性价值？ |

## 二、覆盖审计

### 1. 个体层

- 主体、自我、选择、孤独、死亡、意义 → TH1
- 成长、亲密关系、家庭与代际 → TH2

### 2. 社会位置层

- 身体、性、种族、文化身份、迁徙、故乡、殖民身份 → TH3
- 阶级、贫富、劳动、资本与社会流动 → TH4
- 国家、法律、官僚、监控、制度与秩序 → TH5

### 3. 极端经验与长期历史层

- 战争、暴力、创伤、复仇、见证 → TH6
- 记忆、遗忘、公共历史、历史重写、时间经验 → TH7

### 4. 终极价值层

- 信仰、善恶、良知、罪、宽恕、救赎、来世、超越 → TH8

结论：V1 已覆盖文学中最稳定、跨时期、跨地域重复出现的人类问题层级。

## 三、系统性重叠审计

### TH1 ↔ TH3

- “我是谁”作为主体形成、人格连续性、自我欺骗 → TH1.1。
- “社会把我认作什么人、我属于哪个群体” → TH3。

### TH1.2 ↔ TH4 / TH5

- 人是否选择、如何承担后果 → TH1.2。
- 阶级与经济条件为什么限制可选项 → TH4。
- 制度为什么只允许某些行动 → TH5。

### TH1.4 / TH1.5 ↔ TH8

- 死亡作为生命有限性 → TH1.4；来世、审判、永生 → TH8。
- 意义与荒诞本身 → TH1.5；神义、信仰与终极救赎 → TH8。

### TH2 ↔ TH3

- 爱情、婚姻、家庭、亲子关系自身 → TH2。
- 性规范、身体位置、社会身份与群体归属 → TH3。

### TH3 ↔ TH4 / TH5

- 身份与归属 → TH3。
- 阶级、贫富、劳动位置 → TH4。
- 制度怎样认证、限制或惩罚身份 → TH5。

### TH5 ↔ TH6

- 暴力如何被授权、程序化、制度化 → TH5。
- 暴力如何实际发生、被承受、留下创伤 → TH6。

### TH6 ↔ TH7

- 伤害与见证困境 → TH6。
- 过去的暴力后来怎样被记忆、遗忘与重写 → TH7。

### TH6 ↔ TH8

- 具体暴力行为产生的加害、共谋、幸存罪责 → TH6。
- 一般伦理意义上的罪、悔改、宽恕与救赎 → TH8。

### TH7 ↔ TH5

- 国家控制档案、审查历史作为权力技术 → TH5。
- 不同历史版本如何竞争、过去如何持续进入现在 → TH7。

结论：一级域之间存在必要的交叉，但没有发现“两个域长期回答同一问题”的系统性重复。

## 四、是否需要 TH9 / TH10

总终审专门检查三个可能的残余主题簇：

1. **自然、环境与非人世界**
2. **知识、科学与技术**
3. **艺术、语言与创作**

它们都具有文学重要性，但当前不恢复为 TH9 / TH10，理由如下：

- 现阶段缺少经过作品压力测试的稳定问题链与正式作品投影；
- 其中一部分经常作为作品对象、设定、类型机制、意象或美学问题出现，而不一定构成独立的人类问题坐标；
- 若提前建域，会回到“见到重要主题就建一级节点”的百科式分类，而偏离 TH 的高覆盖坐标原则。

因此将三者进入**解冻观察名单**，而不是宣告永久排除。

### 新域重启条件

只有同时满足以下条件，才讨论新增 TH9：

1. 至少形成 15 部跨时期、跨地域作品压力测试语料；
2. 其中至少 8 部不能被现有 TH1—TH8 的问题中心稳定承接；
3. 可形成不少于 4 个彼此独立、可比较的问题入口；
4. 与 TY、IM、CN、M 等其他轴的职责边界可清楚写出；
5. 新增后能提高作品定位辨识度，而不是增加普遍多重命中。

## 五、多重命中治理

一部作品允许同时拥有多个 TH，但每个 TH 必须回答不同问题。

错误方式：

```text
“这是移民、后殖民、少数族裔作品”
→ 机械标 TH3.3 / TH3.4 / TH3.5 / TH3.6 / TH3.7
```

正确方式：逐项证明：

```text
被种族化？             → TH3.3
文化共同体认同冲突？   → TH3.4
实际迁徙是核心？       → TH3.5
地方归属是核心？       → TH3.6
殖民关系塑造身份等级？ → TH3.7
```

同理，战争、制度、历史与伦理等组合也必须分别证明问题独立。

## 六、与其他轴的总边界

- **TH**：作品主要在思考什么人类问题。
- **TY**：作品采用什么类型、叙事与文化机制。
- **IM**：文本中有哪些高显著、反复出现并承担功能的意象。
- **CN**：作品与哪些长期文化叙事结构发生关系。
- **T / R / M / G**：作品处于什么时间、地域、思潮与体裁坐标。

一个对象“重要”并不意味着它必须成为 TH；只有它稳定构成作品的核心问题，才进入 TH。
