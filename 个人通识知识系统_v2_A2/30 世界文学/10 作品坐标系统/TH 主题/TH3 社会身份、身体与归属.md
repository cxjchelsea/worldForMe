# TH3 社会身份、身体与归属

> 路径：作品坐标系统 → TH 主题与人类问题 → **TH3 社会身份、身体与归属**

问题域。本域关注主体如何被身体、性规范、社会分类、文化共同体、迁徙经验、地方归属与殖民关系定位，以及这些位置如何被继承、内化、协商、反抗或重新定义。泛化的自我认识与主体性问题优先进入 TH1.1。

## 上位统一机制

TH3 共同研究的不是泛化的“身份”，而是：

> **人如何被某种社会差异、规范、群体、共同体、移动、地方或历史权力关系放置在一个位置；这个位置又怎样影响生活条件、自我理解与行动可能，并被继承、协商、隐藏、跨越、拒绝或重写。**

```text
差异 / 经历 / 关系条件
→ 社会命名与意义赋予
→ 成员资格 / 位置 / 边界形成
→ 家庭、共同体、制度与日常实践放大
→ 资源、空间、关系与行动可能发生差异
→ 主体内化 / 协商 / 隐匿 / 跨越 / 反抗
→ 原有位置被再生产、混合或重写
```

该机制只用于域级理解，不新增中间坐标层。

## 多标签治理

TH3 允许复杂作品同时命中多个叶节点，但必须满足：

1. 每个标签都能用一句不同的问题解释；
2. 删除一个标签后，其他问题仍能独立成立；
3. 性别、族裔、国籍、移民或殖民背景本身都不是自动命中证据；
4. TH3.3—TH3.7 出现大面积同时命中时必须逐项复核，避免把“后殖民 / 移民作品”机械展开成全部标签。
