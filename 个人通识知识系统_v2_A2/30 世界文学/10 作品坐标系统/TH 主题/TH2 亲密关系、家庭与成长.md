# TH2 亲密关系、家庭与成长

> 路径：作品坐标系统 → TH 主题与人类问题 → **TH2 亲密关系、家庭与成长**

TH2 研究的不是泛泛的“人际关系”，而是：**人如何进入亲密关系，如何把关系转化为持续共同生活，如何被家庭与代际结构嵌入，以及个体又如何在这些关系与结构中成长、分离或重新定位。**

当前五个叶节点全部完成 A 级内容建设，并通过整域终审；本域坐标结构继续冻结，不预建更细层级。


## 五叶最小问题

```text
为什么偏偏是这个人，我是否真正看见并得到对方回应？
→ TH2.1 爱情与欲望

关系建立之后，我们怎样承诺、共同生活、信任、修复与退出？
→ TH2.2 婚姻与亲密关系

一个家庭/家族网络怎样定义成员、分配资源与义务，并跨代维系？
→ TH2.3 家庭与家族

具体上一代—下一代怎样照料、期待、控制、分离、传递与重新理解？
→ TH2.4 亲子与代际

一个人怎样通过时间和经验发展、学习、受阻、拒绝或重写成人位置？
→ TH2.5 童年与成长
```

## 上位导航模型

```text
具体他者成为爱欲对象
→ 持续伴侣关系形成
→ 伴侣关系进入家庭/家族网络
→ 纵向代际关系展开
→ 个体在这些关系及更大社会经验中形成发展轨迹
```

压缩为：

```text
爱欲对象 → 伴侣关系 → 家庭系统 → 代际关系 → 个体发展
```

这不是强制生命周期，只是用于区分五种解释单位。

- 具体他者如何成为爱欲对象、投射与相互性 → TH2.1；
- 欲望/性行为/性身份如何被允许、禁止、分类，以及同意如何成立 → TH3.2。

## 多标签原则

TH2 允许多标签，但每个标签必须有独立问题句。人物有恋人、婚姻、家庭、父母子女或青年身份，都不是自动命中依据。

若作品同时命中 TH2.1–TH2.5 中 4 个以上叶节点，默认触发人工复核，排除“家庭题材全家桶”式机械扩张。
