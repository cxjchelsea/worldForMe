# TH1 自我、存在与生命

> 路径：作品坐标系统 → TH 主题与人类问题 → **TH1 自我、存在与生命**

TH1 已完成整域 A 级终审并冻结。它不承担泛化的“人物内心世界”，而研究一个有限而有意识的主体如何形成自我、作出行动、建立连接、面对死亡，并在没有绝对保证的条件下维持或重建生活意义。

```text
TH1  自我、存在与生命
├─ TH1.1 自我认同与主体性
├─ TH1.2 自由与选择
├─ TH1.3 孤独
├─ TH1.4 死亡
└─ TH1.5 意义与荒诞
```

## 五个叶节点的最小判别

```text
我是谁？                    → TH1.1
这是我的选择吗？            → TH1.2
我还能与别人/世界连接吗？   → TH1.3
我如何面对终将到来的死亡？  → TH1.4
为什么这样的生命仍值得？    → TH1.5
```
