TH3 可以正式视为 A 级成熟内容域。

七个叶节点并非七类“身份标签”，而是七种不同的**社会定位机制**：

```text
身体差异怎样成为社会位置？             → TH3.1
欲望怎样被判断为允许或禁止？           → TH3.2
群体分类怎样带来差别待遇？             → TH3.3
文化共同体怎样生产“我们”的成员资格？ → TH3.4
移动怎样重组生活？                     → TH3.5
地方怎样成为或失去“家”的意义？       → TH3.6
殖民等级怎样进入自我理解？             → TH3.7
```

## 二、TH3 的上位统一机制

TH3 共同研究的不是抽象“我是谁”，而是：

> **人如何被身体、规范、群体、共同体、移动、地方与历史权力关系放置在某种社会位置；这种位置又如何进入人的生活条件、自我理解与行动可能，并被继承、协商、隐藏、跨越、拒绝或重写。**

可统一为：

```text
差异 / 经历 / 关系条件
→ 社会命名与意义赋予
→ 成员资格 / 位置 / 边界形成
→ 家庭、共同体、制度与日常实践放大
→ 资源、空间、关系与行动可能发生差异
→ 主体内化 / 协商 / 隐匿 / 跨越 / 反抗
→ 原有位置被再生产、混合或重写
```

这条总机制只用于解释 TH3 的共同性，不新增中间坐标。

## 三、七叶为什么不能合并

### TH3.1 与 TH3.2

两者都可能涉及身体和性，但核心问题不同：

- TH3.1：**身体被赋予什么社会意义，并因此获得什么角色、资格与行动边界？**
- TH3.2：**欲望、性行为和性身份被判断为什么可以 / 不可以，以及同意如何成立？**

例如生殖身体被国家管理可进入 TH3.1；性关系是否被禁止、污名化或刑罚化进入 TH3.2。两者可交叉，但不可合并。

### TH3.3 与 TH3.4

- TH3.3：外部分类、他者化与差别待遇。
- TH3.4：内部文化传递、共同叙事与成员资格。

“别人把我当成谁”与“我为什么认为自己属于我们”是两种不同的身份生成机制。

### TH3.4、TH3.5 与 TH3.6

```text
属于什么文化共同体？ → TH3.4
移动发生了什么？     → TH3.5
哪里被经验为家？     → TH3.6
```

这是 TH3 内最容易机械全标的一组，也是本轮重点复核对象。三者均能在复杂移民 / 离散作品中独立成立，且不存在稳定合并证据。

### TH3.3 / TH3.4 与 TH3.7

TH3.7 不是“种族 + 文化”的重复节点。只有当分类与文化差异被殖民秩序组织成中心 / 边缘、文明 / 落后等等级，并进入主体自我评价时，才进入 TH3.7。

## 四、七叶共享但不重复的结构

| 节点 | 被社会组织的核心对象 | 最关键的中介 | 最典型后果 |
|---|---|---|---|
| TH3.1 | 身体与性别位置 | 凝视、审美、医学、家庭、制度 | 角色、资格、身体自主 |
| TH3.2 | 欲望、性行为、性身份 | 道德、禁忌、同意、法律、宗教 | 隐匿、羞耻、公开、性自主 |
| TH3.3 | 种族 / 族群分类 | 命名、刻板赋值、隔离、制度化 | 差别待遇、passing、边界重组 |
| TH3.4 | 文化共同体成员资格 | 语言、传统、叙事、家庭、教育 | 继承、真实性、混杂、文化重写 |
| TH3.5 | 位移过程 | 边境、证件、生计、家庭网络 | 断裂、安顿、悬置、回返 |
| TH3.6 | 地方归属 | 日常、关系、记忆、物质锚点 | 家园感、失乡、返乡陌生化、再归属 |
| TH3.7 | 殖民身份等级 | 教育、语言、知识、审美、帝国制度 | 模仿、羞耻、中介、去殖民化 |

七者共享“社会定位”这一上位逻辑，但各自处理的对象、中介和后果都不同，因此属于**互补叶节点**，不是同义标签。

## 五、复杂作品多标签终审

多标签不是错误；错误的是没有说明每个标签分别解释什么。

### 《美国佬》型作品

可能同时命中：

- TH3.3：在美国被种族化与差别对待；
- TH3.4：尼日利亚 / 美国文化归属与真实性；
- TH3.5：跨国迁移、异地生活与返回；
- TH3.6：回国后“家”的重新体验。

四个标签不是同一件事的重复表达，而分别回答“被分类”“属于什么文化”“如何移动”“哪里是家”。

### 《宠儿》型作品

可能同时命中：

- TH3.1：奴役制度对女性身体与母职身体的占有；
- TH3.3：种族化分类与奴役身份；
- TH3.6：奴役与逃亡之后能否建立家园；
- TH6：暴力、创伤及其持续。

这里 TH3 与 TH6 的分工也稳定：TH3 解释社会位置与归属，TH6 解释伤害及创伤余波。

### 《瓦解》型作品

可能同时命中：

- TH3.4：传统共同体、语言 / 宗教 / 习俗与文化身份；
- TH3.7：殖民秩序如何重估本土文化并制造文明等级；
- TH5：殖民机构与制度权力；
- TH7：若作品重点涉及过去如何被后来叙述，可局部进入历史记忆问题。

“殖民作品”不因此自动把 TH3.3—TH3.7 全部打开。

## 六、多标签治理规则最终版

一部作品命中多个 TH3.x 时，必须逐项通过以下检查：

1. **独立问题测试**：每个标签都能用一个不同的问题句解释；
2. **删除测试**：删除一个标签的分析问题后，另一个标签仍能独立成立；
3. **背景排除测试**：国籍、族裔、性别、移民背景、殖民背景本身都不是命中证据；
4. **机制证据测试**：作品必须真正呈现该节点的机制，而不是只有相关人物或场景；
5. **优先域测试**：若问题已有更稳定的 TH1/TH2/TH4–TH8 去向，不因“身份”二字拉回 TH3；
6. **大面积全标复核**：TH3.3–TH3.7 出现四个以上同时命中时，默认触发人工复核，而不是默认合理。

## 七、TH3 与域外主题的最终边界

TH3 只处理**社会位置、身体位置、群体位置与空间归属位置**。以下问题不因其能被称为“身份”就进入 TH3：

```text
我是谁、如何成为自己               → TH1.1
爱谁、如何建立亲密关系             → TH2
财富、阶级、劳动位置               → TH4
国家、法律、机构如何运行           → TH5
伤害、战争、创伤如何发生和持续     → TH6
过去如何被记住、重写和争夺         → TH7
善恶、信仰、罪责与终极价值         → TH8
```

只有当这些问题具体通过身体、性规范、群体分类、文化归属、迁徙、家园或殖民身份进入人物生活时，TH3 才兼标。

## 八、整域压力测试结论

本轮不再重复每个叶节点已经完成的 20 组左右作品压力测试，而是在其基础上做域级组合测试。重点覆盖以下高重叠类型：

- 女性 / 酷儿 / 身体治理作品；
- 种族与文化身份交叉作品；
- 移民、离散、返乡作品；
- 殖民 / 后殖民作品；
- 奴役、战争、国家暴力造成身份后果的作品；
- 历史背景、异国背景、少数群体角色等假阳性样本。

结果：

- 七叶均存在独立核心问题与作用机制；
- 未发现两个叶节点长期只能共同出现、无法区分；
- 未发现新的稳定第八类社会身份问题；
- “公民身份、阶级身份、宗教身份、职业身份”仍分别由 TH5、TH4、TH8 等更稳定问题域承担；
- TH3.3–TH3.7 的后殖民 / 移民机械全标风险已由多标签治理规则控制；
- TH3.1 / TH3.2 的身体—性边界稳定；
- 叶节点均已达到 L1–L6 成熟知识地图标准。

## 九、TH3 的成熟知识结构

TH3 现在已经同时具备：

- **L1 定义与边界**：七叶均有稳定纳入 / 排除规则；
- **L2 核心问题**：每叶六问左右，已通过独立性压力测试；
- **L3 机制模型**：七叶均已建立可复用作用链；
- **L4 稳定张力 / 变体**：能比较内部结构而非只列现象；
- **L5 跨时代 / 地域 / 传统比较**：不再依赖单一现代西方身份模型；
- **L6 作品群与阅读路线**：作品开始承担比较和训练能力，而非只用于验证坐标。

因此 TH3 已从“可靠的身份主题分类树”升级为“成熟的社会身份、身体与归属知识域”。

## 十、冻结后的继续建设方式

A级不代表内容停止增长，而意味着**结构不需要继续分叉**。以后新增阅读材料优先进入：

```text

```

只有满足原结构解冻条件时才重新讨论坐标树。
