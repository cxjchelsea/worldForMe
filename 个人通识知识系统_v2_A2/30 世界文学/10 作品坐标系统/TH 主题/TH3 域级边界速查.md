# TH3 域级边界速查

```text
TH3.1 性别与身体
→ 性别化身体如何改变社会位置、能动性与被承认方式

TH3.2 性、欲望与性规范
→ 性欲、性行为与性身份如何被允许、禁止、命名和规训

TH3.3 种族与族群
→ 谁被划入哪一群，以及群体边界如何造成差别待遇

TH3.4 民族与文化身份
→ 人如何通过语言、传统与共同体叙事理解“我们是谁”

TH3.5 迁徙与流亡
→ 离开、跨境、流亡与异地生活如何改变生活结构

TH3.6 故乡与归属
→ 什么地方被经验为家，以及这种地方归属如何形成、失去或重建

TH3.7 殖民身份
→ 殖民关系如何制造身份等级并进入自我理解
```

最常用的三组区分：

```text
被怎样分类？ → TH3.3
属于什么文化？ → TH3.4
殖民等级如何塑造身份？ → TH3.7

发生了什么移动？ → TH3.5
哪里是家？ → TH3.6

性别化身体位置？ → TH3.1
性欲/性行为/性身份规范？ → TH3.2
```

完整治理规则见 [[TH3 域级总终审]]。
