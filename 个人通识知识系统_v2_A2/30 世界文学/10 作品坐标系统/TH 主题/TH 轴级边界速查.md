# TH 轴级边界速查

## 一级域一句话判定

| 坐标 | 一句话判断 |
|---|---|
| TH1 自我、存在与生命 | 作为一个人，我是谁、如何选择、如何面对孤独、死亡和意义？ |
| TH2 亲密关系、家庭与成长 | 我与亲密他人、家庭、父母子女及成长过程如何相互塑造？ |
| TH3 社会身份、身体与归属 | 社会、身体、群体、文化、迁徙与殖民位置把我定义成什么人、让我属于哪里？ |
| TH4 社会、阶级与劳动 | 阶级、财富、劳动与资源为什么让不同人的生活机会不平等？ |
| TH5 权力、制度与秩序 | 谁制定规则，制度如何让人服从、受限、被惩罚或反抗？ |
| TH6 战争、暴力与创伤 | 暴力如何发生、被承受，并在事件结束后继续伤害人？ |
| TH7 历史、记忆与时间 | 过去怎样被记住、遗忘、改写，并继续存在于现在？ |
| TH8 信仰、伦理与超越 | 什么是善恶、罪与救赎，人能否面对神圣、苦难、来世和超越？ |

## 高频二选一

### TH1.1 vs TH3
- “我究竟是谁、我如何成为我自己” → TH1.1
- “别人/社会把我当作哪类人，我属于哪个群体” → TH3

### TH1.2 vs TH4 vs TH5
- “我怎么选” → TH1.2
- “贫穷、阶级、劳动为什么让我没得选” → TH4
- “制度、法律、组织为什么不允许我选” → TH5

### TH1.4 vs TH8
- “死亡意味着生命有限” → TH1.4
- “死后是否有审判、来世、永生、救赎” → TH8

### TH1.5 vs TH8
- “世界有没有意义 / 是否荒诞” → TH1.5
- “神为何允许苦难 / 信仰能否提供终极解释” → TH8

### TH2.1 vs TH3.2
- “为什么爱、爱谁、爱是否互相” → TH2.1
- “这种欲望/性行为/性身份是否被允许、怎样被规范” → TH3.2

### TH2.3 vs TH4
- “财产与继承怎样组织这个家庭” → TH2.3
- “财产怎样决定人在整个社会的阶级位置” → TH4

### TH3.3 vs TH3.4 vs TH3.7
- “我被划入哪种种族/族群并因此怎样被对待” → TH3.3
- “我如何理解自己属于哪种民族/文化共同体” → TH3.4
- “殖民关系为何把这些身份组织成文明/落后、中心/边缘等级” → TH3.7

### TH3.5 vs TH3.6
- “发生了什么移动、为什么离开、能否返回” → TH3.5
- “哪里是家、为什么返乡却陌生、新地方何时成为家” → TH3.6

### TH3 vs TH5
- “身份是什么、如何形成归属” → TH3
- “制度怎样认证、限制、登记、惩罚这个身份” → TH5

### TH4 vs TH5
- “谁有钱、土地、工作机会和资本” → TH4
- “谁有制定并执行公共规则的权力” → TH5

### TH5 vs TH6
- “强制如何被制度化、合法化和执行” → TH5
- “暴力实际怎样伤害身体、关系与心理” → TH6

### TH6 vs TH7
- “经历暴力的人如何承受、创伤和见证” → TH6
- “后来的人和社会怎样记住、忘记和解释这段过去” → TH7

### TH6 vs TH8
- “具体暴力行为的加害、共谋、幸存罪责” → TH6
- “一般意义上的罪、悔改、宽恕、救赎” → TH8

### TH5 vs TH8
- “法律规定什么合法” → TH5
- “即使合法，它是否仍然是恶；即使违法，我是否仍有义务做” → TH8

## 标注规则

1. 多重命中允许，但每个 TH 必须对应一个独立问题。
2. 背景出现不等于主题命中。
3. 作者身份不自动转换为作品主题。
4. 历史题材、宗教题材、战争背景、移民人物都不能单凭题材触发 TH。
5. 若一句话无法说明“这部作品在这个 TH 中具体追问什么”，则暂不标。
