# TH1「自我、存在与生命」域级总终审

## 一、终审结论

TH1 五个叶节点已完成 A 级内容建设，可以整体冻结：

```text
TH1  自我、存在与生命
├─ TH1.1 自我认同与主体性
├─ TH1.2 自由与选择
├─ TH1.3 孤独
├─ TH1.4 死亡
└─ TH1.5 意义与荒诞
```

本轮没有发现必须新增第六叶、合并现有叶节点或继续拆分 `TH1.x.y` 的稳定证据。

TH1 的共同问题不是泛化的“人物内心世界”，而是：

> **一个有限而有意识的主体，如何形成自我、作出行动、与他者建立连接、面对死亡，并在没有绝对保证的条件下维持或重建生活意义。**

五个叶节点分别回答这一存在结构中的五种不可互相替代的问题，因此可以构成一个稳定的一级主题域。

## 二、五节点的最小区分规则

| 节点 | 核心提问 | 最小判定 |
|---|---|---|
| TH1.1 自我认同与主体性 | 我是谁，我怎样成为并维持“我”？ | 自我叙述、人格连续性、角色与面具、他者承认、主体分裂或重构成为核心 |
| TH1.2 自由与选择 | 这是不是我的选择，我能否行动并承担后果？ | 可选范围、约束、决断、不行动、行动归属、不可逆性与责任成为核心 |
| TH1.3 孤独 | 我能否与他人、共同体和世界建立有效连接？ | 可接近、可表达、可理解、可回应、可承认、可归属中的一个或多个持续失效 |
| TH1.4 死亡 | 一个知道自己终将死亡的人如何面对有限性？ | 死亡意识、临终、死亡恐惧、面对死亡、他人之死、选择死亡或死后持续成为核心 |
| TH1.5 意义与荒诞 | 为什么这样的生命仍值得继续？ | 意义来源、意义崩塌、世界沉默、重复耗损、苦难挑战、局部意义与继续行动成为核心 |

最小快速判别可以压缩为：

```text
我是谁？                    → TH1.1
这是我的选择吗？            → TH1.2
我还能与别人/世界连接吗？   → TH1.3
我如何面对终将到来的死亡？  → TH1.4
为什么这样的生命仍值得？    → TH1.5
```

## 三、TH1 的统一上位机制

五个叶节点不是一条强制线性人生流程，但可以放入同一存在结构：

```text
形成“我是谁”的自我结构
        ↓
在处境中面对可选可能性并行动
        ↓
通过关系与共同体检验和维持自身
        ↓
在失去、失败、孤独和死亡有限性中遭遇边界
        ↓
重新回答生活为什么仍值得继续
```

更抽象地说：

```text
主体形成
→ 行动
→ 连接
→ 有限性
→ 意义
```

这不是五个节点的上下级关系，而是一个用于导航和多标签解释的域级模型。

## 四、域内边界终审

### 1. TH1.1 ↔ TH1.2

- “这个选择让我成为什么样的人” → TH1.1。
- “我是否真的拥有选择、为何这样选、要承担什么后果” → TH1.2。
- 身份可以被选择改变，但“自我结构”和“行动归属”必须分别成立才兼标。

### 2. TH1.1 ↔ TH1.3

- “我如何理解自己、维持人格连续性” → TH1.1。
- “我能否被理解、回应、承认并进入共同世界” → TH1.3。
- 被误解可能造成自我危机，但社会不理解并不自动等于主体性主题。

### 3. TH1.2 ↔ TH1.4

- 自杀、牺牲、主动赴死中的行动自由与责任 → TH1.2。
- 为什么死亡本身成为可选择或不可选择的生命终点 → TH1.4。

### 4. TH1.3 ↔ TH1.4

- 死亡造成关系永久断裂以后，连接为何不能恢复 → TH1.3。
- 死亡作为不可逆事件如何改变活者、临终者以及对有限性的理解 → TH1.4。

### 5. TH1.4 ↔ TH1.5

```text
我会死，这件事怎样改变生命经验？ → TH1.4
正因为我会死，生命为什么仍值得？ → TH1.5
```

死亡可以触发意义危机，但有限性问题和意义问题不能合并。

### 6. TH1.2 ↔ TH1.5

```text
我能不能选择、行动并负责？ → TH1.2
即使能选择，我为什么值得这样做？ → TH1.5
```

行动是否自由与行动为何有价值必须保持区分。

### 7. TH1.3 ↔ TH1.5

- “是否仍能与别人和世界建立连接” → TH1.3。
- “即使连接存在，生活是否仍有意义” → TH1.5。

孤独可以造成意义危机，但亲密与共同体并不是意义的唯一来源。

## 五、与 TH1 域外节点的硬边界

TH1 研究的是主体的存在经验，不承担所有心理、社会或伦理问题。

| 问题 | 优先去向 | TH1 何时可兼标 |
|---|---|---|
| 爱情、婚姻、家庭、亲子、成长关系 | TH2 | 这些关系直接改变主体、自主、孤独、死亡或意义结构时 |
| 性别、身体、种族、文化、迁徙、故乡、殖民身份 | TH3 | 社会位置进一步进入“我是谁”、选择、连接或意义问题时 |
| 阶级、劳动、贫困、财富 | TH4 | 结构性处境进一步制造主体异化、选择压缩或意义耗损时 |
| 国家、制度、法律、行政与权力 | TH5 | 制度作用进一步压缩行动、摧毁连接或改变主体理解时 |
| 战争、暴力、伤害、创伤 | TH6 | 这些经验进一步成为死亡、孤独、主体断裂或意义危机时 |
| 历史记忆、遗忘、时间与见证 | TH7 | 记忆进一步维持人格连续性、死者持续或意义结构时 |
| 信仰、伦理、善恶、救赎、超越 | TH8 | 信仰/伦理体系进一步回答“我如何选择”“如何面对死亡”“为什么活”时 |

因此 TH1 不承担“所有人的内心问题”，更不能因为一部作品有心理描写就自动命中。

## 六、潜在第六叶缺口检查

### 1. 痛苦 / 苦难

无需新增。暴力与创伤归 TH6；苦难如何挑战意义进入 TH1.5；疼痛或身体经验若改变社会位置进入 TH3.1。

### 2. 幸福

暂不新增。“什么使生活值得”可由 TH1.5 承担；爱情、家庭、共同体等幸福来源由相应一级域解释。当前尚无证据证明“幸福”形成独立于意义、关系和伦理的稳定文学问题域。

### 3. 欲望

无需新增。性欲与性规范归 TH3.2；爱情欲望归 TH2；欲望如何驱动选择进入 TH1.2；欲望如何成为人生意义可进入 TH1.5。

### 4. 时间 / 衰老

无需新增。历史时间与记忆归 TH7；死亡有限性和临终时间压缩归 TH1.4；衰老若成为身体社会位置问题归 TH3.1。

### 5. 异化

无需新增。异化可能是 TH1.1 的主体分裂、TH1.3 的连接失效、TH4 的劳动结构或 TH5 的制度结果，不宜单独建立一个含义过宽的坐标叶。

### 6. 荒诞是否应独立于意义

不需要。荒诞在当前体系中不是独立对象，而是“人的意义需求与世界不保证回应”之间的特殊失配机制，由 TH1.5 内部稳定承担。

因此：

```text
NEW_TH1_LEAF_REQUIRED = FALSE
```

## 七、多标签治理规则

TH1 允许复杂作品同时命中多个叶节点，但必须满足：

1. 每个命中都能写成一句不同的问题；
2. 删除其中一个问题后，其他问题仍然成立；
3. 情绪、剧情事件和人物属性都不能单独成为命中证据；
4. 必须说明该节点在作品中解释的是“机制”，而不是共享背景；
5. `axis_th` 只记录作品级稳定主题，专题内部 P1/P2 等不反向升级为坐标；
6. 如果一部作品 TH1.1–TH1.5 几乎全部命中，应触发复核，避免把“存在主义/心理文学”机械展开为五个标签。

### 示例：《局外人》

```text
死刑使死亡成为切身事实           → TH1.4
世界不提供终极意义保证           → TH1.5
社会无法理解其情感表达方式       → 可与 TH1.3 比较
```

但不能因为作品“很存在主义”就自动加入 TH1.1、TH1.2、TH1.3、TH1.4、TH1.5 全部标签。

### 示例：《地下室手记》

```text
高度自我反思与自我欺骗           → TH1.1
行动与不行动、自由意志的悖论     → TH1.2
主动退缩使连接进一步失败         → TH1.3
对理性功利意义结构的拒绝         → TH1.5
```

这是可解释的多标，因为四个问题分别成立。

## 八、整域完备性判断

从文学中最常见的存在问题看，五叶已经覆盖五个相互区分的核心维度：

```text
SELF        → 自我与主体
AGENCY      → 自由与行动
RELATION    → 连接与孤独
FINITUDE    → 死亡与有限性
MEANING     → 意义与荒诞
```

这五者既能分别承载完整内部结构，又能通过复杂作品发生有解释力的交叉。

目前不存在：

- 两个叶节点长期稳定共命中到无法区分；
- 一个叶节点内部已经裂成两套互不相干的体系；
- 大量作品持续出现同一种无法归入五叶的存在问题。

因此五叶数量具有足够稳定性。

## 十、解冻条件

TH1 冻结不代表永久不能修改。只有出现以下系统性证据时才重新开启结构讨论：

- 新增大规模作品后，持续出现无法归入五叶的同一类存在问题；
- 某两个叶节点长期在绝大多数作品中稳定共同命中，证明辨识度不足；
- 某一叶节点内部持续裂成两套互不相干、且各自有稳定作品辨识度的体系；
- TH2–TH8 后续终审发现域际边界存在系统性冲突；
- 实际检索和标注中出现稳定的高误判率。

在这些条件出现之前，TH1 后续工作应转向：**作品补标、阅读校准、专题案例丰满与跨作品比较**，而不是继续扩展坐标树。
