# TH5 权力、制度与秩序

> 路径：作品坐标系统 → TH 主题与人类问题 → **TH5 权力、制度与秩序**

## 定义

关注**社会秩序如何获得合法性，国家、法律、官僚、监控、审查、惩罚等制度如何把权力变成人物可感知的规则、程序与行动边界，以及人物如何服从、绕开、反抗或重建这种秩序**。

## 边界

- 个人在限制中如何选择 → TH1.2；限制如何被制度化和执行 → TH5。
- 阶级、贫富、劳动和资本关系 → TH4；国家、法律和公共制度如何组织社会 → TH5。
- 身份与归属本身 → TH3；制度如何认证、限制或惩罚身份 → TH5。
- 战争、暴力与创伤本身 → TH6；惩罚、监禁、警察与例外状态作为制度机制 → TH5。
- 历史与记忆本身 → TH7；国家审查、档案控制与官方叙事作为权力机制 → TH5。
- 道德正义与责任 → TH8；法律如何定义合法/非法、罪与权利 → TH5。

## 叶节点判断

V1 压力测试显示，合法性、法律、官僚程序、监控规训、惩罚强制与秩序重建可以由同一“制度化权力”问题链稳定统摄；继续拆成 `TH5.x` 会使大量政治/反乌托邦/官僚文学作品稳定重复命中。
