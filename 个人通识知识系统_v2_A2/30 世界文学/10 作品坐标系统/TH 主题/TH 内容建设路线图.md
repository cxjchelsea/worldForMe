# TH 内容建设路线图

> 前提：TH 分类树与公共格式已冻结。本路线图只处理**专题内容成熟度**，不重新设计 TH1—TH8 坐标。

## 1. 总目标

把 TH 从：

```text
主题分类系统
+ 核心问题体系
+ 分类治理记录
```

推进为：

```text
主题坐标
+ 可复用解释模型
+ 跨作品比较网络
+ 阅读路径
+ 可持续扩展的专题知识地图
```

目标不是让 TH 看起来像 T / R / M，而是让它达到与成熟 T / R / M 专题相同的**知识密度与可用性**。

---

## 2. 建设优先级

### P0：先做三个宽叶节点

1. **TH4 社会、阶级与劳动**
2. **TH5 权力、制度与秩序**
3. **TH8 信仰、伦理与超越**

原因：

- 三者都直接停在一级 TH，承载范围最大；
- 坐标不继续细分，因此内部专题必须承担全部复杂度；
- 当前核心问题已经可靠，适合停止分类讨论、立即建设第二层知识结构；
- 三者又分别连接社会结构、政治制度、伦理/宗教，是后续跨 TH 比较的重要枢纽。

建议顺序：

```text
TH4
→ TH5
→ TH8
```

TH4 相对最容易从文学作品与社会史经验中形成稳定模型，可作为新一轮专题丰满的样板。

### P1：整合 TH6 / TH7 旧资产

4. **TH6 战争、暴力与创伤**
5. **TH7 历史、记忆与时间**

这里不应直接新增大量文件，而应先完成资产职责重排：

```text
TH6
战争文学旧资产
→ 战争作为暴力形态与文学经验的一部分
+ 非战争暴力
+ 创伤与余波

TH7
记忆旧资产
→ 历史/记忆/时间三者中的“记忆”子层
+ 历史叙述
+ 时间经验
```

目标是保留历史积累，同时消除“旧专题名称代表整个新 TH”的错觉。

### P2：丰满 TH3.1—TH3.7

TH3 的七个专题已经通过边界压力测试，当前最适合按相同方法逐个补知识层：

```text
TH3.1 性别与身体
TH3.2 性、欲望与性规范
TH3.3 种族与族群
TH3.4 民族与文化身份
TH3.5 迁徙与流亡
TH3.6 故乡与归属
TH3.7 殖民身份
```

推荐顺序不是编号顺序，而是从关系最清楚、最容易形成机制模型的节点开始：

```text
TH3.3 种族与族群
→ TH3.4 民族与文化身份
→ TH3.5 迁徙与流亡
→ TH3.6 故乡与归属
→ TH3.7 殖民身份
→ TH3.1 性别与身体
→ TH3.2 性、欲望与性规范
```

前五个可以连续处理“分类—共同体—移动—地方—殖民”这一组身份/归属问题；TH3.1/3.2 再作为身体与性规范组处理。

### P3：把 TH1 / TH2 从 B 推到 A

TH1 / TH2 已经可用，不应抢在薄弱节点之前全面重做。

后续重点是：

- 把已有“机制概述”升级为稳定知识节点；
- 利用更多已读/经典作品建立对照组；
- 整合 TH2.1 / TH2.3 / TH2.5 的旧专题历史资产；
- 丰富跨时代、跨地域答案，而不是增加核心问题。

## 3. 每个专题的标准建设循环

以后丰满任一 TH 叶专题，都采用同一工作循环，但不强迫内部目录完全一致。

### Step 1：保留已冻结核心问题

除非出现跨作品、跨传统、持续性的结构反例，否则不改现有六/七问。

先问：

> 这些问题之间通过什么共同机制发生？

### Step 2：从作品反推第二层结构

至少选择：

- 5—8 部核心骨架作品；
- 5—8 部比较作品；
- 2—4 部边界/反例作品。

不是为了“数量达标”，而是寻找反复出现的解释结构。

第二层候选只有满足以下条件才正式建立：

```text
跨 ≥ 3 部作品重复出现
+ 不是某个核心问题的换名
+ 能同时解释 ≥ 2 个核心问题
+ 能产生新的作品比较价值
```

### Step 3：建立机制 / 关系模型

把“问题清单”转换为关系模型。例如：

```text
条件 / 位置
→ 规范或压力
→ 人物感知与关系变化
→ 行动策略
→ 后果
→ 结构再生产或改变
```

具体专题可以使用自己的模型，不要求每个主题完全同构。

### Step 4：建立稳定变体与结构张力

重点寻找：

- 同一问题的相反答案；
- 同一机制的不同后果；
- 不同社会位置下的不同经验；
- 个人层与制度层的张力；
- 维持 / 逃离 / 反抗 / 重建等不同策略。

这些内容比继续新增 P8/P9 更有价值。

### Step 5：做跨时间 / 地域 / 传统比较

不要写泛化的“中西不同”。至少要能形成具体比较句：

```text
在 A 传统中，X 主要通过……发生；
在 B 传统中，同一问题更多通过……发生；
这种差异与……的制度/宗教/家庭/历史条件有关。
```

### Step 6：建立作品比较组

每个专题至少形成 3 组明确比较：

```text
组 A：同问题，不同答案
组 B：同机制，不同时代/地域
组 C：表面相似，但实际属于不同 TH 边界
```

必要时再增加：

```text
组 D：典型 → 转型
组 E：中心案例 → 反例
```

### Step 7：重做 Canvas

Canvas 不再只是文件目录图，而至少呈现：

```text
核心问题
↕
机制
↕
变体 / 张力
↕
作品组
↕
相邻 TH / T / R / M / TY / IM / CN
```

### Step 8：升级 Base 的比较用途

作品 Base 除 ★/◆/△ 与已读状态外，逐步增加真正能用于比较的专题字段。

但禁止为了 Base 好看制造无意义字段。

### Step 9：成熟验收

使用 [[TH 内容成熟度审计#7. 成熟验收标准|成熟验收标准]]，通过后再将专题从 C/B 标记为 A。

## 4. 第一阶段具体建设任务

### TH4 社会、阶级与劳动

建议优先建立四类知识层：

```text
A. 社会位置如何形成
   出身 / 财产 / 教育 / 职业 / 性别 / 身份条件

B. 劳动如何组织生活
   时间 / 身体 / 技能 / 尊严 / 异化 / 照料

C. 阶级如何被再生产或跨越
   继承 / 婚姻 / 教育 / 城市 / 职业 / 消费

D. 阶级结构如何变得可见
   住房 / 城市空间 / 礼仪 / 语言 / 服饰 / 休闲
```

再用现有六问交叉，而不是把 A—D 升成 TH4.x。

### TH5 权力、制度与秩序

建议建立：

```text
合法性来源
→ 规则与分类
→ 官僚程序
→ 监控与规训
→ 惩罚与例外
→ 服从 / 协商 / 规避 / 反抗
→ 秩序维持或重建
```

重点不是再列“法律、监狱、国家”，而是解释权力如何从抽象关系进入人物日常生活。

### TH8 信仰、伦理与超越

建议把七问组织成三组张力：

```text
信仰层：神圣 ↔ 怀疑
伦理层：义务 / 良知 / 善恶 ↔ 冲突与罪责
超越层：苦难 / 死亡 ↔ 宽恕 / 救赎 / 超越
```

再建立跨传统比较：宗教性回答、世俗伦理回答、怀疑/失信仰回答，而不是按宗教名称做百科式分类。

## 5. 不建议做的事

### 不按 TRM 作品数量机械追平

M2 有大量作品支撑，不代表每个 TH 必须达到同样数量。主题轴允许一部作品多重命中，作品数量不是成熟度本身。

### 不把第二层知识结构变成新的 TH 坐标

例如：

```text
TH4 内部“劳动异化”
≠ TH4.1 新坐标
```

除非未来坐标级压力测试证明它可以独立承担作品定位功能。

### 不继续用治理文件替代知识建设

同一专题已有压力测试、终审、挑错记录后，下一轮优先写知识，不重复证明“为什么不拆”。

### 不一次性创建空目录

第二层只有被作品证据反复验证后才建立文件。

### 不为了统一删旧资产

TH2.1 / TH2.3 / TH2.5 / TH6 / TH7 的旧专题结构应被重解释、重链接，而不是清空重做。

## 6. 推荐推进节奏

```text
阶段 A：样板专题
TH4
→ 验证“主题成熟模型”是否好用

阶段 B：宽叶补齐
TH5 → TH8

阶段 C：旧资产整合
TH6 → TH7

阶段 D：身份与归属组
TH3.3 → TH3.4 → TH3.5 → TH3.6 → TH3.7

阶段 E：身体与性规范组
TH3.1 → TH3.2

阶段 F：成熟专题深化
TH1 / TH2
```

每完成一个专题，都先实际用作品 Base、Canvas 和阅读路线检验；不要连续生成大量文件后再回头验证。

## 7. 下一步

本路线图建议下一项实际建设为：

> **TH4 社会、阶级与劳动：从 C 级“可靠骨架”升级为第一个按新成熟标准建设的 A 级主题专题样板。**

TH4 完成后，再根据实际使用体验校准本路线图，而不是在没有样板验证前同时改造全部 22 个专题。
