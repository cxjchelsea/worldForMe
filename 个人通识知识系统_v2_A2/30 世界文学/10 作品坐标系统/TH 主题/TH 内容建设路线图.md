# TH 内容建设路线图

> 本路线图原用于把 TH 从“可靠主题骨架”推进到“成熟主题知识地图”。该建设阶段现已完成。

## 1. 建设目标完成情况

```text
主题坐标
+ 可复用解释模型
+ 跨作品比较网络
+ 阅读路径
+ 可持续扩展的专题知识地图
```

```text
TH1.1—TH1.5 = A
TH2.1—TH2.5 = A
TH3.1—TH3.7 = A
TH4—TH8 = A
ALL_22_LEAF_TOPICS = A
```

## 3. 已验证的标准建设循环

本轮建设验证了一套可继续用于未来专题维护的方法：

```text
冻结核心问题
→ 从作品反推机制
→ 建立统一解释模型
→ 建立结构张力与稳定变体
→ 做跨时间 / 地域 / 传统比较
→ 建立作品比较组
→ 重做阅读路线
→ 用边界 / 反例做压力测试
→ 达到阈值后标记 A
```

关键经验：

- 不用新增坐标来代替知识建设；
- 不用 P8/P9 堆数量来代替机制深化；
- 不用作品数量代替解释能力；
- 不把历史层、类型层、机制层混成第二坐标维度；
- 负向样本与边界样本和正向骨架作品同样重要。

## 4. 当前不再继续做的事情

TH 已经进入成熟期，因此默认停止以下建设式操作：

- 按编号继续增加 TH1.6 / TH2.6 / TH3.8；
- 把 TH4—TH8 拆成新的子坐标；
- 把专题内部机制升格为坐标；
- 一次性创建空目录或空结构文件；
- 为追求“更完整”重复新增治理文档；
- 机械追平 T / R / M 的作品数量。

## 5. 新阶段：使用与维护路线

### M1 新作品进入

```text
阅读 / 导入作品
→ 写出作品真正持续追问的问题
→ 标注一个或多个 TH
→ 每个标签给出独立理由
→ 投影到对应专题
```

### M2 专题持续丰满

允许增加：

- 新骨架案例；
- 同问题不同答案比较；
- 同机制跨传统比较；
- 典型与反例对照；
- 阅读笔记与跨轴链接。

但默认不改变坐标和核心问题。

### M3 高密度多标复核

当作品在同一多叶域内出现异常高密度标签时，触发人工复核。重点检查：

```text
是否只是题材背景？
是否多个标签用了同一个理由？
删掉某个问题后作品结构是否仍完整？
问题本身与外部条件是否被混淆？
```

### M4 跨轴联动

后续重点从“TH 内部建设”转向：

```text
TH × T
TH × R
TH × M
TH × TY
TH × IM
TH × CN
```

目标是让主题坐标与时间、地域、思潮、类型、意象和文化叙事真正形成可检索的作品网络。

### M5 算法与检索验证

未来如果开展推荐、相似作品发现、专题检索或自动标注，应记录：

- 哪些 TH 最容易误判；
- 哪些边界经常被系统混淆；
- 哪些标签过密或过稀；
- 哪些真实作品持续无法定位。

只有真实使用数据反复证明结构存在问题，才进入解冻评估。

## 6. 解冻不是日常维护

观察名单继续保留：

```text
自然 / 环境 / 非人世界
知识 / 科学 / 技术
艺术 / 语言 / 创作
```

它们只有满足 [[TH 轴级总终审]] 的新域重启条件，才允许讨论 TH9。

同理，单个叶节点只有持续出现跨作品、跨时期、跨传统且无法由现有问题和机制解释的反例，才允许讨论重新拆分。
