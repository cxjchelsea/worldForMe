# TH 主题与人类问题

> 路径：世界文学 → 作品坐标系统 → **TH 主题与人类问题**

TH 与 T / R / M 同属作品坐标轴，回答：**作品主要在思考什么主题 / 人类问题？**

一部作品可以拥有多个 TH；canonical 作品字段为 `axis_th`。旧 `axis_q` 仅作迁移期 fallback。

## 内容建设

- [[TH 内容成熟度审计]]：判断 TH 与成熟 T / R / M 专题之间真正的内容差距。
- [[TH 内容建设路线图]]：规定后续从“可靠主题骨架”推进到“成熟主题知识地图”的顺序与验收标准。

当前阶段的重点不再是继续拆 TH 分类，而是补充机制、稳定变体、跨传统比较、作品比较组与阅读路线。

### 优先级

- `★` 核心：建立专题骨架的作品；
- `◆` 重点：重要比较、转折或补充；
- `△` 扩展：边界、变体与延伸阅读。

### 节点模型

```text
axis
→ taxonomy_group
→ taxonomy_leaf
→ literature_topic_map
→ structure database / work database
```

专题内部问题不自动升级为新的作品坐标。

## 与其他轴的边界

- **TH**：作品主要在思考什么；
- **TY**：作品采用什么类型、叙事与文化机制；
- **IM**：文本以什么高显著意象承载意义；
- **CN**：作品接入什么长期文化叙事结构；
- **T / R / M / G**：时间、地域、思潮与体裁坐标。

## 观察名单

以下方向继续观察，但 V1 不新增为 TH：

- 自然、环境与非人世界；
- 知识、科学与技术；
- 艺术、语言与创作。
