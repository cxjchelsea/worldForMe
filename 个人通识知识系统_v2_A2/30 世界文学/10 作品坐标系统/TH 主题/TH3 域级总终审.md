# TH3「社会身份、身体与归属」域级总终审

## 一、终审结论

TH3 七个叶节点在 V1 阶段可以整体冻结：

```text
TH3  社会身份、身体与归属
├─ TH3.1 性别与身体
├─ TH3.2 性、欲望与性规范
├─ TH3.3 种族与族群
├─ TH3.4 民族与文化身份
├─ TH3.5 迁徙与流亡
├─ TH3.6 故乡与归属
└─ TH3.7 殖民身份
```

未发现必须新增第八叶节点、合并现有叶节点或继续拆分 `TH3.x.y` 的稳定结构证据。

TH3 的共同问题不是泛化的“身份”，而是：

> **主体如何被身体、性规范、群体分类、文化共同体、空间移动、地方归属与殖民关系定位；这些外部位置又如何被继承、内化、协商、反抗或重新定义。**

泛化的“我是谁、如何成为自己”仍优先进入 TH1.1；TH3 只有在“社会位置 / 身体位置 / 群体位置 / 空间位置”成为主体问题的稳定来源时才命中。

## 二、七节点的最小区分规则

| 节点 | 核心提问 | 最小判定 |
|---|---|---|
| TH3.1 性别与身体 | 我的性别化身体如何影响社会位置与行动可能？ | 性别角色、身体经验、身体控制改变被观看、被承认或能动性 |
| TH3.2 性、欲望与性规范 | 什么样的性欲、性行为与性身份被允许、禁止和命名？ | 性本身成为规范、羞耻、隐匿、合法性或自主问题 |
| TH3.3 种族与族群 | 谁把我划入哪一群，而这个群体得到怎样的差别待遇？ | 群体边界、种族化、他者化、隔离、passing、族群归属 |
| TH3.4 民族与文化身份 | 我如何成为、继承或重写某个文化共同体的一员？ | 语言、传统、民族叙事、文化实践和真实性构成身份 |
| TH3.5 迁徙与流亡 | 离开与移动如何改变生活结构？ | 迁移、跨境、流亡、难民化、异地生存、实际回返 |
| TH3.6 故乡与归属 | 什么地方被经验为家？ | 地方依附、故乡记忆、返乡陌生化、失乡、新家建立 |
| TH3.7 殖民身份 | 殖民关系如何制造身份等级并进入自我理解？ | 殖民者/被殖民者、中心/边缘、文明/野蛮及其内化与去殖民化 |

## 三、域内边界终审

### 1. TH3.1 ↔ TH3.2

- 性别角色、身体经验、生育身体、医学化、身体控制 → TH3.1。
- 性欲、性行为、性取向、性身份分类、性禁忌与性规范 → TH3.2。
- 性规范通过身体治理发生时可兼标，但分析问题必须分别成立。

### 2. TH3.3 ↔ TH3.4

- “别人把我划成什么群体，并因此怎样对待我” → TH3.3。
- “我如何理解自己属于哪个语言、民族、文化共同体” → TH3.4。
- 族群身份既可能被外部分类，也可能被内部继承；只有两个问题都成为作品稳定冲突时才兼标。

### 3. TH3.4 ↔ TH3.5 ↔ TH3.6

这是 TH3 内最重要的三角边界：

```text
移动发生了什么？       → TH3.5
移动后我属于什么文化？ → TH3.4
哪里仍然是我的家？     → TH3.6
```

- 跨国移动本身不能自动推出文化身份主题。
- 返乡行为本身不能自动推出故乡归属主题。
- 双文化身份也不等于迁徙仍是作品核心。

### 4. TH3.3 / TH3.4 ↔ TH3.7

殖民身份不等于“种族 + 文化”。只有**殖民关系是身份等级的来源**时进入 TH3.7：

- 一般种族化与歧视 → TH3.3。
- 一般语言、传统、文化共同体认同 → TH3.4。
- 种族或文化被殖民秩序组织成“文明/落后、中心/边缘”的等级 → TH3.7。

## 四、与 TH3 域外节点的硬边界

TH3 不追求字面意义上的“所有社会身份”。以下问题由其他一级域承担，不能为了填补 TH3 而重新引入：

| 问题 | 优先去向 | TH3 何时可兼标 |
|---|---|---|
| 泛化自我认同、主体连续性 | TH1.1 | 社会/身体位置成为主体危机的直接来源时 |
| 爱情、婚姻、家庭、亲子 | TH2 | 身份规范或迁徙/文化位置成为关系冲突的独立核心时 |
| 阶级、贫困、劳动、经济位置 | TH4 | 阶级与种族/性别/文化身份发生稳定交叉时 |
| 国家机器、法律、行政、制度权力 | TH5 | 制度通过身份分类规定人物位置时 |
| 战争、暴力、创伤 | TH6 | 暴力制造迁徙、种族化或殖民身份后果时 |
| 历史记忆、时间、遗忘 | TH7 | 记忆维持文化身份、故乡归属或殖民身份时 |
| 宗教信仰、救赎、超越 | TH8 | 宗教作为文化共同体身份或殖民等级工具时 |

因此，“阶级身份”“宗教身份”“公民身份”“职业身份”等暂不新增 TH3 子坐标：它们已有更稳定的上位问题域，或尚未形成独立于 TH4/TH5/TH8 的文学主题坐标。

## 五、覆盖缺口检查

本轮重点检查以下潜在缺口：

### 身体疾病、残障、衰老

无需新增节点。只有它们改变社会位置、被承认方式和能动性时进入 TH3.1；疾病、死亡或痛苦本身由其他主题承接。

### 混血、混杂、passing

无需新增节点。一般群体跨界归 TH3.3；文化混合归 TH3.4；由殖民等级制造的中介/混杂身份归 TH3.7。

### 移民第二代、离散后代

无需新增节点。实际迁移经历归 TH3.5；第二代文化身份归 TH3.4；“哪里是家”归 TH3.6。

### 无家者、难民、流亡者

无需新增节点。移动与法律/生活处境归 TH3.5；失乡与地方归属归 TH3.6；战争原因归 TH6。

### 国家/公民身份

暂不新增。国家共同体想象可进入 TH3.4；法律资格、国家制度与公民权由 TH5 优先承担。只有未来作品压力测试显示“公民身份”存在大量不能被这两者解释的稳定冲突，才重新评估。

## 六、域级公共机制：只用于导航，不新增坐标层

七个叶节点可以按三组机制理解，但这只是**域内导航视图**，不是新的分类层：

```text
A. 身体与性规范
   TH3.1 性别与身体
   TH3.2 性、欲望与性规范

B. 群体与文化身份
   TH3.3 种族与族群
   TH3.4 民族与文化身份
   TH3.7 殖民身份

C. 空间、移动与地方归属
   TH3.5 迁徙与流亡
   TH3.6 故乡与归属
```

三组之间允许交叉，但不新增 `TH3-A / TH3-B / TH3-C` 或其他中间坐标层，以避免把已经稳定的作品坐标树重新复杂化。

## 七、重复命中治理规则

TH3 允许一部作品同时命中多个叶节点，但必须满足：

1. 每个命中都能用一句独立问题解释；
2. 删除其中一个问题后，另一个问题仍然成立；
3. 不允许因为作品背景存在某种身份标签就自动写入坐标；
4. `axis_th` 记录作品层面的主题坐标，专题内部 P1/P2 等只用于比较，不反向升级为坐标；
5. 如果一部作品出现 TH3.3/TH3.4/TH3.5/TH3.6/TH3.7 大面积全命中，应逐项复核，避免把“后殖民/移民背景”机械展开成全部标签。

## 九、解冻条件

TH3 冻结不意味着永久不能修改。只有出现以下任一证据才重新开启结构讨论：

- 新增大规模作品后，持续出现无法归入七叶的同一类主题问题；
- 某两个叶节点长期在绝大多数作品中稳定共同命中，证明坐标辨识度不足；
- 某叶节点内部作品持续分裂成两套互不相干、且各自具有独立作品辨识度的体系；
- TH4–TH8 建设完成后发现域际边界存在系统性冲突；
- 实际使用中检索错误率表明当前边界规则无法操作。

在这些条件出现之前，TH3 的后续工作应转向**作品补标、阅读校准与专题内容丰满**，而不是继续修改坐标树。
