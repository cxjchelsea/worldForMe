## 4. 成熟知识地图验收

A 级不是“文件很多”，而是专题能够稳定完成六种工作。

### 4.1 定义与边界

每个叶节点均具有明确的核心问题与最小判据，并能与相邻 TH 及其他轴区分。

### 4.2 统一解释机制

每个专题已经不只列问题，而能回答“这个问题怎样发生”。例如：

```text
TH4：资源 → 社会位置 → 劳动 → 生活机会 → 再生产
TH5：合法性 → 规则 → 程序 → 规训 → 强制 → 再生产
TH6：敌我化 → 卷入 → 伤害 → 创伤 → 责任/见证 → 延续/终止
TH7：过去 → 痕迹 → 记忆/解释 → 传递 → 公共化 → 遗忘/重写 → 当下/未来
TH8：价值依据 → 判断 → 行动 → 责任/后果 → 危机 → 转化
```

TH1—TH3 的每个叶节点也已经形成自己的关系模型，而不是共享一套空泛模板。

### 4.3 结构张力与变体

专题内部已经能够比较相反答案、不同策略和不同后果，而不是继续无限新增 P8/P9 或 THx.x.x。

### 4.4 跨时间、地域与传统比较

比较不再使用“古代/现代”“东方/西方”的简单二分，而围绕固定问题比较不同制度、宗教、家庭、历史与文化条件下的机制差异。

### 4.5 作品支撑与反例

作品不再只是证明坐标存在的样本；每个 A 级专题都有骨架案例、比较案例、边界/反例及压力测试，可用于阅读与校准。

### 4.6 阅读导航

专题阅读路线已经从书目顺序升级为“学习某种分析能力”的路线。

因此：


## 5. 一级域覆盖终审

本轮重新检查此前观察名单及可能残余主题。

### 自然、环境与非人世界

文学价值很高，但目前仍不能证明需要新增 TH9。相关作品可分别进入：人与自然的伦理/超越 → TH8；资源、土地与环境分配 → TH4；国家治理与环境制度 → TH5；灾难、暴力与创伤 → TH6；故乡与地方归属 → TH3.6；非人叙事机制则可能属于 TY / IM / CN。

### 知识、科学与技术

技术本身常是对象或设定。只有当它稳定形成独立人类问题中心、无法由主体性、制度、劳动、伦理等域承接时，才考虑新域。目前证据不足。

### 艺术、语言与创作

艺术家主体可进入 TH1；文学制度、劳动与阶级可进入 TH4/TH5；语言与文化身份可进入 TH3.4；艺术形式本身主要属于 M / G / TY。当前同样不足以建立新域。

因此观察名单继续保留，但不作为 TH 尚未成熟的缺口。

## 6. 多标签治理总规则

TH 允许多标签，但每个标签必须有独立问题句和独立机制证据。

```text
背景出现 ≠ 命中
人物身份 ≠ 命中
题材名称 ≠ 命中
类型标签 ≠ 命中
同一理由重复解释多个 TH ≠ 合格多标
```

推荐判断顺序：

1. 写出作品真正持续追问的问题；
2. 为每个候选 TH 写独立问题句；
3. 检查删掉该问题后作品主要结构是否仍基本完整；
4. 区分“问题本身”与造成问题的外部条件；
5. 高密度多标时触发人工复核。

TH1、TH2、TH3 各域已有局部高密度复核规则；轴级原则统一为：**标签密度不等于分析深度。**

## 7. 与其他轴的最终边界

```text
T   → 作品处于什么时间
R   → 作品处于什么地域/传统
M   → 作品处于什么思潮/美学谱系
G   → 作品是什么体裁
TH  → 作品主要在思考什么人类问题
TY  → 作品采用什么类型、叙事与文化机制
IM  → 作品用哪些高显著意象承载意义
CN  → 作品接入哪些长期文化叙事结构
```

TH 不承担“所有重要内容”。它只承担具有稳定跨作品辨识度的人类问题。

## 8. 冻结后的工作模式

从本终审开始，TH 从“建设期”转入“使用与维护期”。默认工作不再是继续扩树，而是：

```text
阅读新作品
→ 标注 TH
→ 将作品投影到专题
→ 用现有机制解释
→ 加入比较组
→ 发现真实反例时记录
→ 达到解冻阈值才修改坐标/核心问题
```

允许继续增加：作品案例、比较组、阅读笔记、跨轴链接、Canvas/Base 展示和局部解释材料。

默认禁止：为了单一作品新增 TH、为了目录整齐新增中间层、把专题内部机制升级成坐标、因为新术语流行而重命名结构。

## 9. 解冻条件

只有出现以下一种或多种稳定证据，才重新打开 TH 结构：

- 连续出现跨时期、跨地域作品无法被现有 8 域稳定承接；
- 某一对一级域长期需要用同一理由双标，说明系统性重叠；
- 某叶内部持续出现无法由现有核心问题和机制解释的作品簇；
- 新候选域满足既有 TH9 重启条件；
- 实际检索/推荐/算法验证表明现有坐标严重降低辨识度。

单一作品、单一理论术语或一次边界争议不足以解冻。
