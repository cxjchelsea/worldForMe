## 2. TH2 的共同问题不是“关系”本身

TH2 不能被泛化成“只要作品里有人际关系就归 TH2”。本域真正处理的是：

> **人如何进入亲密关系，如何把关系转化为持续共同生活，如何被家庭与代际结构嵌入，以及个体又如何在这些关系与结构中成长、分离或重新定位。**

因此 TH2 的五叶分别承担五种不可互换的解释职责：

```text
为什么偏偏是这个人，我是否真正看见并得到对方回应？
→ TH2.1 爱情与欲望

关系建立之后，我们怎样承诺、共同生活、信任、修复与退出？
→ TH2.2 婚姻与亲密关系

一个家庭/家族网络怎样定义成员、分配资源与义务，并跨代维系？
→ TH2.3 家庭与家族

具体上一代—下一代怎样照料、期待、控制、分离、传递与重新理解？
→ TH2.4 亲子与代际

一个人怎样通过时间和经验发展、学习、受阻、拒绝或重写成人位置？
→ TH2.5 童年与成长
```

## 3. TH2 的上位关系模型

TH2 不应被理解成严格生命周期，但五叶之间存在稳定的关系尺度递进：

```text
具体他者成为爱欲对象
→ 持续伴侣关系形成
→ 伴侣关系进入更大的家庭/家族网络
→ 家庭网络中的纵向代际关系展开
→ 个体在这些关系及更大社会经验中形成发展轨迹
```

压缩为：

```text
爱欲对象
→ 伴侣关系
→ 家庭系统
→ 代际关系
→ 个体发展
```

这只是导航与解释模型，不是强制时间顺序：
- 未婚关系可以直接命中 TH2.2；
- 包办婚姻可能直接进入 TH2.2 / TH2.3，而无 TH2.1；
- 无稳定家庭的成长作品仍可进入 TH2.5；
- 成年子女与老年父母的关系仍属于 TH2.4，而非“成长完成后退出 TH2”。

## 4. 五叶最小边界

### TH2.1 vs TH2.2

```text
为什么是这个人？是否真正看见对方？是否存在回应？
→ TH2.1

形成持续关系后怎样生活、承诺、信任、修复、退出？
→ TH2.2
```

**恋爱结婚 ≠ 自动双标。** 只有两套问题都独立成立才兼标。

### TH2.2 vs TH2.3

```text
两个人怎样共同生活？
→ TH2.2

这段婚姻怎样改变家族联盟、继承、成员位置与资源网络？
→ TH2.3
```

婚姻既可作为两人关系，也可作为亲属制度接口；必须按解释单位区分。

### TH2.3 vs TH2.4

```text
家庭系统规定谁是成员、谁继承、谁承担什么义务？
→ TH2.3

具体父母/祖辈与子女如何照料、期待、控制、分离？
→ TH2.4
```

有父母子女不自动命中 TH2.4；有家庭也不自动命中 TH2.3。

### TH2.4 vs TH2.5

```text
父母怎样面对孩子的成长与独立？
→ TH2.4

孩子怎样通过经验获得能力、判断与新的成人位置？
→ TH2.5
```

同一事件可以双标，但必须分别解释“关系变化”和“发展变化”。

### TH2.1 vs TH2.5

青年恋爱可以参与成长，但：

```text
爱欲对象本身、投射、回应、占有与失去
→ TH2.1

恋爱经验怎样改变人物的发展轨迹、能力与成熟标准
→ TH2.5
```

## 5. 多标签治理规则

TH2 允许高密度多标签，但不鼓励“家庭题材全家桶”。

### 5.1 独立问题句原则

每一个 TH2.x 标签都必须能写出不同的问题句；不能用同一句“家庭关系很复杂”支撑多个标签。

### 5.2 删除测试

删除某一标签及其对应问题后，其余标签必须仍然独立有意义。

### 5.3 背景不等于命中

以下均不能独立构成 TH2 命中：

```text
人物有恋人
人物已婚
人物有家庭
人物有父母子女
人物是青少年
故事跨越多年
```

必须存在相应关系机制或发展机制。

### 5.4 高密度人工复核

如果一部作品同时命中 TH2.1–TH2.5 中 4 个以上叶节点，默认触发人工复核：

- 是否只是“人物一生都写到了”；
- 是否把家庭背景误作家庭系统；
- 是否把所有青年经历误作成长；
- 是否把婚姻自动拆成爱情 + 亲密 + 家族；
- 是否每个标签真的拥有独立问题。

## 6. 复杂作品校准

### 《红楼梦》

```text
宝黛等具体爱欲关系、投射与回应
→ TH2.1

若分析持续伴侣关系运行，则证据有限，不因婚配议题自动 TH2.2

贾府成员资格、资源、婚配、等级和衰败
→ TH2.3

贾政—宝玉等父子期待、权威与分离
→ TH2.4

青春共同体、礼法教育、失去与成人秩序之间的成长问题
→ TH2.5
```

因此《红楼梦》可高密度多标，但每个标签必须由不同机制支撑。

### 《简·爱》

```text
爱情对象、相互承认与主体边界
→ TH2.1

若分析长期共同生活运行，TH2.2 不是当然主轴

原生家庭缺失、替代家庭与成员承认
→ TH2.3 可作边界/比较

稳定亲子关系并非不可替代中心
→ 不自动 TH2.4

童年压迫、教育、职业、爱情和自主形成发展长弧
→ TH2.5
```

### 《宠儿》

```text
奴隶制破坏亲属网络、家庭重新组成
→ TH2.3

母女照料、保护、创伤传递与失去后的关系
→ TH2.4

若关注丹佛的发展、离家与获得行动能力
→ TH2.5

暴力与创伤本身
→ TH6（域外）
```

### 《安娜·卡列尼娜》

```text
爱欲对象、相互性、欲望与社会阻碍
→ TH2.1

婚姻、忠诚、信任、共同生活与退出成本
→ TH2.2

家庭成员资格、社会承认与孩子归属若构成稳定问题
→ TH2.3 / TH2.4 可按具体机制兼标
```

不能因为“婚外情 + 有孩子”自动命中全部 TH2。

### 《喜福会》

```text
母女期待、传递、分离与重新理解
→ TH2.4

女儿们在移民、文化与亲密经验中的发展变化
→ TH2.5

若分析整个家族网络和跨代成员结构，才进入 TH2.3
```

## 7. 是否需要第六叶

重点测试以下候选：

### 7.1 友谊

**不新增。**

友谊可承担重要亲密关系，但当前更适合作为：
- TH2.5 P3 的成长机制；
- TH1.3 的连接与孤独反向结构；
- 某些 chosen family 场景下进入 TH2.3。

目前没有证据证明“友谊”能像爱情、伴侣、家庭、亲子、成长一样形成稳定且不重叠的一级关系单位。

### 7.2 兄弟姐妹

**不新增。**

具体兄弟姐妹互动可进入 TH2.3 的家庭系统内部机制；若作为同伴关系参与成长，可进入 TH2.5。当前不足以独立成叶。

### 7.3 照料

**不新增。**

照料横跨 TH2.2、TH2.3、TH2.4，并可与 TH3.1、TH4、TH6 发生交叉。它是关系机制，不是稳定坐标叶。

### 7.4 失去与哀悼

**不新增。**

失去恋人、伴侣、家人、父母或子女之后分别回到相应关系叶；死亡有限性归 TH1.4，记忆归 TH7。独立新增会形成横跨多个关系单位的大口袋。

### 7.5 社区 / 共同体

**不新增。**

文化共同体与归属已有 TH3.4 / TH3.6；制度与公共共同体归 TH5；家庭外的一般共同体不应由 TH2 吸收。

### 7.6 性 / 性关系

**不新增。**

爱欲对象可进入 TH2.1；性规范、性身份、同意与许可问题归 TH3.2。当前边界已经足够稳定。


## 8. 域外边界

### TH1 自我、存在与生命

```text
我是谁、是否自由、是否孤独、如何面对死亡、人生是否有意义
→ TH1

这些问题通过恋爱、伴侣、家庭、亲子或成长机制展开
→ 可兼标 TH2
```

不能因为亲密关系影响自我就自动加 TH1.1。

### TH3 社会身份、身体与归属

```text
身体、性别、性规范、族群、文化身份、迁徙、故乡、殖民身份
→ TH3

这些社会位置怎样进入具体亲密/家庭/代际关系
→ 可兼标 TH2
```

特别是 TH2.1 / TH3.2 必须保持“具体欲望对象”与“性规范/同意/身份分类”之分。

### TH4 社会、阶级与劳动

```text
阶级、财富、劳动关系本身
→ TH4

资源通过婚姻、继承、家业和亲属网络传递
→ TH2.3

职业/阶级经验改变人物成长轨迹
→ TH2.5
```

### TH5 权力、制度与秩序

学校、法律、婚姻制度、国家、宗教机构如何运行归 TH5；这些制度进入伴侣、家庭或成长关系时才兼标 TH2。

### TH6 战争、暴力与创伤

暴力和创伤本身归 TH6；它们破坏家庭网络、亲子照料或成长轨迹时分别进入 TH2.3 / TH2.4 / TH2.5。

### TH7 历史、记忆与时间

记忆、传承与历史意识本身归 TH7；家庭作为传递装置归 TH2.3，具体上一代—下一代传递归 TH2.4。

### TH8 信仰、伦理与超越

婚姻、家庭、孝、性与成长的伦理判断若以善恶、义务、宗教/终极价值为中心归 TH8；关系运行本身仍归 TH2。

## 9. 域级上位机制

TH2 可用以下模型作为上位导航：

```text
关系需求 / 社会条件 / 人生阶段
→ 与具体他者建立关系
→ 关系被承诺、制度化或嵌入家庭网络
→ 资源、照料、权威、期待与记忆在关系中流动
→ 个体获得支持，也受到约束
→ 分离、背叛、冲突、历史冲击与成长使旧关系结构失效
→ 协商、修复、退出、重组或重新理解
→ 关系结构与个体发展同时被改写
```

压缩：

```text
建立关系
→ 组织共同生活
→ 嵌入家庭结构
→ 代际传递
→ 分离 / 成长 / 重组
```

这一模型仅用于整域解释，不新增任何中间坐标层。

## 10. 最终冻结规则

TH2 达到 A 级后，默认停止分类扩张。未来仅在以下情况重新打开：

1. 持续出现跨传统、跨时期、跨形式作品，无法由 TH2.1–TH2.5 任一叶稳定解释；
2. 某一候选问题必须长期依赖多个现有叶拼接，且拥有独立作品簇；
3. 现有兄弟边界在真实作品标注中反复失败，而不是个别作品天然多主题；
4. 新叶能够明显降低误标，而不是增加概念数量。

否则：

> **坐标停止向下拆分以后，由专题知识地图接管复杂度。**
