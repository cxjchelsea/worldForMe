# M5.2 权力、身份与世界批评

> 路径：[[../../00 世界文学使用规则|世界文学]] → [[../../10 轴/M轴 文学思潮与美学范式|M轴]] → [[M5 战后与当代美学范式|M5 战后与当代范式]] → **M5.2 权力、身份与世界批评**

M5.2 是叶节点。

> 核心问题：**谁有权定义“主体”“文明”“性别”“文学”与“世界”？哪些声音被帝国、父权、异性恋规范、知识制度与人类中心主义排除？**

## 内部范围

### 殖民与知识权力
- 后殖民
- 去殖民

### 性别、身体与身份
- 女性主义
- 酷儿

### 人类与非人世界
- 生态批评
- 生态文学

这些对象的共同点，不是共享一种形式技巧，而是重新检查文学与权力、身份、知识生产、环境和世界秩序之间的关系。

## 认知主线

经典 / 帝国 / 父权 / 规范性主体 / 人类中心主义  
→ 谁被允许说话、被怎样表述、谁被排除  
→ 后殖民与去殖民重审帝国和知识秩序  
→ 女性主义与酷儿理论重审性别、身体与规范性  
→ 生态批评进一步质疑人类作为唯一尺度的世界观。

## 边界

- M5.2 不是主题标签集合。作品只是涉及女性、殖民或自然，并不足以自动进入本节点。
- M5.2 关注能够支撑批评范式、知识权力或世界观转型的理论、文学实践与代表作品。
- Négritude、Harlem Renaissance、反殖民文学运动等真实发生的集体文化运动主要归 [[M4 政治、民族与文化运动|M4 集体文学运动与文化政治]]；后殖民/去殖民作为后续理论与批评框架归 M5.2。
- 一个作品可以同时投影到 M4 与 M5.2：前者解释它参与什么历史运动，后者解释它如何被权力/身份框架重新理解。
