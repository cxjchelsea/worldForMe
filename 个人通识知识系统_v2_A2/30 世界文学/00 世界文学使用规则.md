# 世界文学使用规则

## 1. 五轴职责

### 四个主坐标
- T：时间 / 文学史阶段
- R：地区 / 文学传统
- M：思潮 / 运动 / 美学范式
- G：文学体裁与文本形式

### 一个辅助坐标
- Q：文学内容域（QT 类型 + QH 主题，两个 facet）

N 轴（叙事技法 / 形式）已整轴撤销，不再作为坐标，也不再挂专题。作品页上的 `axis_n`、`WL-TOPIC-N2-UNRELIABLE` 与对应 `topic_links` 已删除，新校准不再写。

五轴不是一棵总树，而是五套回答不同问题的坐标系统。一部作品可以同时拥有多个轴值；同一轴在语义允许时也可以是列表。

## 2. T轴：只有真实时间范围才是时间坐标

当前全局 canonical 时间坐标为 T0–T6。

旧版 `T0.1 / T3.5 / T5.2 ...` 描述的是一个时期中的制度、文类、思潮或历史过程，不是更细时间区间，因此 v2 统一解释为 `historical_feature / stage_feature`，不再作为新的 `axis_t` 值。

真正需要细分时间时，必须显式定义时间范围。专题内部时间阶段不会自动升格为全局 T 节点。

## 3. R轴：区域树允许跨区域关系

R 轴全局坐标只到一级：R1–R10。国家、语言、内部区域和大多数离散类型在专题内部展开，不建成 `R4.2`、`R2.1` 这类全局子节点。

唯一例外：非洲离散文学的 canonical 坐标为 `R10.2`；R7 通过关系指向它，不再同时维护 `R7.7`。

若以后某个内部传统要独立成专题，再二选一：继续留在现有整区专题里，或新建叶节点并同步拆专题。不预建空的国家节点。

## 4. M / Q 的已修复坍缩节点

当前已冻结：

```text
M3 现代主义与先锋派
├─ M3.1 现代主义                 ← 现代主义文学
└─ M3.2 先锋派                   ← 专题待建

Q
├─ QT 类型与叙事传统
│   QT1–QT14 类型叶；QT8 文化类型传统 → QT8.1–QT8.8
└─ QH 主题与人类问题
    QH1–QH10 十个问题域；专题挂在叶子上
```

旧 `Q1–Q16` 全部视为 legacy。新校准写 `QT*` + `QH*`，一部作品可以同时有多个。

## 5. G轴：只划文本形式

G 只回答「这部作品在形式上是什么」。判断标准：内容全部换掉，这个标签还能成立吗？

现行骨架：

```text
G1 诗歌
G2 戏剧
G3 小说
G4 散文与随笔
G5 生命书写
G6 纪实与文学非虚构
G7 混合与跨文类
```

`G1–G7` 已整轴重编号。旧树（口述民间、旧小说号、旧纪实号）全部停用。

- 神话／传说／童话／民间故事／寓言 → QT9 / QT11 / QT12 / QT13 / QT14
- 推理、科幻、奇幻、恐怖、冒险、反乌托邦、历史叙事 → QT1–QT7
- 武侠等 → QT8.1–QT8.8
- 成长／家族／爱情／战争 → QH
- 游记专题 → G6.3；虚构作品里的旅行是内容，不是 Travel Writing
- 儿童／YA、口述／书写不进五轴

已有坐标的作品页已按现行号重对齐。**旧 `G4` 是小说，新 `G4` 是散文。新校准小说写 `G3`。** 只有专题、没有五轴的作品不自动补轴。

类型专题改挂：

- 成长 → QH2.3.2　家族 → QH2.2.3　爱情 → QH2.1.1　战争 → QH6.1
- 历史叙事 → QT7
- 推理／科幻／奇幻／恐怖／冒险／反乌托邦／神话 → QT1–QT6、QT9
- 旅行文学 → G6.3
- 武侠等 → QT8.1–QT8.8

## 7. 作品如何进入系统

作品实体唯一位于 `40 作品/`。

作品可以写五轴。来源必须分开：

```text
axis_t
axis_r
axis_m
axis_g
axis_q
axis_source: read_calibrated | inferred
```

- `read_calibrated`：已读后手校，或已读页上只补了空的 M。
- `inferred`：由专题、年份或名著母库推出，可被以后手校覆盖。
- 已有非空坐标不因推断改写。没信号的轴保持空，不填默认欧洲、不填默认 T6。
- 专题挂进来的书可以有推断轴，但不能把 `inferred` 当成已读校准。

### G轴规则

`axis_g` 只写文本形式：现行 `G1–G7` 及其叶子。

- 一本作品同时写形式、类型和主题：例如长篇科幻写 `G3` / `G3.3` + `QT2` + 若干 `QH*`。篇幅不确定时写 `G3`，不要猜 `G3.3`。
- 已有坐标已清洗到现行号。新校准不要再写旧 `G4.5` / `Q1–Q16` / `axis_n`。
- 旧 `G4` ≠ 新 `G4`。映射时看名称，不看光秃秃的编号。

### T / R / M legacy 规则

- 已有 `T*.x` 坐标不进行无差别批量改写，但新校准不再写这些 feature code。
- `R7.7` 视为 `R10.2` 的 deprecated duplicate alias；后续主动校准时迁移到 `R10.2`。
- 已有 `M2.1` / `M2.2` / `M5.4` 等细坐标已收到现行叶：M2、M5。M3.1 仍是现行坐标。新校准写 M1–M5，或该思潮独立成专题后的叶节点。
- `axis_n` 与 `WL-TOPIC-N2-UNRELIABLE` 随 N 轴撤销而停用。作品页上的 `axis_n`、该专题 ID 与对应链接已删除，正文「六轴坐标」已改为「五轴坐标」。

## 8. Topic 机器关系

`topics` 只保存稳定 Topic ID，例如：

```text
WL-TOPIC-G45-SF
WL-TOPIC-G46-DYSTOPIA
```

专题换 anchor 不修改这些 ID。专题 Base 继续使用 `topics.contains("...")` 精确匹配。

当前正式顶层 Topic 的 stable ID → canonical anchor 映射统一登记在 `id-registry-world-literature.json` 的 `topic_anchors` 中。`WL-TOPIC-N2-UNRELIABLE` 已随 N 轴撤销。

## 9. Registry：唯一机器真相

六轴修复已经完成首轮收束。从 v2.4 开始：

- `id-registry-world-literature.json` 是**唯一 canonical identity registry**；
- registry 只承担 stable ID、父子关系、节点语义、anchorability、Topic anchor 与 legacy alias；
- 阅读优先级、解释正文与导航链接以各 canonical node Markdown 为准，避免 registry 重复维护易过期展示信息；
- 原先 G / M-N-Q / T-R 三份 overlay 已完成 fold，不再参与运行时读取。

## 10. 分级系统

### T / R / M / G：文学史重要度
- **S**：承重骨架
- **A**：重要支系
- **B**：扩展节点

### Q：阅读经验覆盖度
- **Core**：应有基础经验
- **Expand**：值得拓展
- **Interest**：兴趣扩展

分级只用于阅读导航，不是文学价值排名。

## 11. 阅读状态与数据职责

`read_status`：未读 / 在读 / 已读 / 重读。

- Markdown：保存知识与规则。
- `.base`：动态展示作品和状态。
- `20 节点/`：五轴坐标节点。
- `30 专题/`：已建专题的知识地图，按锚点节点名建文件夹。
- `40 作品/`：唯一作品实体。
- `_source/`：原始资料与审计档案。
- 专题首页不维护动态作品数量。
- `50 作者/`、`60 奖项/`：实体访问层，不进入五轴，不占用 `WL-TOPIC-*`。
- `70 世界名著/`：正典层，作品上用 `canon_level` 标注，实体仍在 `40 作品/`。日常浏览 `01 世界名著.base`，规则与对照见 `00 匹配说明`。

作者层、奖项层、名著层与五轴互补：五轴回答作品在文学世界中的位置；作者层回答沿一个创作者如何继续阅读；奖项层回答沿一个奖的口味如何继续阅读；名著层回答它在世界正典里站在哪一层。它们都不是第六轴。N 轴已撤销。

一本作品可以同时拥有五组坐标。五轴是互补坐标，不是必须互相嵌套的单棵分类树。

## 13. 已建专题

专题整包在 `30 专题/`，与 `10 轴`、`20 节点` 平级。节点笔记留在 `20 节点/`。细节和「骨架未读」回各专题自己的 `03 *作品.base`。

1. 每个专题只设置一个主锚点。
2. 专题层不处理多轴归属；一本具体作品的其他 T / R / M / G / Q 标签留到作品层。
3. 暂无合适主锚点的候选专题不强行接入五轴；讽刺文学当前继续保持未正式接入状态。
4. 专题 stable ID 不因改挂而改变。
