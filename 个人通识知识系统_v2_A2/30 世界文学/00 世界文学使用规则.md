# 世界文学使用规则

> 自 2026-09-07 起，世界文学采用“作品坐标系统 + 作品知识网络”作为顶层模型。完整治理见 [[04 系统架构/00 作品坐标与知识网络总则|作品坐标与知识网络总则]]。

## 1. 顶层职责

```text
A 作品坐标系统
T  时间 / 文学史阶段
R  地域 / 文学传统
M  思潮 / 运动 / 美学范式
G  体裁 / 文本形式
TH 主题 / 人类问题
TY 类型 / 叙事机制

B 作品知识网络
IM 意象网络
CN 文化叙事网络
```

不要再把 TH / TY / IM / CN 当作四个完全等价的“Q 子轴”，也不称为“八轴”。

- TH / TY：高覆盖作品坐标，回答作品“在哪里”；
- IM：稀疏作品内抽取，回答作品“有什么”；
- CN：稀疏文化关系，回答作品“通向哪里 / 与哪些长期文化结构有关”。

TH / TY / IM / CN 的代码全部保留；旧 `Q` 只作为历史兼容命名空间，不再是 canonical 坐标。

N 轴（叙事技法 / 形式）仍维持已撤销状态，不恢复。

## 2. 作品唯一事实源

作品实体唯一位于 `40 作品/`。专题、节点、Base、Canvas 都只能投影、聚合、解释作品，不复制作品实体。

新作品 / 新校准使用：

```yaml
axis_t: []
axis_r: []
axis_m: []
axis_g: []
axis_th: []
axis_ty: []
axis_source: read_calibrated | inferred

qx: []
cultural_narrative_relations: []
```

详细字段规范：[[40 作品/01 作品字段规范|作品字段规范]]。

已有 `axis_q` 暂时允许保留并作为 fallback 读取，但新写入必须拆成 `axis_th` + `axis_ty`。不得把 IM / CN 写进任何 `axis_*` 字段。

## 3. 坐标系统

### T：只有真实时间范围才是时间坐标

当前 canonical 时间坐标为 T0–T6。旧 `T0.1 / T3.5 / T5.2 ...` 中若描述制度、文类、思潮或历史过程，只作为 `historical_feature / stage_feature`，不新增 `axis_t` 值。

### R：区域树允许跨区域关系

R 轴全局坐标以 R1–R10 为主。国家、语言、内部区域与大多数离散类型优先在专题内部展开。非洲离散文学 canonical 为 `R10.2`；`R7.7` 视为 deprecated duplicate alias。

### M：思潮 / 美学范式

现有 M 节点继续使用。M3 的现代主义 / 先锋派拆分规则保持现状，不因本轮顶层迁移重新编号。

### G：只划文本形式

G 只回答“这部作品在形式上是什么”。现行一级骨架：G1 诗歌、G2 戏剧、G3 小说、G4 散文与随笔、G5 生命书写、G6 纪实与文学非虚构。

旧 G 编号迁移规则保持不变；新校准不再写旧 `G4.5` / `G7`。

### TH：主题坐标

TH 回答“作品在思考什么”。TH1–TH3 仍有现行子叶；TH4–TH8 维持当前粒度。主题可以多值，但应有解释价值，不追求机械铺满。

入口：[[20 节点/Q 主题/TH 主题/TH 主题与人类问题|TH 主题与人类问题]]。

### TY：类型 / 叙事机制坐标

TY 回答“作品采用什么类型契约或叙事机制”。推理、科幻、奇幻、恐怖、冒险、反乌托邦、历史叙事、爱情、灾变、讽刺、旅行等继续使用当前节点。

现存 TY8 及其部分子树是旧“类型 + 文化传统”混合设计的遗产，与 CN3 职责重叠。本轮不删、不改号、不搬路径，但冻结其作为新文化模型 taxonomy 的继续扩展。以后文化角色 / 社会秩序模型进入 CN3。

入口：[[20 节点/Q 主题/TY 类型/TY 类型与叙事传统|TY 类型与叙事机制]]。

旧 `Q1–Q16` 全部视为 legacy。

## 4. IM 意象网络

IM 是作品内生意象抽取网络，不要求每本书都有。

正式单作品事实只维护在作品页 `qx:` 中。核心字段继续使用 `object / salience / function / evidence`，并沿用现有 IM 准入门槛和聚类规则。

IM 真正的整合发生在跨作品意象类别 / 专题层，而不是单作品页。

入口：[[20 节点/Q 主题/IM 意象/IM 文学意象与场景|IM 文学意象与场景]]。

## 5. CN 文化叙事网络

CN 不再被定义为普通 Q facet，而是长期文化叙事关系网络：

```text
CN1 = 纵向谱系
CN1.1 来源环境 / 文化土壤
CN1.2 具体叙事传统的历史生命

CN2 = 跨传统可复用叙事组件
CN3 = 历史化文化模型
```

- CN1：故事从哪里来、怎样演变；
- CN2：故事用了哪些可脱离具体传统复用的结构零件；
- CN3：这些资源进入具体社会后如何形成稳定角色、关系、伦理、空间和秩序模型。

CN 映射必须稀疏。读完作品只在有明确价值时建立关系；没有就留空。

作品侧关系优先写为 `cultural_narrative_relations:`，关系词优先使用：`retells / adapts / continues / reframes / structural_similarity / uses / foregrounds / transforms / critiques / subverts / reorders`。

证据纪律永久有效：

```text
text date ≠ origin
precedence ≠ direct source
plot similarity ≠ transmission
later coherent narrative ≠ early original
modern reconstruction ≠ extant original
```

入口：[[20 节点/Q 主题/CN 母题/CN 母题与叙事组件|CN 文化叙事网络]]；治理：[[20 节点/Q 主题/CN 母题/CN 总体架构与建设规范 V2|CN 总体架构与建设规范 V2]]。

## 6. Topic 机器关系

`topics` 只保存稳定 Topic ID；`topic_links` 只承担 Obsidian 导航。专题换 anchor 不应改 stable ID。

专题与坐标 / 网络的职责必须分离：

- `axis_*`：作品坐标；
- `topics` / `topic_links`：专题投影；
- `qx`：意象事实；
- `cultural_narrative_relations`：文化叙事关系。

## 7. 节点治理

`20 节点/` 仍暂时保留原物理目录，避免破坏 WikiLink。它现在同时容纳两类节点：

- 坐标节点：T / R / M / G / TH / TY；
- 网络节点：IM / CN。

因此 `20 节点/Q 主题/` 的目录名只视为 legacy physical path，不再表示 IM / CN 是主题坐标。

stable ID、code、parent、anchorable、topic_map 继续作为节点身份；但新 Base / 导航应按 `system_role` 或代码前缀区分“坐标”和“网络”，不再只按旧 `axis: Q` 分组。

## 8. 分级与覆盖

- T / R / M / G：文学史重要度 S / A / B 机制保持现状。
- TH / TY：阅读经验覆盖度可继续使用 Core / Expand / Interest。
- IM / CN：不以 coverage 为目标，不能因为“缺字段”而强制补标。

## 9. 迁移兼容

本轮不做大规模物理搬迁：

```text
10 轴/                         保留旧链接
20 节点/Q 主题/                保留旧链接
TH / TY / IM / CN 编号         全部保留
axis_q                         legacy fallback，只读优先
axis_th / axis_ty              新 canonical 坐标字段
qx                             继续 canonical
cultural_narrative_relations                   新 canonical 关系字段
```

物理路径是否第二阶段迁移，必须等 WikiLink、Base、Canvas、专题依赖和作品字段覆盖率检查完成后再决定。
