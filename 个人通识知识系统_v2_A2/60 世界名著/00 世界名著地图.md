# 世界名著地图

> 这一层是**世界名著本身的地图**，不是第七轴，也不是专题。  
> 作品实体仍只在 `30 作品/`。这里只规定 Canon 层级，并读取已标注的作品。

它回答的是：**在世界名著这张单子上，一部作品的正典档位是什么；时代、地域、类型只是浏览切面。**

```text
判定（一部书只能有一档）
  Core / Major / Extended

浏览（对全部名著都生效）
  按时代　古代 / 中世纪 / 近代 / 19世纪 / 现代主义 / 战后当代
  按地域　欧洲 / 东亚 / 南亚 / 东南亚 / 西亚北非 / 非洲 / 北美 / 拉美 / 大洋洲
  按类型　推理 / 科幻 / 奇幻 / 恐怖 / 历史 / 冒险 / 儿童 / 女性 / 其他
```

档位和切面分开：Core 也有地域，Extended 也有时代。不把时代绑死在核心、地域绑死在主要。
