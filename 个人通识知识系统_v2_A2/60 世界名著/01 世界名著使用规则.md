# 世界名著使用规则

## 1. 这一层是什么

世界名著是一张可浏览的 Canon 地图，用来衡量作品在世界文学正典中的位置。它不是 T/R/M/G/N/Q 之外的轴，不占用 `WL-TOPIC-*`，也不复制作品实体。

## 2. 作品上写什么

只写在 `30 作品/`：

```yaml
canon_id: CANON-178
canon_level: Core
canon_era: 战后/当代
canon_region: 拉美
canon_genre: 其他专题
```

- `canon_id`：母库稳定号，与书名解耦。
- `canon_level`：`Core` | `Major` | `Extended`，一部书只能有一个。
- `canon_era` / `canon_region` / `canon_genre`：地图切面，不覆盖 `axis_t` / `axis_r` / `axis_g`。

不要用母库里的「个人状态」覆盖 `read_status`。

## 3. 档位与切面

`canon_level` 是判定。`canon_era` / `canon_region` / `canon_genre` 是浏览切面，对 Core、Major、Extended 都有效，不要绑死在某一档上。

**时代：** 古代 / 中世纪 / 近代 / 19世纪 / 现代主义 / 战后/当代  
**地域：** 欧洲 / 东亚 / 南亚 / 东南亚 / 西亚/北非 / 撒哈拉以南非洲 / 北美 / 拉美 / 大洋洲  
**类型：** 推理 / 科幻 / 奇幻 / 恐怖 / 历史 / 冒险 / 儿童文学 / 女性文学 / 其他专题

儿童文学、女性文学可以先当 Canon 切面，不因此新建专题。

## 4. 和六轴、专题、奖项

- 已校准的六轴、专题、阅读状态：标注 Canon 时一律不改。
- 新建缺口作品：入库时写最稳的 `axis_t` / `axis_r` / `axis_g`，专题只在范围明确时才写；`verification_status: 需复核`。
- 诺贝尔等作者生涯奖写在作者实体，不写进作品。
- 奖项 CSV 先不灌库；只在已有作品上按需补 `awards`。

## 5. 什么时候扩编

195 部是第一期骨架。扩到 300～350 部前，先补判定证据，再针对非欧洲文学和类型文学缺页加书。不要按获奖表整表建作品。
