# 世界名著使用规则

## 1. 这一层是什么

世界名著是一张可浏览的 Canon 地图，用来衡量作品在世界文学正典中的位置。它不是 T/R/M/G/Q 之外的轴，不占用 `WL-TOPIC-*`，也不复制作品实体。

这一层只保留经典程度。时代、地域、思潮、类型、主题都用五轴，不再另写一套 Canon 切面。

## 2. 作品上写什么

只写在 `30 作品/`：

```yaml
canon_id: CANON-178
canon_level: Core
```

- `canon_id`：母库稳定号，与书名解耦。
- `canon_level`：`Core` | `Major` | `Extended`，一部书只能有一个。

不要写 `canon_era` / `canon_region` / `canon_genre`。不要用母库里的「个人状态」覆盖 `read_status`。

## 3. 档位

`canon_level` 是这一层唯一的判定：

- **Core**：跨文化正典，文学史上长期站得住
- **Major**：某国、某时期或某传统的核心，世界影响次一等
- **Extended**：区域、类型或时期里稳，但还不算全球核心

浏览时按 `axis_t` / `axis_r` / `axis_m` / `axis_g` / `axis_q` 分组。

## 4. 和五轴、专题、奖项

- 已校准的五轴、专题、阅读状态：标注 Canon 时一律不改。
- 新建缺口作品：入库时写最稳的 `axis_t` / `axis_r` / `axis_g`，专题只在范围明确时才写；`verification_status: 需复核`。
- 诺贝尔等作者生涯奖写在作者实体，不写进作品。
- 奖项 CSV 先不灌库；只在已有作品上按需补 `awards`。

## 5. 什么时候扩编

300 部已经覆盖 v1 + v2 增量。再扩之前先补判定证据，针对仍缺的非欧洲文学和类型文学加书。不要按获奖表整表建作品。
