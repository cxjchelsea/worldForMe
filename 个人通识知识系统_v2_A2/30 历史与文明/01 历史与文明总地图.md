# 历史与文明总地图

> 历史不是一棵必须按朝代读完的树，而是一张可以从兴趣不断进入、再回接时间与因果的网络。

## 一、三层结构

```text
                         时间主轴
                            ↑
                            │
生活对象入口 ───────→ 历史知识网络 ←────── 喜欢的作品入口
                            │
                            ↓
               制度 / 经济 / 社会 / 思想
               技术 / 战争 / 环境 / 迁移
```

一句话：**兴趣提供入口，时间提供坐标，历史提供解释。**

---

- 冷战、去殖民化与战后社会

### B. 喜欢的作品入口

作品入口不局限于“历史作品”。只要某个作品能够稳定触发历史问题，就可以成为入口。

当前首批：**桌游**。

- 《工业革命：伯明翰》→ 工业革命、运河、铁路、煤铁工业、英国城市化
- 《重塑火星》→ 天文学史、火星想象史、太空竞赛、航天史
- 《劳哈·创世》→ 创世神话、生态思想、人与自然
- 《方舟动物园》→ 动物园史、博物学、殖民收藏、自然保护
- 《璀璨宝石》→ 文艺复兴、宝石贸易、商人阶层、奢侈品
- 《花砖物语》→ 葡萄牙、伊斯兰艺术、瓷砖、建筑装饰、颜色与审美
- 《波多黎各》→ 殖民主义、种植园、大西洋贸易、奴隶制
- 《卡坦岛》→ 战后德国、德式桌游、现代桌游产业、全球化
- 《奥法之战》→ 炼金术、欧洲神秘主义、科学史
- 《阿瓦隆》→ 亚瑟王传说、骑士文化、英国民族神话
- 《狼人杀》→ 社交推理游戏史、群体心理、狼人传说、猎巫文化
- 《血染钟楼》→ 社交推理游戏演化、信息不对称、群体判断
- 《铁路环游》→ 铁路史、工业革命、旅行史、标准时间、城市网络
- 《七大奇迹：对决》→ 古代文明、建筑、科学、战争、城市
- 《勃艮第城堡》→ 中世纪晚期、贵族、庄园、土地制度、宫廷文化

## 四、历史解释层

任何兴趣入口进入后，都不止回答“发生了什么”，而要继续解释“为什么”。

主要解释维度：

1. 政治与制度
2. 经济与贸易
3. 社会与阶层
4. 宗教与思想
5. 科学与技术
6. 战争与国家竞争
7. 环境与地理
8. 人口与迁移
9. 传播、媒介与消费

## 五、历史路线

真正的学习单元不是“一个分类节点”，而是“一条问题路线”。

例如：

```text
《工业革命：伯明翰》
→ 为什么工业革命首先发生在英国？
→ 煤炭与铁
→ 运河网络
→ 铁路革命
→ 私人资本与信贷
→ 工厂制度
→ 城市化
→ 工人阶级
→ 英国成为世界工厂
```

```text
花砖物语
→ 为什么葡萄牙建筑有大量彩釉瓷砖？
→ 伊斯兰艺术
→ 安达卢斯
→ 阿尔罕布拉宫
→ 伊比利亚文化交流
→ 葡萄牙王室
→ 航海时代
→ 全球陶瓷贸易
```

```text
名字
→ 人为什么需要名字？
→ 姓氏如何出现？
→ 宗族与继承
→ 名、字、号
→ 国家人口管理
→ 政治时代与命名风格
→ 当代审美与流行文化
```

## 七、使用原则

- 不追求覆盖完整，而追求真实兴趣持续生长。
- 不把作品当作史实；作品只负责触发问题。
- 每条路线必须回接时间坐标。
- 每条路线尽量包含地区比较。
- 关注普通人的生活、制度、技术、消费与文化，不只关注帝王与战争。
- 允许一条路线横跨多个兴趣入口。
