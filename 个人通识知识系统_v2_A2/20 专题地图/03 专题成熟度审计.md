# 世界文学专题成熟度审计

> 本审计回答的不是“哪个专题更重要”，也不是“哪个专题作品更多”，而是：**当前专题地图已经完成到什么程度，下一轮内容生产应当补哪里。**

审计基线：`main @ fc8b1c283ee7bdeb8eb9e6fb1816655bcce7008f`。

## 1. 先说明一个容易误解的问题

前几轮规范化**已经同时做了结构工作和内容工作**。例如奇幻、恐怖、冒险补出了原本不存在的历史知识节点，T / R / M / N / Q 也补写了高层解释、机制页和跨专题桥接。

因此这里的 `B` 不表示“没有补内容”，而表示：

> **结构已经成立，内容也已有第一版，但部分 `11 / 12` 节点仍主要承担定位、路由和动态 Base 入口，尚未达到成熟知识页的解释密度。**

文件大小只作为审计信号，不作为机械评分阈值。一个 600B 的节点可以在职责上成立；问题在于它是否已经包含足够的定义、内部差异、文本链、比较关系与阅读抓手。

## 2. 成熟度等级

### A — 基本成熟

满足：
- `00 / 01 / 02 / 03` 数据与导航合同稳定；
- `10` 高层解释已经能独立支撑专题阅读；
- 至少一个主要知识维度已经形成真正的解释性节点，而不只是路由页；
- Base、Canvas、Markdown 职责清楚；
- 后续工作以局部加厚、读后校准、案例补充为主，不需要再次整体重构。

### B — 结构完成，内容第一版

满足：
- 已按 `literature-topic-v1` 建立稳定结构；
- `11` 第一主维度和必要的 `12` 已经存在；
- 但大量低层节点仍偏薄，常见形态是“一段定位 + 动态作品入口”；
- 下一步应该加厚知识，而不是再改目录。

### C — 尚未完成当前生产合同

表现为：
- 仍使用旧版内部结构，尚未按 v1 重新判断第一主维度 / 第二分析维度；或
- 高层结构页本身仍非常薄，且缺少真正的内部知识层；
- 需要先完成一次专题内部规范化，再进入内容加厚。

> `12` 缺失本身**不是** C。N2 已验证：如果 `11` 本身就是完整机制层，完全可以没有 `12`。

### Q15 子专题的处理原则

不要八个一起机械复制同一模板。推荐：

1. 先选 **武侠文学** 做 Q15 子专题样板；
2. 再用 **西部文学** 做第二个对照样板；
3. 验证“文明型武人传统”和“边疆类型传统”是否需要不同第一主维度；
4. 再批量推进其余六个。

## 5. 内容加厚的最低目标

B 类专题下一轮不要再做“新增一个标题 + 一段简介 + Base 链接”。一个真正值得保留的 `11 / 12` 知识节点，建议至少能够回答以下 5 类问题中的 4 类：

1. **定位**：为什么这个节点值得独立存在？与相邻节点边界是什么？
2. **内部结构**：这一阶段 / 传统 / 机制内部有哪些关键分叉或矛盾？
3. **关键文本链**：哪些文本共同展示了它如何形成、转向或被反写？不要复制完整书单。
4. **关系**：它与同专题其他 `11 / 12` 节点、以及其他正式专题如何连接？
5. **阅读抓手**：读一部作品时具体应该观察什么？

推荐骨架：

```text
# 节点名称

## 定位与边界
## 核心结构 / 内部差异
## 关键演变或文本链
## 与其他节点 / 专题的关系
## 阅读抓手
## 动态作品
```

这不是强制每页写成相同格式；它只是避免知识页退化为路由器。

## 7. 结论

当前世界文学专题系统已经完成了两个阶段：

```text
专题架构设计与全轴验证      ✓
第一轮结构 + 内容补全        ✓
```

现在真正剩下的是：

```text
B 类薄节点知识加厚           ← 当前主线
Q15 子专题内部规范化         ← 独立支线
读后校准与作品关系修正       ← 持续进行
```

因此后续原则是：

> **不再把“批量改目录”当进展；只在有知识收益时新增或加厚 Note。**
