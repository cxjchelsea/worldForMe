# 世界武人、边疆与法外英雄文学

> 路径：世界文学 → Q轴 → Q15 武人、英雄与秩序

## 核心问题

Q15研究的不是“谁拿什么武器”，而是：

> **私人暴力怎样获得道德合法性？**

八套系统围绕这个问题给出不同答案：

```text
武侠            → 义与江湖
欧洲骑士        → 忠诚、荣誉与制度
日本武士/剑豪   → 身份义务、忠诚与“道”
Western         → 边疆、法律形成与私人正义
Gaucho          → 国家扩张与被制造的法外者
Outlaw Hero     → 法律与正义分裂时站哪一边
Maritime Outlaw → 海洋空间中的临时秩序与国家暴力
Swashbuckler    → 骑士退场后，个人剑士与现代英雄
```
