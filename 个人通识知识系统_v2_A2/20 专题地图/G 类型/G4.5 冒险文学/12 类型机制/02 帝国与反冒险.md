# 帝国与反冒险

19世纪 Adventure Fiction 与帝国扩张长期共生：

```text
未知土地
→ 地图
→ 探险者
→ 发现
→ 命名
→ 占有
```

因此现代阅读不能只保留“刺激”，还要追踪它的殖民前提。

随后出现的 Anti-Adventure / Counter-Robinsonade / Postcolonial rewriting 会反过来拆解这种结构：

- 未知世界并不是空白；
- 探险者没有天然解释权；
- “发现”可能只是入侵者的说法；
- 生存故事也可以从女性、家庭、被殖民者和当地人的位置重新书写。

这条批评线是冒险文学区别于纯娱乐书单的关键，也与旅行文学中对“观看权/叙述权”的审问形成重要桥接。
