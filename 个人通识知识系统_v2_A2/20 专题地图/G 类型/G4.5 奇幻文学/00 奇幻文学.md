# 奇幻文学

> 路径：世界文学 → G轴 → G4.5 现代类型文学 → **奇幻文学**

## 专题定位

奇幻的核心不是“有没有魔法”，而是：**世界的基本法则允许超自然、神话或第二世界成为真实的一部分。**

原书单最值得保留的是四层结构：

```text
前现代幻想母体
→ 现代 Fantasy 形成
→ 类型内部不断分叉
→ 全球传统与新媒介重新改写奇幻
```

因此本专题用“历史 + 子类型 + 地域/神话重述”共同定位作品，而不是把所有奇幻压成托尔金式史诗奇幻。
