# 世界神话文学

> 路径：世界文学 → G轴 → G1 口述与民间文学 → **世界神话文学**

## 专题定位

神话文学不是一套“诸神百科”，而是不同文明用叙事回答一组反复出现的问题：

```text
世界从哪里来？
人为什么会死？
英雄为什么必须受难？
王权凭什么成立？
神与人的边界在哪里？
混沌为什么不断回来？
```

因此本专题采用两条同时存在的坐标：

- **纵向：文明 / 神话传统**
- **横向：跨文化神话母题**

再单独保留“神话 → 史诗 / 悲剧 / 骑士传奇 → 现代奇幻”的文学转化链。
