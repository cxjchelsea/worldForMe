# 类型谱系与核心机制

冒险比很多类型更适合按**叙事动作**而不是世界观分类。

## 1. 任务与移动

Quest / Journey / Expedition。

核心问题：人物为什么必须离开原位，目标如何把路线组织成情节？

## 2. 生存与封闭空间

Survival / Shipwreck / Island Adventure / Polar / Jungle。

核心问题：环境如何从背景变成主动约束？

## 3. 欲望对象与地图

Treasure Hunt / Lost World / Map。

核心问题：目标为何值得寻找，“未知”又如何被想象成可发现、命名和占有的空间？

## 4. 类型化场景

Sea Adventure / Frontier / Historical Adventure / Scientific Adventure / Spy Adventure。

核心问题：其他类型的世界怎样借用冒险发动机？

## 5. 关系与返回

Companionship / Masculinity / Return / Anti-Adventure。

核心问题：谁有资格成为冒险者，伙伴关系如何形成，回来以后英雄是否仍属于原来的世界？
