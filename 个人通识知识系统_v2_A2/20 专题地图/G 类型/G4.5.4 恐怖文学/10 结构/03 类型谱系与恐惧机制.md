# 类型谱系与恐惧机制

恐怖最适合用“恐惧从哪里来、通过什么形式进入叙事”来理解，而不是只按怪物名称分类。

## 1. 超自然与空间

Ghost / Haunted House / Occult / Demonic / Folk Horror。

核心问题：**过去、土地、宗教或共同体为什么无法被现代秩序清除？**

## 2. 身体与物种边界

Vampire / Werewolf / Monster / Body Horror。

核心问题：**人的身体、欲望和物种身份在哪里失去稳定边界？**

## 3. 认知与宇宙尺度

Psychological Horror / Cosmic Horror / Weird。

核心问题：**恐惧来自外部现实，还是来自人类理解能力本身的失败？**

## 4. 社会与系统

Domestic / Social / Racial / Queer / Eco / Tech Horror。

核心问题：**如果家庭、制度、环境或技术本身就是威胁，怪物是否还必须是超自然的？**
