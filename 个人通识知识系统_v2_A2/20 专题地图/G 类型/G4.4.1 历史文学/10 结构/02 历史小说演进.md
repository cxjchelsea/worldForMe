# 历史小说演进

```text
史传 / 演义 / 传奇前史
→ Walter Scott：普通人成为大历史窗口
→ 19世纪Historical Novel / Adventure
→ 20世纪：人物意识与心理化
→ 古代 / 中世纪 / 近代各类历史小说专业化
→ 世界大战、Holocaust与殖民历史
→ 中日现代历史小说传统
→ 后现代：历史叙述本身被质疑
→ 女性、Queer、后殖民者重新进入历史
```

历史小说从“重现过去”，逐渐转向“争夺谁能解释过去”。
