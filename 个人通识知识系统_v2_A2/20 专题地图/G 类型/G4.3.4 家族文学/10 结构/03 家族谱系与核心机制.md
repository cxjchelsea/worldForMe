# 家族谱系与核心机制

家族文学不是按“几代人”机械分类，而是在几组制度关系之间组织叙事：

```text
谱系与资源
继承 / 财产 / 土地 / 祖宅 / 姓名
+
家庭权力
父权 / 母系 / 婚姻 / 兄弟姐妹 / 家庭劳动
+
时间机制
代际冲突 / 秘密 / 重复 / 创伤 / 家族兴衰
+
历史位移
国家 / 战争 / 奴隶制 / 殖民 / Migration / Diaspora
```

`family_axes` 因而是一套多标签关系坐标。它帮助比较“同样写三代人”的作品究竟是在写继承制度、国家形成、失落家谱，还是 chosen family。
