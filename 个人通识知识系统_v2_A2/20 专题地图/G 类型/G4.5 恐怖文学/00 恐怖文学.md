# 恐怖文学

> 路径：世界文学 → G轴 → G4.5 现代类型文学 → **恐怖文学**

## 专题定位

恐怖文学不是“让人害怕的故事”这么简单。它不断把一个社会最难处理的东西变成可感知的形式：

```text
诅咒 / 鬼魂 / 怪物
→ 身体与双重人格
→ 宇宙未知
→ 家庭与心理
→ 宗教、社会、种族、性别、生态与技术恐惧
```

Gothic、Horror、Weird、Dark Fantasy 会重叠，但它们不应被当成完全相同的标签。
