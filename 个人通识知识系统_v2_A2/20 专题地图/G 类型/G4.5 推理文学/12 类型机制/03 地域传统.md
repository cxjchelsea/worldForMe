# 地域传统

地域不是推理文学的另一套独立分类，而是对历史轴的第二种进入方式：

- **历史轴**回答：什么时候发生了什么变化？
- **地域轴**回答：同一套推理语法进入不同文学传统后，变成了什么？

## 英国及欧洲古典传统

入口：[[../11 历史细分/01 前史、侦探诞生与黄金时代]]

重点观察：

- 哥特/犯罪故事如何进入理性侦探小说；
- 福尔摩斯如何确立侦探中心结构；
- 黄金时代如何形成公平游戏与封闭谜题；
- 密室、逻辑游戏与文学化如何在内部继续分叉。

## 美国及跨大西洋类型扩张

入口：[[../11 历史细分/02 美国犯罪小说传统与类型扩张|英美犯罪小说传统与类型扩张]]

重点不是“美国也写推理”，而是犯罪小说如何从庄园走向城市、职业机构、法庭、法医系统与私人生活。

## 日本

入口：[[../11 历史细分/03 日本推理传统]]

日本传统尤其适合观察“输入—本土化—反复重构”：

```text
西方古典谜题
→ 本格 / 变格
→ 社会派
→ 新本格
→ 日常 / 特殊设定 / 元本格 / 当代融合
```

## 北欧与欧洲大陆

入口：[[../11 历史细分/04 北欧与欧洲大陆犯罪文学]]

这里可以同时观察两条方向：

- Nordic Noir：犯罪作为福利社会裂缝的入口；
- 欧洲大陆心理犯罪：逐渐削弱“理性必然恢复秩序”的古典承诺。

## 中文推理

入口：[[../11 历史细分/05 中文推理与边界类型|中文推理]]

核心问题不是简单比较“水平”，而是：

- 福尔摩斯范式如何在民国本土化；
- 当代社会犯罪怎样进入制度与现实问题；
- 中文本格如何与日系本格、历史叙事重新组合。

## 跨地域边界

入口：[[../11 历史细分/06 边界类型：间谍、盗窃与犯罪者小说]]

间谍小说、Caper 与犯罪者小说共享调查、信息差、身份判断和欺骗机制，但不必被强行归入传统侦探小说主干。
