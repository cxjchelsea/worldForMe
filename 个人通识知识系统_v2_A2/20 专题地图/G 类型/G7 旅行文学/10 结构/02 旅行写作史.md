# 旅行写作史

```text
古代旅行 / 地理 / 民族志未分家
→ 朝圣与跨文明宗教旅行
→ 早期现代海洋遭遇
→ Grand Tour：旅行作为教育
→ 19世纪科学 / 帝国 / 女性旅行
→ 20世纪：旅行者开始怀疑客观叙述
→ 后殖民 Reverse Gaze / Diaspora / Return
→ 当代Essay + Fiction + Memory + Ecology混合
```

这条历史最深的变化是：

> “世界等待我去观看”
> 逐渐变成
> “我的观看方式本身就是问题的一部分。”
