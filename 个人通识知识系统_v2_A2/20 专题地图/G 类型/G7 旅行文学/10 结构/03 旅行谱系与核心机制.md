# 旅行谱系与核心机制

旅行文学不能只按“去了哪里”分类。更稳定的分析方式，是把一次旅行拆成几个彼此关联的变量：

> **为什么出发 → 谁在观看 → 怎样移动 → 怎样描述 → 旅行结束后怎样重新理解自己与地方。**

这些变量最终落入 `travel_axes`，一本作品可以同时占据多个坐标。

## 1. 旅行目的

Pilgrimage / Knowledge / Self-Cultivation / Homecoming

目的决定旅行者预期看见什么，也决定哪些经验会被写进文本。

## 2. 观看与权力

Otherness / Travel Gaze / Empire / Women Travellers / Postcolonial Reverse Gaze

这里处理的不是“观点是否客观”这么简单，而是：谁有进入某个空间、命名某个地方、代表某群人的资格。

## 3. 空间与交通

Nature / Wilderness / City / Road / Railway / Walking / River / Polar / Desert

交通方式不是背景变量。步行、铁路、海路或极地远征会改变速度、身体经验、可见范围和人与地方的关系。

## 4. 时间与身份

Tourist vs Traveller / Travel + Memory / Travel + War / Scientific Travel

旅行既可能制造“第一次看见”，也可能是返乡、重访、考察或战争后的重新进入；此时空间经验会与记忆、身份和知识制度叠加。

## 使用原则

- 不按目的地批量制造子专题。
- `travel_axes` 允许多选，但只标真正影响理解作品的关系。
- 地域归属仍由作品层 R 轴处理；旅行专题内部不复制一套世界地理分类。
- 当某条横轴积累了足够解释、比较和阅读路径时，再从 Property 升格为独立 Note。
