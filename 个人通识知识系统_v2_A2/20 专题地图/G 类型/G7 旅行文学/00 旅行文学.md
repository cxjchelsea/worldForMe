# 旅行文学

> 路径：世界文学 → G轴 → G7 纪实文学 → **旅行文学**

## 专题定位

旅行文学真正研究的是：

> **观察者、地方与叙述权之间的关系。**

旅行者从来不是透明摄像机。旅行目的、交通方式、阶级、性别、帝国位置、知识制度和写作时间都会改变“他看见了什么”。

所以本专题同时保留：

- 历史演进；
- 旅行方式与空间；
- Travel Gaze / Empire；
- Women Travellers；
- Scientific Travel；
- Postcolonial Reverse Gaze；
- Travel + Memory / War / Return。
