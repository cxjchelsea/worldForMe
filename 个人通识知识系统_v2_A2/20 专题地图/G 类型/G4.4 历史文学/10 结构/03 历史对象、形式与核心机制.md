# 历史对象、形式与核心机制

历史文学最容易混淆两种不同分类：**作品在写哪个过去**，以及**作品用什么形式处理过去**。

```text
历史对象
古代 / 中世纪 / 王朝宫廷 / 革命 / 奴隶制 / 殖民 / 一战 / 二战 / Holocaust …
+
叙事形式
Historical Novel / 历史人物小说 / 家族史 / Historical Mystery / Historical Romance
+
边界与改写
Alternate History / Fantasy / Horror / Historiographic Metafiction
```

因此 `historical_axes` 是多标签坐标，而不是一套互斥的“历史小说子类型”。把对象和形式分开以后，才能比较同一历史时期如何被现实主义、推理、爱情、奇幻或元小说用完全不同的方法重新组织。
