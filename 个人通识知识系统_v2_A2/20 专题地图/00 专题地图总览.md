# 世界文学专题地图总览

视觉入口：[[02 专题入口]]。专题细节和「骨架未读」回各专题自己的 `03 *作品.base`，不在总作品库重复切片。

本层采用简单规则：

1. 每个专题只设置一个主锚点。
2. 专题层不处理多轴归属；一本具体作品的其他 T / R / M / G / N / Q 标签留到作品层。
3. 暂无合适主锚点的候选专题不强行接入六轴；讽刺文学当前继续保持未正式接入状态。
4. 武侠、骑士、剑豪、剑客、西部、Gaucho、侠盗、海盗统一进入 [[Q15 武人、英雄与秩序]]。
5. 专题物理目录编号与 canonical taxonomy anchor 对齐；专题 stable ID 不因目录迁移而改变。
