# 世界文学专题地图总览

视觉入口：[[02 专题入口]]。专题细节和「骨架未读」回各专题自己的 `03 *作品.base`，不在总作品库重复切片。

本层采用简单规则：

1. 每个专题只设置一个主锚点。
2. 专题层不处理多轴归属；一本具体作品的其他 T / R / M / G / N / Q 标签留到作品层。
3. 暂无合适主锚点的候选专题不强行接入六轴；讽刺文学当前继续保持未正式接入状态。
4. 武侠、骑士、剑豪、剑客、西部、Gaucho、侠盗、海盗统一进入 [[Q15 武人、英雄与秩序]]。
5. 专题物理目录编号与 canonical taxonomy anchor 对齐；专题 stable ID 不因目录迁移而改变。

## 暂不正式接入：讽刺文学

当前结论：**保留为候选专题，但不创建正式专题目录、稳定 `WL-TOPIC-*` ID 或新的轴。**

原因不是讽刺文学不重要，而是它目前更接近一种跨体裁的 **mode / critical posture（文学模式 / 批评姿态）**：讽刺可以进入小说、戏剧、诗歌、寓言、科幻、反乌托邦等多种形式，也可能服务于不同主题与历史语境。若为了得到一个目录位置而把它强行固定到 G / M / Q 任一节点，会把“主要导航锚点”误当成“全部语义归属”。

治理规则：

- 当前不为讽刺单独制造 `X` 轴或“跨轴专题”目录。
- 先观察后续是否持续出现 **2–3 个同样无法合理选择单一主锚点、但又值得长期维护的成熟专题**。
- 达到这一阈值后，再统一评估是否建立 `X 跨轴专题/` 或其他 mode 层，而不是为单个讽刺专题改动六轴底层。
- 在此之前，具体作品仍按现有 T / R / M / G / N / Q 与已经正式存在的专题关系表达，不新增临时讽刺 Topic ID。

这是一项架构保留决策，不代表未来永不接入。
