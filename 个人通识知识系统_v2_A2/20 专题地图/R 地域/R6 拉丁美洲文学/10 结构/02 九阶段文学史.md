# 九阶段文学史

```text
前哥伦布
→ 征服 / 殖民
→ 独立与民族国家
→ Modernismo
→ 先锋 / 革命 / Indigenismo
→ Boom前夜
→ Boom
→ Post-Boom / 独裁 / Testimonio
→ 1990s—21世纪多中心化
```

这条历史尤其要避免“所有道路都为了通向《百年孤独》”的倒叙。

Boom 是一个巨大节点，但不是拉美文学的目的地。
