# 拉丁美洲文学

> 路径：世界文学 → R轴 → R6 拉丁美洲与加勒比 → **拉丁美洲文学**

## 专题定位

拉美文学不是“魔幻现实主义作品集合”，也不能被Boom代表全部。R6 是一个**区域文学传统型专题**：它既追踪长期历史，又必须持续处理语言、殖民、原住民、Afro-Latin、巴西、加勒比、性别、国家与跨境迁徙造成的内部差异。

```text
前哥伦布原住民传统
→ 征服与殖民档案
→ 独立与民族国家
→ Modernismo
→ 先锋 / 革命 / Indigenismo / Brazilian Modernismo
→ Boom前夜
→ Boom
→ Post-Boom / 独裁 / Testimonio
→ 当代暴力、性别、边境、怪奇与 Diaspora
```

## 核心问题

> **谁有资格代表“拉丁美洲”；当殖民、语言、种族、国家与世界文学市场不断改变这个区域时，拉美文学怎样同时形成共同问题和彼此不同的传统？**
