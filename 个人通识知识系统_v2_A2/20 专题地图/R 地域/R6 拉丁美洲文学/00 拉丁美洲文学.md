# 拉丁美洲文学

> 路径：世界文学 → R轴 → R6 拉丁美洲与加勒比 → **拉丁美洲文学**

## 专题定位

拉美文学不能被缩写成“魔幻现实主义”。

真正的长线是：

```text
前哥伦布原住民传统
→ 征服与殖民档案
→ 独立与民族国家
→ Modernismo
→ 先锋 / 革命 / Indigenismo / Brazilian Modernismo
→ Boom前夜
→ Boom
→ Post-Boom / 独裁 / Testimonio
→ 当代暴力、性别、边境、怪奇与Diaspora
```

同时，巴西、加勒比、安第斯、墨西哥、南锥体等内部传统并不相同。
