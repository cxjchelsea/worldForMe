# 不可靠叙述

> 路径：世界文学 → N轴 → N2 聚焦与可靠性 → **不可靠叙述**

## 专题定位

不可靠叙述不是“最后反转一下”的技巧，而是：

> **读者无法直接把叙述者的话等同于作品世界的真实。**

不可靠可能发生在不同层级：

```text
信息
→ 他知道但不说

认知
→ 他看错、记错、解释错

价值
→ 他试图让你接受扭曲的判断

文本
→ 连“谁控制这个故事”都变得不稳定
```
