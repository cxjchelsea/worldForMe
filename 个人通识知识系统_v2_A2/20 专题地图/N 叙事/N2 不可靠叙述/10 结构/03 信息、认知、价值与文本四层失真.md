# 信息、认知、价值与文本四层失真

11种体验还可以进一步理解为四个层级：

```text
信息层
主动隐瞒 / 自相矛盾

认知层
自我欺骗 / 感知 / 解释 / 记忆 / 意识

价值层
价值判断扭曲

多主体层
多重证词 / 叙事真相

文本层
文本劫持
```

层级越往下，读者越难相信自己能找到一个稳定的“客观版本”。
