# 五层失真：信息、认知、价值、多主体与文本

十一种不可靠体验还可以进一步理解为五个层级：

```text
信息层
主动隐瞒 / 自相矛盾

认知层
自我欺骗 / 感知失真 / 解释失真 / 记忆重构 / 意识破碎

价值层
价值扭曲

多主体层
多重证词 / 叙事真相

文本层
文本劫持
```

这里修正了旧标题中的“四层”表述：旧正文实际上一直包含**信息、认知、价值、多主体、文本五层**。

层级越往下，读者越难相信自己能够恢复一个单一、稳定、客观的版本。但“五层”不是严格的等级考试，同一作品可以同时让多个层级失稳。

## 使用方式

- 先用 `unreliable_modes` 标记具体机制，再用五层模型理解机制发生在哪里。
- 五层模型不写入新的作品枚举，避免与十一种稳定机制重复建模。
- 重点不是判断“叙述者是不是骗子”，而是判断作品把真实性问题放在哪个层面。
