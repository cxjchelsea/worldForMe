# 不可靠叙述

> 路径：世界文学 → N轴 → N2 聚焦与可靠性 → N2.2 叙述可靠性 → N2.2.2 不可靠叙述 → **不可靠叙述专题**

## 专题定位

不可靠叙述不是“最后反转一下”的情节技巧，也不是只要第一人称就天然不可靠。本专题落在 **N2.2 叙述可靠性** 下：它研究读者为什么不能直接把叙述者的话等同于作品世界的真实，以及作品怎样迫使读者判断叙述权、证据和价值。

```text
信息
→ 他知道但不说 / 前后矛盾

认知
→ 他看错、记错、解释错

价值
→ 他试图让你接受扭曲的判断

多主体
→ 不同证词彼此冲突

文本
→ 连“谁控制这个故事”都变得不稳定
```

## 核心问题

> **当叙述者不能直接被相信时，读者根据什么判断故事；如果作品最终也不给出唯一真相，判断本身为什么仍然重要？**
