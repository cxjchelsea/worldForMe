# 爱情文学

> 路径：世界文学 → Q轴 → Q2 爱、欲望与亲密关系 → **爱情文学**

## 专题定位

爱情文学 **不等于 Romance 类型小说**。

爱情作为文学问题远早于现代小说，也远大于“男女相爱—阻碍—结婚”：

```text
欲望
→ 求偶
→ 婚姻
→ 禁忌
→ 阶级
→ 身体
→ 毁灭
→ 错过
→ Queer Love
→ 现代Genre Romance
```

所以本专题同时保留“爱情文学史”和“Romance类型史”。
