# 英雄 → 神话 → 类型 → 解构

八套传统最终都出现相似的文学变化：

```text
真实历史 / 社会角色
→ 英雄化
→ 民间神话
→ 类型公式
→ 大众文化扩张
→ 文学反思
→ 解构英雄神话
```

差异在于发生时间和社会条件完全不同。

所以Q15的成熟读法不是寻找“世界版武侠”，而是观察每一种社会如何制造、需要、怀疑并最终重新解释自己的武人英雄。
