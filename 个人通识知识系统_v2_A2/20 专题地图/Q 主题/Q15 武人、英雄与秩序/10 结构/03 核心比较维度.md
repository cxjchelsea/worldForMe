# 核心比较维度

Q15的比较不从武器、服饰和“谁更强”开始，而从同一组结构问题开始。

## 六个维度

1. [[../12 比较维度/01 私人暴力的合法性|私人暴力的合法性]]：私人暴力凭什么被认为是正义的？
2. [[../12 比较维度/02 国家强度、空间与英雄组织方式|国家强度、空间与英雄组织方式]]：国家离英雄有多远，空间怎样允许私人秩序存在？
3. [[../12 比较维度/03 武人伦理、忠诚与共同体|武人伦理、忠诚与共同体]]：英雄究竟忠于谁，又被谁评价？
4. [[../12 比较维度/04 法律身份、国家授权与法外化|法律身份、国家授权与法外化]]：合法、非法、被授权与民间正当性怎样发生转换？
5. [[../12 比较维度/05 技艺、武器与身体的文学化|技艺、武器与身体的文学化]]：超常能力怎样被训练、继承、职业化并转化成文学魅力？
6. [[../12 比较维度/06 英雄退场、神话化与解构|英雄退场、神话化与解构]]：当国家、技术与社会结构变化后，英雄为何被神话化、怀旧化或解构？

## 使用方法

不要一次把八个子专题全部读完再比较。更有效的方法是：

```text
选一个比较维度
→ 每个系统各取1—2个骨架节点
→ 比较其答案
→ 再回到某个子专题深读
```

这样Q15才是一张比较文学地图，而不是八张书单的总目录。
