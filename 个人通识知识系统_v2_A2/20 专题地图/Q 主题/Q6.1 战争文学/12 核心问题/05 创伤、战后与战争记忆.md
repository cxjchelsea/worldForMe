# 创伤、战后与战争记忆

战争文学不会在停战日结束。现代战争写作越来越关心暴力怎样在退伍者、家庭、幸存者、第二代与公共记忆中继续存在。

## 主体谱系

```text
值得歌颂的死亡
→ 普通人的恐惧
→ 战争机器中的身体
→ 平民与占领
→ 屠杀 / Genocide
→ 幸存者证词
→ 创伤与退伍经验
→ 第二代记忆
→ 公共纪念与遗忘
```

## 核心问题

- “战后”究竟从什么时候开始？
- 创伤如何改变时间感、记忆与叙事连续性？
- 幸存者、退伍者与第二代是否拥有相同的记忆位置？
- 私人记忆怎样进入国家纪念、公共历史与遗忘政治？
- 当战争经验被反复文学化时，记忆会被保存、重构还是神话化？
