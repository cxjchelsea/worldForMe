# 二十条战争问题横轴

`war_axes` 不是第二套体裁分类，而是一组**可以横穿不同时代、地区和文体的比较问题**。同一作品可以同时落在多个横轴上。

原有二十条横轴：

> 英雄主义、普通士兵、反战、荒诞、平民、占领、女性、儿童、战争与爱情、军事制度、战俘、Holocaust/Genocide、轰炸与核战争、内战、殖民战争、创伤/Afterwar、战争记忆、战争真相与叙事、加害者/Complicity、战争×类型融合。

为了让它们真正可用于阅读，本专题进一步归并成六个问题群。

英雄主义 / 普通士兵 / 反战 / 荒诞 / 军事制度 / 战俘

核心追问：**战士是战争的主人，还是战争机器中的一个身体？**

→ [[../12 核心问题/01 战斗、士兵与军事制度]]

平民 / 占领 / 女性 / 儿童 / 战争与爱情

核心追问：**当战争进入整个社会以后，谁还能够被称作“非战斗人员”？**

→ [[../12 核心问题/06 真相、责任与战争叙事]]

## 横轴使用规则

- `war_axes` 可以多选，不追求每部作品填满。
- 只有当某个问题对理解作品具有结构意义时才标注。
- 轻量分类先留在 Property / Base；只有需要独立解释、比较和阅读路线的问题群才升格为 Note。
- “没有标某横轴”不等于作品不涉及该问题，只表示当前知识库尚未将其结构化为主要关系。

战争文学成熟的标志之一，就是它不再只问“谁赢了”，而不断追问：

> **谁付出了代价？谁有资格讲述？战争结束以后为什么还没有结束？**
