# 从英雄主义到战争记忆

战争文学的重心变化可以压成：

```text
值得歌颂的死亡
→ 普通人的恐惧
→ 战争机器
→ 平民与占领
→ 屠杀 / Genocide
→ 幸存者证词
→ 创伤
→ 第二代记忆
→ 加害者责任
→ 谁控制战争叙事
```

因此Q6会天然与Q10“历史、记忆与时间”重叠，但Q6的中心始终是战争暴力如何进入生活。
