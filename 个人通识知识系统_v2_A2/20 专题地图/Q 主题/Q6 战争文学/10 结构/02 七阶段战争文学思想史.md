# 七阶段战争文学思想史

```text
英雄史诗
→ 近代现实主义
→ WWI：英雄语言崩塌
→ WWII：总体战进入整个社会
→ Holocaust / Nuclear：见证与不可表述
→ 去殖民、Vietnam与后殖民战争
→ 现代长期战争：前线与日常生活失去清晰边界
```

这条历史真正记录的是“战争主体”怎样不断扩大。
