# 战争文学

> 路径：世界文学 → Q轴 → Q6 战争、暴力与创伤 → **战争文学**

## 专题定位

战争文学不是“有战争背景的小说”，也不等于 `G4.4 战争小说`。本专题采用广义 **War Literature / War Writing** 视野：小说、诗歌、戏剧、回忆录、日记、书信、见证、文学新闻都可以进入，只要战争是改变人物、社会、伦理、记忆或叙事形式的不可替代条件。

它真正追踪的是战争怎样不断改变文学中的主体：

```text
英雄
→ 普通士兵
→ 战壕中的身体
→ 平民
→ 占领者与被占领者
→ 女性与儿童
→ 受害者、幸存者与加害者
→ 退伍者
→ 记忆与第二代
```

## 核心问题

> **战争怎样进入人的身体、家庭、制度、伦理与记忆；而战争结束以后，为什么战争仍然没有结束？**

战争文学的成熟，不只是从“歌颂战争”走向“反战”，而是不断扩大谁能够成为战争主体、谁有资格讲述战争，以及文学必须用什么形式面对极端暴力。
