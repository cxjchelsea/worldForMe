# 战争文学

> 路径：世界文学 → Q轴 → Q6 战争、暴力与创伤 → **战争文学**

## 专题定位

战争文学不是“有战争背景的小说”。

它真正追踪的是战争怎样不断改变文学中的主体：

```text
英雄
→ 普通士兵
→ 战壕中的身体
→ 平民
→ 占领者与被占领者
→ 女性与儿童
→ 受害者、幸存者与加害者
→ 退伍者
→ 记忆与第二代
```

战争史最终从“战士怎样战斗”转向“战争怎样进入每一个人的生活”。
