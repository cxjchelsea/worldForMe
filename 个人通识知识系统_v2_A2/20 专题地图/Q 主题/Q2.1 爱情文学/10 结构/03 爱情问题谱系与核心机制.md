# 爱情问题谱系与核心机制

因为爱情文学是 Q 轴跨文类专题，它不适合模仿类型文学建立一棵“子类型树”。更合适的是三层问题模型：

```text
关系制度
求偶 / 婚姻 / 婚姻以后 / 禁忌 / 阶级
+
主体与欲望
身体 / 性 / 女性主体 / Queer Love / 无法实现 / 错过 / 毁灭
+
文类与类型接口
诗歌 / 戏剧 / 小说 / Gothic Romance / Historical Romance / Genre Romance / 其他类型混合
```

`love_axes` 因而记录的是问题坐标，而不是 G 轴类型分类。它允许爱情诗、悲剧、现实主义小说和现代 Genre Romance 在同一个关系问题上被比较，同时保持各自的文类身份。
