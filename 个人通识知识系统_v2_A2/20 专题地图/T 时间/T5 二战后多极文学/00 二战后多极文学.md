# 二战后多极文学

> 路径：世界文学 → T轴 → T5 二战后多极文学 → **1945—1980**

## 专题定位

T5 不是“1945—1980出版的所有作品”，而是观察二战之后世界文学如何从少数欧洲中心快速变成多中心网络：

```text
废墟 / Holocaust / 战败
→ Cold War与存在主义
→ 去殖民与独立
→ Boom、非洲、加勒比、南亚、中东进入世界文学
→ 民权、女性主义、反文化
→ Postmodernism与新的技术社会
```

因此这个专题最重要的不是类型，而是**同一历史时段中不同中心如何同时改写文学问题**。
