# 二战后多极文学

> 路径：世界文学 → T轴 → T5 二战后多极文学 → **1945—1980**

## 专题定位

T5 不是“1945—1980出版的所有作品”，而是一个**时间切片型专题**：它观察同一历史时段里，战争废墟、冷战、去殖民、民族国家、民权、女性主义、消费社会与后现代形式怎样在不同文学中心同时发生。

```text
废墟 / Holocaust / 战败
→ Cold War 与存在主义
→ 去殖民与独立
→ Boom、非洲、加勒比、南亚、中东进入世界文学
→ 民权、女性主义、反文化
→ Postmodernism 与新的技术社会
```

## 核心问题

> **1945以后，世界文学为什么不再能够由单一欧洲中心解释；同一组战后问题又怎样在不同地区长成不同文学形式？**
