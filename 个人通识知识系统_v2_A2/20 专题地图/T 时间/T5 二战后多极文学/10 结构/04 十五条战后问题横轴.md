# 十五条战后问题横轴

T5 的横轴比地域列表更重要：

1. 二战 → 废墟 → 创伤
2. Holocaust与见证
3. 存在 → 荒诞 → 后现代
4. 传统小说被拆解
5. Cold War
6. 殖民 → 独立
7. 独立 → 幻灭
8. Partition / 分裂
9. Migration / 流亡 / Diaspora
10. 种族与民权
11. 女性自我书写
12. 科技与现代社会
13. 革命
14. 乡村 → 都市 / 消费社会
15. 历史与记忆

这些关系写入 `postwar_axes`，使作品能够跨国比较，而不是只留在国别格子里。
