# 余华

> 第一个 Author Map 试点：从现有已读基础出发，确认缺口、补齐创作阶段，并理解作品之间的演变关系。通行小说与主要文集已入库；覆盖率只对作品库有效。

## 为什么值得系统阅读

余华把先锋实验、长篇现实叙事和晚近社会 / 历史写作连成一条可追踪的创作线。已经读过几部名作之后，值得继续看：早期暴力与形式实验如何转到《活着》的克制，再转到《第七天》《兄弟》《文城》。

## 创作生涯总览

1. **习作起步**（1983–1985）：《第一宿舍》等到文化馆前后的早期短篇。
2. **早期先锋 / 实验期**（约 1986–1990）：暴力、身体、荒诞、叙事陌生化。
3. **长篇转型 / 现实叙事**（1991–1995）：《在细雨中呼喊》《活着》《许三观卖血记》。
4. **世纪之交 / 当代社会**（2005–2013）：《兄弟》《第七天》。
5. **晚近历史 / 新尝试**（2021–）：《文城》《卢克明的偷偷一笑》。
6. **随笔 / 文学观**：与小说并行，文集重编很多，按入口读即可。
