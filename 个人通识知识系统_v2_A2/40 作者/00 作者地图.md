# 作者地图

> 作者层是世界文学的**实体访问层**，不是 T / R / M / G / N / Q 之外的第七轴。

它回答的是：**如果我喜欢一个作者，如何沿着他的全部创作继续阅读？**

## 入口

- [[01 作者作品索引|作者作品索引]]：直接读取 `30 作品/` 中现有作品，按 `author` 动态分组。
- [[02 作者实体库|作者实体库]]：只收录已经主动升级为作者实体的作家。
- [[03 作者追读工作台|作者追读工作台]]：管理“下一本 / 核心未读 / 延伸未读 / 已读 / 未读”。
- [[10 作者实体/00 作者实体说明|作者实体规则]]
- [[20 作者专题/00 作者专题说明|作者专题规则]]

## 四层模型

```text
作品 author 字段
    ↓
Implicit Author / 隐式作者
    ↓ 产生持续追读兴趣
Author Entity / 作者实体
    ↓ 制定追读优先级
Author Reading / 作者追读
    ↓ 需要系统阅读、研究创作演变
Author Map / 作者专题地图
```

### 1. 隐式作者

只要 `30 作品/` 中存在：

```yaml
author: 某作者
```

该作者就会自动出现在 [[01 作者作品索引]] 中。此阶段**不需要创建作者文件**。

### 2. 作者实体

当你明确想持续追读某位作者时，在 `40 作者/10 作者实体/` 建立作者实体。

作者实体主要维护：

- 标准姓名与别名
- 生卒年
- 地域 / 文学传统
- 主要创作时期
- 主要思潮 / 类型关联
- 当前追读状态
- 追读目标
- 是否已升级为作者专题

作者实体**不手工复制作品列表**；作品关系继续由 `30 作品/` 的 `author` 字段提供。

### 3. Author Reading v1

[[03 作者追读工作台]] 直接读取作品库，不建立第二份书单。

只有当你真的想安排某位作者的后续阅读时，才在对应作品上可选增加：

```yaml
author_reading_priority: 下一本 | 核心 | 延伸
```

含义：

- `下一本`：当前最希望接着读的作品；
- `核心`：理解该作者时优先补齐的核心作品；
- `延伸`：核心作品之后再读的补充作品；
- 字段缺失：仅收录，不代表需要追读。

不要为所有作品批量填写这个字段。

作者阅读覆盖率定义为：

```text
(已读 + 重读) / 当前作品库中该作者的全部收录作品
```

它是**派生指标**。v1 不把百分比写进作者实体，避免每次新增作品或完成阅读后留下过期缓存；以 Base 中按作者分组的实时作品集合为准。

### 4. 作者专题地图

只有当你希望系统阅读一个作者的创作世界时，才在 `40 作者/20 作者专题/` 建立专题目录。

推荐拆成：

```text
作者专题
├─ 创作阶段
├─ 作品谱系
├─ 核心主题 / 母题
├─ 风格与叙事机制
└─ 阅读路线
```

## 数据原则

1. **作品实体唯一位于 `30 作品/`。** 作者层不复制作品实体。
2. **`author` 是作品 → 作者关系的当前事实来源。**
3. **作者不是 taxonomy。** 不增加 A 轴，不改变六轴 frozen structure。
4. **作者实体按需建立。** 不因为数据库里出现一个作者就批量生成作者页。
5. **作者追读优先级按需标记。** `author_reading_priority` 是规划字段，不是文学分类字段。
6. **作者专题按兴趣升级。** 只有系统追读时才建立完整地图。
7. **`author` 使用中文标准名。** 英文名、简称、垃圾标签应归一到通行中文译名，避免同一作者被拆成两个分组。原文拼写保留在 `author_original`，不覆盖已有该字段。
8. **派生进度不重复存储。** 已收录、已读、未读和覆盖率从作品库实时读取。

## 使用方式

### 想找“这个作者我还有什么没读”

打开 [[01 作者作品索引]]，按作者分组查看已读 / 未读作品。

### 想决定下一本

打开 [[03 作者追读工作台]]，在目标作品上按需设置：

```yaml
author_reading_priority: 下一本
```

### 想建立核心追读清单

将真正重要的未读作品标记为：

```yaml
author_reading_priority: 核心
```

不要把作者全部作品都标成核心。

### 想开始追一个作者

从 [[99 Templates/作者/01 作者实体模板|作者实体模板]] 建立实体，并填写 `reading_goal`。

### 想系统读完一个作者

使用 [[99 Templates/作者/02 作者专题模板|作者专题模板]] 升级为作者专题。
