# 作者实体说明

作者实体是“我希望持续追读这个作者”的显式记录，不是作者百科数据库。

## 什么时候建立

满足任一条件即可：

- 已读一部作品后明确想继续读这个作者；
- 已读多部作品，希望集中查看阅读进度；
- 准备建立作者专题地图。

没有持续追读意图的作者，只保留在作品 `author` 字段和 [[../01 作者作品索引|作者作品索引]] 中即可。

## 必填字段

```yaml
id: WL-AUTHOR-...
type: author
name: 标准作者名
aliases: []
author_status: 关注 | 追读 | 暂停 | 完成
author_map_status: 未建立 | 已建立
```

## 可选字段

```yaml
birth_year:
death_year:
regions: []
movements: []
notes: ""
```

## 关系原则

作品列表不写进作者实体 frontmatter。作者拥有的作品由 `30 作品/` 中：

```yaml
author: 标准作者名
```

动态反向聚合。

如果未来需要处理笔名、多人合著或同名作者，再升级关系模型；v1 不提前复杂化。
